## 0.1 152.乘积最大子数组

给你一个整数数组 `nums` ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32-位** 整数。

**请注意**，一个只包含一个元素的数组的乘积是这个元素的值。

**示例 1:**

**输入:** nums = [2,3,-2,4]
**输出:** `6`
**解释:** 子数组 [2,3] 有最大乘积 6。

**示例 2:**

**输入:** nums = [-2,0,-1]
**输出:** 0
**解释:** 结果不能为 2, 因为 [-2,-1] 不是子数组。

**提示:**

- `1 <= nums.length <= 2 * 104`
- `-10 <= nums[i] <= 10`
- `nums` 的任何子数组的乘积都 **保证** 是一个 **32-位** 整数

## 0.2 Notes

### 0.2.1 核心思路
由于数组中含有负数，负负得正，**当前位置的最优解不一定来自前一个位置的最优解**：最小的乘积（负数）乘以下一个负数反而可能变成最大乘积。

因此需要**同时维护两个状态**：
- `maxF[i]`：以 `nums[i]` 结尾的子数组的**最大乘积**
- `minF[i]`：以 `nums[i]` 结尾的子数组的**最小乘积**

### 0.2.2 状态转移（三种选择）

以 `maxF[i]` 为例，决定以 `i` 结尾的最大乘积时，有三种选择：

| 选择 | 含义 | 适用场景 |
|------|------|----------|
| `maxF[i-1] * nums[i]` | 当前正数 × 前面最大乘积 | `nums[i]` 为正，延续此前的最大趋势 |
| `minF[i-1] * nums[i]` | 当前负数 × 前面最小乘积 | `nums[i]` 为负，最小乘积（负）翻转为正，可能反超 |
| `nums[i]` | 重新开始子数组 | 前面的乘积还不如当前数本身大（如遇 `0` 或乘积变小） |

```
maxF[i] = max( maxF[i-1] * nums[i], minF[i-1] * nums[i], nums[i] )
minF[i] = min( maxF[i-1] * nums[i], minF[i-1] * nums[i], nums[i] )
```

### 0.2.3 复杂度
- **时间**：O(n)，一次遍历
- **空间**：O(n)，可优化到 O(1)（只保留 `i-1` 的两个状态值）

### 0.2.4 注意
- 需要处理整数溢出（用 `long` 类型过渡），以及 `INT_MIN` 边界情况。
- 最终答案是 `max(maxF[0], ..., maxF[n-1])`，而非 `maxF[n-1]`。


## 0.3 Solution 
```cpp

class Solution {
public:
    int maxProduct(vector<int>& nums) {
        vector <long> maxF(nums.begin(),nums.end()), minF(nums.begin(), nums.end());
        for (int i = 1; i < nums.size(); ++i) {
            maxF[i] = max(maxF[i - 1] * nums[i], max((long)nums[i], minF[i - 1] * nums[i]));
            minF[i] = min(minF[i - 1] * nums[i], min((long)nums[i], maxF[i - 1] * nums[i]));
            if(minF[i]<INT_MIN) {
                minF[i]=nums[i];
            }
        }

        return *max_element(maxF.begin(), maxF.end());
    }
};
```
