## 0.1 2333.统计包含每个点的矩形数目

给你一个二维整数数组 `rectangles` ，其中 `rectangles[i] = [li, hi]` 表示第 `i` 个矩形长为 `li` 高为 `hi` 。给你一个二维整数数组 `points` ，其中 `points[j] = [xj, yj]` 是坐标为 `(xj, yj)` 的一个点。

第 `i` 个矩形的 **左下角** 在 `(0, 0)` 处，**右上角** 在 `(li, hi)` 。

请你返回一个整数数组 `count` ，长度为 `points.length`，其中 `count[j]`是 **包含** 第 `j` 个点的矩形数目。

如果 `0 <= xj <= li` 且 `0 <= yj <= hi` ，那么我们说第 `i` 个矩形包含第 `j` 个点。如果一个点刚好在矩形的 **边上** ，这个点也被视为被矩形包含。

**示例 1：**

![](images/2333_example1.png)

**输入：**rectangles = [[1,2],[2,3],[2,5]], points = [[2,1],[1,4]]
**输出：**[2,1]
**解释：**
第一个矩形不包含任何点。
第二个矩形只包含一个点 (2, 1) 。
第三个矩形包含点 (2, 1) 和 (1, 4) 。
包含点 (2, 1) 的矩形数目为 2 。
包含点 (1, 4) 的矩形数目为 1 。
所以，我们返回 [2, 1] 。

**示例 2：**

![](images/2333_example2.png)

**输入：**rectangles = [[1,1],[2,2],[3,3]], points = [[1,3],[1,1]]
**输出：**[1,3]
**解释：**
第一个矩形只包含点 (1, 1) 。
第二个矩形只包含点 (1, 1) 。
第三个矩形包含点 (1, 3) 和 (1, 1) 。
包含点 (1, 3) 的矩形数目为 1 。
包含点 (1, 1) 的矩形数目为 3 。
所以，我们返回 [1, 3] 。

**提示：**

- `1 <= rectangles.length, points.length <= 5 * 104`
- `rectangles[i].length == points[j].length == 2`
- `1 <= li, xj <= 109`
- `1 <= hi, yj <= 100`
- 所有 `rectangles` **互不相同** 。
- 所有 `points` **互不相同** 。

## 0.2 Notes

核心思路：==两个数组都排序 + 双指针实时构建树状数组==，其中 ==实时构建== 是本题最关键的一点。

- 问题转化：矩形左下角在原点，点 `(x, y)` 被包含 ⇔ `x <= l` 且 `y <= h`。即要数出同时满足「长 ≥ x」且「高 ≥ y」的矩形个数，是二维偏序问题。
- ==两个数组都排序==：`rectangles` 按 `l` 降序、`points` 按 `x` 降序（记得给点带上原下标）。排序后把二维条件拆成一维扫描：
  - 按 x 从大到小处理点，满足 `l >= x` 的矩形集合只会单调扩大，处理过的矩形永远不会被踢出去。
- ==实时构建树状数组==（最重要）：不为每个点重新建树，而是用双指针 `j` 维护「长已经满足条件」的矩形集合：
  - 处理当前点时，把 `l >= x` 的新矩形的高度逐个 `add(h, 1)` 插入树状数组；
  - 由于 x 单调递减，`j` 只增不减，每个矩形恰好入树一次，总建树成本 `O(n log H)`，而不是每个点都重建的 `O(m * n log H)`。
  - 这就是 ==实时（在线）构建== 与「离线排序 + 增量更新」结合的精髓：先离线排序定好访问顺序，再在线增量维护数据结构。
- 查询：树状数组里存的是每个高度的矩形个数，统计 `h >= y` 的矩形数 = 后缀和 `query(max_h) - query(y - 1)`（用两个前缀和相减）。
- 剪枝与细节：
  - `h` 值域只有 `100`（远小于 `l` 的 `10^9`），树状数组直接开 `max_h + 1` 大小，==无需离散化==；
  - `y > max_h` 的点不可能被任何矩形包含，答案必为 0，提前 `continue` 跳过。
- 复杂度：排序 `O(n log n + m log m)`，建树 + 查询 `O((n + m) log 100)`。

## 0.3 Solution 
```python
class Solution:
    def countRectangles(self, rectangles: List[List[int]], points: List[List[int]]) -> List[int]:

        '''树状数组模板'''
        def lowbit(x):      # lowbit函数
            return x & (-x)

        def add(i, delta):  # 坐标i处依次添加delta
            while i<len(tree):
                tree[i] += delta
                i += lowbit(i)
        
        def query(i):       # presum函数
            presum = 0
            while i > 0:
                presum += tree[i]
                i -= lowbit(i)
            return presum
        
        '''主程序'''
        rectangles.sort(reverse = True)     # 按照横、纵坐标倒序排列
        points = [(x, y, i) for i, (x, y) in enumerate(points)]
        points.sort(reverse = True)
        
        # 【固定x，检索y】
        max_recy = 0                # 树状数组中元素的最大值
        for rec in rectangles:
            max_recy = max(max_recy, rec[1])

        tree = [0] * (max_recy+1)   # 树状数组的大小
        
        res = [0] * len(points)
        j = 0
        for (x, y, i) in points:
            if y > max_recy:    # point_y > rec_y的最大值，没有矩形能够包含
                continue
            # rec_x >= point_x的矩形，其rec_y放入树状数组中
            while j < len(rectangles) and x <= rectangles[j][0]:   
                add(rectangles[j][1], 1)    # 更新树状数组
                j += 1
            
            res[i] = query(max_recy) - query(y-1)   # 区间和
        
        return res
```
