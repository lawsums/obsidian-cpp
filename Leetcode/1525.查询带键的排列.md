## 0.1 1525.查询带键的排列

给定一个正整数数组 `queries` ，其取值范围在 `1` 到 `m` 之间。 请你根据以下规则按顺序处理所有 `queries[i]`（从 `i=0` 到 `i=queries.length-1`）：

- 首先，你有一个排列 `P=[1,2,3,...,m]`。
- 对于当前的 `i` ，找到 `queries[i]` 在排列 `P` 中的位置（**从 0 开始索引**），然后将它移到排列 `P` 的开头（即下标为 0 处）。注意， `queries[i]` 的查询结果是 `queries[i]` 在 `P` 中移动前的位置。

返回一个数组，包含从给定  `queries` 中查询到的结果。

**示例 1：**

**输入：**queries = [3,1,2,1], m = 5
**输出：**[2,1,2,1] 
**解释：处理** queries 的过程如下：
对于 i=0: queries[i]=3, P=[1,2,3,4,5], 3 在 P 中的位置是 **2**，然后我们把 3 移动到 P 的开头，得到 P=[3,1,2,4,5] 。
对于 i=1: queries[i]=1, P=[3,1,2,4,5], 1 在 P 中的位置是 **1**，然后我们把 1 移动到 P 的开头，得到 P=[1,3,2,4,5] 。 
对于 i=2: queries[i]=2, P=[1,3,2,4,5], 2 在 P 中的位置是 **2**，然后我们把 2 移动到 P 的开头，得到 P=[2,1,3,4,5] 。
对于 i=3: queries[i]=1, P=[2,1,3,4,5], 1 在 P 中的位置是 **1**，然后我们把 1 移动到 P 的开头，得到 P=[1,2,3,4,5] 。 
因此，包含结果的数组为 [2,1,2,1] 。  

**示例 2：**

**输入：**queries = [4,1,2,2], m = 4
**输出：**[3,1,2,0]

**示例 3：**

**输入：**queries = [7,5,5,8,3], m = 8
**输出：**[6,5,0,7,5]

**提示：**

- `1 <= m <= 10^3`
- `1 <= queries.length <= m`
- `1 <= queries[i] <= m`

## 0.2 Notes

### 0.2.1 题目本质
维护一个初始为 `P=[1..m]` 的排列，每次查询一个数字并把它**移到最前**，返回它移动前的下标。难点在于"移到最前"会让其左侧元素整体右移，朴素数组模拟单次是 O(m)。

### 0.2.2 核心思路：用"扩展空间"代替物理移位
关键观察：**与其真的移动元素，不如在 BIT 里给"最前面"预留 n 个空位**（n = queries 长度），让每次被移到最前的元素从右往左依次占据这些空位。

1. 开辟大小为 `n + m` 的树状数组。下标 `1..n` 为预留空位，`n+1..n+m` 放初始排列 `1..m`。
2. 初始化：数字 `i` 放在位置 `n + i`，执行 `update(n + i, 1)` 打上"占用"标记。
3. 处理第 `i` 个查询 `x`：
   - 答案 = 位置 `cur = pos[x]` 之前的 1 的个数（前缀和）。
   - 删除旧位置：`update(cur, -1)`。
   - 移到最前：新位置 `new_pos = n - i`，`update(new_pos, 1)`，并更新 `pos[x] = new_pos`。

### 0.2.3 为什么这样是对的
- **不冲突**：`new_pos = n - i` 随 `i` 严格递减（`n, n-1, ..., 1`），每次占据的预留空位互不重复。
- **空位一定为空**：放置第 `i` 个元素时，`new_pos` 左侧的 `1..new_pos-1` 全是 0 —— 预留区里更靠左的位置还没被用过，所以新元素放进去不会干扰前缀和。
- **相对顺序没变**：初始 m 个元素一直待在 `n+1..n+m`，彼此相对顺序不变；答案只关心"某数字前面有几个元素"，前缀和恰好给出这个值。

> 一句话总结：**把"移动"翻译成 BIT 上的"删一个 1、加一个 1"，用越界的空位吸收所有位移。**

### 0.2.4 复杂度
- 时间：O((n+m) log(n+m))，每个查询 2~3 次 BIT 操作。
- 空间：O(n+m)。

### 0.2.5 一题多解
- 直接模拟：O(m·n)，本题 m,n ≤ 10^3 可过。
- Sqrt Decomposition：分块维护，块大小 ≈ √m，移动时块内打标记。

### 0.2.6 思考题（"扩展空间 / 预留空位" 类的树状数组题）

这种"**用 BIT 维护虚拟位置/空位，把物理移动变成计数**"的思路，在以下题目中反复出现，建议按顺序思考：

1. **LeetCode 406. 根据身高重建队列**（Medium）· [链接](https://leetcode.com/problems/queue-reconstruction-by-height/)
   - 关联点：**预留空位**。按身高从高到低、k 从小到大排序后，依次把每个人"插"进当前剩余空位中下标恰为 k 的位置。
   - 做法：BIT 存空位（1=空），用**二分 + 前缀和**找"第 k+1 个空位"，放入后 `update(pos, -1)`。
   - 与本题异同：本题空位在数组最左、从右往左填；406 的空位散落在整个结果数组、按"第几个空位"定位。本质都是"用 BIT 数空位"。

2. **LeetCode 1505. K 次相邻交换后的最小整数**（Hard）· [链接](https://leetcode.com/problems/minimum-possible-integer-after-at-most-k-adjacent-swaps-on-digits/)
   - 关联点：元素被"拿走"后，剩余元素下标整体前移；用 BIT 维护"还活着的位"，即可 O(log n) 算出任意数字当前的**真实下标**，避免真的去交换。
   - 做法：从左到右贪心，BIT 记 1=存活；查询"当前位之前有几个存活位"得到下标，选好目标数字后把它标记删除。
   - 与本题异同：本题是"预留新位置"，1505 是"回收被删位置"，一加一减，互为正逆。

3. **POJ 2828 Buy Tickets（买票插队）**（经典）· [链接](http://poj.org/problem?id=2828)
   - 关联点：**逆序处理 + BIT 找第 k 个空位**。每个人报 pos_i 表示"站到当前队伍第 pos_i 个人后面"。
   - 做法：从最后一个人往前处理，BIT 存空位（1=空），二分找"第 pos_i+1 个空位"放入后置 0。逆序处理让每个位置"一次定终身"。
   - 与本题异同：本题从前往后、空位固定在左侧递减；2828 从后往前、空位随放置动态变化。可对照理解"空位计数"的两种方向。

4. （对照）**LeetCode 315. 计算右侧小于当前元素的个数**（Hard）→ 已有笔记 [[Leetcode/315.计算右侧小于当前元素的个数]]
   - 关联点：这是**坐标压缩（离散化）** —— 把稀疏值域压到稠密下标再套 BIT，与"扩展空间"相反（一个是压缩到够用，一个是扩展出空位）。
   - 目的：对比着看，理解 BIT 对"下标空间"的两种灵活处理。

> 使用方法：先不看题解，想清楚"移动 / 删除 / 插入"如何用 BIT 里的 1 和前缀和表达，再动手实现。

## 0.3 Solution 
```python
class BIT:
    # ... 树状数组的标准实现 ...
    # query(x): 返回 [1, x] 区间内所有值的和
    # update(x, dt): 将位置 x 的值增加 dt

class Solution:
    def processQueries(self, queries: List[int], m: int) -> List[int]:
        n = len(queries)
        # 1. 初始化树状数组，大小为 n+m
        bit = BIT(m + n)
        
        # pos[i] 记录数字 i 在当前虚拟数组中的逻辑位置
        pos = [0] * (m + 1)
        
        # 2. 初始化：将数字 1 到 m 放置在虚拟数组的末尾 (n+1 到 n+m)
        for i in range(1, m + 1):
            pos[i] = n + i       # 记录数字 i 的位置
            bit.update(n + i, 1) # 在树状数组中标记该位置为 1 (有数字)
        
        ans = list()
        
        # 3. 开始处理每个查询
        for i, query in enumerate(queries):
            # --- 查询阶段 ---
            cur = pos[query]          # 获取当前查询数字的逻辑位置
            bit.update(cur, -1)       # 在树状数组中，将该位置的值减1，表示“移除”这个数字
            ans.append(bit.query(cur)) # 查询 cur 位置之前有多少个数字（即前缀和），这就是答案
            
            # --- 移动阶段 ---
            # 计算新的逻辑位置。i 从 0 开始，所以新位置是 n, n-1, n-2...
            new_pos = n - i
            pos[query] = new_pos      # 更新该数字的逻辑位置
            bit.update(new_pos, 1)    # 在树状数组中，将新位置的值加1，表示“放置”这个数字
            
        return ans
```
