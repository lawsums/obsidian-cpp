## 0.1 1511.统计作战单位数

 `n` 名士兵站成一排。每个士兵都有一个 **独一无二** 的评分 `rating` 。

从中选出 **3** 个士兵组成一个作战单位，规则如下：

- 从队伍中选出下标分别为 `i`、`j`、`k` 的 3 名士兵，他们的评分分别为 `rating[i]`、`rating[j]`、`rating[k]`
- 作战单位需满足： `rating[i] < rating[j] < rating[k]` 或者 `rating[i] > rating[j] > rating[k]` ，其中  `0 <= i < j < k < n`

请你返回按上述条件组建的作战单位的方案数。

**示例 1：**

**输入：**rating = [2,5,3,4,1]
**输出：**3
**解释：**我们可以组建三个作战单位 (2,3,4)、(5,4,1)、(5,3,1) 。

**示例 2：**

**输入：**rating = [2,1,3]
**输出：**0
**解释：**根据题目条件，我们无法组建作战单位。

**示例 3：**

**输入：**rating = [1,2,3,4]
**输出：**4

**提示：**

- `n == rating.length`
- `3 <= n <= 1000`
- `1 <= rating[i] <= 10^5`
- `rating` 中的元素都是唯一的

## 0.2 Notes

### 0.2.1 一题多解：解法总览

本题是 ==树状数组（Fenwick Tree）计数模板题==，核心是「枚举中间点 j + 乘法原理」。常见做法按效率排序：

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| 暴力三重循环 | O(n³) | O(1) | ==效率最差==，枚举所有 `(i,j,k)` 检查是否单调 |
| 动态规划（线性扫描计数） | O(n²) | O(1) | 枚举中间点 j，左右两侧各线性扫一遍统计大小 |
| 线段树 + 离散化 | O(n log n) | O(n) | ==效率最高== |
| ==值域树状数组（本笔记做法）== | O(n log V) | O(V) | ==效率次高==，V = max(rating) ≤ 1e5，免离散化 |
| 树状数组 + 离散化 | O(n log n) | O(n) | 教科书 ==最优解法==（时间空间均衡，推荐背板） |

> 除暴力、DP 外的「最优解法」是 **离散化 + 树状数组**；本笔记主解法是它的简化版 —— 因为 `rating[i] ≤ 1e5` 值域不大，直接省掉离散化这一步。

### 0.2.2 核心思路：前缀树状数组 + 后缀树状数组

枚举每个元素作为三元组的 ==中间点 j==，那么 `i` 一定在左侧、`k` 一定在右侧。只要知道「左侧比 `rating[j]` 小/大的个数」和「右侧比 `rating[j]` 大/小的个数」，就能用乘法原理直接累加答案。

两棵树状数组维护的都是 ==计数数组（权值数组）==：下标代表 `rating` 的值，数组值代表该值出现过多少次。

- **后缀树状数组 `right_tree`**：==初始包含所有元素==（每个 `rating` 值在值域下标处 +1）。遍历时边走边对当前元素做 ==减量更新== `update(r, -1)`，把它从「右侧集合」移除，保证它只作为中间点、不混进右侧计数。
- **前缀树状数组 `left_tree`**：==初始为空==。遍历时把处理完的元素做 ==增量更新== `update(r, 1)` 加入「左侧集合」，供后续元素作为左侧计数。

对每个中间点 `r`，四个关键量都是 O(log V) 查询：

```
left_less     = left_tree.pre(r - 1)          # 左侧比 r 小的个数
left_greater  = left_tree.query(r + 1, max)   # 左侧比 r 大的个数
right_less    = right_tree.pre(r - 1)         # 右侧比 r 小的个数
right_greater = right_tree.query(r + 1, max)  # 右侧比 r 大的个数

ans += left_less    * right_greater   # 递增三元组 rating[i] < rating[j] < rating[k]
ans += left_greater * right_less      # 递减三元组 rating[i] > rating[j] > rating[k]
```

> 正确性：位置关系 `i<j<k` 固定，所以「左小 × 右大」恰好覆盖所有递增三元组，「左大 × 右小」恰好覆盖所有递减三元组，不重不漏。

### 0.2.3 为什么可以不做离散化

- 本题约束 `rating[i] <= 10^5`，值域不大，==直接以 rating 的值作为树状数组下标==，开一个大小为 `max_rating` 的数组即可。
- 若值域很大（如 `10^9`）或出现负数，就必须 ==离散化==：把每个值排序后映射为 `1..m` 的秩，再套同一个模板。树状数组本身不变，变的只是「值 → 下标」的映射 —— 这就是「离散化 + 树状数组」做法的由来。
- 本题 `rating` 元素唯一，计数数组每个位置至多为 1；若允许重复，做法同样成立（计数会累加），「严格小于/大于」仍写 `pre(r-1)` 与 `query(r+1, max)`。

### 0.2.4 复杂度

- 时间：O(n log V)，V = max(rating) ≤ 10^5，n 次枚举 × 每次 O(log V)
- 空间：O(V)，两棵值域大小的树状数组
- 若改用离散化：时间 O(n log n)、空间 O(n)，当 n ≪ V 时更优

## 0.3 Solution 

**解法一：值域树状数组（不离散化）—— 本笔记做法**

```python
# 模板来源 https://leetcode.cn/circle/discuss/mOr1u6/
class FenwickTree:
    def __init__(self, n: int):
        self.tree = [0] * (n + 1)  # 使用下标 1 到 n

    # a[i] 增加 val
    # 1 <= i <= n
    # 时间复杂度 O(log n)
    def update(self, i: int, val: int) -> None:
        t = self.tree
        while i < len(t):
            t[i] += val
            i += i & -i

    # 计算前缀和 a[1] + ... + a[i]
    # 1 <= i <= n
    # 时间复杂度 O(log n)
    def pre(self, i: int) -> int:
        t = self.tree
        res = 0
        while i > 0:
            res += t[i]
            i &= i - 1
        return res

    # 计算区间和 a[l] + ... + a[r]
    # 1 <= l <= r <= n
    # 时间复杂度 O(log n)
    def query(self, l: int, r: int) -> int:
        if r < l:
            return 0
        return self.pre(r) - self.pre(l - 1)
        
class Solution:
    def numTeams(self, rating: List[int]) -> int:
        n = len(rating)
        # 由于 rating 中的元素唯一，最大值即为值域上界
        max_rating = max(rating)
        
        # 初始化两个树状数组，分别维护左边和右边的元素
        left_tree = FenwickTree(max_rating)
        right_tree = FenwickTree(max_rating)
        
        # 1. 先将所有元素加入 right_tree，表示当前所有元素都在右边
        for r in rating:
            right_tree.update(r, 1)
            
        ans = 0
        # 2. 枚举每个元素作为中间点 j
        for r in rating:
            # 当前元素从右边移除，表示它作为中间点，不应该算在左右两侧
            right_tree.update(r, -1)
            
            # 查询左侧比 r 小和比 r 大的数量
            left_less = left_tree.pre(r - 1)
            left_greater = left_tree.query(r + 1, max_rating)
            
            # 查询右侧比 r 小和比 r 大的数量
            right_less = right_tree.pre(r - 1)
            right_greater = right_tree.query(r + 1, max_rating)
            
            # 计算以当前 r 为中间点的作战单位数
            ans += left_less * right_greater  # 递增: i < j < k
            ans += left_greater * right_less  # 递减: i > j > k
            
            # 当前元素变为已遍历，加入左侧，供后续元素作为“左边”使用
            left_tree.update(r, 1)
            
        return ans
        
```


**解法二：离散化 + 树状数组 —— 教科书最优解法**

```python
class Solution:
    def numTeams(self, rating: List[int]) -> int:
        # 离散化：把 rating 的值压缩为 1..m 的秩（m <= n），树状数组大小 = m
        vals = sorted(set(rating))
        rank = {v: i + 1 for i, v in enumerate(vals)}
        a = [rank[v] for v in rating]
        m = len(vals)

        left_tree = FenwickTree(m)
        right_tree = FenwickTree(m)
        for v in a:
            right_tree.update(v, 1)

        ans = 0
        for v in a:
            right_tree.update(v, -1)              # 作为中间点，从右侧移除
            left_less     = left_tree.pre(v - 1)
            left_greater  = left_tree.query(v + 1, m)
            right_less    = right_tree.pre(v - 1)
            right_greater = right_tree.query(v + 1, m)
            ans += left_less    * right_greater   # 递增
            ans += left_greater * right_less      # 递减
            left_tree.update(v, 1)                # 加入左侧
        return ans
```
