## 0.1 1517.恢复数组

某个程序本来应该输出一个整数数组。但是这个程序忘记输出空格了以致输出了一个数字字符串，我们所知道的信息只有：数组中所有整数都在 `[1, k]` 之间，且数组中的数字都没有前导 0 。

给你字符串 `s` 和整数 `k` 。可能会有多种不同的数组恢复结果。

按照上述程序，请你返回所有可能输出字符串 `s` 的数组方案数。

由于数组方案数可能会很大，请你返回它对 `10^9 + 7` **取余** 后的结果。

**示例 1：**

**输入：**s = "1000", k = 10000
**输出：**1
**解释：**唯一一种可能的数组方案是 [1000]

**示例 2：**

**输入：**s = "1000", k = 10
**输出：**0
**解释：**不存在任何数组方案满足所有整数都 >= 1 且 <= 10 同时输出结果为 s 。

**示例 3：**

**输入：**s = "1317", k = 2000
**输出：**8
**解释：**可行的数组方案为 [1317]，[131,7]，[13,17]，[1,317]，[13,1,7]，[1,31,7]，[1,3,17]，[1,3,1,7]

**示例 4：**

**输入：**s = "2020", k = 30
**输出：**1
**解释：**唯一可能的数组方案是 [20,20] 。 [2020] 不是可行的数组方案，原因是 2020 > 30 。 [2,020] 也不是可行的数组方案，因为 020 含有前导 0 。

**示例 5：**

**输入：**s = "1234567890", k = 90
**输出：**34

**提示：**

- `1 <= s.length <= 10^5`.
- `s` 只包含数字且不包含前导 0 。
- `1 <= k <= 10^9`.

## 0.2 Notes

### 0.2.1 核心思路：向前分割

将字符串 `s` 从前往后分割成若干个合法的数字（每个数字 $\in [1, k]$，无前导零），求方案数。

**定义状态**：`f[i]` 表示前缀 `s[0..i-1]` 的分割方案数（即前 `i` 个字符的方案数）。最终答案为 `f[n]`。

**转移**：枚举最后一段数字 `s[j..i-1]`（即从位置 `j` 开始到 `i-1` 结束的子串），如果该子串合法，则：

$$f[i] = \sum_{j} f[j], \quad \text{其中 } s[j..i-1] \text{ 合法}$$

> 通俗理解：走到位置 `i` 时，往前（向左）找所有可能的「最后一段」，把之前 `f[j]` 的方案数累加起来。

### 0.2.2 合法性判定

对于子串 `s[j..i-1]`，必须同时满足：

1. **无前导零**：`s[j] != '0'`（单 `'0'` 也不行，因为数字必须在 $[1,k]$）
2. **数值范围**：$1 \le \text{int}(s[j..i-1]) \le k$
3. **长度剪枝**：如果子串长度 > $k$ 的位数，则数值必然 > $k$，可直接 stop（因为再往左扩只会更长，数值更大）

### 0.2.3 复杂度

- 时间复杂度：$O(n \cdot \log_{10} k)$，因为内层循环最多往前枚举 $k$ 的位数次（约 10 次）
- 空间复杂度：$O(n)$

## 0.3 Solution

### 0.3.1 解法一：递推 DP（自底向上）

```python
class Solution:
    def numberOfArrays(self, s: str, k: int) -> int:
        n, m = len(s), len(str(k))
        mod = 10 ** 9 + 7
        f = [1] * (n + 1)          # f[0] = 1，其余暂设为 1（后续会被重设）
        for i in range(n):          # i：当前考虑的右端点索引
            f[i + 1] = 0            # 先清零，准备计算 s[0..i] 的方案数
            for j in range(i, -1, -1):  # j：从 i 向左枚举最后一段的起点
                t = s[j:i + 1]
                if int(t) > k or i - j + 1 > m:
                    break            # 长度超限/数值超限，再往左只会更大
                if 1 <= int(t) <= k and s[j] != '0':
                    f[i + 1] = (f[i + 1] + f[j]) % mod
        return f[n]
```

**状态解释**：
- `f[i]`：前缀 `s[0..i-1]` 的分割方案数
- 遍历 `i` 从 0 到 `n-1`，内层 `j` 从 `i` 向左扫描，枚举最后一段数字 `s[j..i]`

### 0.3.2 解法二：记忆化 DFS（自顶向下）

```python
class Solution:
    def numberOfArrays(self, s: str, k: int) -> int:
        n = len(s)
        mod = 10 ** 9 + 7

        @cache
        def dfs(i: int) -> int:
            if i == -1:              # 空串，一种方案
                return 1

            res = 0
            for j in range(i, -1, -1):  # j：最后一段的起点
                if int(s[j:i + 1]) > k or i - j + 1 > len(str(k)):
                    break
                if 1 <= int(s[j:i + 1]) <= k and s[j] != '0':
                    res = (res + dfs(j - 1)) % mod

            return res

        return dfs(n - 1)            # 从整个串的末尾开始递归
```

**状态解释**：
- `dfs(i)`：前缀 `s[0..i]` 的分割方案数
- 从 `i = n-1`（整个串）递归向下，枚举最后一段数字 `s[j..i]`，合法则累加 `dfs(j-1)`
