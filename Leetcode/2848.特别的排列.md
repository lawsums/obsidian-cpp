## 0.1 2848.特别的排列

给你一个下标从 **0** 开始的整数数组 `nums` ，它包含 `n` 个 **互不相同** 的正整数。如果 `nums` 的一个排列满足以下条件，我们称它是一个特别的排列：

- 对于 `0 <= i < n - 1` 的下标 `i` ，要么 `nums[i] % nums[i+1] == 0` ，要么 `nums[i+1] % nums[i] == 0` 。

请你返回特别排列的总数目，由于答案可能很大，请将它对 `109 + 7` **取余** 后返回。

**示例 1：**

**输入：**nums = [2,3,6]
**输出：**2
**解释：**[3,6,2] 和 [2,6,3] 是 nums 两个特别的排列。

**示例 2：**

**输入：**nums = [1,4,3]
**输出：**2
**解释：**[3,1,4] 和 [4,1,3] 是 nums 两个特别的排列。

**提示：**

- `2 <= nums.length <= 14`
- `1 <= nums[i] <= 109`

## 0.2 Notes

### 0.2.1 核心思路：状压 DP

这道题用**状压 DP**解决，关键观察有两个：

- **不关心顺序**：已经选过的数，我们只关心"选了一个集合中的哪些数"（用 `mask`/`S` 表示），而不关心它们内部的具体先后顺序；
- **只关心上一个数**：题目要求相邻的两个数必须满足整除关系（`nums[i] % nums[i+1] == 0` 或 `nums[i+1] % nums[i] == 0`），所以当前能选哪个数，只取决于**上一个选的数是几**。

因此，在纯 `mask` 之上**多加一维 `i`**（上一个选的数的下标），就能完整刻画状态。

### 0.2.2 状态定义

- `s`：位掩码，第 `j` 位为 `1` 表示 `nums[j]` **还没被选**（代码里 `s` 是"剩余可选集合"）；
- `i`：上一个选的数的下标；
- `dfs(s, i)`：当前剩余集合为 `s`、上一个选的数是 `nums[i]` 时，能构造出的特别排列总数。

> 注意代码里 `s` 表示的是"还没选的数"，和常见的"已选集合"掩码含义相反，初始时 `s = (1 << n) - 1`（全部未选）。

### 0.2.3 状态转移

```python
pre = nums[i]
for j, x in enumerate(nums):
    if s >> j & 1 and (pre % x == 0 or x % pre == 0):
        res += dfs(s ^ (1 << j), j)
```

- 枚举还没选的 `j`，若 `nums[j]` 与上一个数 `pre` 满足整除关系（双向），就把它选上，进入下一状态；
- **边界**：`s == 0` 说明所有数都选完了，构成一条完整排列，返回 `1`；
- **初始**：枚举第一个选的数 `i`，累加 `dfs(u ^ (1 << i), i)`，对 `1e9+7` 取模。

### 0.2.4 为什么不用管顺序

一个特别排列，只要知道两件事：

1. 已经选了哪些数（`s` 的补集）；
2. 最后一个数是谁（`i`）。

后续能放什么数就完全确定了——只能放与当前最后一个数满足整除关系的未选数。**至于前面具体怎么排列，对后续没有任何影响**，所以相同 `(s, i)` 的子问题只需要算一次，DP 不会重复计算。

### 0.2.5 复杂度分析

- 状态数：`O(2^n × n)`（`2^n` 种掩码 × `n` 种"上一个数"的下标）；
- 每个状态需要枚举一个长度为 `n` 的"下一个数"；
- **时间：`O(2^n × n^2)`**。`n = 14` 时，`2^14 × 14^2 ≈ 3.2 × 10^6`（约 321 万），轻松通过；
- **空间：`O(2^n × n)`**（记忆化缓存的大小）。

对比朴素**全排列**枚举 `O(n!)`：`n = 14` 时 `14! ≈ 8.7 × 10^10`（约 870 亿），完全不可行。状压 DP 把指数从 `n!` 降到 `2^n`，是质的飞跃。

### 0.2.6 易错点

1. `s` 是"剩余未选集合"而非"已选集合"，判断能否选 `j` 用 `s >> j & 1`。
2. 整除关系是**双向**的：`pre % x == 0 or x % pre == 0`，漏掉一边会出错。
3. 最终答案要对 `1_000_000_007` 取模。

## 0.3 Solution 
```python
class Solution:
    def specialPerm(self, nums: List[int]) -> int:
        @cache
        def dfs(s: int, i: int) -> int:
            if s == 0:
                return 1  # 找到一个特别排列
            res = 0
            pre = nums[i]
            for j, x in enumerate(nums):
                if s >> j & 1 and (pre % x == 0 or x % pre == 0):
                    res += dfs(s ^ (1 << j), j)
            return res

        n = len(nums)
        u = (1 << n) - 1
        return sum(dfs(u ^ (1 << i), i) for i in range(n)) % 1_000_000_007
```
