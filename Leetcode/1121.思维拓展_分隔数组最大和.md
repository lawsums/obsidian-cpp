# 1 思维拓展题：分隔数组问题变体

基于 [[1121.分隔数组以得到最大和.md]] 的 DP 思想，以下是几个值得思考的变体问题。

---

## 1.1 变体一：子数组数量恰好为 k

> **题目**：将数组分割为**恰好 k 个**连续子数组，子数组长度任意（≥1），每个子数组的所有元素变为该子数组的最大值。求最大和。

**与原题区别**：原题限制了每段长度 ≤ k；本题限制的是**子数组的数量**。

### 1.1.1 DP 解法

**状态定义**：`dp[i][p]` = 将前 i 个元素划分为恰好 p 个子数组的最大和。

**状态转移**：枚举最后一段长度 j。

$$dp[i][p] = \max_{1 \leq j \leq i} \big( dp[i-j][p-1] + \max(arr[i-j \dots i-1]) \times j \big)$$

**代码：**

```python
def maxSumAfterPartitioning_kSubarrays(arr: List[int], k: int) -> int:
    n = len(arr)
    # dp[i][p] 初始化为 -inf
    dp = [[float('-inf')] * (k + 1) for _ in range(n + 1)]
    dp[0][0] = 0
    
    for i in range(1, n + 1):
        for p in range(1, min(i, k) + 1):
            max_val = 0
            for j in range(1, i + 1):
                max_val = max(max_val, arr[i - j])
                if dp[i - j][p - 1] != float('-inf'):
                    dp[i][p] = max(dp[i][p], dp[i - j][p - 1] + max_val * j)
    
    return dp[n][k]
```

- ⏱ 时间复杂度：$O(n^2 k)$
- 📦 空间复杂度：$O(nk)$，可滚动优化到 $O(n)$

## 1.2 变体四：每段代价 = (最大值 - 最小值) × 长度

> **题目**：将数组分割，每段长度 ≤ k，每段的"价值"定义为 `(max - min) × 长度`。求最大总价值。

**关键难点**：枚举最后一段时，需要同时维护该段的**最大值和最小值**。

### 1.2.1 DP 解法

$$dp[i] = \max_{1 \leq j \leq \min(i,k)} \big( dp[i-j] + (maxVal - minVal) \times j \big)$$

```python
def maxSumAfterPartitioning_range(arr: List[int], k: int) -> int:
    n = len(arr)
    dp = [float('-inf')] * (n + 1)
    dp[0] = 0
    
    for i in range(1, n + 1):
        cur_max = 0
        cur_min = float('inf')
        for j in range(1, min(i, k) + 1):
            cur_max = max(cur_max, arr[i - j])
            cur_min = min(cur_min, arr[i - j])
            dp[i] = max(dp[i], dp[i - j] + (cur_max - cur_min) * j)
    
    return dp[n]
```

- ⏱ 时间复杂度：$O(nk)$
- 📦 空间复杂度：$O(n)$

## 1.3 变体五：子数组长度恰好为 k（无选择）

> **题目**：每段长度**必须恰好为 k**。数组长度 n 必须是 k 的倍数，否则无法分割。每个子数组元素变为该段最大值，求最大和。

**这是最简单的退化情形**——没有"选择"的自由度。

### 1.3.1 DP 解法

$$dp[i] = dp[i-k] + \max(arr[i-k \dots i-1]) \times k \quad (i = k, 2k, 3k, \dots)$$

```python
def maxSumAfterPartitioning_fixedK(arr: List[int], k: int) -> int:
    n = len(arr)
    assert n % k == 0, "数组长度必须是 k 的倍数"
    
    dp = [0] * (n + 1)
    for i in range(k, n + 1, k):
        max_val = max(arr[i - k:i])
        dp[i] = dp[i - k] + max_val * k
    return dp[n]
```

- ⏱ 时间复杂度：$O(n)$
- 📦 空间复杂度：$O(n)$

## 1.4 总结对比

| 变体      | 限制条件     | DP 维度 | 复杂度       | 核心变化                 |
| ------- | -------- | ----- | --------- | -------------------- |
| **原题**  | 每段长度 ≤ k | 1D    | $O(nk)$   | 枚举 j ∈ [1, min(i,k)] |
| **变体一** | 恰好 k 段   | 2D    | $O(n^2k)$ | 增加段数维度 p             |
| **变体二** | 每段长度 ≥ k | 1D    | $O(n^2)$  | 枚举 j ∈ [k, i]        |
| **变体三** | 求最小值     | 1D    | $O(nk)$   | max → min            |
| **变体四** | 代价含 min  | 1D    | $O(nk)$   | 同时维护 max 和 min       |
| **变体五** | 每段恰好 = k | 1D    | $O(n)$    | 退化为固定步长              |

### 1.4.1 核心 DP 思想提炼

这类问题的共同模式：

1. **线性扫描**：从左到右处理，`dp[i]` 表示前缀 `[0, i)` 的最优解。
2. **枚举最后一段**：向前扫描可能的最后一段长度，**滚动维护**该段的统计量（max/min）。
3. **组合子问题**：`dp[i-j]`（独立子问题）+ 最后一段的贡献。

> 💡 **关键技巧**：正向扫描 `i` + 反向扫描 `j`，可以在 $O(1)$ 摊销时间维护区间最大值，避免 $O(n^3)$ 的暴力。
