## 0.1 1240.石子游戏 II

Alice 和 Bob 继续他们的石子游戏。许多堆石子 **排成一行**，每堆都有正整数颗石子 `piles[i]`。游戏以谁手中的石子最多来决出胜负。

Alice 和 Bob 轮流进行，Alice 先开始。最初，`M = 1`。

在每个玩家的回合中，该玩家可以拿走剩下的 **前** `X` 堆的所有石子，其中 `1 <= X <= 2M`。然后，令 `M = max(M, X)`。

游戏一直持续到所有石子都被拿走。

假设 Alice 和 Bob 都发挥出最佳水平，返回 Alice 可以得到的最大数量的石头。

**示例 1：**

**输入：**piles = [2,7,9,4,4]
**输出：**10
**解释：**如果一开始 Alice 取了一堆，Bob 取了两堆，然后 Alice 再取两堆。Alice 可以得到 2 + 4 + 4 = 10 堆。
如果 Alice 一开始拿走了两堆，那么 Bob 可以拿走剩下的三堆。在这种情况下，Alice 得到 2 + 7 = 9 堆。返回 10，因为它更大。

**示例 2:**

**输入：**piles = [1,2,3,4,5,100]
**输出：**104

**提示：**

- `1 <= piles.length <= 100`
- `1 <= piles[i] <= 104`

## 0.2 Notes
这题的思路是不是设一个二维 dp？其实一维度是表示从哪个坐标开始，第二维度表示当前的 m 是多少。然后我们当做就是这位置最多能拿多少石头，然后它的 dp 就相当于是向后转移。我们向后转移之后因为是交给另外一个人，所以我们要取得最多的石头的话，就是拿当前比如说拿当前 f01 作为初始状态，因为一开始坐标是 0，然后 m 是 1。然后转移到后面的话，可以转移到后面 2m 个状态，也可以转移到 f11 和 f22 对吧？因为你跳一格的话它的 m 是不变的，而跳两个的话 m 就变成了 2。然后在这个 f11 里面依旧是可以往后面转移两个状态，在 f22 里面可以转移四个状态，因为它的 m 等于 2。然后我们的 f01 它是等于整个 piles 减去它可以转移状态里面的最小值，因为后面的一个状态是表示对方，对方能拿的这个堆数，我们肯定希望对方能拿的最少。

## 0.3 Solution 
```python
from typing import List

class Solution:
    def stoneGameII(self, piles: List[int]) -> int:
        n = len(piles)
        
        # 1. 预处理后缀和，方便 O(1) 计算从 i 到末尾的总和
        suffix_sum = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix_sum[i] = suffix_sum[i + 1] + piles[i]
            
        # 2. 记忆化字典，用来存储已经计算过的 dp[i][m] 状态，避免重复计算
        memo = {}
        
        # 3. 定义递归函数
        def dp(i, m):
            # 如果已经越界，说明没有石子可拿了
            if i >= n:
                return 0
            
            # 如果当前状态已经计算过，直接返回结果
            if (i, m) in memo:
                return memo[(i, m)]
            
            # 如果剩下的石子堆数 <= 2M，当前玩家可以直接全部拿走
            if i + 2 * m >= n:
                return suffix_sum[i]
            
            # 4. 状态转移：当前玩家能拿的最大值 = 剩余总和 - 对手能拿的最大值
            # 对手能拿的最大值，就是我们在所有合法的 X 中，寻找 dp(i + x, max(m, x)) 的最大值
            min_opponent = float('inf')
            for x in range(1, 2 * m + 1):
                # 对手在下一轮的状态
                opponent_val = dp(i + x, max(m, x))
                min_opponent = min(min_opponent, opponent_val)
                
            # 当前玩家的最大收益
            result = suffix_sum[i] - min_opponent
            memo[(i, m)] = result
            return result
        
        # 游戏从下标 0 开始，初始 M = 1
        return dp(0, 1)
```
