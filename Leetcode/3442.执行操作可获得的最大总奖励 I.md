## 0.1 3442.执行操作可获得的最大总奖励 I

给你一个整数数组 `rewardValues`，长度为 `n`，代表奖励的值。

最初，你的总奖励 `x` 为 0，所有下标都是 **未标记** 的。你可以执行以下操作 **任意次** ：

- 从区间 `[0, n - 1]` 中选择一个 **未标记** 的下标 `i`。
- 如果 `rewardValues[i]` **大于** 你当前的总奖励 `x`，则将 `rewardValues[i]` 加到 `x` 上（即 `x = x + rewardValues[i]`），并 **标记** 下标 `i`。

以整数形式返回执行最优操作能够获得的 **最大** 总奖励。

**示例 1：**

**输入：**rewardValues = [1,1,3,3]

**输出：**4

**解释：**

依次标记下标 0 和 2，总奖励为 4，这是可获得的最大值。

**示例 2：**

**输入：**rewardValues = [1,6,4,3,2]

**输出：**11

**解释：**

依次标记下标 0、2 和 1。总奖励为 11，这是可获得的最大值。

**提示：**

- `1 <= rewardValues.length <= 2000`
- `1 <= rewardValues[i] <= 2000`

## 0.2 Notes

**优化思路：**

1. **纯开数组的 DP（空间浪费）**：第二维空间开得很大（`sum(rewardValues) + 1`），但实际能到达的状态很少，导致大量无效空间被分配却从未使用。
2. **用 Set 做的 DP（按需扩展）**：只有真正能到达的状态才占据空间，避免了无效空间的浪费。因此该方法通过 LeetCode 测试，而数组解法会 MLE。

---

### 0.2.1 拓展：类似需要"节省空间"的 DP 题目

这一类题目的共同特征：**状态空间理论很大，但实际可达状态稀疏**，直接用二维数组会 MLE，需要用 Set / Map / Bitset 来压缩。

## 0.3 Solution 

### 0.3.1 解法一：Set DP（通过）

将问题转化为：每次选择一张牌，只有当 `reward > x`（当前总奖励）时才能选，选完后 `x += reward`。用 `set` 记录所有可达的总奖励值。

```python
class Solution:
    def maxTotalReward(self, rewardValues: List[int]) -> int:
        rewardValues.sort()
        
        # 用 set 记录所有可达的总价值
        reachable = {0}
        
        for reward in rewardValues:
            new_reachable = set()
            for total in reachable:
                # 只有当 reward > 当前总价值时，才能选这张牌
                if reward > total:
                    new_reachable.add(total + reward)
            reachable |= new_reachable
        
        return max(reachable)
```

### 0.3.2 解法二：纯数组 DP（MLE）

当做 01 背包来做：`dp[i][j]` 表示考虑前 i 张牌能否恰好凑出总奖励 j。选牌条件是 `reward > j - reward`（即 reward 大于之前的总奖励）。因为第二维空间太大，所以会 MLE。

```python
class Solution:
    def maxTotalReward(self, rewardValues: List[int]) -> int:
        rewardValues.sort()
        dp = [[-1] * (sum(rewardValues) + 1) for _ in range(len(rewardValues) + 1)]
        dp[0][0] = 0
        ans = 0

        dp_n, dp_m = len(dp), len(dp[0])
        for i in range(1, dp_n):
            reward = rewardValues[i - 1]
            for j in range(dp_m):
                # 如果当前 reward > 之前的总奖励（j - reward），则可以选
                if reward > j - reward and dp[i - 1][j - reward] != -1:
                    dp[i][j] = 0
                    ans = max(ans, j)
            
                # 否则继承上方的值
                dp[i][j] = max(dp[i - 1][j], dp[i][j])
        
        return ans
```
