## 0.1 100325.解密数字

现有一串神秘的密文 `ciphertext`，经调查，密文的特点和规则如下：

- 密文由非负整数组成
- 数字 0-25 分别对应字母 a-z

请根据上述规则将密文 `ciphertext` 解密为字母，并返回共有多少种解密结果。

**示例 1：**

**输入：**ciphertext = 216612
**输出：**`6`
**解释：**216612 解密后有 6 种不同的形式，分别是 "cbggbc"，"vggbc"，"vggm"，"cbggm"，"cqgbc" 和 "cqgm" 

**提示：**

- `0 <= ciphertext < 231`

## 0.2 Notes

**核心思路：爬楼梯模型**

这道题本质上是一个带条件的"爬楼梯"问题：

- 把密文字符串 `s` 想象成一段楼梯，你需要从最后一阶（`n-1`）走到第 `-1` 阶（越界基案）
- 每一步你可以：
  - **走 1 阶**（取 1 个数字）：任何单个数字都一定能映射到一个字母（0~9 全在 0~25 内）
  - **走 2 阶**（取 2 个数字）：需要满足两个条件才能走

**走两阶的合法性判定：**

设当前在位置 `i`，要取 `s[i-1]` 和 `s[i]` 两个数字：

1. **无前导零**：`s[i-1] != '0'`，因为 `"06"` 这类是无效的两位数表示
2. **数值范围**：`int(s[i-1:i+1]) < 26`，即数值必须在 0~25 之内

**状态定义与转移：**

定义 `dfs(i)` = 子串 `s[0..i]` 的解密方案数（从前向后考虑前 `i+1` 个数字）

- **递归基案**：`dfs(-1) = 1`，空串有一种方案（什么也不翻译）
- **走 1 阶**：`dfs(i) = dfs(i-1)` — 最后一个数字单独翻译
- **走 2 阶**：`dfs(i) += dfs(i-2)` — 当最后两个数字能合并翻译时

转移方程：
$$
dfs(i) = dfs(i-1) + \begin{cases} dfs(i-2), & i \geq 1 \land s[i-1] \neq \text{'0'} \land \text{int}(s[i-1:i+1]) < 26 \\ 0, & \text{otherwise} \end{cases}
$$

**与经典爬楼梯的对应关系：**

| 爬楼梯 | 本题 |
|--------|------|
| 走 1 步 | 取 1 位数字单独翻译 |
| 走 2 步 | 取 2 位数字合并翻译 |
| 无条件 | 需要校验合法性 |
| `dp[i] = dp[i-1] + dp[i-2]` | 同上，但 `dp[i-2]` 有条件 |

**复杂度分析：**

- 时间复杂度：$O(n)$，每个状态只计算一次（记忆化）
- 空间复杂度：$O(n)$，递归栈深度 + 缓存

**递推写法（自底向上）：**

```python
def crackNumber(self, ciphertext: int) -> int:
    s = str(ciphertext)
    n = len(s)
    # dp[i] 表示前 i 个字符的解密方案数
    dp = [0] * (n + 1)
    dp[0] = 1  # 空串
    
    for i in range(1, n + 1):
        # 走 1 阶：取最后 1 位
        dp[i] = dp[i - 1]
        # 走 2 阶：取最后 2 位（需校验）
        if i >= 2 and s[i-2] != '0' and int(s[i-2:i]) < 26:
            dp[i] += dp[i - 2]
    
    return dp[n]
```

空间可进一步优化为 $O(1)$，只保留 `dp[i-1]` 和 `dp[i-2]`。


## 0.3 Solution 
```python
class Solution:
    def crackNumber(self, ciphertext: int) -> int:
        s = str(ciphertext)
        n = len(s)

        @cache
        def dfs(i: int) -> int:
            if i == -1: return 1

            # 如果是一个数字的话呢，它注定是能对应上一个字母的
            res = dfs(i - 1)

            # 如果是两个数字呢，需要判定一下
            if i >= 1 and s[i - 1] != '0' and int(s[i-1:i+1]) < 26:
                res += dfs(i - 2)
            
            return res

        return dfs(n - 1)
```
