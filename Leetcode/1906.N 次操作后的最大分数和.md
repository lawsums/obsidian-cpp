## 0.1 1906.N 次操作后的最大分数和

给你 `nums` ，它是一个大小为 `2 * n` 的正整数数组。你必须对这个数组执行 `n` 次操作。

在第 `i` 次操作时（操作编号从 **1** 开始），你需要：

- 选择两个元素 `x` 和 `y` 。
- 获得分数 `i * gcd(x, y)` 。
- 将 `x` 和 `y` 从 `nums` 中删除。

请你返回 `n` 次操作后你能获得的分数和最大为多少。

函数 `gcd(x, y)` 是 `x` 和 `y` 的最大公约数。

**示例 1：**

**输入：**nums = [1,2]
**输出：**1
**解释：**最优操作是：
(1 * gcd(1, 2)) = 1

**示例 2：**

**输入：**nums = [3,4,6,8]
**输出：**11
**解释：**最优操作是：
(1 * gcd(3, 6)) + (2 * gcd(4, 8)) = 3 + 8 = 11

**示例 3：**

**输入：**nums = [1,2,3,4,5,6]
**输出：**14
**解释：**最优操作是：
(1 * gcd(1, 5)) + (2 * gcd(2, 4)) + (3 * gcd(3, 6)) = 1 + 4 + 9 = 14

**提示：**

- `1 <= n <= 7`
- `nums.length == 2 * n`
- `1 <= nums[i] <= 106`

## 0.2 Notes

### 0.2.1 核心思路：状压 DP（状态压缩 / 位掩码）

这道题用 **状压 DP** 来解决，原因有二：

1. **选取顺序影响分数**：每次操作的得分是 `i * gcd(x, y)`，系数 `i` 随操作次序递增。同样的两个元素，放在第 1 次操作和第 3 次操作得到的分不同，因此**不能贪心**，必须枚举"先选哪一对、后选哪一对"的所有顺序。
2. **`n ≤ 7`，状态空间足够小**：`nums` 长度为 `2n ≤ 14`，用一个整数的二进制掩码 `mask` 的第 `i` 位表示 `nums[i]` 是否已被选走，状态总数只有 `2^14 = 16384` 种，完全可以在 `O(2^(2n) · n²)` 内枚举完。

### 0.2.2 状态定义

- `mask`：二进制掩码，第 `i` 位为 `1` 表示 `nums[i]` 已被选取（删除）。
- `ind`：当前是第几次操作（从 `1` 开始计数），同时也是这一步的得分系数。
- `dfs(ind, mask)`：在**第 `ind` 次操作**、当前已选集合为 `mask` 时，**还能获得的最大分数**。

> 实际上 `ind` 可以由 `mask` 中 `1` 的个数推出来（`popcount(mask) = 2 × (ind - 1)`）。代码里单独传 `ind` 只是让转移更直观。

### 0.2.3 状态转移

```python
res = max(res,
          dfs(ind + 1, mask | (1 << i) | (1 << j)) + ind * gcd(nums[i], nums[j]))
```

- 枚举两个还没被选走的下标 `i < j`；
- 本次操作获得 `ind * gcd(nums[i], nums[j])`；
- 把 `i`、`j` 对应位置 1 后进入第 `ind + 1` 次操作；
- 在所有合法的 `(i, j)` 中取最大值。

**边界条件**：`ind == m + 1`（`m = len(nums) // 2` 为操作总次数）时所有元素都选完了，返回 `0`。

### 0.2.4 复杂度分析

- 状态数：`O(2^(2n))`，即 `2^14 = 16384`；
- 每个状态枚举配对：`O((2n)²)`；
- 时间：`O(2^(2n) · n²)`，量级在 `10^6` 以内，轻松通过；
- 空间：`O(2^(2n))`，即记忆化缓存大小。

### 0.2.5 为什么不能贪心 / 回溯为什么可行

- **贪心不可行**：得分系数 `i` 随次序递增，所以"当前 gcd 最大的一对"不一定带来全局最优。例如示例 2 的 `[3,4,6,8]`：贪心先取 `gcd` 最大的 `(4,8)` → `1×4 + 2×3 = 10`，反而取不到最优的 `11`（先 `(3,6)` 再 `(4,8)`）。这正说明顺序很重要。
- **朴素回溯可行但重复计算多**：枚举所有配对顺序有 `(2n-1)!!` 种；但大量子状态（已选集合相同）会被重复求解。用记忆化（即状压 DP）后每个状态只算一次。

### 0.2.6 代码要点

- `@cache` 自动做记忆化；
- `if mask >> i & 1: continue` 跳过已选元素；
- 最终答案从 `dfs(1, 0)` 开始：第 1 次操作、空掩码。

### 0.2.7 易错点

1. 注意变量含义：代码里 `n = len(nums)` 是**元素个数**，`m = n // 2` 才是**操作次数**。
2. 掩码位从 0 开始；`i` 从 0 枚举、`j` 从 `i + 1` 开始，保证每对元素只被枚举一次。
3. `ind` 从 1 开始（对应题目"操作编号从 1 开始"），到边界 `m + 1` 时返回 0 并回溯。

## 0.3 Solution 
```python
class Solution:
    def maxScore(self, nums: List[int]) -> int:
        n = len(nums)
        m = n // 2

        @cache
        def dfs(ind: int, mask: int) -> int:
            if ind == m + 1:
                return 0

            res = 0 # 后面取最大值
            for i in range(n - 1):
                # 如果已经拿过这一位了，我们就继续
                if mask >> i & 1: continue
                for j in range(i + 1, n):
                    if mask >> j & 1: continue
                    res = max(res, 
                            dfs(ind + 1, mask | 1 << i | 1 << j) + 
                            ind * gcd(nums[i], nums[j])
                            )
                    
            return res

        return dfs(1, 0)
```
