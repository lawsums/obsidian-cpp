## 0.1 1188.花括号展开 II

如果你熟悉 Shell 编程，那么一定了解过花括号展开，它可以用来生成任意字符串。

花括号展开的表达式可以看作一个由 **花括号**、**逗号** 和 **小写英文字母** 组成的字符串，定义下面几条语法规则：

- 如果只给出单一的元素 `x`，那么表达式表示的字符串就只有 `"x"`。`R(x) = {x}`
    - 例如，表达式 `"a"` 表示字符串 `"a"`。
    - 而表达式 `"w"` 就表示字符串 `"w"`。
- 当两个或多个表达式并列，以逗号分隔，我们取这些表达式中元素的并集。`R({e_1,e_2,...}) = R(e_1) ∪ R(e_2) ∪ ...`
    - 例如，表达式 `"{a,b,c}"` 表示字符串 `"a","b","c"`。
    - 而表达式 `"{{a,b},{b,c}}"` 也可以表示字符串 `"a","b","c"`。
- 要是两个或多个表达式相接，中间没有隔开时，我们从这些表达式中各取一个元素依次连接形成字符串。`R(e_1 + e_2) = {a + b for (a, b) in R(e_1) × R(e_2)}`
    - 例如，表达式 `"{a,b}{c,d}"` 表示字符串 `"ac","ad","bc","bd"`。
- 表达式之间允许嵌套，单一元素与表达式的连接也是允许的。
    - 例如，表达式 `"a{b,c,d}"` 表示字符串 `"ab","ac","ad"​​​​​​`。
    - 例如，表达式 `"a{b,c}{d,e}f{g,h}"` 可以表示字符串 `"abdfg", "abdfh", "abefg", "abefh", "acdfg", "acdfh", "acefg", "acefh"`。

给出表示基于给定语法规则的表达式 `expression`，返回它所表示的所有字符串组成的有序列表。

假如你希望以「集合」的概念了解此题，也可以通过点击 “**显示英文描述**” 获取详情。

**示例 1：**

**输入：**expression = "{a,b}{c,{d,e}}"
**输出：**["ac","ad","ae","bc","bd","be"]

**示例 2：**

**输入：**expression = "{{a,z},a{b,c},{ab,z}}"
**输出：**["a","ab","ac","z"]
**解释：**输出中 **不应** 出现重复的组合结果。

**提示：**

- `1 <= expression.length <= 60`
- `expression[i]` 由 `'{'`，`'}'`，`','` 或小写英文字母组成
- 给出的表达式 `expression` 用以表示一组基于题目描述中语法构造的字符串

## 0.2 Notes

### 0.2.1 代数视角：这是一个「正则语言半环」上的表达式求值

把题目给的语法直接翻译成集合代数：

| 表达式语法 | 集合含义 | 记号 |
| --- | --- | --- |
| 单字母 `x` | 单元素集合 | `{x}` |
| `e₁,e₂`（逗号） | ==并集== | `R(e₁) ∪ R(e₂)` |
| `e₁e₂`（相邻相接） | ==连接==（笛卡尔积拼接） | `{a + b \| a∈R(e₁), b∈R(e₂)}` |
| `{e}` | 括号只改变优先级，不改变语义 | `R(e)` |

于是需要记住两个「单位元」，它们是整个解法的地基：

- ==连接的乘法单位元是空串 `""`==：`"" + x = x`，乘积集合的初值必须是 `{""}`。
- ==并集的加法单位元是空集 ∅==：`∅ ∪ S = S`，`result` 的初值就是 ∅。

> 单位元是本题唯一容易写错的地方 —— 一份「空集合」初值会让整份代码恒等于 ∅，见 0.2.3。

### 0.2.2 解法一核心思路：递归下降 + 增量笛卡尔积（C++）

一次自左向右扫描，任何时刻只维护两个集合：

- `result`：==本层已并入的并集==（被逗号切分出来、已经收尾的那些项）
- `now`：==当前这一项的乘积集合==（还没遇到逗号，正在一点点长大）

四种字符，四种动作：

| 读到 | 动作 | 对应语义 |
| --- | --- | --- |
| 小写字母 `c` | `now ← now × {c}`（每个串尾部 `+= c`） | 连接一个单元素集合 |
| `{` | ==递归==解析子表达式得到 `vec`，再 `now ← now × vec` | 连接一个子集合 |
| `,` | 把 `now` 整体倒进 `result`，==并重置 `now = {""}`== | 取并集，并开始新的一项 |
| `}` 或 `\0` | 把 `now` 倒进 `result`，排序去重后 `return` | 本层收尾 |

> `\0` 是字符串结尾哨兵：让「最外层结束」和「遇到 `}`」走同一条收尾逻辑，省掉一个分支 —— 这正是 `*str++` 能一直读下去的原因。

每一层的 `sort` + `unique` + `resize` 做 ==就地去重==，所以内层递归返回时就已经是集合语义，外层再并起来也不会爆规模。

### 0.2.3 为什么要 `now.emplace_back()` 推入一个空串？（代码里的 TODO）

因为它是 ==连接运算的单位元 ε==。`now` 的语义是「当前项的笛卡尔积」，初值必须是 `{""}` 而不是 ∅：

- 若初值是**空 vector**，那么遇到 `{a,b}` 时 `for (auto &xs : ori)` ==一次都不会执行==，`now` 恒为 ∅；
- 后面的 `for (auto &s : now) s.push_back(ch)`（处理普通字母）同样不执行，`now` 永远是 ∅；
- 而 ∅ 与任何集合的笛卡尔积仍是 ∅ —— ==整个函数会稳定地返回空集==，一个答案都产不出来。

有了栈底那个 `""`，`"" + "a" = "a"`，第一项才能「从真空里长出来」。同理，逗号把 `now` 倒空之后必须再补一个 `""`，否则**下一项**同样长不出来。

> 一句话：`now` 是「当前项的集合」，而乘法的 1 是 `""`，不是空集。空集是加法的 0。

### 0.2.4 两个容易被当成「炫技」的实现细节

1. **`now.reserve(...)` 必须写在 `const span<string> ori = now;` 之前。**
   - `ori` 是 ==指向 `now` 内部缓冲区的视图（view），不是拷贝==，只覆盖此刻的前 `now.size()` 个元素。
   - 若容量不够，后面的 `now.push_back(...)` 会触发扩容 → 缓冲区搬家 → `ori` 立刻变成==悬垂 span（UB）==。
   - 先按 `now.size() * vec.size()` 预留，保证整个流程不再 reallocate，`ori` 才始终指向有效内存。
2. **`for (auto &sf = vec.front(); auto &s: ori) s += sf;`**
   - 笛卡尔积里「与 `vec[0]` 相乘」的那一份，==直接复用 `now` 里已有的串就地追加==，省掉 `ori.size()` 次拷贝；
   - 「与 `vec[1..]` 相乘」的部分无处复用，只能 `now.push_back(xs + s)` 新建。
   - 两条路径合起来，`now` 的元素集合恰好是 `{xs + s | xs ∈ ori, s ∈ vec}`。

### 0.2.5 解法二核心思路：正则重写 + `eval` 求半环表达式（Python）

不解方程，直接把题目表达式==翻译成 Python 表达式==交给 `eval`：

| 步骤 | 正则 | 作用 |
| --- | --- | --- |
| 1 | `(\w+)` → `S(["\1"])` | 每个字母（或连续字母串）变成单元素集合 |
| 2 | `,` `{` `}` → `+` `(` `)` | 逗号变并集运算符，花括号变小括号 |
| 3 | `\)([S\(])` → `)*\1` | ==补上隐式的乘号==：前一个原子以 `)` 结束、下一个原子以 `S` 或 `(` 开头时插入 `*` |

再用 `class S(set)` 把集合包装成半环，两个运算符正好对应两种语义：

- `__add__`（`+`）→ ==并集== `self \| other`
- `__mul__`（`*`）→ ==笛卡尔积拼接== `{i + j for i, j in product(self, other)}`

由于每个原子都写成 `S([...])` 或 `(...)`，==所有原子的右边界都是 `)`==，第 3 步的补乘号只需匹配 `)` 后面跟 `S` 或 `(` 这一种情形，非常干净。

> 两解法的关键差异：解法一==边扫边算，必须有一个显式的 ε 起手==（0.2.3）；解法二==先把 AST 建好再整体求值，乘法的两个操作数都是完整集合，永远不会出现「半成品累积器」，所以根本不需要 ε==。同一套语义，两种承载方式。

### 0.2.6 复杂度对比

设字符数为 `n`，最终结果集合大小为 `k`：

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| --- | --- | --- | --- |
| ==解法一：递归下降 + 增量笛卡尔积（C++）== | O(n · k) | O(k) | ==本笔记做法==，每层去重，中间规模被压住 |
| 解法二：正则重写 + `eval`（Python） | O(n · k) | O(k) | 代码最短，但依赖 `eval`，且乘号要手动补 |

- `k` 本身是==指数级==的（如 `{a,b}{a,b}{a,b}...` 有 2^m 个结果），任何解法都逃不掉 —— 因为必须把每个字符串都输出一遍。
- 真正能优化的只有「中间规模」：两解法都在集合层面去重（解法一每层 `sort` + `unique`），避免同一中间结果被反复枚举。
- 单次拼接是 O(串长)，所以完整上界还要乘一个串长因子。

## 0.3 Solution 

**解法一：递归下降 + 增量笛卡尔积 —— 本笔记做法（C++）**

```cpp
class Solution {
public:
    // C++23：this auto&& self 是显式对象参数（deducing this），用它实现递归 lambda
    static vector<string> braceExpansionII(const string& s) {
        return [str = s.data()](this auto&& self) {
            vector<string> result, now;   // result: 本层的并集; now: 当前项的乘积集合
            now.emplace_back();           // 乘法的单位元 ε = "" ，见 Notes 0.2.3
            for (;;) {
                const auto ch = *str++;
                if (ch == '}' or ch == 0) {          // '}' 或字符串结尾 '\0'：本层收尾
                    result.reserve(result.size() + now.size());
                    for (auto &s: now) {
                        result.push_back(move(s));
                    }
                    sort(result.begin(), result.end());
                    result.resize(unique(result.begin(), result.end()) - result.begin());  // 每层去重
                    return result;
                }
                else if (ch == '{') {
                    auto vec = self();           // 递归解析子表达式，得到子集合
                    now.reserve(now.size() * vec.size());  // 必须先 reserve，否则 push_back 扩容会让 ori 悬垂
                    const span<string> ori = now;          // 只观察前 now.size() 个元素，不拷贝
                    for (auto &s: vec | views::drop(1)) {  // 与 vec[1..] 相乘：无处复用，只能新建
                        for (auto &xs: ori) {
                            now.push_back(xs + s);
                        }
                    }
                    for (auto &sf = vec.front(); auto &s: ori) {  // 与 vec[0] 相乘：就地追加，省一次拷贝
                        s += sf;
                    }
                }
                else if (ch == ',') {                // 逗号：当前项收尾并入 result，并重置 now = {""}
                    result.reserve(result.size() + now.size());
                    for (auto &s: now) {
                        result.push_back(move(s));
                    }
                    now.clear();
                    now.emplace_back();
                }
                else {                               // 普通字母：now × {ch}
                    for (auto &s: now) {
                        s.push_back(ch);
                    }
                }
            }
        } ();
    }
};
```

**解法二：正则重写 + `eval` 求半环表达式（Python）**

```python
import re, itertools

class S(set):
    def __add__(self, other):                       # '+' 对应并集（逗号）
        return S(self | other)

    def __mul__(self, other):                       # '*' 对应连接（隐式相乘 → 笛卡尔积拼接）
        return S(i + j for i, j in itertools.product(self, other))

class Solution:
    def braceExpansionII(self, expression: str) -> List[str]:
        expression = re.sub('(\w+)', r'S(["\1"])', expression)          # 字母 → 单元素集合
        d = {',': '+', '{': '(', '}': ')'}                              # 逗号→并集，花括号→小括号
        expression = re.sub('[\,\{\}]', lambda x: d[x.group(0)], expression)
        expression = re.sub('\)([S\(])', r')*\1', expression)           # 补上隐式的乘号
        return sorted(S(eval(expression)))
```
