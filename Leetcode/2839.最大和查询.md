## 0.1 2839.最大和查询

给你两个长度为 `n` 、下标从 **0** 开始的整数数组 `nums1` 和 `nums2` ，另给你一个下标从 **1** 开始的二维数组 `queries` ，其中 `queries[i] = [xi, yi]` 。

对于第 `i` 个查询，在所有满足 `nums1[j] >= xi` 且 `nums2[j] >= yi` 的下标 `j` `(0 <= j < n)` 中，找出 `nums1[j] + nums2[j]` 的 **最大值** ，如果不存在满足条件的 `j` 则返回 **-1** 。

返回数组 `answer` _，_其中 `answer[i]` 是第 `i` 个查询的答案。

**示例 1：**

**输入：**nums1 = [4,3,1,2], nums2 = [2,4,9,5], queries = [[4,1],[1,3],[2,5]]
**输出：**[6,10,7]
**解释：**
对于第 1 个查询：`xi = 4` 且 `yi = 1` ，可以选择下标 `j = 0` ，此时 `nums1[j] >= 4` 且 `nums2[j] >= 1` 。`nums1[j] + nums2[j]` 等于 6 ，可以证明 6 是可以获得的最大值。
对于第 2 个查询：`xi = 1` 且 `yi = 3` ，可以选择下标 `j = 2` ，此时 `nums1[j] >= 1` 且 `nums2[j] >= 3` 。`nums1[j] + nums2[j]` 等于 10 ，可以证明 10 是可以获得的最大值。
对于第 3 个查询：`xi = 2` 且 `yi = 5` ，可以选择下标 `j = 3` ，此时 `nums1[j] >= 2` 且 `nums2[j] >= 5` 。`nums1[j] + nums2[j]` 等于 7 ，可以证明 7 是可以获得的最大值。
因此，我们返回 `[6,10,7]` 。

**示例 2：**

**输入：**nums1 = [3,2,5], nums2 = [2,3,4], queries = [[4,4],[3,2],[1,1]]
**输出：**[9,9,9]
**解释：**对于这个示例，我们可以选择下标 `j = 2` ，该下标可以满足每个查询的限制。

**示例 3：**

**输入：**nums1 = [2,1], nums2 = [2,3], queries = [[3,3]]
**输出：**[-1]
**解释：**示例中的查询 `xi` = 3 且 `yi` = 3 。对于每个下标 j ，都只满足 nums1[j] < `xi` 或者 nums2[j] < `yi` 。因此，不存在答案。 

**提示：**

- `nums1.length == nums2.length` 
- `n == nums1.length` 
- `1 <= n <= 105`
- `1 <= nums1[i], nums2[i] <= 109` 
- `1 <= queries.length <= 105`
- `queries[i].length == 2`
- `xi == queries[i][1]`
- `yi == queries[i][2]`
- `1 <= xi, yi <= 109`

## 0.2 Notes

### 0.2.1 思路总览

这是一个**二维限制下的离线最值查询**问题：对每个查询 `(x, y)`，在所有满足 `nums1[j] >= x` **且** `nums2[j] >= y` 的 `j` 中，求 `nums1[j] + nums2[j]` 的最大值。

`n, m <= 1e5`，暴力是 O(nm)，不可行。核心套路是**离线 + 排序消掉一维 + 数据结构维护另一维**：

1. **排序消掉 `x` 这一维（滑动窗口）**：把数对 `(nums1[i], nums2[i])` 按 `nums1` **降序**排序，查询也按 `x` **降序**排序。处理查询时用一个单调前进的指针 `idx`，把所有 `nums1[idx] >= x` 的数对"插入"数据结构。由于查询按 `x` 递减处理，指针只增不减，每个数对只会被插入一次，`x` 的限制就解决了。
2. **数据结构维护 `y` 这一维**：插入的数对已经全部满足 `x` 限制，剩下只需回答"`nums2 >= y` 的数对里，和的最大值"——这是一个**后缀最大值查询**。
3. 这里的数据结构就是**维护最大值的树状数组**（配合坐标翻转）。

### 0.2.2 树状数组在这里的具体作用

树状数组以**离散化后的 `nums2` 为位置**、以 **`nums1 + nums2` 为值**，支持两种操作：

- **插入** `add(pos, val)`：沿 `lowbit` 向上更新覆盖该位置的所有节点，取 `max`。
- **查询** `query(pos)`：返回位置 `1..pos` 上的最大值，沿 `lowbit` 向下累计取 `max`。

**为什么要把位置"倒过来"（`sz - mapping[...]`）？**

标准的树状数组只能高效回答**前缀**查询（`[1, pos]` 的最大值），而本题需要**后缀**查询（`nums2 >= y` 的所有位置的最大值）。最大值不像求和那样可以"前缀作差"，所以做一次**坐标翻转**：

- 离散化排名 `mapping[v]` 越大代表 `v` 越大；
- 翻转后位置 `pos = sz - mapping[v]`：`nums2` 越大，`pos` 越小；
- 于是 `nums2 >= y` ⟺ `mapping >= mapping[y]` ⟺ `pos <= sz - mapping[y]`，后缀查询就变成了前缀查询 `query(sz - mapping[y])`。

**直观理解**：翻转后的位置 `pos` 相当于"大于等于该值的离散值个数"；`query(k)` 就是在问"`nums2` 排名前 `k` 大的那些数对里，和的最大值"。

几个配套的细节：

- **离散化**：值域高达 `1e9`，但只有 `n + m` 个不同的 `y` 相关值，压缩到 `sz <= 2e5` 作为树状数组大小。
- **为什么树状数组够用**：数对是**只插入、不删除**的（指针单调前进），而树状数组天然支持单点更新，不支持删除——恰好匹配。若需要删除就得换线段树/CDQ。
- **初始化为 -1**：`tr` 全为 `-1`，某个位置从未被更新过时查询自然返回 `-1`，与题意"不存在满足条件的数对返回 -1"一致。
- **为什么不用线段树**：线段树当然可以，还能直接做区间/后缀最值；树状数组代码短、常数小，配合坐标翻转即可覆盖后缀查询场景。另一个等价写法是：不翻转坐标，改为 `add` 向低处走、`query` 向高处走。

### 0.2.3 复杂度

- 离散化：`O((n+m) log(n+m))`
- 排序：`O(n log n + m log m)`
- 树状数组：每个数对插入一次、每个查询查询一次，各 `O(log sz)`，共 `O((n+m) log(n+m))`
- **总复杂度**：`O((n+m) log(n+m))`，空间 `O(n+m)`。

### 0.2.4 示例走一遍

`nums1 = [4,3,1,2], nums2 = [2,4,9,5], queries = [[4,1],[1,3],[2,5]]`

- 数对及和：`(4,2)=6, (3,4)=7, (1,9)=10, (2,5)=7`
- `y` 离散化：`{1,2,3,4,5,9} → 0..5`，`sz = 6`
- 数对按 `nums1` 降序：`(4,2), (3,4), (2,5), (1,9)`；查询按 `x` 降序：`(4,1,q0), (2,5,q2), (1,3,q1)`

| 步骤 | 查询 | 插入的数对（翻转位置） | 树状数组查询 | 结果 |
|------|------|----------------------|-------------|------|
| 1 | (4,1) | (4,2)：pos=5, val=6 | query(6) | 6 → ans[0]=6 |
| 2 | (2,5) | (3,4)：pos=3, val=7；(2,5)：pos=2, val=7 | query(2) | 7 → ans[2]=7 |
| 3 | (1,3) | (1,9)：pos=1, val=10 | query(4) | 10 → ans[1]=10 |

输出 `[6,10,7]`。✓

注意第 2 步：`(3,4)` 的 `nums2 = 4 < 5`，翻转后 `pos = 3 > 2`，前缀查询 `query(2)` 自然把它排除——这就是"坐标翻转"正确性的直观体现。

## 0.3 Solution 
```python
class Solution:
    def maximumSumQueries(self, nums1: List[int], nums2: List[int], queries: List[List[int]]) -> List[int]:
        sz = 0
        tr = []

        def lowbit(x):
            return x & -x
        def add(a, b):
            i = a
            while i <= sz:
                tr[i] = max(tr[i], b)
                i += lowbit(i)
        def query(x):
            ans, i = -1, x
            while i > 0:
                ans = max(ans, tr[i])
                i -= lowbit(i)
            return ans
        
        n, m = len(nums1), len(queries)
        # 构建新的 nums 和 nq
        nums = [(nums1[i], nums2[i]) for i in range(n)]
        nq = [(queries[i][0], queries[i][1], i) for i in range(m)]
        
        #  对要添加到树状数组的 nums[i][1] 和 nq[i][1] 进行离散化（构建映射字典, 将原值映射到 [0, m - 1])
        unique_set = set()
        for x in nums:
            unique_set.add(x[1])
        for q in nq:
            unique_set.add(q[1])
        unique_list = list(unique_set)
        unique_list.sort()
        sz = len(unique_list)
        mapping = {val: idx for idx, val in enumerate(unique_list)}
        
        # 调整询问顺序, 解决其中一维限制
        nums.sort(key=lambda x: x[0], reverse=True)
        nq.sort(key=lambda x: x[0], reverse=True)
        
        tr = [-1] * (sz + 10)
        
        ans = [0] * m
        idx = 0
        for x, y, i in nq:
            # 扫描所有满足 nums[idx][0] >= x 的数对, 添加到树状数组中（其中离散值作为位置信息, 数对和作为值信息）
            while idx < n and nums[idx][0] >= x:
                add(sz - mapping[nums[idx][1]], nums[idx][0] + nums[idx][1])
                idx += 1
            ans[i] = query(sz - mapping[y])  # 查询树状数组中的最值
        return ans
```
