## 0.1 1000010.二叉搜索树序列

从左向右遍历一个数组，通过不断将其中的元素插入树中可以逐步地生成一棵二叉搜索树。

给定一个由**不同节点**组成的二叉搜索树 `root`，输出所有可能生成此树的数组。

**示例 1：**

**输入：**root = [2,1,3]
**输出：**[[2,1,3],[2,3,1]]
**解释：**数组 [2,1,3]、[2,3,1] 均可以通过从左向右遍历元素插入树中形成以下二叉搜索树
       2 
      / \ 
     1   3

**示例** **2：**

**输入：**root = [4,1,null,null,3,2]
**输出：**[[4,1,3,2]]

**提示：**

- 二叉搜索树中的节点数在 `[0, 1000]` 的范围内
- `1 <= 节点值 <= 106`
- 用例保证符合要求的数组数量不超过 `5000`

## 0.2 Notes

先一句话结论：
**这题不是全排列暴力回溯，是带强约束的剪枝回溯；题目还直接卡死了答案总数上限，所以根本不可能超时。**

### 0.3 你为什么会觉得会超时？
你潜意识把问题当成了：
> 把所有节点全排列，再逐个校验是不是合法BST插入序列

如果是**暴力全排列**：
n 个节点就是 \(n!\) 复杂度，n=12 就直接上亿，**铁定超时**。
你是按「全排列回溯」的复杂度去评估的，所以觉得会炸。

### 0.4 但真实解法根本不是全排列
咱们这个回溯有**超级强的前置约束**：
1. **必须先选父节点，才能选子节点**
2. 每一步只能从**合法候选集**里选，不是随便乱选剩下所有节点
3. 大量非法分支**从根源上根本不会进入递归**，直接被剪掉了

举个例子：根节点**必须第一个选**，所有根不在第一位的排列，**全程不会生成**，直接少掉绝大部分分支。

### 0.5 题目还有一个关键保底限制
题目提示写了：
> 用例保证符合要求的数组数量不超过 **5000**

意思就是：
不管树有多少节点（哪怕1000个），**合法序列最多就5000条**。
回溯算法本质就是**只生成这5000条合法序列就结束**，递归深度和分支数被题目直接锁死了。

- 链式BST：只有**1条**序列，秒出结果
- 稍微分叉多的：最多也就5000条
- 完全没有爆炸的阶乘级搜索空间

### 0.6 再帮你梳理：你的思路完全没问题
你一开始想的：
> 放之前父节点必须先放置，是序列排序问题

**完全就是本题核心精髓**。
只是你误把「带约束的组合回溯」当成了「无约束全排列回溯」，用错了复杂度模型，才误以为会超时。

### 0.7 一句话总结
1. 思路：✅ 完全正确
2. 超时担心：❌ 错误，因为不是暴力全排列，是**强约束剪枝回溯**
3. 再加题目**答案总数≤5000**的硬限制，怎么写都不可能超时。

## 0.8 Solution 
```cpp
class Solution {
public:
    vector<vector<int>> res;  // 存放最终答案

    vector<vector<int>> BSTSequences(TreeNode* root) {
        if (!root) return {{}};  // 空树特殊处理
        vector<TreeNode*> candidates;  // 候选节点：当前可以选的节点
        vector<int> path;            // 当前生成的序列
        candidates.push_back(root);
        backtrack(candidates, path);
        return res;
    }

    // 回溯：candidates 当前可选节点，path 当前路径
    void backtrack(vector<TreeNode*> candidates, vector<int> path) {
        // 没有可选节点，说明生成完成一条合法序列
        if (candidates.empty()) {
            res.push_back(path);
            return;
        }

        int size = candidates.size();
        // 遍历每一个可选节点
        for (int i = 0; i < size; ++i) {
            TreeNode* cur = candidates[i];
            // 选择当前节点
            path.push_back(cur->val);

            // 构建新候选集：删除当前节点，加入它的左右孩子
            vector<TreeNode*> newCandi;
            // 先把除了 i 以外的候选加进去
            for (int j = 0; j < size; ++j) {
                if (j != i) newCandi.push_back(candidates[j]);
            }
            // 加入左右孩子
            if (cur->left) newCandi.push_back(cur->left);
            if (cur->right) newCandi.push_back(cur->right);

            // 递归
            backtrack(newCandi, path);

            // 回溯：撤销选择
            path.pop_back();
        }
    }
};
```
