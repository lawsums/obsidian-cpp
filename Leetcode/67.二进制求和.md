## 0.1 67.二进制求和

给你两个二进制字符串 `a` 和 `b` ，以二进制字符串的形式返回它们的和。

**示例 1：**

**输入:**a = "11", b = "1"
**输出：**"100"

**示例 2：**

**输入：**a = "1010", b = "1011"
**输出：**"10101"

**提示：**

- `1 <= a.length, b.length <= 104`
- `a` 和 `b` 仅由字符 `'0'` 或 `'1'` 组成
- 字符串如果不是 `"0"` ，就不含前导零

## 0.3 Solution 

![[67.二进制求和.cpp]]

```cpp  
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    string addBinary(string a, string b) {
        // 反转两个字符串
        reverse(a.begin(), a.end());
        reverse(b.begin(), b.end());

        // 设置一个carry位
        int carry = 0;
        vector<char> res;
        int n = a.size(), m = b.size();
        for (int i = 0, op1, op2, cur; carry || i < max(n, m); i++) {
            op1 = i < n ? (a[i] - '0') : 0;
            op2 = i < m ? (b[i] - '0') : 0;
            cur = (carry + op1 + op2) % 2;
            carry = (carry + op1 + op2) / 2;
            res.push_back(cur + '0');
        }

        reverse(res.begin(), res.end());
        return string(res.begin(), res.end());
    }
};

int main() {
    string a = "11", b = "1";
    Solution().addBinary(a, b);
}
```  
