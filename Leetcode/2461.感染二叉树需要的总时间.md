## 0.1 2461.感染二叉树需要的总时间

给你一棵二叉树的根节点 `root` ，二叉树中节点的值 **互不相同** 。另给你一个整数 `start` 。在第 `0` 分钟，**感染** 将会从值为 `start` 的节点开始爆发。

每分钟，如果节点满足以下全部条件，就会被感染：

- 节点此前还没有感染。
- 节点与一个已感染节点相邻。

返回感染整棵树需要的分钟数_。_

**示例 1：**

![](images/2461_image-20220625231744-1.png)

**输入：**root = [1,5,3,null,4,10,6,9,2], start = 3
**输出：**4
**解释：**节点按以下过程被感染：
- 第 0 分钟：节点 3
- 第 1 分钟：节点 1、10、6
- 第 2 分钟：节点5
- 第 3 分钟：节点 4
- 第 4 分钟：节点 9 和 2
感染整棵树需要 4 分钟，所以返回 4 。

**示例 2：**

![](images/2461_image-20220625231812-2.png)

**输入：**root = [1], start = 1
**输出：**0
**解释：**第 0 分钟，树中唯一一个节点处于感染状态，返回 0 。

**提示：**

- 树中节点的数目在范围 `[1, 105]` 内
- `1 <= Node.val <= 105`
- 每个节点的值 **互不相同**
- 树中必定存在值为 `start` 的节点

## 0.2 Notes

### 0.2.1 题目转化

> 感染只能沿「相邻边」传播；二叉树里每个节点的邻居除了 ==左右孩子==，还有 ==父节点==。把树临时当成一张 ==无向图==（给每条边补上反向可达性），问题就等价于：从值为 `start` 的节点出发感染全树需要多少轮，即 `start` 到最远节点的距离。

### 0.2.2 具体步骤

1. ==DFS 建图==：一次 DFS 记录两样东西
   - `parent[node]`：每个节点的父节点（根节点记为 `None`，供 BFS 往上走时用）；
   - `node_map[val]`：值 → 节点的映射。题目保证 ==节点值互不相同==，所以 BFS 队列里可直接用「值」作为单元。
2. ==BFS 分层扩散==：从 `start` 开始，`visit` 记录已感染的值；每一轮把当前层每个节点的三个方向邻居（==父、左、右==）中未感染的加入下一层，`ans` 计一轮。这样不会漏掉「先往上再往下」的最短路。

### 0.2.3 关键细节

- 最后返回 `ans - 1`：`while` 每一轮结束 `ans` 都 `+1`，但==最后一轮队列已空、没有新感染==，这一轮是多计的。
- 判断父方向要写 `if father and not visit[father.val]`：因为==根节点没有父节点==（为 `None`）。
- 用 `defaultdict` 时：所有会被读取的键在读取前都已被 `dfs` 显式赋值（根节点父为 `None`），不会误触默认值。

### 0.2.4 复杂度

| 指标 | 值 | 说明 |
| --- | --- | --- |
| 时间复杂度 | O(n) | DFS 建图 + BFS 各遍历每个节点常数次 |
| 空间复杂度 | O(n) | `parent` / `node_map` / `visit` 各存 n 项，队列最多一层的节点数 |

## 0.3 Solution 
```python
from collections import defaultdict, deque
from typing import Optional

class Solution:
    def amountOfTime(self, root: Optional[TreeNode], start: int) -> int:
        visit = defaultdict(bool)
        parent = defaultdict(TreeNode)  # 存储父节点
        node_map = defaultdict(TreeNode)  # 值 -> 节点

        def dfs(node, father):
            if not node:
                return
            parent[node] = father
            node_map[node.val] = node
            dfs(node.left, node)
            dfs(node.right, node)

        dfs(root, None)

        q = deque([start])
        visit[start] = True
        ans = 0

        while q:
            for _ in range(len(q)):
                val = q.popleft()
                cur = node_map[val]

                # 父节点
                father = parent[cur]
                if father and not visit[father.val]:
                    visit[father.val] = True
                    q.append(father.val)

                # 左子节点
                if cur.left and not visit[cur.left.val]:
                    visit[cur.left.val] = True
                    q.append(cur.left.val)

                # 右子节点
                if cur.right and not visit[cur.right.val]:
                    visit[cur.right.val] = True
                    q.append(cur.right.val)

            ans += 1

        return ans - 1  # 因为最后一轮扩散后多加了一次
```
