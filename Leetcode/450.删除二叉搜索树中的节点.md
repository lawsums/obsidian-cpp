## 0.1 450.删除二叉搜索树中的节点

给定一个二叉搜索树的根节点 **root** 和一个值 **key**，删除二叉搜索树中的 **key** 对应的节点，并保证二叉搜索树的性质不变。返回二叉搜索树（有可能被更新）的根节点的引用。

一般来说，删除节点可分为两个步骤：

1. 首先找到需要删除的节点；
2. 如果找到了，删除它。

**示例 1:**

![](images/450_del_node_1.jpg)

**输入：**root = [5,3,6,2,4,null,7], key = 3
**输出：**[5,4,6,2,null,null,7]
**解释：**给定需要删除的节点值是 3，所以我们首先找到 3 这个节点，然后删除它。
一个正确的答案是 [5,4,6,2,null,null,7], 如下图所示。
另一个正确答案是 [5,2,6,null,4,null,7]。

![](images/450_del_node_supp.jpg)

**示例 2:**

**输入:** root = [5,3,6,2,4,null,7], key = 0
**输出:** [5,3,6,2,4,null,7]
**解释:** 二叉树不包含值为 0 的节点

**示例 3:**

**输入:** root = [], key = 0
**输出:** []

**提示:**

- 节点数的范围 `[0, 104]`.
- `-105 <= Node.val <= 105`
- 节点值唯一
- `root` 是合法的二叉搜索树
- `-105 <= key <= 105`

**进阶：** 要求算法时间复杂度为 O(h)，h 为树的高度。

## 0.2 Notes
1. 添加一个 dummy 用来排除删除 root 的边界条件 
2. 分四种情况删除子节点

## 0.3 Solution 
**记得复制题目**

![[450.删除二叉搜索树中的节点.cpp]]

```cpp
class Solution {
private:    
    TreeNode *father;
    string direction;

public:
    TreeNode* deleteNode(TreeNode* root, int key) {
        TreeNode *dummy = new TreeNode(INT_MIN / 2);
        dummy->right = root;
        handler(dummy, key);
        return dummy->right;
    }

    // 把自己当作子节点的话, 优点: 只要考虑一个分支
    void handler(TreeNode *node, int key) {
        if (!node) return;

        // fprintln("node->val = {}", node->val);
        // cout << node->val << '\n';

        // 删除逻辑
        if (node->val == key) { 
            // fprintln("delete_node_key = {}", node->val);
            if (direction == "L") {
                father->left = delete_handler(node, key);
            } else {
                father->right = delete_handler(node, key);
            }
            return;
        } 

        father = node;
        if (node->val > key) {
            direction = "L";
            handler(node->left, key);
        } else if (node->val < key) {
            direction = "R";
            handler(node->right, key);
        }
    }

    TreeNode *delete_handler(TreeNode *node, int key) {
        bool nl = node->left == nullptr, nr = node->right == nullptr;
        // 1. !left && !right 直接删除返回nullptr
        if (nl && nr) {
            return nullptr;
        } else 
        // 2. !left && right 直接返回right的右孩子
        if (nl) {   
            return node->right;
        } else 
        // 3. left && !right 
        if (nr) {
            return node->left;
        } else 
        // 4. left && right 将删除节点的左子树头结点（左孩子）放到删除节点的右子树的最左面节点的左孩子上，返回删除节点右孩子为新的根节点。
        {
            mostLeftNode(node->right)->left = node->left;
            node->left = nullptr;
            return node->right;
        }
    }

    TreeNode *mostLeftNode(TreeNode *node) {
        auto cur = node;
        while (cur->left) {
            cur = cur->left;
        } // !cur->left
        return cur;
    }
};
```
