## 0.1 3927.交替方向的最小路径代价 II

给你两个整数 `m` 和 `n`，分别表示网格的行数和列数。

进入单元格 `(i, j)` 的成本定义为 `(i + 1) * (j + 1)`。

另外给你一个二维整数数组 `waitCost`，其中 `waitCost[i][j]` 定义了在该单元格 **等待** 的成本。

路径始终从第 1 步进入单元格 `(0, 0)` 并支付入场花费开始。

每一步，你都遵循交替模式：

- 在 **奇数秒** ，你必须向 **右** 或向 **下** 移动到 **相邻** 的单元格，并支付其进入成本。
- 在 **偶数秒** ，你必须原地 **等待****恰好** 1 秒并在 1 秒期间支付 `waitCost[i][j]`。

返回到达 `(m - 1, n - 1)` 所需的 **最小** 总成本。

**示例 1：**

**输入：**m = 1, n = 2, waitCost = [[1,2]]

**输出：**3

**解释：**

最佳路径为：

- 从第 1 秒开始在单元格 `(0, 0)`，进入成本为 `(0 + 1) * (0 + 1) = 1`。
- **第 1 秒**：向右移动到单元格 `(0, 1)`，进入成本为 `(0 + 1) * (1 + 1) = 2`。

因此，总成本为 `1 + 2 = 3`。

**示例 2：**

**输入：**m = 2, n = 2, waitCost = [[3,5],[2,4]]

**输出：**9

**解释：**

最佳路径为：

- 从第 1 秒开始在单元格 `(0, 0)`，进入成本为 `(0 + 1) * (0 + 1) = 1`。
- **第 1 秒**：向下移动到单元格 `(1, 0)`，进入成本为 `(1 + 1) * (0 + 1) = 2`。
- **第 2 秒**：在单元格 `(1, 0)` 等待，支付 `waitCost[1][0] = 2`。
- **第 3 秒**：向右移动到单元格 `(1, 1)`，进入成本为 `(1 + 1) * (1 + 1) = 4`。

因此，总成本为 `1 + 2 + 2 + 4 = 9`。

**示例 3：**

**输入：**m = 2, n = 3, waitCost = [[6,1,4],[3,2,5]]

**输出：**16

**解释：**

最佳路径为：

- 从第 1 秒开始在单元格 `(0, 0)`，进入成本为 `(0 + 1) * (0 + 1) = 1`。
- **第 1 秒**：向右移动到单元格 `(0, 1)`，进入成本为 `(0 + 1) * (1 + 1) = 2`。
- **第 2 秒**：在单元格 `(0, 1)` 等待，支付 `waitCost[0][1] = 1`。
- **第 3 秒**：向下移动到单元格 `(1, 1)`，进入成本为 `(1 + 1) * (1 + 1) = 4`。
- **第 4 秒**：在单元格 `(1, 1)` 等待，支付 `waitCost[1][1] = 2`。
- **第 5 秒**：向右移动到单元格 `(1, 2)`，进入成本为 `(1 + 1) * (2 + 1) = 6`。

因此，总成本为 `1 + 2 + 1 + 4 + 2 + 6 = 16`。

**提示：**

- `1 <= m, n <= 105`
- `2 <= m * n <= 105`
- `waitCost.length == m`
- `waitCost[0].length == n`
- `0 <= waitCost[i][j] <= 105`

## 0.2 Notes

### 0.2.1 核心思路

题目要求交替进行：**奇数秒移动**（右/下），**偶数秒等待**（原地等待 1 秒，支付 `waitCost[i][j]`）。

这意味着：**每进入一个格子后，必须在该格子等待 1 秒才能进行下一次移动。**

但有两个例外：
- **起点 `(0, 0)`**：从第 1 秒直接进入，不需要先等待。
- **终点 `(m-1, n-1)`**：到达后即结束，不需要再等待。

因此：
- 常规格子的总代价 = **进入成本** `(i+1)*(j+1)` + **等待成本** `waitCost[i][j]`
- 起点：只有进入成本 `1`，无等待成本
- 终点：最后一步不需要等待，所以 DP 结果要**减去终点的 waitCost**

### 0.2.2 状态定义

`dp[i][j]` = 从 `(0,0)` 出发，到达 `(i,j)` 的**最小累计代价**（假设所有格子都加了 waitCost）。

### 0.2.3 状态转移

由于只能向右或向下移动，到达 `(i,j)` 只能从上方 `(i-1,j)` 或左方 `(i,j-1)` 来：

`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + (i+1)*(j+1) + waitCost[i][j]`

最终答案：`dp[m-1][n-1] - waitCost[m-1][n-1]`

### 0.2.4 复杂度

- 时间复杂度：`O(m*n)`，每个格子计算一次
- 空间复杂度：方法二 `O(m*n)`，可优化为 `O(n)`（仅需前一行）

## 0.3 Solution

### 0.3.1 方法一：记忆化搜索（自顶向下）

```python
class Solution:
    def minCost(self, m: int, n: int, waitCost: List[List[int]]) -> int:
        # 记忆化搜索（自顶向下 DP）
        @cache
        def dfs(i: int, j: int) -> int:
            if i == 0 and j == 0:
                # 起点：只有进入成本 (0+1)*(0+1) = 1，无需等待
                return 1
            if i < 0 or j < 0:
                return inf
            
            # 从上方或左方转移而来
            # 每进入一个格子，都要加进入成本 + 等待成本
            return min(dfs(i - 1, j), dfs(i, j - 1)) + (i + 1) * (j + 1) + waitCost[i][j]

        # 终点的 waitCost 不需要支付（到达即结束），减去修正
        return dfs(m - 1, n - 1) - waitCost[-1][-1]
```

### 0.3.2 方法二：递推 DP（自底向上）

```python
class Solution:
    def minCost(self, m: int, n: int, waitCost: List[List[int]]) -> int:
        dp = [[0] * n for _ in range(m)]
        dp[0][0] = 1  # 起点
        
        # 第一列（只能从上方来）：j=0 时进入成本 = (i+1)*1 = i+1
        for i in range(1, m):
            dp[i][0] = dp[i - 1][0] + (i + 1) + waitCost[i][0]
        
        # 第一行（只能从左方来）：i=0 时进入成本 = 1*(j+1) = j+1
        for j in range(1, n):
            dp[0][j] = dp[0][j - 1] + (j + 1) + waitCost[0][j]
        
        # 其余格子：从上方或左方取 min
        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + (i + 1) * (j + 1) + waitCost[i][j]
        
        # 终点的 waitCost 不需要支付（到达即结束），减去修正
        return dp[-1][-1] - waitCost[-1][-1]
```
