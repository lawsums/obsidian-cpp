## 0.1 1989.两个数组最小的异或值之和

给你两个整数数组 `nums1` 和 `nums2` ，它们长度都为 `n` 。

两个数组的 **异或值之和** 为 `(nums1[0] XOR nums2[0]) + (nums1[1] XOR nums2[1]) + ... + (nums1[n - 1] XOR nums2[n - 1])` （**下标从 0 开始**）。

- 比方说，`[1,2,3]` 和 `[3,2,1]` 的 **异或值之和** 等于 `(1 XOR 3) + (2 XOR 2) + (3 XOR 1) = 2 + 0 + 2 = 4` 。

请你将 `nums2` 中的元素重新排列，使得 **异或值之和** **最小** 。

请你返回重新排列之后的 **异或值之和** 。

**示例 1：**
**输入：**nums1 = [1,2], nums2 = [2,3]
**输出：**2
**解释：**将 `nums2` 重新排列得到 `[3,2] 。`
异或值之和为 (1 XOR 3) + (2 XOR 2) = 2 + 0 = 2 。

**示例 2：**
**输入：**nums1 = [1,0,3], nums2 = [5,3,4]
**输出：**8
**解释：**将 `nums2 重新排列得到` `[5,4,3] 。`
异或值之和为 (1 XOR 5) + (0 XOR 4) + (3 XOR 3) = 4 + 4 + 0 = 8 。

**提示：**
- `n == nums1.length`
- `n == nums2.length`
- `1 <= n <= 14`
- `0 <= nums1[i], nums2[i] <= 107`

## 0.2 Notes

### 0.2.1 思路：状态压缩 DP（位掩码）

**核心思想**：`n ≤ 14`，把 `nums2` 重新排列等价于给 `nums1` 的每个下标匹配一个 `nums2` 的元素。用一个 `n` 位二进制数 `mask` 记录匹配状态：

- `mask` 的第 `j` 位为 `1`，表示 `nums2[j]` 已经被选走
- `mask` 中 `1` 的个数 `mask.bit_count()`，就是已经匹配好的元素个数

**为什么能省去一维？**
解法一 `dfs(i, mask)` 同时记录「当前匹配 `nums1` 的第几个元素」和「`nums2` 的选择状态」。
但 `i` 其实可以由 `mask` 直接推出：**既然总是按顺序匹配 `nums1`，已经选走 `i` 个元素，说明 `nums1[0..i-1]` 都已匹配完**，所以 `i = mask.bit_count()`。于是状态压缩成一维 `dfs(mask)`。

**状态转移**：
```
dfs(mask) = min_{j 未被选择} ( nums1[i] ^ nums2[j] + dfs(mask | (1 << j)) )
```
其中 `i = mask.bit_count()`，`j` 遍历所有 `mask` 中为 `0` 的位。

**边界**：`mask == u`（所有元素都已匹配）时返回 `0`。

**复杂度**：状态数 `2^n`，每个状态枚举 `n` 个 `j`，总复杂度 `O(n · 2^n)`。`n = 14` 时 `2^14 = 16384`，很快。

## 0.3 Solution 

### 0.3.1 解法一：`dfs(i, mask)`（两维状态）

```python
class Solution:
    def minimumXORSum(self, nums1: List[int], nums2: List[int]) -> int:
        # 1 <= n <= 14
        # n <= 10 回溯型 n!
        # n <= 20 状态压缩型 dp 2^n, 2^20 = 10^6
        n = len(nums1)
        u = (1 << n) - 1

        @cache
        def dfs(i: int, mask: int) -> int:
            # 边界条件
            if i == n or mask == u:
                return 0

            res = inf
            for j in range(n):
                # 说明可以选
                if ((mask >> j) & 1) == 0:
                    # 注意：Python 中加号优先级高于异或符号
                    xor_res = nums1[i] ^ nums2[j]
                    res = min(res,
                              xor_res + dfs(i + 1, mask | (1 << j)))

            return res

        return dfs(0, 0)
```

### 0.3.2 解法二：`dfs(mask)`（一维状态，更优）

`i` 由 `mask` 推导：`i = mask.bit_count()`

```python
class Solution:
    def minimumXORSum(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        u = (1 << n) - 1

        @cache
        def dfs(mask: int) -> int:
            # 边界条件：所有 nums1 的元素都已匹配
            if mask == u:
                return 0

            # i 表示当前要匹配 nums1 中的哪个元素
            i = mask.bit_count()

            res = inf
            for j in range(n):
                if ((mask >> j) & 1) == 0:
                    xor_res = nums1[i] ^ nums2[j]
                    res = min(res, xor_res + dfs(mask | (1 << j)))

            return res

        return dfs(0)
```
