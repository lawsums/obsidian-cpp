## 0.1 3438.数组中的峰值

数组 `arr` 中 **大于** 前面和后面相邻元素的元素被称为 **峰值** 元素。

给你一个整数数组 `nums` 和一个二维整数数组 `queries` 。

你需要处理以下两种类型的操作：

- `queries[i] = [1, li, ri]` ，求出子数组 `nums[li..ri]` 中 **峰值** 元素的数目。
- `queries[i] = [2, indexi, vali]` ，将 `nums[indexi]` 变为 `vali` 。

请你返回一个数组 `answer` ，它依次包含每一个第一种操作的答案。

**注意：**

- 子数组中 **第一个** 和 **最后一个** 元素都 **不是** 峰值元素。

**示例 1：**

**输入：**nums = [3,1,4,2,5], queries = [[2,3,4],[1,0,4]]

**输出：**[0]

**解释：**

第一个操作：我们将 `nums[3]` 变为 4 ，`nums` 变为 `[3,1,4,4,5]` 。

第二个操作：`[3,1,4,4,5]` 中峰值元素的数目为 0 。

**示例 2：**

**输入：**nums = [4,1,4,2,1,5], queries = [[2,2,4],[1,0,2],[1,0,4]]

**输出：**[0,1]

**解释：**

第一个操作：`nums[2]` 变为 4 ，它已经是 4 了，所以保持不变。

第二个操作：`[4,1,4]` 中峰值元素的数目为 0 。

第三个操作：第二个 4 是 `[4,1,4,2,1]` 中的峰值元素。

**提示：**

- `3 <= nums.length <= 105`
- `1 <= nums[i] <= 105`
- `1 <= queries.length <= 105`
- `queries[i][0] == 1` 或者 `queries[i][0] == 2`
- 对于所有的 `i` ，都有：
    - `queries[i][0] == 1` ：`0 <= queries[i][1] <= queries[i][2] <= nums.length - 1`
    - `queries[i][0] == 2` ：`0 <= queries[i][1] <= nums.length - 1`, `1 <= queries[i][2] <= 105`

## 0.2 Notes

### 0.2.1 为什么模板只需要这几个方法

模板只有三个方法：

- `update(i, val)`：单点修改，`tree[i] += val`
- `pre(i)`：求前缀和 `[1..i]`
- `query(l, r)`：区间和，本质就是前缀和差分 `pre(r) - pre(l - 1)`

所以 `query` 不是新东西，`pre` 就是前缀和。**真正的核心是 `update` 和 `pre` 里的两个位运算**：

- `lowbit(x) = x & -x`：取出 x 二进制最低位的 1（如 `12 = 1100₂`，`12 & -12 = 4 = 100₂`）。注意是**按位与**，不是除法
- `update` 里 `i += lowbit(i)`：沿树向上跳到下一个覆盖 i 的节点
- `pre` 里 `i -= lowbit(i)`（等价 `i &= i - 1`，清掉最低位的 1）：把前缀 `[1..i]` 从后往前拆段累加

为什么这样就对了：`tree[i]` 的定义是存区间 `[i - lowbit(i) + 1, i]` 的和，即以 i 结尾、长度为 `lowbit(i)` 的一段。

- 前缀 `[1..i]` 恰好能拆成 O(log n) 段：`i → i - lowbit(i) → …`，所以 `pre` 是 O(log n)
- 更新位置 p 时，所有覆盖 p 的 tree 节点恰好是 `p → p + lowbit(p) → …`，也只有 O(log n) 个
- 正是 lowbit 的"对齐/倍增"特性让这两种跳法都 O(log n)，这就是树状数组的核心性质

### 0.2.2 使用树状数组的标准流程

1. **创建**：`t = FenwickTree(n)`（内部开 `n + 1`，索引 1-based）
2. **初始化**：把初始信息逐个 `update` 进去。不初始化的话树里全是 0，查询必然不对
   - 本题：遍历每个位置，`is_peak(i)` 为真就 `update(i + 1, 1)`，树里存的是"峰值指示数组"（峰值 = 1，否则 = 0）
   - 最标准的单点修改/区间查询题：`for i: update(i, a[i])`，把原数组直接建进去
3. **处理查询**：遍历 queries，更新用 `update`，查询用 `query`，其余逻辑全部写在外部

### 0.2.3 update / query 需要改吗

基本不用改，绝大多数题目只需改**外部使用方式**：

- 区间修改 + 单点查询：用差分思想，区间加 = 两次 `update`，点查 = `pre`，方法本身不动
- 区间修改 + 区间查询：需要两个树状数组（差分 + 加权差分），方法仍不动
- 值域建树（如 315. 计算右侧小于当前元素的个数）：先离散化/偏移，`update`/`query` 不用改
- 求第 k 小：在模板上**新增**一个树上二分方法，原有 `update`/`pre` 依然不动

真正不能用的情况：合并运算**不可逆**（如区间最大值/最小值），前缀差分 `pre(r) - pre(l - 1)` 失效，此时换线段树。

结论：模板方法几乎不改，变化都在外部逻辑；只有运算性质变了才换数据结构。

### 0.2.4 本题细节：先删后加的峰值状态更新

- 提取 `is_peak(i)`：`0 < i < n - 1 and nums[i - 1] < nums[i] > nums[i + 1]`，把峰值判定收敛到一个函数
- 树状数组维护的不是原数组，而是"峰值指示数组"，区间峰值数 = 指示数组的区间和
- 查询 `[l, r]`：子数组首尾不可能是峰值 → 有效范围 `[l + 1, r - 1]`，1-based 即 `query(l + 2, r)`
- 更新 `nums[ind] = val` 的妙处：只有 `ind - 1, ind, ind + 1` 三个位置的峰值状态会受影响，于是：
  1. **先删旧**：对这三个位置，若当前是峰值，`update(pos + 1, -1)`
  2. **改值**：`nums[ind] = val`
  3. **后加新**：对这三个位置，若现在是峰值，`update(pos + 1, 1)`
- 好处：不用枚举"旧峰→非峰、非峰→新峰"等转移，统一用"删旧贡献 + 加新贡献"两轮扫描，只需一个 `is_peak` 函数，逻辑大幅简化
- 推广：凡"单点修改只影响 O(1) 个相邻位置状态"的问题（相邻关系、连续段、峰值等），都能套这个先删后加套路


## 0.3 Solution 
```python
class FenwickTree:
    def __init__(self, n: int):
        self.tree = [0] * (n + 1)

    def update(self, i: int, val: int) -> None:
        t = self.tree
        while i < len(t):
            t[i] += val
            i += i & -i

    def pre(self, i: int) -> int:
        t = self.tree
        res = 0
        while i > 0:
            res += t[i]
            i &= i - 1
        return res

    def query(self, l: int, r: int) -> int:
        if r < l:
            return 0
        return self.pre(r) - self.pre(l - 1)

class Solution:
    def countOfPeaks(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        n = len(nums)
        t = FenwickTree(n)

        # 辅助函数：判断 0-based 索引 i 是否为峰值
        def is_peak(i: int) -> bool:
            return 0 < i < n - 1 and nums[i - 1] < nums[i] > nums[i + 1]

        # 1. 初始化树状数组
        for i in range(1, n - 1):
            if is_peak(i):
                t.update(i + 1, 1)  # 转换为 1-based 索引

        ans = []
        for tp, op1, op2 in queries:
            if tp == 1:
                # 2. 查询区间：实际有效峰值区间为 0-based 的 [op1 + 1, op2 - 1]
                # 转换为 1-based 即为 [op1 + 2, op2]
                ans.append(t.query(op1 + 2, op2))
            else:
                ind, val = op1, op2
                
                # 3. 简化的更新逻辑：先减去旧状态
                for i in (ind - 1, ind, ind + 1):
                    if is_peak(i):
                        t.update(i + 1, -1)
                        
                # 修改数组值
                nums[ind] = val
                
                # 加上新状态
                for i in (ind - 1, ind, ind + 1):
                    if is_peak(i):
                        t.update(i + 1, 1)

        return ans
```
