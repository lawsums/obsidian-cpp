## 0.1 3350.将元素分配到两个数组中 II

给你一个下标从 **1** 开始、长度为 `n` 的整数数组 `nums` 。

现定义函数 `greaterCount` ，使得 `greaterCount(arr, val)` 返回数组 `arr` 中 **严格大于** `val` 的元素数量。

你需要使用 `n` 次操作，将 `nums` 的所有元素分配到两个数组 `arr1` 和 `arr2` 中。在第一次操作中，将 `nums[1]` 追加到 `arr1` 。在第二次操作中，将 `nums[2]` 追加到 `arr2` 。之后，在第 `i` 次操作中：

- 如果 `greaterCount(arr1, nums[i]) > greaterCount(arr2, nums[i])` ，将 `nums[i]` 追加到 `arr1` 。
- 如果 `greaterCount(arr1, nums[i]) < greaterCount(arr2, nums[i])` ，将 `nums[i]` 追加到 `arr2` 。
- 如果 `greaterCount(arr1, nums[i]) == greaterCount(arr2, nums[i])` ，将 `nums[i]` 追加到元素数量较少的数组中。
- 如果仍然相等，那么将 `nums[i]` 追加到 `arr1` 。

连接数组 `arr1` 和 `arr2` 形成数组 `result` 。例如，如果 `arr1 == [1,2,3]` 且 `arr2 == [4,5,6]` ，那么 `result = [1,2,3,4,5,6]` 。

返回整数数组 `result` 。

**示例 1：**

**输入：**nums = [2,1,3,3]
**输出：**[2,3,1,3]
**解释：**在前两次操作后，arr1 = [2] ，arr2 = [1] 。
在第 3 次操作中，两个数组中大于 3 的元素数量都是零，并且长度相等，因此，将 nums[3] 追加到 arr1 。
在第 4 次操作中，两个数组中大于 3 的元素数量都是零，但 arr2 的长度较小，因此，将 nums[4] 追加到 arr2 。
在 4 次操作后，arr1 = [2,3] ，arr2 = [1,3] 。
因此，连接形成的数组 result 是 [2,3,1,3] 。

**示例 2：**

**输入：**nums = [5,14,3,1,2]
**输出：**[5,3,1,2,14]
**解释：**在前两次操作后，arr1 = [5] ，arr2 = [14] 。
在第 3 次操作中，两个数组中大于 3 的元素数量都是一，并且长度相等，因此，将 nums[3] 追加到 arr1 。
在第 4 次操作中，arr1 中大于 1 的元素数量大于 arr2 中的数量（2 > 1），因此，将 nums[4] 追加到 arr1 。
在第 5 次操作中，arr1 中大于 2 的元素数量大于 arr2 中的数量（2 > 1），因此，将 nums[5] 追加到 arr1 。
在 5 次操作后，arr1 = [5,3,1,2] ，arr2 = [14] 。
因此，连接形成的数组 result 是 [5,3,1,2,14] 。

**示例 3：**

**输入：**nums = [3,3,3,3]
**输出：**[3,3,3,3]
**解释：**在 4 次操作后，arr1 = [3,3] ，arr2 = [3,3] 。
因此，连接形成的数组 result 是 [3,3,3,3] 。

**提示：**

- `3 <= n <= 105`
- `1 <= nums[i] <= 109`

## 0.2 Notes

核心思路：==树状数组== + ==离散化== + 分情况模拟。

- 数值值域较大（`nums[i] <= 10^9`），所以需要==离散化==：对数组==去重并排序==，构建一个==反向映射字典==，把数值从小到大映射到 `0, 1, 2, ...` 这个序列上。
- 两个数组各维护一棵树状数组，每次==更新的是这个离散值对应的位置==——记录该值当前有多少个元素。
- 求**比它大的有多少个**：直接用 ==总共有多少个元素 − 小于等于它的元素个数== 来算，而小于等于它的个数用树状数组的 ==`pre`==（前缀查询）实现。
- 剩下的就是==分情况模拟==：
  - `greater1 > greater2` → 加入 `arr1`
  - `greater1 < greater2` → 加入 `arr2`
  - 相等 → 加入长度较小的那个数组；长度也相等 → 加入 `arr1`
- 最后实现两个更新函数 `update1` / `update2`（各自负责 append + 树状数组更新 + 计数自增）来==去耦合==。

## 0.3 Solution 
```python
class FenwickTree:
    def __init__(self, n: int):
        self.tree = [0] * (n + 1)

    def update(self, i: int, val: int) -> None:
        # 树状数组的下标从 1 开始，所以这里需要 i + 1
        i += 1 
        while i < len(self.tree):
            self.tree[i] += val
            i += i & -i

    def pre(self, i: int) -> int:
        # 同样，查询时下标也需要 +1
        i += 1
        res = 0
        while i > 0:
            res += self.tree[i]
            i &= i - 1
        return res

class Solution:
    def resultArray(self, nums: List[int]) -> List[int]:
        # 1. 离散化
        unique_nums = sorted(set(nums))
        # 建立值到索引的映射
        val_to_idx = {val: i for i, val in enumerate(unique_nums)}
        
        n = len(unique_nums)
        t1 = FenwickTree(n)
        t2 = FenwickTree(n)
        
        # 初始化两个数组和树状数组
        nums1 = [nums[0]]
        nums2 = [nums[1]]
        t1.update(val_to_idx[nums[0]], 1)
        t2.update(val_to_idx[nums[1]], 1)
        
        # 使用 nonlocal 声明，以便在内部函数中修改外部变量
        cnt1, cnt2 = 1, 1

        def update1(num):
            nonlocal cnt1
            nums1.append(num)
            t1.update(val_to_idx[num], 1)
            cnt1 += 1
    
        def update2(num):
            nonlocal cnt2
            nums2.append(num)
            t2.update(val_to_idx[num], 1)
            cnt2 += 1

        # 2. 模拟过程
        for i in range(2, len(nums)):
            num = nums[i]
            # 查询离散化后的索引
            idx = val_to_idx[num]
            
            # 计算大于当前数字的元素个数
            # t.pre(idx) 得到的是小于等于当前数字的元素个数
            greater1 = cnt1 - t1.pre(idx)
            greater2 = cnt2 - t2.pre(idx)

            if greater1 > greater2:
                update1(num)
            elif greater1 < greater2:
                update2(num)
            else:
                # 如果大于的数目相同，则比较数组长度
                if cnt2 < cnt1:
                    update2(num)
                else:
                    update1(num)
        
        return nums1 + nums2
```
