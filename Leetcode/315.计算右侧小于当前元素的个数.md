## 0.1 315.计算右侧小于当前元素的个数

给你一个整数数组 `nums` ，按要求返回一个新数组 `counts` 。数组 `counts` 有该性质： `counts[i]` 的值是  `nums[i]` 右侧小于 `nums[i]` 的元素的数量。

**示例 1：**

**输入：**nums = [5,2,6,1]
**输出：**`[2,1,1,0]  **解释：**`
5 的右侧有 **2** 个更小的元素 (2 和 1)
2 的右侧仅有 **1** 个更小的元素 (1)
6 的右侧有 **1** 个更小的元素 (1)
1 的右侧有 **0** 个更小的元素

**示例 2：**

**输入：**nums = [-1]
**输出：**[0]

**示例 3：**

**输入：**nums = [-1,-1]
**输出：**[0,0]

**提示：**

- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`

## 0.2 Notes
这是一个==归并排序==统计==逆序数==类型的问题

``` python
from typing import List

class Solution:
    def countSmaller(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [0] * n
        index = list(range(n))
        
        def mergesort(left, right):
            if left >= right:
                return
            mid = (left + right) // 2
            mergesort(left, mid)
            mergesort(mid + 1, right)
            merge(left, mid, right)

        def merge(l, m, r):
            tmp = []
            tmp_idx = []
            p1, p2 = l, m + 1
            offset = 0
            
            while p1 <= m and p2 <= r:
                if nums[p1] <= nums[p2]:
                    tmp.append(nums[p1])
                    tmp_idx.append(index[p1])
                    ans[index[p1]] += offset
                    p1 += 1
                else:
                    tmp.append(nums[p2])
                    tmp_idx.append(index[p2])
                    p2 += 1
                    offset += 1
            
            while p1 <= m:
                tmp.append(nums[p1])
                tmp_idx.append(index[p1])
                ans[index[p1]] += offset
                p1 += 1
            
            while p2 <= r:
                tmp.append(nums[p2])
                tmp_idx.append(index[p2])
                p2 += 1
            
            # 覆盖回原数组
            nums[l:r+1] = tmp
            index[l:r+1] = tmp_idx

        mergesort(0, n - 1)
        return ans
```
