## 0.1 3799.不同三位偶数的数目

给你一个数字数组 `digits`，你需要从中选择三个数字组成一个三位偶数，你的任务是求出 **不同** 三位偶数的数量。

**注意**：每个数字在三位偶数中都只能使用 **一次** ，并且 **不能** 有前导零。

**示例 1：**

**输入：** digits = [1,2,3,4]

**输出：** 12

**解释：** 可以形成的 12 个不同的三位偶数是 124，132，134，142，214，234，312，314，324，342，412 和 432。注意，不能形成 222，因为数字 2 只有一个。

**示例 2：**

**输入：** digits = [0,2,2]

**输出：** 2

**解释：** 可以形成的三位偶数是 202 和 220。注意，数字 2 可以使用两次，因为数组中有两个 2 。

**示例 3：**

**输入：** digits = [6,6,6]

**输出：** 1

**解释：** 只能形成 666。

**示例 4：**

**输入：** digits = [1,3,5]

**输出：** 0

**解释：** 无法形成三位偶数。

**提示：**

- `3 <= digits.length <= 10`
- `0 <= digits[i] <= 9`

## 0.2 Notes

### 0.2.1 核心思路：回溯枚举 + 集合去重

从 `digits` 中选出 ==3 个不同下标==的数字，按选取顺序拼成一个三位数。用 `visit` 标记下标是否已用过，`path` 维护当前拼出的数字，走到第 3 位时收集结果，再回溯撤销。

- **为什么用 `set` 去重**：`digits` 里可能有重复数字，不同下标组合也可能拼出同一个数（如 `[1,2,3,4]` 只能得到 132 一种下标组合，但重复数字会产生重复结果），用 `set` 保证==不同的三位数只计一次==，最后返回 `len(s)`。
- **按下标去重而非按值**：`visit` 是按==下标==标记的，所以 `[0,2,2]` 里的两个 2 可以各用一次，得到 202、220 两个数，符合题意。

### 0.2.2 关键剪枝与细节

- ==前导零剪枝==：`if digits[j] == 0 and path == 0: continue`。`path == 0` 表示当前还是空路径（即将填最高位），此时选 0 会形成前导零，直接跳过。
- ==偶数判定==：只在凑满 3 位时检查 `path % 2 == 0`，是偶数才 `s.add(path)`。
- ==回溯维护 `path`==：进入时 `path = path * 10 + digits[j]`，回溯时 `path //= 10` 撤销，两者严格配对（`nonlocal path`）。
- 终止条件写成 `i == min(3, n)`：本题 `n >= 3`，实际等价于 `i == 3`；`min(3, n)` 是对 `n < 3` 的兜底。

### 0.2.3 复杂度分析

| 指标 | 值 | 说明 |
| --- | --- | --- |
| 时间复杂度 | O(n³) | 每层枚举 n 个下标，共 3 层，`n ≤ 10` 时最多约 720 种排列 |
| 空间复杂度 | O(n) | 递归深度最多 3，`visit` 长度 n，另加 `set` 存放答案 |

### 0.2.4 其他思路（可选）

- ==三重循环暴力==：枚举三个下标 `i < j < k`，再去重排序——判重反而更麻烦，不如回溯干净；
- ==直接枚举三位偶数==：遍历 `100 ~ 998` 的所有偶数，逐个判断能否由 `digits` 拼出（要正确处理重复数字的计数），思路最直观。

## 0.3 Solution 
```python
import inspect
import re

DEBUG = 0  # 提交时改成 0 即可关闭所有日志

def _get_var_names(stack_depth=2):
    """提取 LV(x, y, z) 括号中的原始变量名字符串"""
    try:
        stack = inspect.stack()
        frame = stack[stack_depth]
        s = frame.code_context[0].strip()
        # 匹配 LV(...) 内部的内容，支持内部带括号（如函数调用或元组）的简单匹配
        m = re.search(r"LV\s*\((.*)\)", s)
        if m:
            # 按照逗号分割变量名，但排除掉被嵌套括号包围的逗号
            content = m.group(1)
            # 简单的逗号分割（如果参数里有复杂的带逗号表达式，可用更高级的正则，通常够用）
            names = [name.strip() for name in content.split(",")]
            return names
        return []
    except:
        return []

def _fmt(obj):
    if isinstance(obj, list):
        if obj and isinstance(obj[0], list):
            return "\n[" + ", \n".join(str(x) for x in obj) + "]"
        else:
            return "[" + ", ".join(str(x) for x in obj) + "]"
    elif isinstance(obj, dict):
        return "{" + ", ".join(f"{k}: {v}" for k, v in obj.items()) + "}"
    elif isinstance(obj, tuple):
        return "(" + ", ".join(str(x) for x in obj) + ")"
    return str(obj)

if DEBUG:
    def LOG(x):
        print(f"[DEBUG] {x}")
    def LOG_V(name, val):
        print(f"[DEBUG] {name}: {_fmt(val)}")
    def LV(*args):
        # 获取调用者的变量名列表
        names = _get_var_names(stack_depth=2)
        # 构造打印字符串
        parts = []
        for i, val in enumerate(args):
            # 如果解析出的变量名数量不够，用 '?' 代替
            name = names[i] if i < len(names) else "?"
            parts.append(f"{name}={_fmt(val)}")
        # 用 C++ 类似的 " | " 拼接起来
        print(f"[DEBUG] {' | '.join(parts)}")
else:
    def LOG(x):
        pass
    def LOG_V(name, val):
        pass
    def LV(*args):
        pass

class Solution:
    def totalNumbers(self, digits: List[int]) -> int:
        n = len(digits)   
        visit = [False for _ in range(n)]
        s = set() 
        path = 0

        def dfs(i):
            nonlocal path

            if i == min(3, n):
                if i == 3 and path % 2 == 0:
                    s.add(path)
                return

            # 回溯
            for j in range(n):
                if not visit[j]:
                    if digits[j] == 0 and path == 0:
                        continue
                    visit[j] = True
                    path = path * 10 + digits[j]

                    dfs(i + 1)

                    visit[j] = False
                    path //= 10

        dfs(0)
        LV(s)
        return len(s)
        # return list(s)
```
