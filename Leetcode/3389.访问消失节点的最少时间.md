## 0.1 3389.访问消失节点的最少时间

给你一个二维数组 `edges` 表示一个 `n` 个点的无向图，其中 `edges[i] = [ui, vi, lengthi]` 表示节点 `ui` 和节点 `vi` 之间有一条需要 `lengthi` 单位时间通过的无向边。

同时给你一个数组 `disappear` ，其中 `disappear[i]` 表示节点 `i` 从图中消失的时间点，在那一刻及以后，你无法再访问这个节点。

**注意**，图有可能一开始是不连通的，两个节点之间也可能有多条边。

请你返回数组 `answer` ，`answer[i]` 表示从节点 `0` 到节点 `i` 需要的 **最少** 单位时间。如果从节点 `0` 出发 **无法** 到达节点 `i` ，那么 `answer[i]` 为 `-1` 。

**示例 1：**

![](https://assets.leetcode.com/uploads/2024/03/09/example1.png)

**输入：**n = 3, edges = [[0,1,2],[1,2,1],[0,2,4]], disappear = [1,1,5]

**输出：**[0,-1,4]

**解释：**

我们从节点 0 出发，目的是用最少的时间在其他节点消失之前到达它们。

- 对于节点 0 ，我们不需要任何时间，因为它就是我们的起点。
- 对于节点 1 ，我们需要至少 2 单位时间，通过 `edges[0]` 到达。但当我们到达的时候，它已经消失了，所以我们无法到达它。
- 对于节点 2 ，我们需要至少 4 单位时间，通过 `edges[2]` 到达。

**示例 2：**

![](https://assets.leetcode.com/uploads/2024/03/09/example2.png)

**输入：**n = 3, edges = [[0,1,2],[1,2,1],[0,2,4]], disappear = [1,3,5]

**输出：**[0,2,3]

**解释：**

我们从节点 0 出发，目的是用最少的时间在其他节点消失之前到达它们。

- 对于节点 0 ，我们不需要任何时间，因为它就是我们的起点。
- 对于节点 1 ，我们需要至少 2 单位时间，通过 `edges[0]` 到达。
- 对于节点 2 ，我们需要至少 3 单位时间，通过 `edges[0]` 和 `edges[1]` 到达。

**示例 3：**

**输入：**n = 2, edges = [[0,1,1]], disappear = [1,1]

**输出：**[0,-1]

**解释：**

当我们到达节点 1 的时候，它恰好消失，所以我们无法到达节点 1 。

**提示：**

- `1 <= n <= 5 * 104`
- `0 <= edges.length <= 105`
- `edges[i] == [ui, vi, lengthi]`
- `0 <= ui, vi <= n - 1`
- `1 <= lengthi <= 105`
- `disappear.length == n`
- `1 <= disappear[i] <= 105`

## 0.2 Notes

### 0.2.1 本质

**单源最短路 + 边权非负** → ==Dijkstra + 小根堆==。起点固定为 `0`，求 `0` 到所有点的最少时间；图是**无向图**（`edges[i] = [u, v, w]` 是**无向边**）。
比模板题多一个约束：每个点带**消失时间** `disappear[i]`，在 `disappear[i]` 这一刻及以后无法再访问它。

### 0.2.2 为什么「缺反向边」会出错（本题关键）

`edges[i] = [u, v, w]` 是**无向边**，等价于两条反向的**有向边** `u → v` 与 `v → u`（权都为 `w`）。所以建图时必须 ==两个方向各加一条==：

| 建图方式                                              | 后果                             |
| ------------------------------------------------- | ------------------------------ |
| 只 `g[u].push_back({v, w})`                        | 只剩 `u → v`，`v → u` 这条通路**不存在** |
| `g[u].push_back({v,w})` + `g[v].push_back({u,w})` | 双向可达（正确）                       |

漏掉反向边时，算法本身没算错，而是**它看到的那张图本身就少了一半的边**：

- 从 `0` 出发，很多最短路要先走到某个点、再沿**反向**回到另一个点；少了反向边，这些路径被整条抹掉；
- 结果要么把**本可达的点算成不可达**（`dist` 停在上限 `INT_MAX`，最终返回 `-1`），要么**被迫绕更长的替代路径**（`dist` 偏大）。

> 一句话：==无向图 = 双向有向图。反向边不是「优化」，它是题目的一部分；漏一条边，连出来的图就不是题目给的图了。==

### 0.2.3 节点消失怎么处理

出堆即定案：某点 `u` 以距离 `d` 第一次从堆里弹出时，`d` 就是「不再受其他点影响」的最短到达时间。此时判断：

- `d < disappear[u]` → 在消失前赶到，正常用它去松弛邻居；
- `d >= disappear[u]` → 到达时（或更早）已经消失，==该点作废==，记为 `-1`，**不再向外松弛**（经由它中转的路径也不成立）。

> 判据是 `>=`：`disappear[i]` 那一刻及以后都不能访问，所以「刚好压线」也算失败。

### 0.2.4 复杂度

| 项 | 复杂度 | 说明 |
| --- | --- | --- |
| 时间 | `O(m log m)` | `m` 为边数；无向图每条边存两次；每点 / 边最多入堆一次，每次堆操作 `log m` |
| 空间 | `O(n + m)` | 邻接表 + `dist` + `visited` + 小根堆 |

## 0.3 Solution 

**解法一：Dijkstra + 小根堆（无向图双向建边）—— 本笔记做法**

```cpp
class Solution {
private:
    vector<vector<pair<int, int>>> g;

public:
    void build(vector<vector<int>>& edges, int n) {
        g.assign(n, vector<pair<int, int>>{});
        for (auto &edge : edges) {
            auto u = edge[0], v = edge[1], w = edge[2];
            g[u].push_back({v, w});
            g[v].push_back({u, w});  // 无向图：反向边必须也加，否则图不完整
        }
    }

    vector<int> minimumTime(int n, vector<vector<int>>& edges, vector<int>& disappear) {
        build(edges, n);

        // g[u] = {(v, w), ...}，点编号 0 ~ n-1
        vector<int> dist(n, INT_MAX);
        vector<bool> visited(n, false);
        // 小根堆，按距离升序
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> heap;

        dist[0] = 0;
        heap.push({0, 0});
        while (!heap.empty()) {
            auto [d, u] = heap.top(); heap.pop();
            if (visited[u]) continue;   // 一个点可能被压入多次，旧的记录直接跳过
            visited[u] = true;          // 出堆即定案，d 就是 0→u 的最短路

            if (d >= disappear[u]) {
                // 到达时该点已消失，作废：记 -1，且不再向外松弛
                dist[u] = -1;
                continue;
            }

            for (auto [v, w] : g[u]) {
                if (!visited[v] && d + w < dist[v]) {
                    dist[v] = d + w;
                    heap.push({dist[v], v});
                }
            }
        }

        // 到最后仍是 INT_MAX 的，说明无法到达
        for (auto &d : dist) {
            if (d == INT_MAX) {
                d = -1;
            }
        }

        return dist;
    }
};
```
