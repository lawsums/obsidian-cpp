## 0.1 1772.通过指令创建有序数组

给你一个整数数组 `instructions` ，你需要根据 `instructions` 中的元素创建一个有序数组。一开始你有一个空的数组 `nums` ，你需要 **从左到右** 遍历 `instructions` 中的元素，将它们依次插入 `nums` 数组中。每一次插入操作的 **代价** 是以下两者的 **较小值** ：

- `nums` 中 **严格小于**  `instructions[i]` 的数字数目。
- `nums` 中 **严格大于**  `instructions[i]` 的数字数目。

比方说，如果要将 `3` 插入到 `nums = [1,2,3,5]` ，那么插入操作的 **代价** 为 `min(2, 1)` (元素 `1` 和  `2` 小于 `3` ，元素 `5` 大于 `3` ），插入后 `nums` 变成 `[1,2,3,3,5]` 。

请你返回将 `instructions` 中所有元素依次插入 `nums` 后的 **总最小代价** 。由于答案会很大，请将它对 `109 + 7` **取余** 后返回。

**输入：**instructions = [1,5,6,2]
**输出：**1
**解释：**一开始 nums = [] 。
插入 1 ，代价为 min(0, 0) = 0 ，现在 nums = [1] 。
插入 5 ，代价为 min(1, 0) = 0 ，现在 nums = [1,5] 。
插入 6 ，代价为 min(2, 0) = 0 ，现在 nums = [1,5,6] 。
插入 2 ，代价为 min(1, 2) = 1 ，现在 nums = [1,2,5,6] 。

## 0.2 Notes

### 核心思想

本质上是 **树状数组（Fenwick Tree）的计数模板题**。

我们要对每个 `instructions[i]` 快速求出「已插入元素中**严格小于**它的个数」和「**严格大于**它的个数」，取 min 后累加。这需要一种能**动态插入 + 快速查询前缀和**的数据结构 —— 树状数组正是 O(log n) 的标准选择。

### 树状数组维护的是什么

维护的是一个**计数数组（权值数组/频次数组）**：

- 用下标 `v` 代表数值 `v`；
- `cnt[v]` = 到目前为止，值为 `v` 的已插入数字个数；
- 树状数组对 `cnt` 做两类操作：
  - `update(v, 1)`：插入一个 `v`，即 `cnt[v] += 1`；
  - `pre(x)`：查询前缀和 `cnt[1] + ... + cnt[x]`，即「数值 ≤ x 的数字个数」。

> 容易混淆的点：这里的树状数组存的是**个数**，不是原数组元素本身，所以它叫计数数组 / 权值数组。

### 两个关键量的推导

设当前已插入的总数为 `total`（代码里即 `i + 1`）：

- **严格小于 `x`** = 已插入且数值落在 `[1, x-1]` 的个数 = `pre(x-1)`
- **严格大于 `x`** = 总数 − 小于等于 `x` 的个数 = `total − pre(x)`
  - 因为 `pre(x)` 统计的是「≤ x」，**包含等于 `x` 的部分**，所以用总数减去它，剩下的就是 `> x` 的个数。

于是每次代价：

```
cost += min( pre(x-1),  total - pre(x) )
```

> 这正是「正难则反」：严格大于不用再单独维护一棵树，靠总数反向一减就得到。

### 与代码的对应关系

代码里有一个小细节：树状数组使用 **1-based 下标**，而数值范围是 `1..1e5`，所以把值 `num` 映射到下标 `num + 1`（避开下标 0）：

```python
t.update(num + 1, 1)        # 插入一个 num
t.pre(num)                  # = 严格小于 num 的个数
(i + 1) - t.pre(num + 1)    # = 严格大于 num 的个数
```

| 概念 | 代码 |
| --- | --- |
| 插入一个数 `num` | `t.update(num + 1, 1)` |
| 严格小于 `num` 的个数 | `t.pre(num)`（前缀到 `num` 下标，即值域 `[1, num-1]`） |
| 小于等于 `num` 的个数 | `t.pre(num + 1)` |
| 当前已插入总数 | `i + 1` |
| 严格大于 `num` 的个数 | `(i + 1) - t.pre(num + 1)` |

### 为什么是「先插入，再算代价」

代码里先 `t.update` 再算代价，正好对应题目流程：把 `instructions[i]` **插入后**，再计算这次插入的代价（看它插入位置左侧/右侧各有多少个数）。此时 `i + 1` 才是插入后的总数。

### 复杂度

- 时间：O(n log m)，n = `instructions` 长度，m = 数值范围（本题固定 1e5）
- 空间：O(m)

### 小结

- 树状数组在这里只充当「可动态维护前缀和的计数桶」；
- 难点不在数据结构本身，而在把「严格小于 / 严格大于」翻译成两个前缀和之差：
  - 小于 = `pre(x-1)`
  - 大于 = `total - pre(x)`
- 套模板稍作修改即可 AC，是一道典型的树状数组模板题。


## 0.3 Solution 
```python
MOD = 10**9 + 7

# 模板来源 https://leetcode.cn/circle/discuss/mOr1u6/
class FenwickTree:
    def __init__(self, n: int):
        self.tree = [0] * (n + 1)  # 使用下标 1 到 n

    # a[i] 增加 val
    # 1 <= i <= n
    # 时间复杂度 O(log n)
    def update(self, i: int, val: int) -> None:
        t = self.tree
        while i < len(t):
            t[i] += val
            i += i & -i

    # 计算前缀和 a[1] + ... + a[i]
    # 1 <= i <= n
    # 时间复杂度 O(log n)
    def pre(self, i: int) -> int:
        t = self.tree
        res = 0
        while i > 0:
            res += t[i]
            i &= i - 1
        return res

    # 计算区间和 a[l] + ... + a[r]
    # 1 <= l <= r <= n
    # 时间复杂度 O(log n)
    def query(self, l: int, r: int) -> int:
        if r < l:
            return 0
        return self.pre(r) - self.pre(l - 1)

class Solution:
    def createSortedArray(self, instructions: List[int]) -> int:
        # 这题是同时维护两个树状数组：一个维护严格小于它的，另一个维护严格大于它的。严格大于它的可以通过总数减去严格小于等于它的得到。
        # 所以，这一题实际上是一个维护树状计数数组的问题。
        t = FenwickTree(100001)
        cost = 0
        
        for i, num in enumerate(instructions):
            t.update(num + 1, 1)
            cost = (cost + 
                    min(t.pre(num), (i + 1) - t.pre(num + 1))
                    ) % MOD

        return cost
```
