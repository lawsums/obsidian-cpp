## 0.1 1728.奇妙序列

请你实现三个 API `append`，`addAll` 和 `multAll` 来实现奇妙序列。

请实现 `Fancy` 类 ：

- `Fancy()` 初始化一个空序列对象。
- `void append(val)` 将整数 `val` 添加在序列末尾。
- `void addAll(inc)` 将所有序列中的现有数值都增加 `inc` 。
- `void multAll(m)` 将序列中的所有现有数值都乘以整数 `m` 。
- `int getIndex(idx)` 得到下标为 `idx` 处的数值（下标从 0 开始），并将结果对 `109 + 7` 取余。如果下标大于等于序列的长度，请返回 `-1` 。

**示例：**

**输入：**
["Fancy", "append", "addAll", "append", "multAll", "getIndex", "addAll", "append", "multAll", "getIndex", "getIndex", "getIndex"]
[[], [2], [3], [7], [2], [0], [3], [10], [2], [0], [1], [2]]
**输出：**
[null, null, null, null, null, 10, null, null, null, 26, 34, 20]

**解释：**
Fancy fancy = new Fancy();
fancy.append(2);   // 奇妙序列：[2]
fancy.addAll(3);   // 奇妙序列：[2+3] -> [5]
fancy.append(7);   // 奇妙序列：[5, 7]
fancy.multAll(2);  // 奇妙序列：[5*2, 7*2] -> [10, 14]
fancy.getIndex(0); // 返回 10
fancy.addAll(3);   // 奇妙序列：[10+3, 14+3] -> [13, 17]
fancy.append(10);  // 奇妙序列：[13, 17, 10]
fancy.multAll(2);  // 奇妙序列：[13*2, 17*2, 10*2] -> [26, 34, 20]
fancy.getIndex(0); // 返回 26
fancy.getIndex(1); // 返回 34
fancy.getIndex(2); // 返回 20

**提示：**

- `1 <= val, inc, m <= 100`
- `0 <= idx <= 105`
- 总共最多会有 `105` 次对 `append`，`addAll`，`multAll` 和 `getIndex` 的调用。

## 0.2 Notes

这题主要要理解==费马小定理==, 通过使用费马小定理可以快速求出逆元

### 0.2.1 一、先理解核心背景
在这道题中，我们需要对 `1e9+7`（记为 MOD）取模，而 MOD 是一个**质数**。
- 直接计算大数的幂（比如 `x^(1e9+5)`）会溢出且效率极低，需要**快速幂**优化
- 模运算中没有直接的除法，`a / b mod MOD` 需要转化为 `a * b的逆元 mod MOD`，而质数模数下的逆元可以用**费马小定理**计算

### 0.2.2 二、pow_mod（快速幂）详解
#### 0.2.2.1 功能
快速计算 `(a^b) % MOD`，时间复杂度是 `O(log b)`，而普通循环计算是 `O(b))`，对于 `b=1e9+5` 这种大数，快速幂是唯一可行的方案。

#### 0.2.2.2 原理（二进制拆分）
任何整数 `b` 都可以拆成二进制形式，比如 `b=5`（二进制 `101`），那么：
`a^5 = a^(4+1) = a^4 * a^1`
通过迭代计算 `a^1, a^2, a^4, a^8...`（每次平方），再根据 `b` 的二进制位是否为 1，决定是否乘入结果。

#### 0.2.2.3 逐行解释代码
```cpp
long long pow_mod(long long a, long long b) {
    long long res = 1;  // 结果初始化为1（乘法单位元）
    a %= MOD;           // 先对底数取模，避免a过大溢出
    while (b > 0) {     // 当指数b不为0时循环
        if (b & 1) {    // 检查b的二进制最后一位是否为1（等价于b%2==1）
            // 如果是1，就把当前的a乘到结果里，并取模
            res = (res * a) % MOD;
        }
        a = (a * a) % MOD;  // 底数平方（计算a^2, a^4, a^8...），并取模
        b >>= 1;            // b右移一位（等价于b//2），处理下一位二进制
    }
    return res;
}
```

#### 0.2.2.4 例子（比如计算 3^5 % 7）
- 初始：res=1, a=3, b=5（二进制101）
- 第一次循环：b=5（101），b&1=1 → res=1*3=3；a=3²=9%7=2；b=5>>1=2（10）
- 第二次循环：b=2（10），b&1=0 → 不更新res；a=2²=4%7=4；b=2>>1=1（1）
- 第三次循环：b=1（1），b&1=1 → res=3*4=12%7=5；a=4²=16%7=2；b=1>>1=0
- 结束，返回5（正确，因为3^5=243，243%7=5）

### 0.2.3 三、inv（乘法逆元）详解
#### 0.2.3.1 什么是乘法逆元？
对于模数 MOD，若 `(b * x) % MOD = 1`，则 x 是 b 的乘法逆元，记作 `b⁻¹`。
模运算中，`a / b mod MOD` 等价于 `a * b⁻¹ mod MOD`（这是逆元的核心作用）。

#### 0.2.3.2 费马小定理（求逆元的依据）
当 MOD 是质数，且 b 不是 MOD 的倍数时：
`b^(MOD-1) ≡ 1 (mod MOD)`
两边同时除以 b，得到：
`b^(MOD-2) ≡ b⁻¹ (mod MOD)`
即：**b的逆元 = b^(MOD-2) % MOD**

#### 0.2.3.3 代码解释
```cpp
long long inv(long long x) {
    // 调用快速幂计算x^(MOD-2) % MOD，得到x的逆元
    return pow_mod(x, MOD - 2);
}
```

#### 0.2.3.4 例子（比如求 2 的逆元，MOD=1e9+7）
- 计算 `2^(1e9+7 - 2) % 1e9+7`，结果是 `500000004`
- 验证：`2 * 500000004 = 1000000008`，`1000000008 % 1e9+7 = 1`，符合逆元定义

### 0.2.4 四、在题目中的应用场景
在 `append` 函数中，我们需要计算 `(val - add) / mul mod MOD`，而除法要转化为：
`(val - add) * inv(mul) % MOD`
这里的 `inv(mul)` 就是通过 `pow_mod(mul, MOD-2)` 计算出来的。

### 0.2.5 总结
1. **pow_mod**：通过二进制拆分指数，将幂运算的时间复杂度从 O(b) 降到 O(log b)，解决大数幂取模的效率和溢出问题。
2. **inv**：利用质数模数下的费马小定理，将逆元计算转化为幂运算，解决模运算中无法直接做除法的问题。
3. 两个函数结合，是处理模运算中乘除、大数运算的基础工具，也是这道题能高效实现的核心。

## 0.3 Solution 

![[1728.奇妙序列.cpp]]

```cpp  
#define MOD 1'000'000'007

class Fancy {
private:
    vector<long long> nums;  // 存储反向计算后的数值
    long long add = 0;       // 全局加法偏移量
    long long mul = 1;       // 全局乘法因子

    // 快速幂计算 (a^b) % MOD
    long long pow_mod(long long a, long long b) {
        long long res = 1;
        a %= MOD;
        while (b > 0) {
            if (b & 1) {
                res = (res * a) % MOD;
            }
            a = (a * a) % MOD;
            b >>= 1;
        }
        return res;
    }

    // 计算乘法逆元 (mod为质数，用费马小定理)
    long long inv(long long x) {
        return pow_mod(x, MOD - 2);
    }

public:
    Fancy() {}
    
    void append(int val) {
        // 反向抵消当前的add和mul，得到存储值
        // 公式推导：存储值 * mul + add = val → 存储值 = (val - add) * inv(mul)
        long long num = (val - add + MOD) % MOD;  // 加MOD避免负数
        num = num * inv(mul) % MOD;
        nums.push_back(num);
    }
    
    void addAll(int inc) {
        // 全局加法：所有元素 += inc → 等价于 add += inc
        add = (add + inc) % MOD;
    }
    
    void multAll(int m) {
        // 全局乘法：所有元素 *= m → 等价于 mul *= m, add *= m
        mul = (mul * m) % MOD;
        add = (add * m) % MOD;
    }
    
    int getIndex(int idx) {
        // 下标越界返回-1
        if (idx < 0 || idx >= nums.size()) {
            return -1;
        }
        // 计算真实值：存储值 * mul + add
        long long res = (nums[idx] * mul + add) % MOD;
        return (int)res;
    }
};

/**

 * Fancy* obj = new Fancy();
 * obj->append(val);
 * obj->addAll(inc);
 * obj->multAll(m);
 * int param_4 = obj->getIndex(idx);
 */
```  
