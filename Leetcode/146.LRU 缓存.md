## 0.1 146.LRU 缓存

请你设计并实现一个满足  [LRU (最近最少使用) 缓存](https://baike.baidu.com/item/LRU) 约束的数据结构。

实现 `LRUCache` 类：

- `LRUCache(int capacity)` 以 **正整数** 作为容量 `capacity` 初始化 LRU 缓存
- `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1` 。
- `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value` ；如果不存在，则向缓存中插入该组 `key-value` 。如果插入操作导致关键字数量超过 `capacity` ，则应该 **逐出** 最久未使用的关键字。

函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

**示例：**

**输入**
["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]
**输出**
[null, null, null, 1, null, -1, null, -1, 3, 4]

**解释**
LRUCache lRUCache = new LRUCache(2);
lRUCache.put(1, 1); // 缓存是 {1=1}
lRUCache.put(2, 2); // 缓存是 {1=1, 2=2}
lRUCache.get(1);    // 返回 1
lRUCache.put(3, 3); // 该操作会使得关键字 2 作废，缓存是 {1=1, 3=3}
lRUCache.get(2);    // 返回 -1 (未找到)
lRUCache.put(4, 4); // 该操作会使得关键字 1 作废，缓存是 {4=4, 3=3}
lRUCache.get(1);    // 返回 -1 (未找到)
lRUCache.get(3);    // 返回 3
lRUCache.get(4);    // 返回 4

**提示：**

- `1 <= capacity <= 3000`
- `0 <= key <= 10000`
- `0 <= value <= 105`
- 最多调用 `2 * 105` 次 `get` 和 `put`

## 0.2 Notes
主要要实现几个主方法:
1. 获取 key 对应的节点 value
	1. 更新节点 
2. 加入一个 {key, value} 的节点 
	1. 更新节点 
	2. 驱逐一个节点 (删除一个节点, 删除一个节点对应 key 在 nodeMap 里的位置)

更新节点 :
1. 从 list 中删除 key 对应的节点 (引入一个快速获取 key -> node 的需求)
2. 加入 list 头部

### 0.3.1 std:: list 做法
```cpp  
class LRUCache {
    using Node = pair<int, int>;// key value
    using NodeList = list<Node>;
    using NodeIterator = NodeList::iterator;

private:
    int capacity_;
    NodeList cache;
    unordered_map<int, NodeIterator> nodeMap;// 存储迭代器

public:
    LRUCache(int capacity) : capacity_(capacity) {
    }

    int get(int key) {
        if (!nodeMap.count(key)) return -1;

        // 如果找到了就直接更新
        int value = nodeMap[key]->second;
        update(key, value);
        return value;
    }

    void put(int key, int value) {
        if (nodeMap.count(key)) {
            update(key, value);
        } else {
            checkCapacity();
            insertToHead(key, value);
        }
    }

private:
    void update(int key, int value) {
        auto it = nodeMap[key];
        it->second = value;
        cache.splice(cache.begin(), cache, it);
    }

    void insertToHead(int key, int value) {
        cache.push_front({key, value});
        nodeMap[key] = cache.begin();
    }

    void checkCapacity() {
        if (cache.size() >= capacity_) {
            // 删除一个元素
            int key = cache.back().first;
            cache.pop_back();
            nodeMap.erase(key);
        }
    }
};
```  

### 0.3.2 智能指针做法
```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int key, val;
    shared_ptr<Node> next;
    weak_ptr<Node> prev;

    Node(int k, int v) : key(k), val(v) {}
};

class LRUCacheSmart {
private:
    int capacity_;
    shared_ptr<Node> head, tail;
    unordered_map<int, shared_ptr<Node>> nodeMap;

    // 核心私有方法：和你 STL 版本完全对齐
    void update(int key, int value);
    void checkCapacity();
    void insertToHead(int key, int value);
    void removeNode(shared_ptr<Node> node);
    void addToHead(shared_ptr<Node> node);

public:
    LRUCacheSmart(int capacity) : capacity_(capacity) {
        head = make_shared<Node>(-1, -1);
        tail = make_shared<Node>(-1, -1);
        head->next = tail;
        tail->prev = head;
    }

    int get(int key) {
        if (!nodeMap.count(key)) return -1;
        auto node = nodeMap[key];
        update(key, node->val);
        return node->val;
    }

    void put(int key, int value) {
        if (nodeMap.count(key)) {
            update(key, value);
        } else {
            checkCapacity();
            insertToHead(key, value);
        }
    }
};

// ==================== 私有方法实现 ====================
void LRUCacheSmart::removeNode(shared_ptr<Node> node) {
    auto prev = node->prev.lock();
    auto next = node->next;
    prev->next = next;
    next->prev = node->prev;
}

void LRUCacheSmart::addToHead(shared_ptr<Node> node) {
    node->next = head->next;
    head->next->prev = node;
    node->prev = head;
    head->next = node;
}

// 1. 更新节点值并移到头部（和 STL 版功能一致）
void LRUCacheSmart::update(int key, int value) {
    auto node = nodeMap[key];
    node->val = value;
    removeNode(node);
    addToHead(node);
}

// 2. 检查容量，满了就淘汰（和 STL 版功能一致）
void LRUCacheSmart::checkCapacity() {
    if (nodeMap.size() == capacity_) {
        auto last = tail->prev.lock();
        nodeMap.erase(last->key);
        removeNode(last);
    }
}

// 3. 插入新节点到头部（和 STL 版功能一致）
void LRUCacheSmart::insertToHead(int key, int value) {
    auto newNode = make_shared<Node>(key, value);
    nodeMap[key] = newNode;
    addToHead(newNode);
}
```
