## 0.1 3518.最高乘法得分

给你一个大小为 4 的整数数组 `a` 和一个大小 **至少**为 4 的整数数组 `b`。

你需要从数组 `b` 中选择四个下标 `i0`, `i1`, `i2`, 和 `i3`，并满足 `i0 < i1 < i2 < i3`。你的得分将是 `a[0] * b[i0] + a[1] * b[i1] + a[2] * b[i2] + a[3] * b[i3]` 的值。

返回你能够获得的 **最大** 得分。

**示例 1：**

**输入：** a = [3,2,5,6], b = [2,-6,4,-5,-3,2,-7]

**输出：** 26

**解释：**  
选择下标 0, 1, 2 和 5。得分为 `3 * 2 + 2 * (-6) + 5 * 4 + 6 * 2 = 26`。

**示例 2：**

**输入：** a = [-1,4,5,-2], b = [-5,-1,-3,-2,-4]

**输出：** -1

**解释：**  
选择下标 0, 1, 3 和 4。得分为 `(-1) * (-5) + 4 * (-1) + 5 * (-2) + (-2) * (-4) = -1`。

**提示：**

- `a.length == 4`
- `4 <= b.length <= 105`
- `-105 <= a[i], b[i] <= 105`

## 0.2 Notes

这道题类似于[[编辑距离]]，但 A 的元素个数必然少于 B。在二维 DP 中：

- **当 `j > i` 时**：`B[j]` 对应的元素可选可不选，直接取 `max` 处理两种情况。
- **当 `i == j` 时**：必须选该元素，否则凑不齐 A 的长度。

核心思路：A 中的每个元素要在 B 中按顺序挑选一个位置配对，每个 B 中的元素要么被 A 的某个元素选中，要么跳过。状态定义为 `dfs(i, j)` 表示 A 的前 i 个元素与 B 的前 j 个元素能获得的最大得分。


## 0.3 Solution 

### 0.3.1 方法一：记忆化 DFS（通用解法，`len(a) ≤ len(b)`）

```python
class Solution:
    def maxScore(self, a: List[int], b: List[int]) -> int:
        @cache
        def dfs(i: int, j: int) -> int:
            # i: a 中剩余待匹配的元素个数（倒序，1-indexed）
            # j: b 中剩余可选的元素个数（倒序，1-indexed）
            if i == 0:
                return 0
            if i > j:            # b 的元素不够匹配 a 的剩余元素
                return -inf
            if i == j:
                # 必须选，否则凑不齐 A 的元素个数
                return a[i - 1] * b[j - 1] + dfs(i - 1, j - 1)
            # j > i：可选可不选，取 max
            return max(
                a[i - 1] * b[j - 1] + dfs(i - 1, j - 1),  # 选 b[j-1] 配对 a[i-1]
                dfs(i, j - 1)                                # 跳过 b[j-1]
            )

        return dfs(len(a), len(b))
```

### 0.3.2 方法二：1D DP（利用 `len(a) == 4` 优化，O(n) 时间，O(1) 空间）

```python
class Solution:
    def maxScore(self, a: List[int], b: List[int]) -> int:
        # dp[i] = 匹配 a[0..i] 的最大得分
        dp = [-inf] * 4
        for num in b:
            for i in range(3, -1, -1):  # 倒序遍历防止重复使用同一个 b 元素
                dp[i] = max(dp[i], (dp[i - 1] if i > 0 else 0) + a[i] * num)
        return dp[3]
```

关键理解：遍历 `b` 的每个元素时，对 `dp[0]→dp[1]→dp[2]→dp[3]` 做**依次匹配**的决策更新。倒序遍历保证了每个 b 元素最多被用一次。

> 时间复杂度：`O(n * m)`，空间复杂度：`O(n * m)`（记忆化递归栈 + 缓存）。
