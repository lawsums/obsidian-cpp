## 0.1 3649.破解锁的最少时间 I

Bob 被困在了一个地窖里，他需要破解 `n` 个锁才能逃出地窖，每一个锁都需要一定的 **能量** 才能打开。每一个锁需要的能量存放在一个数组 `strength` 里，其中 `strength[i]` 表示打开第 `i` 个锁需要的能量。

Bob 有一把剑，它具备以下的特征：

- 一开始剑的能量为 0 。
- 剑的能量增加因子 `x` 一开始的值为 1 。
- 每分钟，剑的能量都会增加当前的 `x` 值。
- 打开第 `i` 把锁，剑的能量需要到达 **至少** `strength[i]` 。
- 打开一把锁以后，剑的能量会变回 0 ，`x` 的值会增加一个给定的值 `k` 。

你的任务是打开所有 `n` 把锁并逃出地窖，请你求出需要的 **最少** 分钟数。

请你返回 Bob 打开所有 `n` 把锁需要的 **最少** 时间。

**示例 1：**

**输入：**strength = [3,4,1], k = 1

**输出：**4

**解释：**

|时间|能量|x|操作|更新后的 x|
|---|---|---|---|---|
|0|0|1|什么也不做|1|
|1|1|1|打开第 3 把锁|2|
|2|2|2|什么也不做|2|
|3|4|2|打开第 2 把锁|3|
|4|3|3|打开第 1 把锁|3|

无法用少于 4 分钟打开所有的锁，所以答案为 4 。

**示例 2：**

**输入：**strength = [2,5,4], k = 2

**输出：**5

**解释：**

|时间|能量|x|操作|更新后的 x|
|---|---|---|---|---|
|0|0|1|什么也不做|1|
|1|1|1|什么也不做|1|
|2|2|1|打开第 1 把锁|3|
|3|3|3|什么也不做|3|
|4|6|3|打开第 2 把锁|5|
|5|5|5|打开第 3 把锁|7|

无法用少于 5 分钟打开所有的锁，所以答案为 5 。

**提示：**

- `n == strength.length`
- `1 <= n <= 8`
- `1 <= k <= 10`
- `1 <= strength[i] <= 106`

## 0.2 Notes

### 0.2.1 这道题的思路

- **为什么顺序有影响**：每破一把锁，能量增长因子 `x` 会增加 `k`。破得越早，`x` 越小，等能量攒到 `strength[i]` 需要的分钟越多；破得越晚，`x` 越大，越省时间。所以必须枚举「先破哪把、后破哪把」的所有顺序来求最小值。
- **为什么用状压 DP**：`n` 只有 `1~8`，「已破解的锁集合」只有 `2^8 = 256` 种状态，完全可以用一个整数的二进制位来表示。比枚举全排列 `8! = 40320` 少得多，还能让相同状态被复用（记忆化）。
- **状态定义**：
  - `s`：bitmask，第 `j-1` 位为 1 表示第 `j` 把锁已被破解。
  - `factor`：当前能量增长因子 `x`，初始为 1，每破一把 `+k`。注意 `factor = 1 + k × popcount(s)`，其实由 `s` 唯一决定。
- **转移**：`dfs(s, factor)` 表示当前已破解集合为 `s`、因子为 `factor` 时，破完剩余所有锁的最少分钟。
  - 枚举下一个要破的锁 `j`（要求 `s >> (j-1) & 1 == 0`，即还没被访问）。
  - 破锁 `j` 需要的分钟：能量从 0 开始、每分钟涨 `factor`，所以 `t = ceil(strength[j] / factor) = (strength[j] + factor - 1) // factor`（向上取整）。
  - `dfs(s, factor) = min( t + dfs(s | (1 << (j-1)), factor + k) )`
  - 边界：`s == (1 << n) - 1`（全部破完）时返回 0。
- **答案**：`dfs(0, 1)`。

### 0.2.2 状压 DP 和普通 DP、普通记忆化搜索 DP 的区别

| 维度 | 普通 DP（递推） | 记忆化搜索 DP | 状压 DP |
|---|---|---|---|
| 状态表示 | 下标形式 `dp[i][j]`（背包、LIS 等） | 递归参数 `(i, j)` + memo 表 | 一个整数的二进制位表示「已选 / 已访问元素集合」 |
| 访问标记 | 常配 `visited[]` 数组 | memo 数组 | **不需要** visit 数组，掩码本身就是状态 |
| 适用场景 | n 较大、状态规整、能写出递推顺序 | 转移复杂、递推顺序难定 | n ≤ 20 的「选集合 / 定顺序」问题 |
| 代表题 | 01 背包、最长公共子序列 | 打家劫舍、爬楼梯变体 | TSP、子集枚举、本题 |

- **普通 DP** 的状态是「位置 + 若干辅助维度」，很难表达「哪些元素已经选过」这种**集合**状态；即使能表达，维度也会随 `n` 爆炸。
- **记忆化搜索 DP** 只是把递推改成递归 + memo，适合转移顺序难写的题；但当状态本身是「一个集合」时，memo 表没法直接用集合当索引，必须把它压缩成整数 —— 于是就成了状压 DP。
- **状压 DP** 的核心：**用一个整数当 visit 数组用**。
  - 判访问：`mask >> i & 1`（第 `i` 位是否为 1）
  - 标记访问：`mask | (1 << i)`
  - 撤销访问：`mask & ~(1 << i)` 或 `mask ^ (1 << i)`
  - 全满掩码：`(1 << n) - 1`；统计已选个数：`__builtin_popcount(mask)` / `mask.bit_count()`
  - 补充：`int` 通常 32 位（`long` 才一般是 64 位），无论哪种对 `n ≤ 8` 都绰绰有余。

### 0.2.3 状压 DP 的一个流程

1. **判断**：`n` 很小（一般 ≤ 20），且 DP 需要知道「哪些元素已选 / 下一步能选谁」→ 用状压 DP。
2. **定状态**：`mask`（第 `i` 位表示元素 `i` 的状态）+ 必要附加参数（本题的 `factor`）。
   - 初始 `mask = 0`，目标 `mask = (1 << n) - 1`。
3. **写转移**：枚举不在 `mask` 中的元素 `i`：
   ```python
   if (mask >> i) & 1 == 0:            # 未访问
       new_mask = mask | (1 << i)      # 标记访问
       dp[new_mask] = min(dp[new_mask], dp[mask] + cost(mask, i))
   ```
4. **定边界 / 取答案**：
   - 记忆化搜索：`dfs(mask, ...)`，`mask == 全满` 时返回 0，答案 `dfs(0, ...)`。
   - 递推：`dp[0] = 0`，mask 从小到大枚举，答案 `dp[全满]`。
5. **算复杂度**：`O(2^n × n)`（再乘附加因子），本题 `2^8 × 8`，非常小。

**本题流程对照**：
```python
dfs(s, factor):
    if s == (1 << n) - 1:  return 0                    # 全破完了
    for j in range(n):
        if (s >> j) & 1 == 0:                          # 锁 j 还没破
            t = (strength[j] + factor - 1) // factor   # 向上取整
            res = min(res, t + dfs(s | (1 << j), factor + k))
    return res
```

## 0.3 Solution 
```python
class Solution:
    def findMinimumTime(self, strength: List[int], k: int) -> int:
        n = len(strength)
        u = (1 << n) - 1

        @cache  # 缓存装饰器，避免重复计算 dfs 的结果（记忆化）
        def dfs(s: int, factor: int) -> int:
            # 这里所有状态都满了，说明已经拿满了，这个时候直接返回 0 就行
            if s == u: return 0

            res = inf # 初始化为正无穷，方便后面取最小值
            for j in range(1, n + 1):
                # 判断这个锁有没有被访问过
                if s >> (j - 1) & 1 == 0: 
                    # 由于选完后能量会清零，所以直接向上取整即可。
                    tmp = (strength[j - 1] + factor - 1) // factor
                    res = min(res, tmp + dfs(s | (1 << (j - 1)), factor + k))
            return res

        return dfs(0, 1)
```

```java
class Solution {
public:
    int findMinimumTime(vector<int>& strength, int k) {
        int n = strength.size();
        int u = (1 << n) - 1;
        int maxFactor = 1 + n * k;
        vector<vector<int>> memo(u + 1, vector<int>(maxFactor + 1, -1));
        
        auto dfs = [&](this auto&& dfs, int state, int factor) -> int {
            if (state == u) return 0;
            if (memo[state][factor] != -1) return memo[state][factor];
            
            int res = INT_MAX / 2;
            for (int j = 0; j < n; j++) {
                if (((state >> j) & 1) == 0) {
                    int tmp = (strength[j] + factor - 1) / factor;
                    res = min(res, tmp + dfs(state | (1 << j), factor + k));
                }
            }
            
            memo[state][factor] = res;
            return res;
        };
        
        return dfs(0, 1);
    }
};
```
