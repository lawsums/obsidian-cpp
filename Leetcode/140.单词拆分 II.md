## 0.1 140.单词拆分 II

给定一个字符串 `s` 和一个字符串字典 `wordDict` ，在字符串 `s` 中增加空格来构建一个句子，使得句子中所有的单词都在词典中。**以任意顺序** 返回所有这些可能的句子。

**注意：**词典中的同一个单词可能在分段中被重复使用多次。

**示例 1：**

**输入:**s = "catsanddog", wordDict = ["cat","cats","and","sand","dog"]
**输出:**["cats and dog","cat sand dog"]

**示例 2：**

**输入:**s = "pineapplepenapple", wordDict = ["apple","pen","applepen","pine","pineapple"]
**输出:**["pine apple pen apple","pineapple pen apple","pine applepen apple"]
**解释:** 注意你可以重复使用字典中的单词。

**示例 3：**

**输入:**s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
**输出:**[]

**提示：**

- `1 <= s.length <= 20`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 10`
- `s` 和 `wordDict[i]` 仅有小写英文字母组成
- `wordDict` 中所有字符串都 **不同**

## 0.3 Solution 

``` python
# 字典树节点
class TrieNode:
    def __init__(self):
        self.children = {}  # 子节点：key=字符，value=TrieNode
        self.is_end = False # 标记是否是一个单词的结尾

# 字典树
class Trie:
    def __init__(self):
        self.root = TrieNode()  # 根节点（空）

    # 插入单词
    def insert(self, word: str) -> None:
        cur = self.root
        for c in word:
            if c not in cur.children:
                cur.children[c] = TrieNode()
            cur = cur.children[c]
        cur.is_end = True  # 单词结束

    # 查找单词是否存在
    def search(self, word: str) -> bool:
        cur = self.root
        for c in word:
            if c not in cur.children:
                return False
            cur = cur.children[c]
        return cur.is_end  # 必须走到结尾才算完整单词

    # 查找是否有以 prefix 开头的单词
    def startsWith(self, prefix: str) -> bool:
        cur = self.root
        for c in prefix:
            if c not in cur.children:
                return False
            cur = cur.children[c]
        return True  # 能走完就说明前缀存在

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> List[str]:
        self.anss = []
        self.path = []
        self.max_wordlen = 0
        self.t = Trie()

        for word in wordDict:
            self.t.insert(word)
            self.max_wordlen = max(self.max_wordlen, len(word))
        
        self.dfs(0, s)
        return self.anss

    def dfs(self, depth: int, s: str):
        if depth == len(s):
            self.anss.append(" ".join(self.path))
            return

        for i in range(depth, min(len(s), depth + self.max_wordlen)):
            # 如果找到了这个单词继续dfs
            word = s[depth: i + 1]
            if self.t.search(word):
                self.path.append(word)
                self.dfs(i + 1, s)
                self.path.pop()
```
