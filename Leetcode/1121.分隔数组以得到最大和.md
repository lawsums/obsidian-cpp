## 0.1 1121.分隔数组以得到最大和

给你一个整数数组 `arr`，请你将该数组分隔为长度 **最多** 为 k 的一些（连续）子数组。分隔完成后，每个子数组的中的所有值都会变为该子数组中的最大值。

返回将数组分隔变换后能够得到的元素最大和。本题所用到的测试用例会确保答案是一个 32 位整数。

**示例 1：**

**输入：**arr = [1,15,7,9,2,5,10], k = 3
**输出：**84
**解释：**数组变为 [15,15,15,9,10,10,10]

**示例 2：**

**输入：**arr = [1,4,1,5,7,3,6,1,9,9,3], k = 4
**输出：**83

**示例 3：**

**输入：**arr = [1], k = 1
**输出：**1

**提示：**

- `1 <= arr.length <= 500`
- `0 <= arr[i] <= 109`
- `1 <= k <= arr.length`

## 0.2 Notes

### 0.2.1 DP 核心理解

> **dp[i] 的值就是：对前 i 个元素按照合理分割后，能得到的最大和。**

**状态转移方程：**

$$
dp[i] = \max_{1 \leq j \leq \min(i,k)} \big( dp[i-j] + \max(arr[i-j \dots i-1]) \times j \big)
$$

其中 $j$ 是最后一段的长度，$\max(arr[i-j \dots i-1])$ 是最后一段的最大值，乘以长度 $j$ 就是最后一段变换后的和。

### 0.2.2 手算推导 — 以 `arr = [1, 15, 7, 9, 2, 5, 10]`, `k = 3` 为例

```
dp[0] = 0                                                    // 空数组

dp[1] = dp[0] + max(1)×1 = 1                                // j=1: [1]

dp[2] = max( dp[1] + max(15)×1 , dp[0] + max(1,15)×2 )     // j=1: [15]; j=2: [1,15]
      = max( 1 + 15 , 0 + 30 ) = 30

dp[3] = max( dp[2] + max(7)×1 ,
             dp[1] + max(15,7)×2 ,
             dp[0] + max(1,15,7)×3 )
      = max( 30+7 , 1+30 , 0+45 ) = 45

dp[4] = max( dp[3] + max(9)×1 ,                             // j=1: [9]
             dp[2] + max(7,9)×2 ,                           // j=2: [7,9]
             dp[1] + max(15,7,9)×3 )                        // j=3: [15,7,9]
      = max( 54 , 48 , 46 ) = 54

dp[5] = max( dp[4] + 2 ,                                    // j=1: [2]
             dp[3] + max(9,2)×2 ,                           // j=2: [9,2]
             dp[2] + max(7,9,2)×3 )                         // j=3: [7,9,2]
      = max( 56 , 63 , 57 ) = 63

dp[6] = max( dp[5] + 5 ,                                    // j=1: [5]
             dp[4] + max(2,5)×2 ,                           // j=2: [2,5]
             dp[3] + max(9,2,5)×3 )                         // j=3: [9,2,5]
      = max( 68 , 64 , 72 ) = 72

dp[7] = max( dp[6] + 10 ,                                   // j=1: [10]
             dp[5] + max(5,10)×2 ,                          // j=2: [5,10]
             dp[4] + max(2,5,10)×3 )                        // j=3: [2,5,10]
      = max( 82 , 83 , 84 ) = 84  ✔
```

最终答案 `dp[7] = 84`。
分割方案：`[1,15,7] → [15,15,15]`（贡献 45），`[9] → [9]`（贡献 9），`[2,5,10] → [10,10,10]`（贡献 30），总和 84。

### 0.2.3 技巧：滚动 max_val 优化

在内层循环中，不必每次都重新计算区间最大值。由于 $j$ 从小到大枚举，新元素 `arr[i-j]` 逐个加入，可以滚动维护：

```python
for i in range(1, n + 1):
    max_val = 0
    for j in range(1, min(i, k) + 1):
        max_val = max(max_val, arr[i - j])
        dp[i] = max(dp[i], dp[i - j] + max_val * j)
```

时间复杂度 $O(nk)$，空间复杂度 $O(n)$。

## 0.3 Solution 
```python
class Solution:
    def maxSumAfterPartitioning(self, arr: List[int], k: int) -> int:
        n = len(arr)
        # dp[i] 表示前 i 个元素能得到的最大和
        dp = [0] * (n + 1)
        
        for i in range(1, n + 1):
            # 记录当前枚举的最后一段的最大值
            max_val = 0
            # 枚举最后一段的长度 j (1 到 k)
            for j in range(1, min(i, k) + 1):
                # 更新最后一段的最大值，注意数组索引是 i-j
                max_val = max(max_val, arr[i - j])
                # 状态转移
                dp[i] = max(dp[i], dp[i - j] + max_val * j)
                
        return dp[n]
```
