## 0.1 2325.选择建筑的方案数

给你一个下标从 **0** 开始的二进制字符串 `s` ，它表示一条街沿途的建筑类型，其中：

- `s[i] = '0'` 表示第 `i` 栋建筑是一栋办公楼，
- `s[i] = '1'` 表示第 `i` 栋建筑是一间餐厅。

作为市政厅的官员，你需要随机 **选择** 3 栋建筑。然而，为了确保多样性，选出来的 3 栋建筑 **相邻** 的两栋不能是同一类型。

- 比方说，给你 `s = "0_**0**_1_**1**_0_**1**_"` ，我们不能选择第 `1` ，`3` 和 `5` 栋建筑，因为得到的子序列是 `"0_**11**_"` ，有相邻两栋建筑是同一类型，所以 **不合** 题意。

请你返回可以选择 3 栋建筑的 **有效方案数** 。

**示例 1：**

**输入：**s = "001101"
**输出：**6
**解释：**
以下下标集合是合法的：
- [0,2,4] ，从 "_**0**_0_**1**_1_**0**_1" 得到 "010"
- [0,3,4] ，从 "_**0**_01_**10**_1" 得到 "010"
- [1,2,4] ，从 "0_**01**_1_**0**_1" 得到 "010"
- [1,3,4] ，从 "0_**0**_1_**10**_1" 得到 "010"
- [2,4,5] ，从 "00_**1**_1_**01**_" 得到 "101"
- [3,4,5] ，从 "001_**101**_" 得到 "101"
没有别的合法选择，所以总共有 6 种方法。

**示例 2：**

**输入：**s = "11100"
**输出：**0
**解释：**没有任何符合题意的选择。

**提示：**

- `3 <= s.length <= 105`
- `s[i]` 要么是 `'0'` ，要么是 `'1'` 。

## 0.2 Notes

### 0.2.1 核心思路：按「已拼好的模式」建状态机

长度为 3 的合法子序列只有两种：`010` 和 `101`。与其枚举三个下标，不如**从左往右扫一遍，把「已经拼到一半的模式」记下来**——每读一个字符，它要么被丢弃（继承旧值），要么接到某个更短的已有模式屁股后面，长成一个新状态。

把「当前已扫描的前缀里，各种模式分别出现了多少次」当成状态：

| 状态 k | 模式 | 含义 |
| --- | --- | --- |
| 0 | `0` | 单个 `0` |
| 1 | `1` | 单个 `1` |
| 2 | `01` | 交替对 |
| 3 | `10` | 交替对 |
| 4 | `010` | **合法答案** |
| 5 | `101` | **合法答案** |

`dp[k][j]` = 只用 `s` 的前 `j` 个字符，能凑出多少个等于状态 `k` 的子序列。

### 0.2.2 转移：先继承，再看新字符能不能接上

```python
for k in range(6):
    dp[k][j] = dp[k][j - 1]      # 继承：这个字符不参与，旧值原地保留

c = s[j - 1]
if c == '0':
    dp[0][j] += 1                 # 这个 0 自己就构成一个 "0"
    dp[3][j] += dp[1][j - 1]      # 之前每个 "1" 后面接上它 → "10"
    dp[4][j] += dp[2][j - 1]      # 之前每个 "01" 后面接上它 → "010"
else:
    dp[1][j] += 1
    dp[2][j] += dp[0][j - 1]      # "0"  + 1 → "01"
    dp[5][j] += dp[3][j - 1]      # "10" + 1 → "101"
```

三行是同一个套路：==新增长度为 L 的模式数，恰好等于旧的长度为 L-1 的模式数==（每个旧模式接上 `c` 都得到一个合法新模式，且一一对应）。`+= 1` 那行是长度 1 的特例：它没有前驱，自己就是一种。

**关键：读的一定是 `dp[?][j - 1]`，不是 `dp[?][j]`。** 同一个字符不能被用两次——`s[j-1]` 不能既当某个 `"01"` 的开头又当它的结尾。

### 0.2.3 两条互不相干的交替链

6 个状态其实是两条链，按**结尾字符**分流：

```
0  ──'1'──▶  01  ──'0'──▶  010
1  ──'0'──▶  10  ──'1'──▶  101
```

- 遇到 `'0'`，能长出来的只有**以 0 结尾**的模式（`0` / `10` / `010`），它们的前驱必然以 `1` 结尾；
- 遇到 `'1'` 则反过来。

所以 `c == '0'` 分支**只写** `{0, 3, 4}`、**只读** `{1, 2}`；`c == '1'` 分支**只写** `{1, 2, 5}`、**只读** `{0, 3}`。==写集合与读集合永远不相交。== 这个性质马上就用得上。

### 0.2.4 二维 → 一维滚动

`dp[·][j]` 只依赖 `dp[·][j - 1]`，所以第 `j - 1` 列用完就能扔，**一维数组就地更新**即可：

```python
dp = [0] * 6
for c in s:
    if c == '0':
        dp[0] += 1;  dp[3] += dp[1];  dp[4] += dp[2]
    else:
        dp[1] += 1;  dp[2] += dp[0];  dp[5] += dp[3]
```

- 那行 `dp[k][j] = dp[k][j - 1]`（继承）**消失了**：一维数组里 `dp[k]` 本来就存着上一轮的值，累加是隐式的。
- 「就地更新会不会读到本轮已经被改过的值？」不会。由 0.2.3，每个分支的写集合与读集合不相交，所以 `dp[k] += dp[other]` 里的 `other` 在这一轮还没被碰过，读到的正是上一轮的值。==因此更新顺序随便写，也不需要临时变量。==

这是滚动数组最舒服的一种形态：**没有逆序遍历、没有备份变量**，纯粹因为读写集合天然错开。

### 0.2.5 边界与复杂度

- `s.length >= 3`，但长度 1、2 的前缀照样要正常累积（`dp[0]` / `dp[1]` 先攒着），所以循环里不要提前返回。
- 答案为 `dp[4] + dp[5]`；一个合法三元组都没有时自然得 0（如 `"11100"`）。
- 时间 O(n)；空间：二维 O(6n)，滚动后 O(6) = **O(1)**。
- ⚠️ **C++ / Java 记得开 64 位**：`n = 1e5` 时答案上界约 `C(1e5, 3) ≈ 1.67e14`，远超 `int` 的 2.1e9，要用 `long long` / `long`。Python 整数无上限，不用管。

## 0.3 Solution 
**解法一：二维 DP 状态机 —— O(n) 时间 / O(n) 空间（本笔记做法）**

```python
class Solution:
    def numberOfWays(self, s: str) -> int:
        n = len(s)
        # dp[k][j]: 处理前 j 个字符后，状态 k 的方案数
        # 状态: 0:"0"  1:"1"  2:"01"  3:"10"  4:"010"  5:"101"
        dp = [[0] * (n + 1) for _ in range(6)]

        for j in range(1, n + 1):
            # 先继承上一轮
            for k in range(6):
                dp[k][j] = dp[k][j - 1]

            c = s[j - 1]
            if c == '0':
                dp[0][j] += 1
                dp[3][j] += dp[1][j - 1]
                dp[4][j] += dp[2][j - 1]
            else:  # c == '1'
                dp[1][j] += 1
                dp[2][j] += dp[0][j - 1]
                dp[5][j] += dp[3][j - 1]

        return dp[4][n] + dp[5][n]
```

**解法二：一维滚动数组 —— O(n) 时间 / O(1) 空间**

```python
class Solution:
    def numberOfWays(self, s: str) -> int:
        # 状态: 0:"0"  1:"1"  2:"01"  3:"10"  4:"010"  5:"101"
        dp = [0] * 6
        for c in s:
            if c == '0':
                dp[0] += 1        # 这个 0 自己 → "0"
                dp[3] += dp[1]    # "1"  + 0 → "10"
                dp[4] += dp[2]    # "01" + 0 → "010"
            else:
                dp[1] += 1        # 这个 1 自己 → "1"
                dp[2] += dp[0]    # "0"  + 1 → "01"
                dp[5] += dp[3]    # "10" + 1 → "101"
        return dp[4] + dp[5]
```

> 两个分支的**写集合与读集合不相交**（`'0'` 写 `{0,3,4}` 读 `{1,2}`；`'1'` 写 `{1,2,5}` 读 `{0,3}`），所以就地累加既不用逆序遍历，也不用备份变量。
