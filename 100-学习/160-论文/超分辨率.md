# 1 超分辨率（Super-Resolution）

传统的超分方法以 **插值法** 为主流，此外还有四条技术路线：**频域外推**、**基于重建**、**邻域嵌入（字典）**、**自相似**。它们各有优缺点。

## 1.1 总览

| 方法   | 核心思想            | 关键局限              |
| ---- | --------------- | ----------------- |
| 插值法  | 邻近像素加权平均后插入新位置  | 不引入新信息            |
| 频域外推 | 频谱在带外解析延拓       | 对噪声极度敏感           |
| 基于重建 | 用先验作约束，解病态反问题   | 需多帧/强先验，单图过平滑     |
| 邻域嵌入 | 外部字典 + 查表（稀疏表示） | 推理慢、字典容量受限、依赖退化假设 |
| 自相似  | 图像内部跨尺度找相似块     | 计算量大、假设不总成立       |

## 1.2 一、插值法

最主流的传统方法。做法是把两侧已知像素 **加权平均** 后插到新位置（双线性、双三次等）。

- **缺点**：**不引入任何新信息**。它只能做到最平滑的衔接，无法凭空恢复高频细节。
- **例子**：若某处本该是一条线稿——两侧是空白，中间本应冒出高对比度的黑色细线——插值只能给出两侧像素的加权平均，无法「无中生有」地重建这条线。

## 1.3 二、频域外推

**首次把超分当作反问题来求解**。它假设图像的频谱在带外（采样截止频率之外）可以通过 **解析延拓** 恢复。

- **优点**：开创了「超分 = 反问题」这一视角。
- **缺点**：**对噪声极度敏感**——向带外外推高频的同时，会把噪声一起放大。

## 1.4 三、基于重建的方法

把 **先验** 写成约束：超分本身是病态问题（答案不唯一），于是用额外知识在众多可行解中挑一个最合理的。

> [!note] 先验（Prior）
> **一句话**：先验就是你事先对「正常答案应该长什么样」的知识。
>
> **为什么需要它**：超分是 **病态问题（ill-posed）**——一帧低分图可以对应无数帧高分图。比如把一个 2×2 的块放大，中间那些像素可以取任何值，都能「解释」观察到的低分图。仅靠观测数据本身无法确定唯一答案。
>
> **它怎么起作用**：写成正则项 / 约束，加入优化目标：
> $$\hat{x} = \arg\min_{x}\ \underbrace{\|DHx - y\|^{2}}_{\text{数据保真}} + \lambda \underbrace{R(x)}_{\text{先验 / 正则}}$$
> - 第一项保证结果与观测一致；
> - 第二项告诉算法「自然图像应该长什么样」；
> - $\lambda$ 权衡二者（越大越依赖先验）。
>
> **常见先验**：
> - 平滑先验（TV / 梯度稀疏）：图像局部变化平缓 → 但过度平滑会糊掉边缘；
> - 稀疏先验：自然图像在小波 / 梯度域只有少数大系数；
> - 边缘 / 结构先验：显式建模边缘方向；
> - **学习到的先验**：现代方法（含扩散模型）直接用数据学一个「图像分布」，这是先验的最强形式。
>
> **直觉类比**：给残缺句子填空，只说「填个词」答案无数；但若先知道「这是中文、是诗、要押韵」，就能挑出最合理的词。先验就是这么一类「额外知识」。

- **缺点**：需要多帧输入，或一个很强的先验；**单图时约束不足**，结果往往是一片平滑（细节被丢掉）。

## 1.5 四、邻域嵌入（稀疏表示）

从外部图像库中学习一个 **字典**，推理时通过「查字典」实现重建。

> [!note] 稀疏表示（Sparse Representation）
> **核心思想**：任何信号都可以用一组「基本砖块」（字典原子）线性拼出来，而且 **只需要很少几块**。
> 写成：$x \approx D\alpha$，其中 $D$ 是 **字典**（列向量叫原子 atom，通常过完备），$\alpha$ 是 **稀疏系数**（大部分元素为 0）。
>
> **为什么叫「稀疏」**：虽然字典很大，但表示一个信号只用其中少数几个原子 → 系数向量 $\alpha$ 里绝大多数是 0。
>
> **在超分里怎么用**（Yang et al. 2010）：
> 1. 用大量高分图块训练出 **一对字典**：$D_h$（高分字典）、$D_l$（低分字典），二者假设共享同一套稀疏系数；
> 2. 推理时，对输入的低分图块求它的稀疏系数 $\alpha$：$\min_\alpha \|y - D_l\alpha\|^2 + \lambda\|\alpha\|_1$；
> 3. 用 **同一个 $\alpha$** 在高分字典上重建：$\hat{x} = D_h\alpha$。
>
> 因为高低分字典共享系数，低分块「缺」的高频细节就能由高分原子的组合「补」出来 → **第一次真正生成高频信息**。
>
> **代价**：每块都要解一个 L1 优化（很慢）；字典容量有限（原子数固定）；效果强依赖训练时的退化模型（模糊核、噪声）是否与实际匹配。

> [!note] 邻域嵌入（Neighbor Embedding）
> 思路和稀疏表示相同（低分块查字典 → 用系数重建高分块），区别在 **「怎么查」**：
> - **稀疏表示**：解优化问题，求精确的稀疏系数（贵但准）；
> - **邻域嵌入**：不优化，直接找字典里与输入低分块 **最接近的 K 个邻居**，用它们的权重来重建 ⇒ 即「**按邻域关系查字典**」。本质是局部线性嵌入（LLE）的思想。
>
> **好处**：省去求解稀疏系数的优化，推理更快。
> **坏处**：字典容量受限（邻居一多就「平均化」，细节糊掉）；同样对退化假设敏感。

- **贡献**：**首次真正生成了缺失的高频信息。**
- **缺点**：推理速度慢、字典容量受限、对退化假设（模糊核 / 噪声）敏感。

## 1.6 五、自相似

在图像 **内部** 寻找相似的邻域，做跨尺度映射。自然图像中大量重复的纹理（草地、砖墙、织物等）即构成「自相似」。

- **优点**：只依赖图像自身，不需要外部字典。
- **缺点**：计算量非常大；且纹理并不一定在图像内重复，**假设并不总是成立**。

## 1.7 六、经典退化假设：这一代方法的天花板

> 前面五种方法的评测，几乎全部建立在 **bicubic 退化** 之上。理解这一点，才能明白它们为什么「在论文里很强、在真实照片上一败涂地」。

### 1.7.1 bicubic 是什么

**bicubic = 双三次插值（bicubic interpolation）**，一种 **插值** 方法。

插值的本质：图像缩放时，新像素落在原图网格的「空隙」里，需要 **估** 出这个位置的颜色。

| 方法 | 用几个邻居估一个点 | 效果 |
| --- | --- | --- |
| 最近邻 nearest | 1 个 | 有马赛克块 |
| 双线性 bilinear | 4 个（2×2） | 较平滑 |
| **双三次 bicubic** | **16 个（4×4）** | 更平滑，权重是一条三次曲线 |

bicubic 用周围 **4×4 = 16 个像素** 加权平均，是图像处理界几十年的「默认缩放算法」（Photoshop / MATLAB / OpenCV 都用它）。

### 1.7.2 训练对是怎么造的：经典退化假设的全部实现

```python
import torch.nn.functional as F

def make_pair(hr, scale=4, mode='bicubic'):
    # hr: (N,C,H,W) 的高清图，像素值归一化到 [0,1]
    lr = F.interpolate(
        hr,
        scale_factor=1.0 / scale,  # 缩小 4 倍
        mode=mode,                 # bicubic 双三次插值
        align_corners=False,       # 采样网格对齐方式
    )
    return lr, hr                  # (低清输入, 高清监督)
```

- `scale_factor=1.0/scale = 1/4`：**缩小**（不是放大），造的是低清图；
- `mode='bicubic'`：这一行就是「经典退化假设」的 **全部实现**——它断言 **低清图 = 高清图做双三次下采样**；
- `align_corners`：决定采样点如何对齐像素网格，影响边界像素，跨实现比较时必须一致；
- HR **免费充当监督信号**，无需人工标注 → 能无限量合成数据，这正是这一代方法流行的原因。

退化的数学形式：

$$LR = D(HR),\quad D = \text{bicubic 下采样}$$

### 1.7.3 陷阱：优化的其实是「bicubic 的逆算子」

> [!warning] 辛辛苦苦优化的，是 bicubic 的逆算子
> 把「从 HR 造出 LR」这个操作记作 **D**（bicubic 下采样）：
> ```
> 正向（造数据）:   HR  ──D──▶  LR
> 反向（超分任务）: LR  ──D⁻¹──▶ HR
> ```
> - 造训练对用的是 **D**；超分要做的是 **反推**，即求 **D 的逆 D⁻¹**；
> - 训练目标 `f(LR) ≈ HR`，而 `HR = D⁻¹(LR)` → **网络 f 逼近的就是 D⁻¹**。
>
> **一句话**：它们以为在学「超分」，其实只在学「怎么把 bicubic 这一步撤销掉」。
>
> **类比**：学生练了一万道「已知 x−3，求 x」的题，练熟的是「加 3」这一个动作，**不是算术**。考试一换成应用题就崩。

### 1.7.4 为什么这个简化是致命的

> [!danger] 真实退化 ≠ bicubic
> 真实世界的低清图不是这条路造出来的。手机拍的低质照片经历：**镜头模糊 → 传感器噪声 → 下采样 → JPEG 压缩 → 上传再缩放**，合起来才是真实退化 **D'**。
> - 模型只学了 **D⁻¹**（撤销 bicubic）；
> - 现实要求 **D'⁻¹**（撤销模糊 + 噪声 + 压缩 …）；
> - 两者差别巨大 → **在真实照片上一败涂地**。
>
> 这个问题直到 **2021 年 Real-ESRGAN** 提出才被系统解决。

### 1.7.5 这一代方法的共同天花板

四条路线，三种结局：

| 路线 | 引入的外部知识 | 结局 |
| --- | --- | --- |
| 插值派 | **无** | 只在已知像素间加权平均，永远造不出高频 |
| 重建派 | 人手工设计的先验 | 手工先验（图像应平滑、梯度应稀疏）写死了想象力，刻画不了「人脸该长什么样」 |
| 字典 / 自相似派 | 有，但 **太小、太慢** | 字典容量有限、推理慢；自相似假设在很多图上不成立 |

> [!note] 共同天花板
> 它们要么不引入外部知识，要么只能用很小、很浅的外部知识。而「什么样的纹理是自然的」这件事，需要 **从海量图像里学出来**——不是把先验写得更精巧就能解决的。

### 1.7.6 两个术语：盲 / 非盲超分

- **非盲超分（non-blind SR）**：退化 **D 已知且固定**（如 bicubic）→ 这一代方法的默认设定；
- **盲超分（blind SR）**：退化 **D 未知**，需与图像一起估 → 真实场景。

bicubic 假设把问题锁死成最简单的非盲情形，这就是「天花板」的技术根源。（严格说 bicubic 下采样 **不可逆**——多个 HR 会压成同一个 LR——所以 f 学的是「统计意义上最可能的那个逆」，不是数学上的真逆，口语里仍叫逆算子。）

### 1.7.7 出路

一旦意识到 **「需要外部知识，而且这份知识必须从数据里学」**，自然的问题就是：能不能直接让模型从大量图像里学这个规律？

> 2014 年 **SRCNN** 给出答案：把「学一个从低清到高清的映射」交给深度网络，整个领域的曲线从此拐弯 → 进入深度学习超分时代。

## 1.8 七、CNN 时代：把放大当成回归问题

> 2014 年，一个只有三层的卷积网络（SRCNN）超过了此前所有手工方法。它证明的其实是一件更根本的事：**原本要分头设计、分头调参的三道工序，可以被一个网络端到端地学出来。**

### 1.8.1 SRCNN：把三道工序合并成一条流水线

在 SRCNN 之前，效果最好的传统方法是 **稀疏表示**（见 1.5），它靠三个「师傅」分头干活：

| 步骤 | 做什么 | 对应 SRCNN 的层 |
| --- | --- | --- |
| ① 取块 | 决定在哪里取块 | conv1 · 9×9 |
| ② 非线性映射 | 用学好的字典做非线性映射 | conv2 · 5×5 |
| ③ 重建 | 把块拼回高清图 | conv3 · 5×5 |

三道工序各有各的超参数，谁也没法保证整条链路一起最优。

**2014 年**，Chao Dong、Chen Change Loy、Kaiming He、Xiaoou Tang 在 ECCV 2014（pp. 184–199）提出 **SRCNN**：三层卷积，把三道工序合并成一条流水线。**端到端训练超分，从这一个网络开始。**

它的历史贡献不是「涨了几个 dB」，而是证明了 **三道工序可以由数据自己决定怎么做**。

```python
import torch.nn as nn

class SRCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 64, kernel_size=9, padding=4)
        self.conv2 = nn.Conv2d(64, 32, kernel_size=5, padding=2)
        self.conv3 = nn.Conv2d(32, 3, kernel_size=5, padding=2)
        self.relu = nn.ReLU(inplace=True)

    def forward(self, x):
        x = self.relu(self.conv1(x))   # 提块
        x = self.relu(self.conv2(x))   # 映射
        return self.conv3(x)           # 重建
```

代码要点：

- `__init__` 里声明「有哪几层」，`forward` 里写「数据怎么流过它们」——PyTorch 的标准写法；
- **conv1**：RGB 3 通道 → 64 特征通道，核 **9×9**。第一层核最大，因为「取块」必须看到足够大的邻域，核太小感受野就撑不起来；
- `padding=4` = 9 的一半向下取整 → 输出尺寸与输入一致，省去每步重新对齐；
- **conv2**：64 → 32 通道，核 5×5，承担「非线性映射」；
- **conv3**：32 → 3 通道，压回 RGB，即「重建」。**故意不加 ReLU**——它要输出连续亮度值，ReLU 会把负值压成 0，暗部一片死黑；
- `inplace=True`：激活函数就地改写输入张量，省显存；
- **非线性的意义**：前两层都套 ReLU；没有非线性，三层卷积叠起来在数学上等价于 **一层**；
- 注意输入 `x`：**已经是双三次插值放大好的低清图**（不是笔误，见下）。

### 1.8.2 SRCNN 的两个缺陷

SRCNN 留了两个洞，后面五年的工作几乎都在补：

> [!warning] 缺陷一：先插值，再进网络
> SRCNN 的输入是 **已经用双三次插值放大好的图**。放大 4 倍，网络就要处理原来 **16 倍** 的像素——这部分算力基本白烧。

> [!warning] 缺陷二：只有 3 层，看得太窄
> `9×9 → 5×5 → 5×5` 叠起来，一个输出像素能参考的输入范围也只有十几像素。**远处的纹理长什么样，它根本看不见。**

### 1.8.3 两个结构创新：把「放大」和「学什么」都重新安排

后续工作用两个结构创新补上了这两个洞：

**① 上采样：从「插值」变成「通道重排」（亚像素卷积 / ESPCN）**

| | 传统做法（SRCNN） | 亚像素卷积（ESPCN） |
| --- | --- | --- |
| 放大位置 | 网络 **前面**（先插值放大） | 网络 **最后**（在低分辨率上卷积） |
| 计算量 | 在 rH×rW 的画布上算 → 乘 r²（4 倍 = 16 倍） | 卷积全在 **低分辨率** 上算，放大只做「搬运」 |
| 做法 | 插值 | 卷积直接输出 3×r² 个通道（4× → 48 通道），再一次 **重排（reshape）** 摊成 4H×4W×3 |

> ESPCN 比 SRCNN 快一个数量级，靠的就是「重算力的卷积留在低分辨率，放大只是搬运数据」。

**② 让网络只学差值（残差连接 / EDSR）**

> [!note] 残差学习
> 高清图和低清图 **高度相似**，让网络去学一个恒等映射纯属浪费容量。改成只学「**高清 − 低清**」那个差值，输出时把输入加回去：
> $$x_{out} = x_{in} + f(x_{in})$$
> 更关键的是，**梯度能沿残差捷径无衰减地回传**——没有它，堆几十层根本训不动。EDSR 能堆到 **32 个残差块**，靠的就是这一条。

> [!tip] 这一屏最重要的两句话
> 1. 上采样从「**插值**」变成「**通道重排**」；
> 2. 让网络只学「**差值**」。
> 下一站：把它们写成代码 → ESPCN / EDSR。
