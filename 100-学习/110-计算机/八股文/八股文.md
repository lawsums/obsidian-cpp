
### 0.1.1 malloc 在内存分配失败的时候返回什么？

**答案：** 返回 `NULL`（空指针）。

**要点：** 每次 `malloc` 调用后必须检查返回值是否为空，避免对空指针解引用导致程序崩溃。

### 0.1.2 Union 在 C 语言中的合法用途有哪些？

**答案：**
1. **类型双关**：通过 union 读取同一块内存的不同类型表示。
2. **节省内存**：多个互斥使用的成员共享同一片内存。
3. **实现简单多态变体类型**。
4. **对齐**：union 的对齐等于最大成员的对齐。

**要点：** 核心思想是"同一片内存，不同视角解释"。

### 0.1.3 `this == NULL` 是合法的吗？析构函数里 `delete this` 合法吗？

**答案：** 都不合法。
- `this == NULL` 不合法：`this` 是右值指针，右值不能被赋值，也不能和 `NULL` 比较出有意义的结果。
- 析构函数里 `delete this` 不合法：`delete this` 会再次调用析构函数，形成**无限循环/重复析构**。

**要点：** `this` 是右值；`delete this` → 析构 → `delete this` → 死循环。

### 0.1.5 inline 的作用是什么？

**答案：**
1. **编译器建议**：建议在调用处展开函数体（消除压栈、跳转、返回开销），适用于频繁调用的小函数。
2. **解决 ODR 问题**：`inline` 函数允许多个翻译单元重复定义（只要定义一致），因此可以**在头文件中写函数实现**。

**要点：**
- `inline` 只是建议，现代编译器（`-O2`）会自行判断是否内联。
- 现代 C++ 中 `inline` 的真正意义是**允许在头文件中定义函数**。
- 类内定义的成员函数**隐式 inline**；模板函数默认 inline。
- 过度内联导致**代码膨胀**，增加 I-cache 未命中率。

### 0.1.6 重载和虚函数分别在什么时候确定？

**答案：**
- **重载（Overloading）**→ **编译时（静态多态）**：编译器根据参数类型和数量在编译期决定调用哪个版本。
- **虚函数（Virtual Function）**→ **运行时（动态多态）**：通过虚函数表（vtable）在运行期根据对象实际类型决定调用哪个版本。

**要点：** 重载 = 静态 = 编译期；虚函数 = 动态 = 运行期（vtable）。

### 0.1.7 内存寻址计算

**题目：** 一个有 128 个字的数据区，起始地址为 `12ABH:00ABH`，求数据区最末一个字单元的物理地址。

**选项：**
- A. `12C5BH` ❌（含非法字符 S）
- B. `12B6BH` ❌（偏小）
- C. `12C59H` ✅
- D. `12BFEH` ❌（偏大）

**答案：C**

**计算过程：**
1. 段地址 ×16 + 偏移地址：`12AB0H + 00ABH = 12B5BH`（起始物理地址）
2. 128 个字 = 256 个字节
3. 最后一个字占 2 字节 → 末地址 = 起始 + 256 - 2 = `12B5BH + FEH = 12C59H`

**要点：** 段地址 ×16 + 偏移地址 → 物理地址；1 字 = 2 字节；末地址 = 起始 + 总字节数 - 字长。

### 0.1.8 规格化浮点数判断

**题目：** 浮点机采用规格化浮点数表示，阶码用移码（最高位为符号位），尾数用原码。下列哪个不是规格化浮点数？

| 选项 | 阶码 | 尾数 |
|------|------|------|
| A | `1111111` | `1.1000...00` |
| B | `0011111` | `1.0111...01` |
| C | `1000001` | `0.1111...01` |
| D | `0111111` | `0.1000...10` |

**答案：B**

**判断依据：** 规格化要求尾数绝对值在 `[1, 2)`，即二进制下小数点左边必须是 `1`。阶码用移码时，最高位 `0` 表示负阶码。B 选项阶码 `0011111`（负阶码）导致实际数值 < 1，不满足规格化条件。

**要点：** 规格化 = 尾数 ∈ [1, 2) → 二进制小数点左边必为 1；移码最高位 0 = 负数。

### 0.1.9 IBM 提出的物联网架构结构类型

**题目：** IBM 提出的物联网架构结构类型是？

**选项：**
- A. 三层 ✅
- B. 四层 ❌
- C. 八横四纵 ❌
- D. 五层 ❌

**答案：A（三层）**

**三层结构：**

| 层次 | 职责 |
|------|------|
| 感知层 | 通过传感器、RFID 等采集物理世界数据 |
| 网络层 | 数据传输，包括通信网络和互联网 |
| 应用层 | 数据处理和智能化应用 |

**要点：** IBM 物联网 = 三层架构（感知 → 网络 → 应用），结构简单、易于标准化和模块化。

### 0.1.10 智能信息设备发展趋势

**题目：** 以下不是智能信息设备的发展趋势的是？

**选项：**
- A. 感知数据更多样化 ✅（是趋势）
- B. 处理能力更强大 ✅（是趋势）
- C. 具有可编程和可定制能力 ✅（是趋势）
- D. 存储能力更强大 ❌（不是特有趋势）

**答案：D**

**要点：** 存储能力提升是**所有电子设备的共同特征**，非智能信息设备**特有**的发展趋势。特有趋势聚焦于感知、处理、可定制三个维度。
