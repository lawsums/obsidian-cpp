# 1 费马小定理（Fermat's Little Theorem）
## 1.1 定理内容
若 **$p$ 是质数**，整数 $a$ 与 $p$ **互质**（即 $\gcd(a,p)=1$），则：
$$
a^{p-1} \equiv 1 \pmod p
$$

等价形式（更常用）：
$$
a^p \equiv a \pmod p
$$

## 1.2 核心用途（算法里最常用）
1. **快速幂求模逆元**
   当 $p$ 是质数时，$a$ 在模 $p$ 下的**乘法逆元**为：
   $$
   a^{-1} \equiv a^{p-2} \pmod p
   $$
   用**快速幂**就能 $O(\log p)$ 求出逆元。

2. **素数测试（费马素性检验）**
   对随机 $a$，检查是否满足
   $$
   a^{n-1} \equiv 1 \pmod n
   $$
   不满足 → $n$ **一定不是质数**；
   满足 → $n$ **大概率是质数**。

3. **大指数取模简化**
   比如求 $a^b \bmod p$（$p$ 质数）：
   $$
   a^b \equiv a^{b \bmod (p-1)} \pmod p
   $$

## 1.3 简单例子
$p=5$（质数），$a=2$：
$$
2^{5-1}=16 \equiv 1 \pmod 5
$$
满足 $a^{p-1}\equiv1\pmod p$。

## 1.4 典型代码模板（C++）
```cpp
// 快速幂：a^b % mod
long long qpow(long long a, long long b, long long mod) {
    long long res = 1;
    while (b > 0) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}

// 费马小定理求逆元（mod必须是质数）
long long inv(long long a, long long mod) {
    return qpow(a, mod - 2, mod);
}
```

## 1.5 一句话总结
费马小定理在算法里 =
**质数判定 + 模逆元 + 高次幂降幂**
是数论、组合数学、密码学的基础工具。
