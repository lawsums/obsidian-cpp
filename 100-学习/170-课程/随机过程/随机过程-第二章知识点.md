# 1 随机过程（第五版）第二章知识点

> [!info] 本篇说什么
> 第 2 章是整本书的「地基」：**把随机过程当成一族随机变量**，然后用概率论里已经学过的工具去处理它。
> 本篇重点解决一个问题：**一维概率密度到底怎么求**（见 1.3 节），这是习题 2.2、2.3 卡住的地方。

---

## 1.1 本章脉络

```
随机过程的定义  X(t), t ∈ T
        │
        ├── 怎么完整描述它？  → 有限维分布函数族  F(x1,…,xn; t1,…,tn)
        │         ├── n=1：一维分布函数 / 一维概率密度   ← 本笔记重点
        │         └── n=2：二维分布函数 / 二维概率密度
        │
        ├── 怎么粗略描述它？  → 数字特征
        │         ├── 均值函数  m_X(t)
        │         ├── 方差函数  D_X(t)
        │         ├── 相关函数  R_X(t1,t2)
        │         └── 协方差函数 B_X(t1,t2)
        │
        └── 有什么重要的特殊过程？
                  ├── 独立增量过程、正交增量过程
                  ├── 正态过程、维纳过程、泊松过程
                  └── 严平稳过程、宽平稳过程
```

**一句话抓住主线**：随机过程 = 一族随机变量 $\{X(t)\}_{t\in T}$。
所以「求 $X(t)$ 的某样东西」= **先固定 $t$，把它当成一个普通随机变量来做**，做完之后结果里保留 $t$ 当参数。

## 1.2 随机过程的定义与分布函数族

### 1.2.1 定义

设 $T$ 是参数集（本书多为 $[0,+\infty)$ 或 $\{0,1,2,\dots\}$），若对每个 $t \in T$，$X(t)$ 都是定义在同一个样本空间 $\Omega$ 上的随机变量，则称 $\{X(t), t \in T\}$ 为**随机过程**。

- **固定 $t$** → $X(t)$ 是随机变量（叫过程在 $t$ 时刻的**状态**）
- **固定 $\omega$** → $X(t,\omega)$ 是 $t$ 的普通函数，叫一条**样本函数 / 轨道**

### 1.2.2 一维分布函数与一维概率密度

对固定的 $t$，$X(t)$ 是随机变量，定义

$$F_X(t; x) = P\{X(t) \le x\}, \quad x \in \mathbb{R}$$

为随机过程的**一维分布函数**。

若存在 $f_X(t; x) \ge 0$ 使得

$$F_X(t; x) = \int_{-\infty}^{x} f_X(t; u)\, du$$

则称 $f_X(t; x)$ 为**一维概率密度函数**。

> [!important] 记号读法
> $f_X(t;x)$ 里的**分号**很关键：$t$ 是「参数」，$x$ 是「自变量」。
> 每换一个 $t$，就是**另一个**随机变量、**另一个**密度函数。$t$ 只是恰好被写在了同一个符号里。

### 1.2.3 二维分布函数与二维概率密度

$$F_X(t_1, t_2;\, x_1, x_2) = P\{X(t_1) \le x_1,\ X(t_2) \le x_2\}$$

$$f_X(t_1,t_2;\,x_1,x_2) = \frac{\partial^2 F_X}{\partial x_1 \partial x_2}$$

### 1.2.4 有限维分布函数族

把 $n$ 维的情形全写出来：

$$F_{t_1,\dots,t_n}(x_1,\dots,x_n) = P\{X(t_1) \le x_1, \dots, X(t_n) \le x_n\}$$

所有 $n \ge 1$、所有 $t_1,\dots,t_n$ 的这族函数，叫**有限维分布函数族**。它**完整地**刻画了随机过程的统计特性。

满足的两条相容性：
- **对称性**：任意置换 $t_i$ 与 $x_i$ 的下标，函数值不变
- **相容性**：令某个 $x_k \to +\infty$，$n$ 维分布退化为 $n-1$ 维分布

### 1.2.5 两个重要的特殊过程

**独立增量过程**：对任意 $n$ 与 $t_1 < t_2 < \dots < t_n$，增量 $X(t_2)-X(t_1),\, X(t_3)-X(t_2),\, \dots$ 相互独立。

**正交增量过程**：$\{X(t), t \ge 0\}$ 满足 $E[X(t)] \equiv 0$，且对任意 $t_1 < t_2 \le t_3 < t_4$，

$$E\big[(X(t_2)-X(t_1))\overline{(X(t_4)-X(t_3))}\big] = 0$$

> [!tip] 正交增量的等价说法
> 「不重叠区间的**增量互不相关**」。它比独立增量弱：独立 ⇒ 正交（在均值为 0 时），反之不然。

## 1.3 【重点】一维概率密度怎么求

### 1.3.1 核心思想

> **求 $X(t)$ 的一维分布，就是把「随机过程」暂时降维成「一个随机变量」。**

对**固定的 $t$**（把 $t$、$\omega$、$A$ 这类都当**常数**），$X(t)$ 就是一个普通随机变量。你在《概率论》里怎么求随机变量函数的分布，这里就怎么用。

产物一般带个 $t$：$f_X(t;x)$。

### 1.3.2 通用四步法

| 步骤 | 做什么 | 常见坑 |
|---|---|---|
| **① 固定 $t$** | 明确哪些是随机变量、哪些是常数 | 把 $\omega$、$A$（常数）误当随机变量 |
| **② 辨型** | $X(t)$ 的取值是「一整片区间」还是「有限个点」？ | 见 1.3.5，两种走法完全不同 |
| **③ 写分布函数** | $F_X(t;x) = P\{X(t) \le x\}$，把事件翻译成对底层随机变量的条件 | 不等式方向搞反 |
| **④ 求导** | $f_X(t;x) = \dfrac{\partial}{\partial x}F_X(t;x)$ | 漏掉链式法则 |

### 1.3.3 套路 A：单调变换（最常用）

**适用**：$X(t)$ 只由**一个**随机变量 $Y$ 决定，即 $X(t) = g(Y; t)$，且 $g(\cdot;t)$ 关于 $y$ **严格单调**。

设反函数为 $h(x;t) = g^{-1}(x;t)$，则

**分布函数**：

$$F_X(t;x) = P\{g(Y;t) \le x\} = \begin{cases}
F_Y\big(h(x;t)\big), & g \text{ 关于 } y \text{ 递增}\\[4pt]
1 - F_Y\big(h(x;t)\big), & g \text{ 关于 } y \text{ 递减}
\end{cases}$$

**密度**（对 $x$ 求导，两种情形合并成一条）：

$$\boxed{\,f_X(t;x) = f_Y\big(h(x;t)\big)\cdot\left|\frac{\partial h}{\partial x}\right|\,}$$

$x$ 落在 $g$ 的值域内时成立，**值域外为 0**。

> [!tip] 不用背「递增还是递减」
> 直接从不等式推：$g$ 递减时 $g(Y)\le x \iff Y \ge h(x;t)$，所以是 $1 - F_Y(h)$。一分钟就推出来了，比记公式可靠。

#### 1.3.3.1 例 1（习题 2.2 —— 单调递减）

> 设 $Y$ 有密度 $f(y)$（$Y>0$），$X(t) = e^{-Yt}$，$t>0$，求 $X(t)$ 的一维概率密度。

**① 固定 $t$**：$t$ 是常数，$Y$ 是唯一的随机变量。

**② 辨型**：$g(y) = e^{-yt}$ 关于 $y$ **严格递减**，属于套路 A。

**③ 定值域**：$y \in (0,\infty) \Rightarrow x = e^{-yt} \in (0,1)$。所以 $x \le 0$ 时 $F=0$，$x \ge 1$ 时 $F=1$。

**④ 反函数与求导**：

$$h(x) = -\frac{\ln x}{t}, \qquad \frac{dh}{dx} = -\frac{1}{tx}, \qquad \left|\frac{dh}{dx}\right| = \frac{1}{tx}$$

**⑤ 代公式**：

$$f_X(t;x) = \frac{1}{tx}\,f_Y\!\left(-\frac{\ln x}{t}\right), \quad 0 < x < 1; \qquad \text{其余 } x \text{ 处为 } 0$$

**验算**（用分布函数走一遍，确认没写反）：

$$F_X(t;x) = P\{e^{-Yt}\le x\} = P\{-Yt \le \ln x\} = P\left\{Y \ge -\frac{\ln x}{t}\right\} = 1 - F_Y\!\left(-\frac{\ln x}{t}\right)$$

两边对 $x$ 求导：$-f_Y(h)\cdot h' = -f_Y(h)\cdot\left(-\frac{1}{tx}\right) = \dfrac{f_Y(h)}{tx}$ ✓ 一致。

> [!note] 为什么结果是拉普拉斯变换的样子
> $E[X(t)] = \int_0^\infty e^{-yt}f(y)dy$ 正是 $f$ 的拉普拉斯变换 $L_Y(t)$。当 $Y$ 是**指数分布**时，$f(y) = \lambda e^{-\lambda y}$，代入得 $f_X(t;x) = \dfrac{\lambda}{t}x^{\lambda/t - 1}$，$0<x<1$ —— 又是 Beta 分布的密度。

### 1.3.4 套路 B：全概率公式（离散分支 / 混合型）

**适用**：$X(t)$ 从一个**有限（或可数）个分支**里随机挑一个，形如

$$X(t) = g_k(t) \quad \text{当事件 } A_k \text{ 发生}, \qquad k = 1,\dots,m$$

其中 $A_1,\dots,A_m$ 互斥且并为全集。这时 $X(t)$ 在固定 $t$ 下是**离散型随机变量**：

$$F_X(t;x) = \sum_{k=1}^{m} P(A_k)\cdot \mathbf{1}\{g_k(t) \le x\}$$

也就是一个**阶梯函数**，在每个 $g_k(t)$ 处跳跃，跳高为 $P(A_k)$。

> [!warning] 这种情况**没有概率密度**
> 阶梯函数几乎处处可导且导数为 0，写不出有意义的密度。题目若问「一维分布函数」就答阶梯函数；若问「密度」，答案就是「不存在」。

#### 1.3.4.1 例 2（习题 2.3 —— 抛硬币）

> 从 $t=0$ 起每隔 $1/2$ 秒抛一枚均匀硬币，
> $$X(t) = \begin{cases}\cos(\pi t), & t \text{ 时刻抛得正面}\\ 2t, & t \text{ 时刻抛得反面}\end{cases}$$
> 求一维分布函数 $F(\tfrac12;x)$、$F(1;x)$。

**关键认识**：题目问的 $F(\frac12;x)$ 和 $F(1;x)$ 是**两个不同的随机变量**的分布函数，要**分开各算一次**。

**算 $t = \frac12$**：

$$X(\tfrac12) = \begin{cases}\cos\frac{\pi}{2} = 0, & \text{正面 } (\text{概率 } \frac12)\\ 2\times\frac12 = 1, & \text{反面 } (\text{概率 } \frac12)\end{cases}$$

$$F(\tfrac12;x) = \begin{cases}0, & x < 0\\ \frac12, & 0 \le x < 1\\ 1, & x \ge 1\end{cases}$$

**算 $t = 1$**：

$$X(1) = \begin{cases}\cos\pi = -1, & \text{正面 } (\frac12)\\ 2\times 1 = 2, & \text{反面 } (\frac12)\end{cases}$$

$$F(1;x) = \begin{cases}0, & x < -1\\ \frac12, & -1 \le x < 2\\ 1, & x \ge 2\end{cases}$$

> [!tip] 小心「撞点」
> 若两个分支在某 $t$ 取值相同（即 $g_1(t) = g_2(t)$），该跳跃点的高度要把两边概率**相加**。例如若某 $t$ 上 $\cos(\pi t) = 2t$，跳跃高度就是 $1$，分布函数直接一步到 1。

#### 1.3.4.2 例 3（习题 2.6 —— 混合型）

> $X(t) = A\sin(\omega t + \Theta)$，$A,\omega$ 常数，$\Theta \sim U(-\pi,\pi)$。求 $X(t)$ 的一维密度。

这里 $\Theta$ 连续，但 $\sin$ 非单调 —— 属于下面 1.3.6 说的「多值反函数」情形。做法是先在 $(-\pi,\pi)$ 上解出 $\theta$ 的两个分支，再用套路 A 分别处理、把两段密度**相加**。

### 1.3.5 套路 C：多个随机变量

**适用**：$X(t) = g(Y_1,\dots,Y_n;t)$，$n \ge 2$ 个随机变量。三条路：

1. **先求联合、再边缘化**：写出 $(Y_1,\dots,Y_n)$ 的联合密度，对区域 $\{g \le x\}$ 积分，再对 $x$ 求导。
2. **变量替换法（雅可比）**：设 $Z = g(Y_1,\dots,Y_n;t)$，凑一个辅助变量 $W$，用雅可比公式求 $(Z,W)$ 的联合密度，再积分掉 $W$。
3. **认结构，直接用已知结论**：这是最快的一条。

#### 1.3.5.1 例 4（习题 2.4 —— 认结构）

> $X(t) = A\cos\omega t + B\sin\omega t$，$A,B$ 独立同 $N(0,\sigma^2)$。

固定 $t$ 后，$X(t)$ 是**独立正态变量的线性组合**，所以直接是正态：

$$m = 0\cdot\cos\omega t + 0\cdot\sin\omega t = 0, \qquad \sigma^2_{X(t)} = \sigma^2\cos^2\omega t + \sigma^2\sin^2\omega t = \sigma^2$$

$$\Rightarrow\quad X(t) \sim N(0,\sigma^2), \qquad f_X(t;x) = \frac{1}{\sqrt{2\pi}\,\sigma}e^{-\frac{x^2}{2\sigma^2}}$$

注意分布**不依赖 $t$**（尽管 $A\cos\omega t$ 显含 $t$）。**这题根本不用做积分。**

> [!important] 求数字特征时，别绕道密度
> 习题 2.4、2.7 这类题**不需要**概率密度。直接用期望的线性性质和独立性：
> $$E[X(t)] = E[A]\cos\omega t + E[B]\sin\omega t$$
> $$R_X(t_1,t_2) = E\big[(Ac_1+Bs_1)(Ac_2+Bs_2)\big] = E[A^2]c_1c_2 + E[B^2]s_1s_2$$
> 只有题目**明说**要密度（如 2.2）时才去求密度。

### 1.3.6 多值反函数怎么办

当 $g(\cdot;t)$ 非单调（典型：$y \mapsto y^2$、$y \mapsto \sin y$），一个 $x$ 对应**多个** $y$。

**做法**：在 $y$ 的定义域上按单调区间分段，每段用套路 A 得到一个分支密度，最后**相加**：

$$f_X(t;x) = \sum_{i} f_Y\big(h_i(x;t)\big)\left|h_i'(x;t)\right|$$

典型例子：$X = Y^2$，$Y$ 有密度 $f_Y$，则

$$f_X(x) = \frac{1}{2\sqrt{x}}\Big[f_Y(\sqrt x) + f_Y(-\sqrt x)\Big], \quad x > 0$$

### 1.3.7 常见陷阱清单

1. **值域先定**。写出密度非零的区间，像 2.2 里的 $0<x<1$，不写就是错的。
2. **链式法则别漏**。$\frac{d}{dx}F_Y(h(x)) = f_Y(h(x))\cdot h'(x)$。
3. **不等式方向**。$g$ 递减时是 $1-F_Y(h)$，不是 $F_Y(h)$。现场推，别背。
4. **离散分支没有密度**。抛硬币这类只有分布函数，见 1.3.4。
5. **结果是 $t$ 的函数**。答案形如 $f_X(t;x)$，不要写成 $f_X(x)$。
6. **求 $R_X(t_1,t_2)$ 时别默认独立**。$X(t_1)$ 与 $X(t_2)$ 常常由**同一个**随机变量驱动（如 $X(t)=e^{-Yt}$ 里的 $Y$），要合并后一起算：

$$R_X(t_1,t_2) = E\left[e^{-Yt_1}e^{-Yt_2}\right] = E\left[e^{-Y(t_1+t_2)}\right] \ne E[e^{-Yt_1}]\,E[e^{-Yt_2}]$$

7. **二维同理但别混淆**。$F_X(t_1,t_2;x_1,x_2) = P\{X(t_1)\le x_1, X(t_2)\le x_2\}$，是**两个**自变量、**两个**取值的联合。

### 1.3.8 一维分布的三种来源（总览）

| 情形 | 固定 $t$ 后 $X(t)$ 的类型 | 求法 | 有密度吗 |
|---|---|---|---|
| 单一连续随机变量的单调函数 | 连续型 | 套路 A（反函数 + 雅可比） | ✅ |
| 单一连续随机变量的非单调函数 | 连续型 | 分段求和 $\sum_i f_Y(h_i)|h_i'|$ | ✅ |
| 有限分支随机选取 | 离散型 | 套路 B（全概率 → 阶梯函数） | ❌ |
| 多个独立随机变量的线性组合 | 连续型 | 认结构（正态 → 正态等） | ✅ |
| 多个随机变量的一般函数 | 连续型 | 联合密度 → 边缘化 / 雅可比 | ✅ |

## 1.4 数字特征

### 1.4.1 五个基本量

| 名称 | 记号 | 定义 | 说明 |
|---|---|---|---|
| 均值函数 | $m_X(t)$ | $E[X(t)]$ | 一阶矩 |
| 均方值函数 | $\psi_X^2(t)$ | $E[X^2(t)]$ | 二阶原点矩 |
| 方差函数 | $D_X(t)$ | $E[(X(t)-m_X(t))^2]$ | 二阶中心矩，记 $\sigma_X^2(t)$ |
| 相关函数 | $R_X(t_1,t_2)$ | $E[X(t_1)X(t_2)]$ | |
| 协方差函数 | $B_X(t_1,t_2)$ | $\operatorname{Cov}(X(t_1),X(t_2))$ | 去均值后的相关 |

互的版本：$R_{XY}(t_1,t_2) = E[X(t_1)Y(t_2)]$，$B_{XY}(t_1,t_2) = R_{XY} - m_X(t_1)m_Y(t_2)$。

### 1.4.2 关系网络

$$B_X(t_1,t_2) = R_X(t_1,t_2) - m_X(t_1)\,m_X(t_2)$$

$$D_X(t) = B_X(t,t) = R_X(t,t) - m_X^2(t) = \psi_X^2(t) - m_X^2(t)$$

$$\sigma_X(t) = \sqrt{D_X(t)}$$

$$\text{若 } m_X \equiv 0 \quad\Longrightarrow\quad B_X(t_1,t_2) = R_X(t_1,t_2)$$

> [!tip] 做题顺序
> 「先算 $R_X$，再减 $m_Xm_X$」通常最省事。$R_X$ 用 $E[\cdot]$ 的线性性质直接展开即可。

### 1.4.3 两条基本不等式

**自协方差**（习题 2.10）：

$$\left|B_X(t_1,t_2)\right| \le \sigma_X(t_1)\,\sigma_X(t_2) \qquad\text{且}\qquad \left|B_X(t_1,t_2)\right| \le \frac{1}{2}\left[\sigma_X^2(t_1)+\sigma_X^2(t_2)\right]$$

**互协方差**（习题 2.11）：

$$\left|B_{XY}(t_1,t_2)\right| \le \sigma_X(t_1)\,\sigma_Y(t_2)$$

**统一证法**：把 $\tilde X(t) = X(t)-m_X(t)$ 看成 $L^2$ 空间里的向量，则

$$B_X(t_1,t_2) = \langle \tilde X(t_1), \tilde X(t_2)\rangle, \qquad \|\tilde X(t)\| = \sigma_X(t)$$

一发 Cauchy–Schwarz $|\langle u,v\rangle| \le \|u\|\|v\|$ 全部搞定。第二式再用 $ab \le \frac{a^2+b^2}{2}$ 加强一次即可。

### 1.4.4 均值函数与相关函数的基本性质

- $m_X(t)$ 是普通函数
- **对称性**：$R_X(t_1,t_2) = R_X(t_2,t_1)$，$B_X(t_1,t_2) = B_X(t_2,t_1)$
- **非负定性**：对任意 $n$、$t_1,\dots,t_n$ 和任意复数 $a_1,\dots,a_n$，
  $$\sum_{i=1}^{n}\sum_{j=1}^{n} a_i \overline{a_j} B_X(t_i,t_j) \ge 0$$
- **对称性（互）**：$B_{XY}(t_1,t_2) = B_{YX}(t_2,t_1)$

## 1.5 平稳性

### 1.5.1 严平稳过程

对任意 $n \ge 1$、任意 $t_1,\dots,t_n$ 和任意 $\tau$，

$$F_{t_1+\tau,\dots,t_n+\tau}(x_1,\dots,x_n) = F_{t_1,\dots,t_n}(x_1,\dots,x_n)$$

即**有限维分布对时间平移不变**。也就是说：统计规律与「从哪一刻开始看」无关。

### 1.5.2 宽平稳过程（弱平稳 / 二阶平稳）

1. $m_X(t) = m_X$ 为**常数**
2. $R_X(t_1,t_2) = R_X(\tau)$ 只依赖于 $\tau = t_1-t_2$
3. $E[X^2(t)] < \infty$

### 1.5.3 两者的关系

| | 严平稳 | 宽平稳 |
|---|---|---|
| 要求 | 全部有限维分布平移不变 | 只看一、二阶矩 |
| 强弱 | **强** | **弱**（严平稳 + 二阶矩存在 ⇒ 宽平稳） |
| 反例 | 宽平稳不一定严平稳 | 见习题 2.15 |

> [!note] 什么时候两者等价
> **正态过程**中，「严平稳 $\iff$ 宽平稳」。因为正态分布的有限维分布完全由均值和协方差决定。

**例**：习题 2.4 中 $m_X \equiv 0$、$R_X = \sigma^2\cos\omega\tau$ 只依赖 $\tau$ —— 所以它是**宽平稳**的（也是严平稳的，因为它是正态过程）。

**例**：习题 2.5 中 $Y(t) = X(t)+\varphi(t)$，若 $X$ 平稳而 $\varphi$ 是**普通函数**，则 $m_Y(t) = m_X + \varphi(t)$ **不是常数** —— 均值的平移破坏了平稳性。

## 1.6 速查表

| 你要干什么 | 用什么 |
|---|---|
| 求一维分布函数 | $F_X(t;x) = P\{X(t)\le x\}$，把 $t$ 当常数 |
| 求一维概率密度 | $f_X(t;x) = \partial F_X/\partial x$；单调变换直接套 $f_Y(h)|h'|$ |
| 单调变换的密度 | $f_X(t;x) = f_Y(h(x;t))\,\lvert h'(x;t)\rvert$，注意**值域外为 0** |
| 非单调变换的密度 | $\sum_i f_Y(h_i(x;t))\,\lvert h_i'(x;t)\rvert$ |
| 离散分支 / 抛硬币 | 全概率，得**阶梯**分布函数，无密度 |
| 求均值函数 | $m_X(t) = E[X(t)]$，直接用线性性质，**别绕道密度** |
| 求相关函数 | $R_X(t_1,t_2) = E[X(t_1)X(t_2)]$，先展开再用独立 / 零均值消项 |
| 相关 → 协方差 | $B_X = R_X - m_X(t_1)m_X(t_2)$ |
| 证协方差有界 | $L^2$ 内积 + Cauchy–Schwarz |
| 判断宽平稳 | $m_X$ 是常数 且 $R_X$ 只依赖 $\tau$ |
| 判断严平稳 | 有限维分布平移不变 |
