# 1 随机过程（第五版）· 泊松过程典型题型

> [!info] 本篇说什么
> 泊松过程的题只有**两种问法**：问 **$N(t)$**（计数型）和问 **$W(n)$**（时刻型）。
> 两者之间有一座桥：$W(n)\le t \iff N(t)\ge n$。
> **所有时刻型的题，第一步都是先过桥翻译成计数型**，翻完就只剩泊松分布律。
> 本页习题 ② 正是「一问你计数、一问你时刻」的配套题。

---

## 1.1 题目

### 1.1.1 习题 ②（手写题，编号为 ②）

以 $N(t)$ 表示 $(0,t]$ 内到达商场的人数。设 $\{N(t),\ t\ge 0\}$ 的 $\lambda > 0$。

1. 求 $P\{N(1) = 0,\ N(2) = 1\}$。
2. 求 $P\{W(1) > 1,\ W(2) \le 2\}$。$W(i)$ 表示第 $i$ 个顾客到来的时刻。

## 1.2 解答

### 1.2.1 习题 ②

**预备**：$N(t)$ 是强度 $\lambda$ 的泊松过程，于是

$$N(t) \sim P(\lambda t), \qquad N(t)-N(s) \sim P\big(\lambda(t-s)\big) \quad (s<t)$$

且**不重叠区间的增量相互独立**。这两条就是全部的武器。

#### （1）$P\{N(1)=0,\ N(2)=1\}$ —— 计数型：拆不重叠增量

$N(1)$ 与 $N(2)$ 区间重叠，**不独立**，不能直接相乘。要把 $(0,2]$ 拆成两段：

$$\{N(1)=0,\ N(2)=1\} \iff \big\{N(1)=0,\ N(2)-N(1)=1\big\}$$

这两件事涉及的区间 $(0,1]$ 与 $(1,2]$ **不重叠**，故增量独立：

$$P\{N(1)=0,\ N(2)=1\} = P\{N(1)=0\}\cdot P\{N(2)-N(1)=1\}$$

区间长度都是 1，两个增量都服从 $P(\lambda)$：

$$= \underbrace{e^{-\lambda}}_{P\{P(\lambda)=0\}} \cdot \underbrace{\lambda e^{-\lambda}}_{P\{P(\lambda)=1\}} = \boxed{\ \lambda e^{-2\lambda}\ }$$

#### （2）$P\{W(1)>1,\ W(2)\le 2\}$ —— 时刻型：先翻译回计数

$W(i)$ 是第 $i$ 个顾客的到达时刻，直接求它的分布要积分，绕远路。**第一步永远是翻译回 $N$**：

| 时刻型事件 | 等价说法 | 等价计数型事件 |
|---|---|---|
| $W(1) > 1$ | 第 1 个人 1 时刻后才到 | 到时刻 1 一个人都没来：$N(1) = 0$ |
| $W(2) \le 2$ | 第 2 个人 2 时刻前已到 | 到时刻 2 至少来了 2 个人：$N(2) \ge 2$ |

于是

$$\{W(1)>1,\ W(2)\le 2\} \iff \{N(1)=0,\ N(2)\ge 2\} \iff \big\{N(1)=0,\ N(2)-N(1)\ge 2\big\}$$

同样两段不重叠，拆开相乘：

$$P = P\{N(1)=0\}\cdot P\{N(2)-N(1)\ge 2\} = e^{-\lambda}\Big[1 - e^{-\lambda} - \lambda e^{-\lambda}\Big]$$

其中方括号是 $P\{P(\lambda)\ge 2\} = 1 - P(0) - P(1)$。整理：

$$\boxed{\ P\{W(1)>1,\ W(2)\le 2\} = e^{-\lambda} - e^{-2\lambda} - \lambda e^{-2\lambda}\ }$$

> [!tip] 换条路验算（走 $W$ 的联合密度，答案一致）
> $W(1) < W(2)$ 的联合密度是 $f(w_1,w_2) = \lambda^2 e^{-\lambda w_2}$（$0<w_1<w_2$），直接积分：
> $$P = \int_{1}^{2}\!\!\int_{1}^{w_2} \lambda^2 e^{-\lambda w_2}\,dw_1\,dw_2 = \lambda^2 e^{-\lambda}\!\int_{0}^{1} u\,e^{-\lambda u}\,du = e^{-\lambda} - e^{-2\lambda} - \lambda e^{-2\lambda} \quad ✓$$
> （令 $u = w_2 - 1$，用 $\int_0^1 u e^{-\lambda u}du = \dfrac{1}{\lambda^2} - \left(\dfrac{1}{\lambda^2}+\dfrac{1}{\lambda}\right)e^{-\lambda}$。）
> **两条路都通，但翻译法几乎是口算**。考场上前一条。

**要点**：这题两问是同一个手法的两面 —— **只要区间重叠就先拆成不重叠的增量，独立性才有资格用**。
(1) 是纯计数型；(2) 的难点全在「$W$ 翻 $N$」这一步，翻完 (2) 和 (1) 长得一模一样。

## 1.3 题型归纳（补充内容）

### 1.3.1 泊松过程的题长什么样

```
泊松过程 N(t)（强度 λ）
      │
      ├── 直接问 N  →  计数型
      │        ├── 单时刻     N(t) ~ P(λt)
      │        ├── 增量       N(t)-N(s) ~ P(λ(t-s))
      │        └── 多时刻  →  拆成不重叠增量 + 独立性相乘
      │
      └── 问 W(n)  →  时刻型
               ├── 第一件事：过桥翻译  W(n) ≤ t ⇔ N(t) ≥ n
               ├── 翻完照计数型做（本页习题 ②(2)）
               └── 或直接套 W(n) ~ Γ(n, λ) 求分布 / 密度
```

**一句话抓住主线**：**能翻译成 $N$ 的题就是简单题。** 看见 $W$ 先别急着积分，先问「这等价于到某时刻为止来了几个人」。

### 1.3.2 那座桥（务必背熟）

$$\boxed{\ W(n)\le t \iff N(t)\ge n \qquad\qquad W(n) > t \iff N(t) \le n-1\ }$$

意思是：第 $n$ 个人在 $t$ 之前到 $\iff$ 到 $t$ 为止至少到了 $n$ 个人。

> [!important] 为什么是「$\le n-1$」不是「$\le n$」
> $W(n) > t$ 表示第 $n$ 个人来得比 $t$ 晚，也就是到 $t$ 为止**还没凑够 $n$ 个人**，所以 $N(t) \le n-1$。
> 写的时候用「互补事件」检查一遍：$N(t)\ge n$ 与 $N(t)\le n-1$ 恰好互补 ✓。

### 1.3.3 计数型的标准三步

1. **把题面里的所有时刻从小到大排好**：$t_1 < t_2 < \dots$
2. **把每个 $N(t_i)$ 改写成末段 + 前段之差**，保证各段区间**不重叠**：
   $$N(t_i) = \big[N(t_1)\big] + \big[N(t_2)-N(t_1)\big] + \dots + \big[N(t_i)-N(t_{i-1})\big]$$
3. **每段独立、分布已知** $P(\lambda \Delta t)$，直接相乘再按需要求和。

### 1.3.4 时刻型的两条路

| 路线 | 做法 | 什么时候用 |
|---|---|---|
| **翻译法**（首选） | 过桥化成 $N$ 的不等式，回到计数型 | 事件是「某个人早 / 晚于某时刻到达」这类不等式 |
| **分布法** | $W(n)\sim\Gamma(n,\lambda)$，$f_{W(n)}(t) = \dfrac{\lambda^n t^{n-1}}{(n-1)!}e^{-\lambda t}\ (t>0)$，积分 | 事件形如「$W(n)$ 落在某个区间」，且 $n$ 小、只要边缘分布 |
| **联合密度法** | $f(w_1,\dots,w_n) = \lambda^n e^{-\lambda w_n}$，$0<w_1<\dots<w_n$ | 多个 $W$ 的联合约束（如 ②(2) 的验算） |

### 1.3.5 常见情形表

| 问法 | 典型问句 | 关键等价 / 结论 | 怎么做 |
|---|---|---|---|
| 计数·单时刻 | $P\{N(t)=k\}$ | $N(t)\sim P(\lambda t)$ | 泊松分布律直接代入 |
| 计数·两时刻 | $P\{N(s)=i,\ N(t)=j\}$ | 拆成 $N(s)$ 与 $N(t)-N(s)$ | 独立增量 → 两个分布律相乘 |
| 计数·增量 | $P\{N(t)-N(s)=k\}$ | $\sim P\big(\lambda(t-s)\big)$ | 泊松分布律（**强度乘区间长**） |
| 时刻·单个 | $P\{W(n)\le t\}$ | $\iff N(t)\ge n$ | 翻译后求和；或 $\Gamma(n,\lambda)$ 积分 |
| 时刻·混合 | $P\{W(1)>1,\ W(2)\le2\}$ **（本页 ②(2)）** | $\iff\{N(1)=0,\ N(2)\ge2\}$ | 逐个翻成 $N$ 的不等式，再拆增量 |
| 等待间隔 | $P\{X_i > t\}$，$X_i = W(i)-W(i-1)$ | $X_i$ i.i.d. $\mathrm{Exp}(\lambda)$ | $e^{-\lambda t}$ |
| 条件分布 | $P\{N(s)=k \mid N(t)=m\}$ | $\sim B\!\left(m,\ \frac{s}{t}\right)$，$s<t$ | 二项分布律代入 |

> [!note] 后两行是补的
> 「等待间隔」「条件分布」两行原文没涉及，是我按本课程常规题型补的，便于和后面章节接上（条件分布那条在第 3 章讲泊松过程的**分解**时是核心工具）。

### 1.3.6 直观理解

- **独立增量** 描述「**过去来过几个人，完全不影响未来还来几个人**」—— 所以拆区间就等于拆独立事件。
- **平稳增量** 描述「**只在乎区间多长，不在乎从哪一刻开始**」—— 所以增量分布只依赖 $\lambda(t-s)$，$t$ 和 $s$ 各自是多少无关紧要。
- **$W(n)$ 是 $\Gamma(n,\lambda)$** 描述「**等第 $n$ 个人 = 等 $n$ 段独立的指数间隔之和**」—— 与第一章 $\Gamma$ 是 $n$ 个 $E(\lambda)$ 之和那条结论对上了。

## 1.4 注意点与陷阱

1. **区间重叠时千万别直接相乘**。$N(1)$ 与 $N(2)$ 不独立，$P\{N(1)=0,N(2)=1\}\ne P\{N(1)=0\}P\{N(2)=1\}$。正确概率是 $\lambda e^{-2\lambda}$，错误算法给的是 $e^{-\lambda}\cdot 2\lambda e^{-2\lambda} = 2\lambda e^{-3\lambda}$，数值不一样。
2. **强度要乘区间长度**。$N(t)-N(s)\sim P\big(\lambda(t-s)\big)$，考生常漏掉 $(t-s)$ 写成 $P(\lambda)$。本页 ② 里两段长度都是 1，所以看起来是 $P(\lambda)$，**别因此记成「增量永远是 $P(\lambda)$」**。
3. **看见 $W$ 先翻译**。直接去积分 $W$ 的联合密度不是错，但慢且积分限容易写反（本页 ②(2) 的验算里积分限是 $1<w_1<w_2\le 2$，很容易写成 $w_1$ 从 1 到 2、$w_2$ 从 $w_1$ 到 2 之外的样子）。
4. **$W(n)\le t$ 对应的是 $\ge n$ 而不是 $=n$**。第 2 个人在 2 时刻前到，可以是恰好来了 2 个，也可以是来了 5 个 —— 所以是 $\ge$，求和时别忘了尾巴。
5. **$N(0)=0$** 以及 $N(t)$ 只取非负整数，写分布律时 $k$ 的取值范围别漏。
6. **题目给的出发点要看清**。本题 $N(t)$ 统计的是 $(0,t]$（左开右闭），所以 $N(1)$ 就是「1 时刻之前来了几个」，与你熟悉的 $[0,t)$ 版本数值上一样，但写区间的时候要一致。

## 1.5 速查表

| 你要干什么 | 用什么 |
|---|---|
| 求 $P\{N(t)=k\}$ | $\dfrac{(\lambda t)^k}{k!}e^{-\lambda t}$ |
| 求 $P\{N(t)-N(s)=k\}$ | 同上，把 $\lambda t$ 换成 $\lambda(t-s)$ |
| 题里有多个时刻 | 先排序，把 $N(t_i)$ 拆成**不重叠**增量之和，再用独立性相乘 |
| 题里出现 $W(n)$ | 过桥：$W(n)\le t \iff N(t)\ge n$ |
| 出现 $W(n) > t$ | $N(t) \le n-1$（互补，用这个避免搞反） |
| 要 $W(n)$ 的分布 | $W(n)\sim\Gamma(n,\lambda)$，$f = \dfrac{\lambda^n t^{n-1}}{(n-1)!}e^{-\lambda t}$ |
| 要 $(W(1),\dots,W(n))$ 的联合密度 | $\lambda^n e^{-\lambda w_n}$，$0<w_1<\dots<w_n$ |
| 事件里既有 $N$ 又有 $W$ | 全部翻译成 $N$ 的不等式，再按计数型做 |
| 出现「间隔」 | $X_i = W(i)-W(i-1)$ i.i.d. $\sim \mathrm{Exp}(\lambda)$ |
