# 1 随机过程（第五版）第六章知识点 · 平稳过程与各态历经性

> [!info] 本篇说什么
> 第 6 章讲**平稳过程**，本篇只解决两个判断题 —— 手写笔记 (9) 里的 ① 和 ②：
> 1. **判断广义平稳性（判断是不是平稳过程）**：三个条件**同时**满足才算 —— 二阶矩存在、均值为常数、自相关只与时间差有关，即 $\boxed{R_X(t_1,t_2) = R_X(\tau),\ \tau = t_1 - t_2}$；
> 2. **判断各态历经性**：看「**一条样本函数的**时间平均」能不能替代「**无穷多条样本的**统计平均」——均值各态历经 $\langle X(t)\rangle = E[X(t)]$，自相关各态历经 $\langle X(t)X(t+\tau)\rangle = R_X(\tau)$；两条都成立才叫过程各态历经。
>
> 一句话：**① 管「平稳不平移」，② 管「一条曲线能不能代表全体」。**

---

## 1.1 本章脉络

```
平稳过程
    │
    ├── 严平稳（狭义平稳）：任意有限维分布对时间平移不变
    │         X(t1+h),…,X(tn+h) 与 X(t1),…,X(tn) 同分布
    │              │
    │              └── 再加「二阶矩存在」 ⇒ 一定宽平稳
    │                     （反之不成立：宽平稳 ≠ 严平稳）
    │
    └── 宽平稳 / 广义平稳【本篇 ①：三条件，缺一不可】
              (1) 二阶矩存在      E[X²(t)] < +∞
              (2) 均值为常数      E[X(t)] = m_X  （与 t 无关）
              (3) 自相关只与时间差有关   R_X(t1,t2) = R_X(τ),  τ = t1 - t2
                       │
                       └── 结论：只要两个数字特征就够用 —— m_X 与 R_X(τ)
                              （协方差 C_X(τ) = R_X(τ) - m_X²）

平稳之后才能问的问题 —— 能不能「测一条曲线就够」？
    │
    └── 各态历经性（遍历性）【本篇 ②】
              (1) 均值各态历经        ⟨X(t)⟩ = E[X(t)] = m_X
              (2) 自相关各态历经      ⟨X(t)·X(t+τ)⟩ = R_X(τ)
              (3) 两条同时成立 ⇒ X(t) 各态历经
              (4) 时间平均怎么算      ⟨X(t)⟩ = lim_{T→∞} (1/2T) ∫_{-T}^{T} X(t) dt
```

**一句话抓住主线**：**先验「三条件」定平稳，再用「时间平均 = 统计平均」验各态历经。** 三条件里最容易被忽略的是 (1)，最常用来判定的是 (3)。

## 1.2 定义

### 1.2.1 严平稳过程（狭义平稳）【补充：手写稿未展开】

对任意 $n \ge 1$、任意 $t_1,\dots,t_n$ 与任意时间平移 $h$，若

$$(X(t_1+h),\dots,X(t_n+h)) \quad\text{与}\quad (X(t_1),\dots,X(t_n)) \ \text{同分布}$$

即**任意有限维分布对时间平移不变**，则称 $X(t)$ 为**严平稳过程**。

### 1.2.2 宽平稳过程（广义平稳）【本篇 ① 原文】

> [!important] 手写稿原文（Part 09 ①）
> **判断广义平稳性 / 平稳过程：**
> 1. **二阶矩存在**；
> 2. **均值为常数**；
> 3. $R_X[t_1,t_2]$ **仅与 $\tau = t_1 - t_2$ 有关**；
> **同时满足以上三点，则是。**

写成式子：

$$\boxed{\ \begin{aligned}
&(1)\quad E\left[X^2(t)\right] < +\infty \quad (\text{二阶矩存在})\\[2pt]
&(2)\quad E\left[X(t)\right] = m_X \quad (\text{与 } t \text{ 无关，是常数})\\[2pt]
&(3)\quad R_X(t_1,t_2) = E\left[X(t_1)X(t_2)\right] = R_X(\tau),\qquad \tau = t_1 - t_2
\end{aligned}\ }$$

同时满足以上三条，就说 $X(t)$ 是**宽平稳过程**（广义平稳过程）。

> [!tip] (3) 是「只看时间差」的意思
> $t_1$、$t_2$ 各自取多少不重要，只有**差** $\tau = t_1 - t_2$ 重要。等价说法是：把 $R_X(t_1,t_2)$ 里的 $t_1,t_2$ 换成 $t+\tau$ 与 $t$ 之后，**$t$ 必须被消掉**。
> 所以检验 (3) 的手法就一句：**看结果里还剩不剩单独的 $t_1$ 或 $t_2$。**

### 1.2.3 时间平均 $\langle\cdot\rangle$

> [!important] 手写稿原文（Part 09 ②(4)）
> $$\langle X(t)\rangle = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T} X(t)\,dt$$

**定义**：对一条**固定**的样本函数 $X(t)$（一条实现、一条曲线），沿**时间轴**取平均，得上式，记作 $\langle X(t)\rangle$。

同类地，**时间自相关函数**为

$$\langle X(t)X(t+\tau)\rangle = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T} X(t)X(t+\tau)\,dt$$

> [!important] 「时间平均」与「统计平均」是两种平均
> - **统计平均** $E[\cdot]$：在**同一时刻** $t$ 上，对**全体样本**（$\omega$）横着平均 —— 理论上要求无穷多次实验；
> - **时间平均** $\langle\cdot\rangle$：对**同一条样本**，沿**时间**竖着平均 —— 理论上要求观测无穷长。
>
> 注意 $\langle X(t)\rangle$ 的结果里**不含 $t$**（被积掉了），但它**仍是随机变量**（因为依赖于取到哪一条样本）。

### 1.2.4 各态历经性（遍历性）【本篇 ② 原文】

> [!important] 手写稿原文（Part 09 ②）
> **判断各态历经性：**
> 1. 若 $\langle X(t)\rangle = E[X(t)]$，则**均值**具有各态历经性；
> 2. 若 $\langle X(t)\cdot X(t+\tau)\rangle = R_X[t_1,t_2]$，则**自相关函数**具有各态历经性；
> 3. 若同时满足以上两式，则 $X(t)$ 具有各态历经性；
> 4. $\langle X(t)\rangle = \lim\limits_{T\to\infty}\dfrac{1}{2T}\displaystyle\int_{-T}^{T} X(t)\,dt$。

写成式子（$X(t)$ 已宽平稳，故 $R_X(t_1,t_2) = R_X(\tau)$）：

$$\boxed{\ \begin{aligned}
(1)&\quad \text{均值各态历经} \iff \langle X(t)\rangle = E[X(t)] = m_X\\[4pt]
(2)&\quad \text{自相关各态历经} \iff \langle X(t)X(t+\tau)\rangle = R_X(\tau)\\[4pt]
(3)&\quad \text{过程各态历经} \iff (1)\ \text{且}\ (2)
\end{aligned}\ }$$

> [!note] 为什么原文第 2 条右边写 $R_X[t_1,t_2]$ 也没错
> 因为各态历经性**只在宽平稳的前提下讨论**（见 1.8 陷阱 5），此时 $R_X(t_1,t_2)$ 本来就是 $R_X(\tau)$，两种写法是同一个数。
> 但**写 $R_X(\tau)$ 更标准** —— 它强调了「右边必须只含 $\tau$，不能含 $t$」。

## 1.3 核心 ①：判断广义平稳性（三条件逐个拆）

| 条件 | 式子 | 为什么必须有它 | 不满足会怎样 |
|---|---|---|---|
| **(1) 二阶矩存在** | $E[X^2(t)] < +\infty$ | $R_X(t_1,t_2)$ 本身就是二阶矩，不存在就无从谈起 | 严平稳但方差无穷 ⇒ 不算宽平稳 |
| **(2) 均值为常数** | $E[X(t)] = m_X$ | 均值随时间漂移就谈不上「稳」 | 如 $X(t)=tY$，均值 $\propto t$ |
| **(3) 自相关只看时间差** | $R_X(t_1,t_2) = R_X(\tau)$ | 统计规律的「形状」不随时间平移而改变 | 如 $R_X = t_1t_2$，单独含 $t_1,t_2$ |

**为什么第三条写成 $R_X(\tau)$ 就够**：宽平稳过程的一切二阶统计量都由 $m_X$ 与 $R_X(\tau)$ 决定，常用的还有

$$C_X(\tau) = \operatorname{Cov}\big(X(t),X(t+\tau)\big) = R_X(\tau) - m_X^2,\qquad D[X(t)] = C_X(0) = R_X(0) - m_X^2$$

因为 $m_X$ 与 $t$ 无关，所以**方差也是常数** —— 这正是「平稳」的实质含义。

> [!note] 严平稳与宽平稳的关系【补充】
> - **严平稳 $+$ 二阶矩存在 $\Rightarrow$ 宽平稳**（平移不变 ⇒ 一维分布不变 ⇒ 均值常数；二维分布不变 ⇒ 自相关只看 $\tau$）；
> - **宽平稳 $\not\Rightarrow$ 严平稳**（只锁住一、二阶矩，管不了高阶分布）；
> - **例外**：**正态过程**（高斯过程）宽平稳 $\iff$ 严平稳 —— 正态分布由均值与协方差完全决定，二阶矩够了。
> - 反例（严平稳但不宽平稳）：$X(t) = 1/Y$，$Y \sim N(0,1)$，分布不随时间变（严平稳），但 $E[X^2] = E[1/Y^2] = +\infty$。

## 1.4 核心 ②：判断各态历经性

### 1.4.1 两条判据怎么用

**判据一（均值）**：算出时间平均 $\langle X(t)\rangle$，与 $m_X = E[X(t)]$ 比。

$$\langle X(t)\rangle = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}X(t)\,dt \quad\stackrel{?}{=}\quad m_X$$

**判据二（自相关）**：算出时间自相关 $\langle X(t)X(t+\tau)\rangle$，与 $R_X(\tau)$ 比。

$$\langle X(t)X(t+\tau)\rangle = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}X(t)X(t+\tau)\,dt \quad\stackrel{?}{=}\quad R_X(\tau)$$

**两条都等号成立，才说 $X(t)$ 各态历经。**

> [!tip] 手算时间平均的两把工具
> 1. **三角函数**：$\dfrac{1}{2T}\displaystyle\int_{-T}^{T}\cos(\omega t+\varphi)\,dt = \dfrac{\sin(\omega T)}{\omega T}\cos\varphi \xrightarrow{T\to\infty} 0$（$\omega \ne 0$）；
> 2. **常数**：$\dfrac{1}{2T}\displaystyle\int_{-T}^{T} c\,dt = c$（常数原样留下）。
>
> 于是「含 $\cos/\sin$ 的项统统归零，只剩不含 $t$ 的常数项」—— 这是绝大多数题的全部计算量。

### 1.4.2 均值各态历经的判据（补充）

判据一是**定义式**，但工程上更常用一条**只跟 $R_X$ 有关**的判据：宽平稳过程均值各态历经 $\iff$

$$\lim_{T\to\infty}\frac{1}{T}\int_{0}^{2T}\left(1-\frac{\tau}{2T}\right)\big[R_X(\tau) - m_X^2\big]\,d\tau = 0$$

**充分条件（最好记）**：

$$\int_{-\infty}^{+\infty}\big|R_X(\tau) - m_X^2\big|\,d\tau < +\infty \quad\Longrightarrow\quad \text{均值各态历经}$$

**意思**：自相关函数**衰减得足够快**（快过 $1/|\tau|$）时，均值就各态历经。特别地，若 $\lim_{|\tau|\to\infty}R_X(\tau) = m_X^2$ 且衰减够快，也成立。

> [!note] 为什么「衰减快」就能各态历经
> $\langle X(t)\rangle$ 是一条曲线上的长时间平均，它与 $m_X$ 的偏差大小由「不同时刻的自相关」决定。$R_X(\tau)$ 在 $\tau$ 大时趋近 $m_X^2$，说明**相隔很久的两个时刻几乎不相干**，长时间平均就会把随机涨落**互相抵消**掉，于是收敛到 $m_X$。
> 反之，若 $R_X(\tau)$ 一直不衰减（比如每一条样本都长期停留在自己的水平上），长时间平均只能得到**这一条样本的**水平，当然代替不了全体样本的均值。

---

## 1.5 自相关函数 $R_X(\tau)$ 的四条性质【补充】

宽平稳过程的自相关函数 $R_X(\tau)$ 必满足：

| 性质 | 式子 | 说明 |
|---|---|---|
| **零点是均方值** | $R_X(0) = E[X^2(t)] \ge 0$ | 也就是 $C_X(0) + m_X^2 = D_X + m_X^2$ |
| **偶函数** | $R_X(-\tau) = R_X(\tau)$ | 由 $R_X(t_1,t_2) = R_X(t_2,t_1)$，差取反号 |
| **上界在零点** | $\lvert R_X(\tau)\rvert \le R_X(0)$ | 柯西–施瓦茨不等式直接得到 |
| **非负定** | $\sum_{i,j}a_i a_j R_X(t_i - t_j) \ge 0$ | 由协方差矩阵半正定得到 |

> [!tip] 这三条是「考场零成本验算」
> 算出 $R_X(\tau)$ 后扫一眼：**是不是偶函数？$\tau=0$ 处是不是最大？值是不是非负？** 三条有任一条不满足，答案必错 —— 比重新推一遍快得多。

## 1.6 常见情形表

| 过程 $X(t)$ | $E[X(t)]$ | $R_X(\tau)$ | 宽平稳？ | 各态历经？ |
|---|---|---|---|---|
| $X(t) = Y$（$Y$ 与 $t$ 无关，$E[Y^2]<\infty$） | $E[Y]$，常数 | $E[Y^2]$，常数 | **是** | **否**（$\langle X\rangle = Y \ne E[Y]$） |
| $X(t) = tY$ | $tE[Y]$，**含 $t$** | $t_1t_2E[Y^2]$，**含 $t_1,t_2$** | 否（(2)(3) 都破） | 无从谈起 |
| $X(t) = Y\sin t$ | $E[Y]\sin t$，**含 $t$** | $E[Y^2]\sin t_1\sin t_2$ | 否（(2)(3) 都破） | 无从谈起 |
| $X(t) = A\cos(\omega t + \Theta)$，$A$ 常数，$\Theta\sim U(0,2\pi)$ | $0$ | $\dfrac{A^2}{2}\cos\omega\tau$ | **是** | **是**（两条都成立） |
| $X(t) = A\cos(\omega t + \Theta)$，$A$ 随机（$D(A)>0$） | $0$ | $\dfrac{E[A^2]}{2}\cos\omega\tau$ | **是** | **均值是，自相关否** |
| $X(t)$ 为白噪声（$m_X = 0$，$R_X(\tau) = \sigma^2\delta(\tau)$） | $0$ | $\sigma^2\delta(\tau)$ | **是** | **是** |
| 正态过程 | 常数 | 只看 $\tau$ | 是 $\iff$ 严平稳 | 按定义验 |

## 1.7 直观理解

- **宽平稳** 描述「**统计规律不随时间的推移而改变**」—— 今天测和明天测，均值一样、波动的「胖瘦」和「相关程度」也一样。所以只要两个数字特征 $m_X$、$R_X(\tau)$ 就够描述它。
- **严平稳** 描述「**整个分布都随时间的推移而平移不变**」—— 比宽平稳强，要求所有阶的分布都不变。
- **时间平均 $\langle\cdot\rangle$** 描述「**沿着一条曲线，用长时间把涨落摊平**」—— 结果是一个随机变量（换一条曲线就换一个值）。
- **各态历经性** 描述「**一条曲线能不能代表全体**」—— 它是把「理论上要做无穷多次实验」换成「实际上只测一条曲线、测足够久」的**许可证**。
- **均值各态历经 / 自相关各态历经** 是**两件独立的事**：一个过程的均值可能可以这样测，自相关却不行（见 1.8 的例 2）。

> [!note] 一个能拔高的观察
> 各态历经性回答的是**工程可行性**问题：随机过程是「一族样本函数」，理论上它的均值要对全体样本平均，可现实中**你只观测得到一条样本**（一台设备的某一次测量记录）。
> 所以「能不能用时间平均代替统计平均」不是数学洁癖，而是**随机过程理论能不能落地的关键** —— 这正是第 6 章把各态历经性紧跟平稳性讲的原因。

## 1.8 例题

### 1.8.1 例 1（快速判定组）【补充】

> 判断下列过程是否宽平稳；若是，再判断是否各态历经。设 $Y$ 是随机变量（$E[Y^2]<\infty$），$\omega$ 为常数。
> (a) $X(t) = Y$； (b) $X(t) = tY$； (c) $X(t) = Y\sin t$

**（a）$X(t) = Y$**

- (1) $E[X^2] = E[Y^2] < \infty$ ✓
- (2) $E[X(t)] = E[Y] = m_X$，与 $t$ 无关 ✓
- (3) $R_X(t_1,t_2) = E[Y\cdot Y] = E[Y^2]$，**与 $t_1,t_2$ 完全无关**（当然只与 $\tau$ 有关）✓
- $\Rightarrow$ **宽平稳**。

各态历经性：

$$\langle X(t)\rangle = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}Y\,dt = \lim_{T\to\infty}\frac{1}{2T}\cdot Y\cdot 2T = Y$$

只有当 $Y$ 以概率 1 等于常数 $E[Y]$ 时才有 $Y = E[Y]$，一般 $Y$ 是随机变量（如 $Y\sim U(0,1)$ 时 $Y \ne 0.5$）$\Rightarrow$ **均值不各态历经**，故**过程不各态历经**。

**（b）$X(t) = tY$**

$$E[X(t)] = t\,E[Y]$$

**含 $t$**（除非 $E[Y]=0$），条件 (2) 破；且 $R_X(t_1,t_2) = t_1t_2E[Y^2]$ 单独含 $t_1,t_2$，条件 (3) 也破 $\Rightarrow$ **不是宽平稳**。（各态历经性必须在宽平稳下谈，此处不用再判。）

**（c）$X(t) = Y\sin t$**

$$E[X(t)] = E[Y]\sin t \quad\text{含 } t\;,\qquad R_X(t_1,t_2) = E[Y^2]\sin t_1 \sin t_2 \quad\text{含 } t_1,t_2$$

$\Rightarrow$ **不是宽平稳**。

**要点**：判 (3) 最快的手法 —— **把 $t_1,t_2$ 写进去算完，看 $t_1,t_2$ 有没有被消掉**。只要结果里还留着单独的 $t$、$\sin t$，就不平稳。
另外注意 (a) 这个「**最平稳却最不各态历经**」的过程：$R_X$ 是常数，平稳性满分，但一条曲线的水平永远停在 $Y$ 上、随不出来 $E[Y]$ —— 它正是「$R_X(\tau)$ 不衰减（恒为常数）⇒ 均值不各态历经」的极端例子。

### 1.8.2 例 2（余弦过程，最经典的完整判定）【补充】

> 设 $X(t) = A\cos(\omega t + \Theta)$，其中 $A$ 与 $\Theta$ 独立，$\Theta \sim U(0,2\pi)$，$\omega$ 为常数，$E[A^2] < \infty$。判断 $X(t)$ 的平稳性与各态历经性。

**① 判断广义平稳性**

$$E[X(t)] = E[A]\,E[\cos(\omega t+\Theta)] = E[A]\cdot \frac{1}{2\pi}\int_0^{2\pi}\cos(\omega t+\theta)\,d\theta = 0 \quad (\text{常数})$$

$$R_X(t_1,t_2) = E[A^2]\,E\big[\cos(\omega t_1+\Theta)\cos(\omega t_2+\Theta)\big]$$

用积化和差 $\cos\alpha\cos\beta = \frac12[\cos(\alpha-\beta)+\cos(\alpha+\beta)]$：

$$R_X(t_1,t_2) = \frac{E[A^2]}{2}\Big(E\big[\cos\omega(t_1-t_2)\big] + E\big[\cos(\omega(t_1+t_2)+2\Theta)\big]\Big)$$

第一项**不含随机量**，第二项对 $\Theta\sim U(0,2\pi)$ 平均为 $0$（$2\Theta$ 遍历整个周期）：

$$\boxed{\ R_X(\tau) = \frac{E[A^2]}{2}\cos\omega\tau\ },\qquad \tau = t_1-t_2$$

又 $R_X(0) = \frac{E[A^2]}{2} < \infty$ ✓。三条齐备 $\Rightarrow$ **宽平稳**。

**② 判断各态历经性 —— 均值**

$$\langle X(t)\rangle = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}A\cos(\omega t+\Theta)\,dt = \lim_{T\to\infty}\frac{A}{2T}\cdot\frac{2\sin(\omega T)\cos\Theta}{\omega} = \lim_{T\to\infty}\frac{A\cos\Theta\sin(\omega T)}{\omega T} = 0$$

$\langle X(t)\rangle = 0 = E[X(t)]$ $\Rightarrow$ **均值各态历经** ✓

**③ 判断各态历经性 —— 自相关**

$$\langle X(t)X(t+\tau)\rangle = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}A^2\cos(\omega t+\Theta)\cos\big(\omega(t+\tau)+\Theta\big)\,dt$$

再用积化和差，第二项是 $t$ 的余弦（频率 $2\omega$），时间平均为 $0$；第一项 $\frac{A^2}{2}\cos\omega\tau$ 与 $t$ 无关，原样留下：

$$\langle X(t)X(t+\tau)\rangle = \frac{A^2}{2}\cos\omega\tau$$

与 (1) 比较：

$$\underbrace{\frac{A^2}{2}\cos\omega\tau}_{\langle X(t)X(t+\tau)\rangle} \quad=\quad \underbrace{\frac{E[A^2]}{2}\cos\omega\tau}_{R_X(\tau)} \quad\Longleftrightarrow\quad A^2 = E[A^2]$$

- 若 $A$ **是常数**（$A^2 = E[A^2]$ 自动成立）$\Rightarrow$ **自相关各态历经**，于是过程**各态历经**；
- 若 $A$ **是随机变量且 $D(A)>0$** $\Rightarrow$ 等号不成立 $\Rightarrow$ **自相关不各态历经**，过程**不是各态历经过程**（但仍是宽平稳过程！）。

**要点**：这道题是第 6 章的「万能模板」，三步全在里面 ——
① $E[\cos(\omega t+\Theta)] = 0$、$E[\cos(\omega(t_1+t_2)+2\Theta)] = 0$（**对 $\Theta$ 均匀分布平均**）；
② $R_X(t_1,t_2)$ 里 $t_1+t_2$ 的项被均掉、只剩 $t_1-t_2$ $\Rightarrow$ 平稳；
③ 时间平均把**频率非零的余弦项全归零**，只剩与 $t$ 无关的常数项。
**另外记住这个「平稳但不各态历经」的标准反例**：振幅随机时，自相关函数各态历经性失效。

> [!warning] 例 2 里最容易丢的条件
> ③ 的最后一步**必须比较 $A^2$ 与 $E[A^2]$**，不能想当然地写「两者相等」。$A$ 随机 $\Rightarrow$ 不等 $\Rightarrow$ 不各态历经 —— 这正是出题人埋的点。
> 另外 $\Theta\sim U(0,2\pi)$ 这个条件不能少：若 $\Theta$ 不是均匀分布，$E[\cos(\omega t+\Theta)]$ 一般不为 $0$，第一步的均值就非常数了。

## 1.9 注意点与陷阱

1. **三个条件必须同时满足**，缺一不可。最常被漏掉的是 **(1) 二阶矩存在** —— 手写稿把它列为第一条，考试里也常考「严平稳但二阶矩发散 ⇒ 非宽平稳」。
2. **$R_X(t_1,t_2) = R_X(\tau)$ 是「只看差」**，不是「随便一个常数都行」。$R_X = E[Y^2]$ 这种常量算合格（它确实只与 $\tau$ 有关，尽管无关得彻底）；但 $R_X = t_1^2 + t_2^2$ 不合格。
3. **偶函数别丢负号**。$R_X(-\tau) = R_X(\tau)$，写 $\cos\omega(-\tau)$ 与 $\cos\omega\tau$ 是同一个值，别在这里翻车。
4. **各态历经性要在宽平稳的前提下谈**。手写稿 ② 的前提就是 ① 已经成立；若过程不平稳，$E[X(t)]$、$R_X(t_1,t_2)$ 都不是常数，「时间平均等于它」这句话本身没有意义。
5. **「均值各态历经」$\ne$「自相关各态历经」**。二者是**独立**的两条，必须分别验。例 2 中 $A$ 随机时前者成立、后者不成立，过程整体就**不算**各态历经。
6. **右边写 $R_X(\tau)$ 而不是 $R_X(t,t+\tau)$**。后者写法虽与前者等值（宽平稳下），但容易让人误以为右边还能含 $t$。
7. **时间平均里的 $\lim$ 是「均方收敛 / 以概率 1 收敛」**，手写稿为简洁写成普通极限。做题时按「算出来相等」处理即可，但概念上别理解成逐点的普通极限。
8. **时间平均的分母是 $2T$、积分区间 $[-T,T]$**。别记成 $1/T$、$[0,T]$ —— 若题目改用 $\frac{1}{T}\int_0^{T}$，结论一样，但写式子时要与题目一致。
9. **$\langle X(t)\rangle$ 的结果仍是随机变量**（依赖取到哪条样本），只是不含 $t$。别把它当成一个确定常数来用。

## 1.10 速查表

| 你要干什么 | 用什么 |
|---|---|
| **判广义平稳** | 三条件同时：$E[X^2]<\infty$、$E[X(t)]=m_X$、$R_X(t_1,t_2)=R_X(\tau)$ |
| 快速检验第 (3) 条 | 把 $t_1,t_2$ 代进去算，看结果里**还剩下单独的 $t_1$ 或 $t_2$** 没有 |
| 由 $R_X(t_1,t_2)$ 导出 $R_X(\tau)$ | 令 $t_1 = t+\tau,\ t_2 = t$，把 $t$ 消掉 |
| 求均方值 | $R_X(0) = E[X^2(t)] = D_X + m_X^2$ |
| 求协方差函数 | $C_X(\tau) = R_X(\tau) - m_X^2$，且 $D_X = C_X(0)$ |
| 由 $m_X,R_X$ 判严平稳（正态过程） | 正态过程：宽平稳 $\iff$ 严平稳 |
| **判均值各态历经** | $\langle X(t)\rangle \stackrel{?}{=} m_X$；充分条件 $\int_{-\infty}^{+\infty}\lvert R_X(\tau)-m_X^2\rvert\,d\tau < \infty$ |
| **判自相关各态历经** | $\langle X(t)X(t+\tau)\rangle \stackrel{?}{=} R_X(\tau)$ |
| **判过程各态历经** | 上面两条同时成立 |
| 算时间平均 | $\langle X(t)\rangle = \lim\limits_{T\to\infty}\dfrac{1}{2T}\displaystyle\int_{-T}^{T}X(t)\,dt$ |
| 算时间自相关 | $\langle X(t)X(t+\tau)\rangle = \lim\limits_{T\to\infty}\dfrac{1}{2T}\displaystyle\int_{-T}^{T}X(t)X(t+\tau)\,dt$ |
| 时间平均里余弦项怎么办 | $\frac{1}{2T}\int_{-T}^{T}\cos(\omega t+\varphi)dt \to 0$（$\omega\ne0$），**含 $t$ 的振荡项统统归零** |
| 验算 $R_X(\tau)$ | $R_X(0)\ge0$、$R_X(-\tau)=R_X(\tau)$、$\lvert R_X(\tau)\rvert \le R_X(0)$ |
