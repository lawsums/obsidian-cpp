# 1 随机过程（第五版）· 马尔可夫链典型题型

> [!info] 本篇说什么
> 三道把第 4 章考点串成一条线的综合题（手写编号 ②、③、④）：
> 1. **两步转移矩阵** $P^{(2)} = P^2$ —— 求 $p_{01}^{(2)}$（对应知识点 1.2.3）
> 2. **全概率公式** —— 由初始分布求 $X_2$ 的边缘分布（本篇补的新套路）
> 3. **证遍历 + 求平稳分布** $\pi P = \pi$（对应知识点 1.11、1.12）
> 4. **状态分类 + 周期 + 返回时间**（对应知识点 1.3~1.5）
>
> 一句话回答常见疑惑：**两步转移矩阵就是一步矩阵自己乘自己**，$P^{(2)} = P\cdot P$；三步再乘一次，$n$ 步就是 $n$ 个 $P$ 相乘。
>
> - 习题 ② 与 ③ 是**同一套拳打两遍**，唯一的变量是**初始分布**（② 均匀、③ 退化）—— 对照见 1.3.6。
> - 习题 ④ 换了个赛道：**可约链**（有闭集、有非常返态），**靠图不靠算** —— 对照见 1.3.7。

1. $P\{X_0 = 0,\ X_2 = 1\}$；

## 1.2 解答

### 1.2.1 习题 ②(1) $P\{X_0=0,\ X_2=1\}$ —— 两步转移矩阵

**第一步：用条件概率拆开。**

$$P\{X_0=0,\ X_2=1\} = P\{X_0=0\}\cdot P\{X_2 = 1 \mid X_0 = 0\} = \frac13\cdot p_{01}^{(2)}$$

初始分布给了 $P\{X_0=0\} = \frac13$，而后一个因子正是**两步转移概率** $p_{01}^{(2)}$。

**第二步：求两步转移矩阵。** 两步转移矩阵就是一步矩阵**自己乘自己**：

$$P^{(2)} = P^2 = P\cdot P = \begin{pmatrix}
\frac58 & \frac{5}{16} & \frac{1}{16}\\[3pt]
\frac{5}{16} & \frac12 & \frac{3}{16}\\[3pt]
\frac{3}{16} & \frac{9}{16} & \frac14
\end{pmatrix}$$

与图中一致 ✓。给一个元素的算法示范（$p_{ij}^{(2)} = \sum_k p_{ik}p_{kj}$）：

$$p_{01}^{(2)} = \frac34\cdot\frac14 + \frac14\cdot\frac12 + 0\cdot\frac34 = \frac{3}{16} + \frac{2}{16} = \frac{5}{16}$$

**第三步：代入。**

$$P\{X_0=0,\ X_2=1\} = \frac13\times\frac{5}{16} = \boxed{\ \frac{5}{48}\ }$$

**要点**：$p_{ij}^{(n)}$ 就是**从矩阵里取元素** —— $p_{01}^{(2)}$ 是 $P^2$ 的**第 0 行第 1 列**。起点写死时，一步到位，不用求和。

### 1.2.2 习题 ②(2) $P\{X_2=1\}$ —— 全概率公式

> *（原图未拍到，以下解答为补）*

**思路**：$X_2 = 1$ 没说从哪出发，那就**对所有可能的起点 $X_0$ 用全概率公式**：

$$P\{X_2=1\} = \sum_{i=0}^{2} P\{X_0 = i\}\,P\{X_2 = 1 \mid X_0 = i\} = \sum_{i=0}^{2} p_i(0)\,p_{i1}^{(2)}$$

三个数就从 $P^2$ 的**第 1 列**取：$p_{01}^{(2)} = \frac{5}{16}$，$p_{11}^{(2)} = \frac12$，$p_{21}^{(2)} = \frac{9}{16}$。

$$= \frac13\left(\frac{5}{16} + \frac12 + \frac{9}{16}\right) = \frac13\cdot\frac{5+8+9}{16} = \frac13\cdot\frac{22}{16} = \boxed{\ \frac{11}{24}\ }$$

> [!tip] 等价写法：分布向量右乘 $P^2$
> 设初始分布的行向量 $\pi^{(0)} = [\frac13,\ \frac13,\ \frac13]$，则 $n$ 步后的分布是
> $$\pi^{(n)} = \pi^{(0)}P^{\,n}$$
> 于是 $\pi^{(2)} = \pi^{(0)}P^2 = [\frac38,\ \frac{11}{24},\ \frac16]$，第 2 个分量就是答案 $\frac{11}{24}$ ✓（顺便自查：三个分量相加 $= 1$ ✓）。
> 两条路是同一件事：**标量写法是「按起点加权求和」，矩阵写法就是一次向量乘矩阵。**

**要点**：(2) 是 (1) 的升级版 —— (1) 起点**固定**，只算一条来路；**(2) 起点不固定，要把所有来路按初始分布加权求和**。

### 1.2.3 习题 ②(3) 证明遍历 + 求平稳分布

> *（①③ 是老师原图给的解答；② 的三步法模板见知识点 1.11）*

#### 1.2.3.1 ① 证明遍历

> [!important] 老师原话 —— 考试就背这一句
> **「因为该马氏链不可约、状态有限且周期为 1，故遍历。」**
> 一句话 = 三个短语 = 遍历的三个条件，考场照写就行，不用展开。

**这一句话为什么够用**（对应知识点 1.12.1、1.12.2）：

| 话里的短语 | 对应条件 | 本题怎么对上 |
|---|---|---|
| 「不可约」 | 不可约 | $0 \leftrightarrow 1 \leftrightarrow 2$，两两互通 |
| 「**状态有限**」 | 正常返 | 有限 + 不可约 $\Rightarrow$ 正常返**自动成立**（1.12.2） |
| 「周期为 1」 | 非周期 | $p_{00} = \frac34 > 0$，有自环 |

> [!tip] 「状态有限」这四个字是这句话的命门
> 它**替掉了「正常返」**——因为「有限状态 + 不可约 ⟹ 正常返」是定理，不必再证。
> 所以句里**一个字都不能少**：少了「状态有限」，正常返就没人管了；少了「周期为 1」，非周期就没验。
> 记法：**不可约（能到处走）+ 状态有限（走得回来、不用等无穷久）+ 周期 1（回来的节拍不乱）**。

**展开写**（万一题目要求写理由）：

- **不可约**：$p_{01} = \frac14 > 0$、$p_{10} = \frac14 > 0$ 给出 $0 \leftrightarrow 1$；$p_{12} = \frac14 > 0$、$p_{21} = \frac34 > 0$ 给出 $1 \leftrightarrow 2$。串起来，$0,1,2$ **两两互通**，互通类唯一 ✓
- **周期为 1**：$p_{00} = \frac34 > 0$ 存在**自环** $\Rightarrow d_0 = 1$；不可约链各状态周期相同 $\Rightarrow$ 全部**非周期** ✓
- **正常返**：状态数 3 有限 + 链不可约 $\Rightarrow$ **自动成立** ✓

三条齐备 $\Rightarrow$ 该过程**遍历**。 $\blacksquare$

#### 1.2.3.2 ② 求平稳分布

按知识点 1.11 的三步法：设 $\pi$ → 列方程 → 解。设 $\pi = [\pi_0\ \ \pi_1\ \ \pi_2]$，列 $\pi P = \pi$（**每个方程取 $P$ 的一列**，为什么见知识点 1.11.2）：

$$\begin{cases}
\pi_0 = \frac34\pi_0 + \frac14\pi_1\\[3pt]
\pi_1 = \frac14\pi_0 + \frac12\pi_1 + \frac34\pi_2\\[3pt]
\pi_2 = \frac14\pi_1 + \frac14\pi_2\\[3pt]
\pi_0 + \pi_1 + \pi_2 = 1
\end{cases}$$

- 第 1 式 $\Rightarrow \frac14\pi_0 = \frac14\pi_1 \Rightarrow \pi_0 = \pi_1$；
- 第 3 式 $\Rightarrow \frac34\pi_2 = \frac14\pi_1 \Rightarrow \pi_2 = \frac13\pi_1$。

代入归一化：$\pi_1 + \pi_1 + \frac13\pi_1 = \frac73\pi_1 = 1 \Rightarrow \pi_1 = \frac37$。

$$\boxed{\ \pi = \left(\tfrac37,\ \tfrac37,\ \tfrac17\right)\ } \qquad \text{与老师原解完全一致 ✓}$$

**验算**（代回 $\pi P = \pi$，逐列算）：

- 第 1 列：$\frac37\cdot\frac34 + \frac37\cdot\frac14 + \frac17\cdot0 = \frac{9+3}{28} = \frac{12}{28} = \frac37$ ✓
- 第 2 列：$\frac37\cdot\frac14 + \frac37\cdot\frac12 + \frac17\cdot\frac34 = \frac{3+6+3}{28} = \frac{12}{28} = \frac37$ ✓
- 第 3 列：$\frac37\cdot0 + \frac37\cdot\frac14 + \frac17\cdot\frac14 = \frac{3+1}{28} = \frac{4}{28} = \frac17$ ✓

#### 1.2.3.3 ③ 顺带：它也是极限分布

因为过程**遍历**，所以

$$\lim_{n\to\infty} p_{ij}^{(n)} = \pi_j = \left(\tfrac37,\ \tfrac37,\ \tfrac17\right), \qquad \text{与出发状态 } i \text{ 无关}$$

**要点**：「证遍历」是**盖章**（走模板，三条条件逐条验），「求平稳分布」是**算数**（解方程）—— 两件事各用各的模板，别混起来做。

### 1.2.4 习题 ③

> *（原图只拍到题干，以下解答为补；模板与习题 ② 完全相同）*

#### 1.2.4.1 （1）前段：两步转移矩阵 $P^{(2)} = P^2$

**还是自己乘自己**：

$$P^{(2)} = P^2 = \begin{pmatrix}0.3&0.7&0\\[3pt]0&0.2&0.8\\[3pt]0.7&0&0.3\end{pmatrix}\begin{pmatrix}0.3&0.7&0\\[3pt]0&0.2&0.8\\[3pt]0.7&0&0.3\end{pmatrix} = \begin{pmatrix}0.09&0.35&0.56\\[3pt]0.56&0.04&0.40\\[3pt]0.42&0.49&0.09\end{pmatrix}$$

两个元素的算法示范（$p_{ij}^{(2)} = \sum_k p_{ik}p_{kj}$）：

$$p_{11}^{(2)} = 0.3\cdot0.3 + 0.7\cdot0 + 0\cdot0.7 = 0.09$$

$$p_{12}^{(2)} = 0.3\cdot0.7 + 0.7\cdot0.2 + 0\cdot0 = 0.21 + 0.14 = 0.35$$

**自查**：每行相加都 $= 1$（$0.09+0.35+0.56=1$、$0.56+0.04+0.40=1$、$0.42+0.49+0.09=1$）⟹ 没乘错 ✓

#### 1.2.4.2 （1）后段：初始分布集中时的 $P\{X_2 = 2\}$

初始分布 $P\{X_0=1\}=1$、其余为 $0$ —— 这是**退化分布**（起点 100% 在状态 1）。全概率公式里只剩一项：

$$P\{X_2=2\} = \sum_{i=1}^{3} P\{X_0=i\}\,p_{i2}^{(2)} = 1\cdot p_{12}^{(2)} + 0 + 0 = p_{12}^{(2)} = 0.35 = \boxed{\ \frac{7}{20}\ }$$

> [!tip] 这正是 1.3.3 的现场演示
> 起点**写死**在状态 1 ⟹ 不用加权求和，**直接取 $P^2$ 的第 1 行第 2 列**。
> 对照 ②(2)：那时初始分布是均匀的，三条来路都要算。**同一套公式，初始分布决定要不要 $\sum$。**

#### 1.2.4.3 （2）求平稳分布

设 $\pi = [\pi_1\ \ \pi_2\ \ \pi_3]$，列 $\pi P = \pi$（**每个方程取 $P$ 的一列**，为什么见知识点 1.11.2）：

$$\begin{cases}
\pi_1 = 0.3\pi_1 + 0\cdot\pi_2 + 0.7\pi_3\\[3pt]
\pi_2 = 0.7\pi_1 + 0.2\pi_2 + 0\cdot\pi_3\\[3pt]
\pi_3 = 0\cdot\pi_1 + 0.8\pi_2 + 0.3\pi_3\\[3pt]
\pi_1 + \pi_2 + \pi_3 = 1
\end{cases}$$

- 第 1 式 $\Rightarrow 0.7\pi_1 = 0.7\pi_3 \Rightarrow \pi_1 = \pi_3$；
- 第 2 式 $\Rightarrow 0.8\pi_2 = 0.7\pi_1 \Rightarrow \pi_2 = \frac78\pi_1$。

代入归一化：$\pi_1 + \frac78\pi_1 + \pi_1 = \frac{23}{8}\pi_1 = 1 \Rightarrow \pi_1 = \frac{8}{23}$。

$$\boxed{\ \pi = \left(\tfrac{8}{23},\ \tfrac{7}{23},\ \tfrac{8}{23}\right)\ }$$

**验算**（代回 $\pi P = \pi$，逐列）：

- 第 1 列：$\frac{8}{23}(0.3) + \frac{7}{23}(0) + \frac{8}{23}(0.7) = \frac{8}{23}(1.0) = \frac{8}{23}$ ✓
- 第 2 列：$\frac{8}{23}(0.7) + \frac{7}{23}(0.2) + \frac{8}{23}(0) = \frac{5.6+1.4}{23} = \frac{7}{23}$ ✓
- 第 3 列：$\frac{8}{23}(0) + \frac{7}{23}(0.8) + \frac{8}{23}(0.3) = \frac{5.6+2.4}{23} = \frac{8}{23}$ ✓

> [!note] 补充：为什么这个平稳分布是唯一的
> 题目没要求，但这层保障值得知道：转移图里有环 $1\to2\to3\to1$，三状态**两两互通**（不可约）；又有自环 $p_{11}=0.3>0$，故**周期为 1**；状态数 3 有限。三条齐备 ⟹ 链**遍历** ⟹ 平稳分布**唯一**，且就是极限分布。判据与 1.2.3.1 完全一样。

**要点**：求平稳分布只做两件事 —— **先从 $\pi P = \pi$ 读出比例关系**（本题读出 $\pi_1=\pi_3$、$\pi_2=\frac78\pi_1$），**再用归一化钉死**。

### 1.2.5 习题 ④

> *（原图只拍到题干，以下解答为补；本页**第一道可约链**）*

#### 1.2.5.1 （1）状态图

把每行画成从该状态出发的箭头（自环记作 ↻）：

```
                    1/2
            ┌──────────────┐
            ▼              │
          (1) ── 1/2 ──> (2)
           ▲              │
           └────── 1 ─────┘

          (3) ── 1/3 ──> (2)
           ↻ 2/3

          (4) ── 1/2 ──> (1)
           └─── 1/2 ──> (3)
```

**一眼看出两件事**（判类型全靠它们）：

- **(1)(2) 互相往来、且走不出去** —— 从 1 只能到 $\{1,2\}$，从 2 只能到 $\{1\}$，所以 $\{1,2\}$ 是**闭集**；
- **(4) 没有任何入边** —— $P$ 的第 4 列**全是 0**，进了 4 就再也回不来（而 4 又一步必离开自己）。

#### 1.2.5.2 （2）各状态的类型和周期

**判断顺序**：先找**闭集**（闭集里的状态必常返），再看闭集外的状态**出去还回不回得来**。

| 状态 | 类型 | 依据 | 周期 |
|---|---|---|---|
| **1** | **正常返** | 属闭集 $\{1,2\}$；有限 + 不可约闭集 ⟹ 正常返 | $p_{11}=\frac12>0$ 有自环 ⟹ $d_1=1$（非周期） |
| **2** | **正常返** | 与 1 同属一个不可约闭集 ⟹ 类型、周期**必然相同** | $p_{22}^{(2)}=\frac12>0$、$p_{22}^{(3)}=\frac14>0$ ⟹ $\gcd(2,3)=1$ ⟹ $d_2=1$ |
| **3** | **非常返** | $f_{33}=\frac23<1$：3 有 $\frac13$ 概率跳到 2，去了**永远回不来** | $p_{33}=\frac23>0$ 有自环 ⟹ $d_3=1$ |
| **4** | **非常返** | $f_{44}=0$：**没有任何入边**，一旦离开就回不来（且一步必离开） | 不定义（能回到 4 的步数集合为空） |

**状态 3 的 $f_{33}$ 怎么算**：一旦离开 3 就再也回不来，所以只有「第 1 步就回 3」这一项：

$$f_{33} = f_{33}^{(1)} = p_{33} = \frac23, \qquad f_{33}^{(k)} = 0\ (k\ge 2) \quad\Longrightarrow\quad f_{33} = \frac23 < 1 \ \Rightarrow\ \textbf{非常返} ✓$$

> [!important] 同一个不可约闭集里，类型与周期全相同
> 状态 1 和 2 同属闭集 $\{1,2\}$，所以**类型和周期必然一样** —— 只需判一个，另一个直接抄。这里判 1 最省事（有自环，一眼非周期）。

#### 1.2.5.3 （3）平稳分布

**能先偷的懒**：3、4 是非常返 ⟹ **平稳分布里 $\pi_3 = \pi_4 = 0$**（非常返状态被访问的次数有限，分不到概率）。

设 $\pi = [\pi_1\ \pi_2\ \pi_3\ \pi_4]$，列 $\pi P = \pi$（**每个方程取 $P$ 的一列**，见知识点 1.11.2）：

$$\begin{cases}
\pi_1 = \frac12\pi_1 + 1\cdot\pi_2 + 0\cdot\pi_3 + \frac12\pi_4\\[3pt]
\pi_2 = \frac12\pi_1 + 0\cdot\pi_2 + \frac13\pi_3 + 0\cdot\pi_4\\[3pt]
\pi_3 = 0\cdot\pi_1 + 0\cdot\pi_2 + \frac23\pi_3 + \frac12\pi_4\\[3pt]
\pi_4 = 0\\[3pt]
\pi_1+\pi_2+\pi_3+\pi_4 = 1
\end{cases}$$

- 第 4 式 ⟹ $\pi_4 = 0$（第 4 列全 0）；
- 第 3 式 ⟹ $\pi_3 = \frac23\pi_3 + 0 \Rightarrow \frac13\pi_3 = 0 \Rightarrow \pi_3 = 0$；
- 第 2 式 ⟹ $\pi_2 = \frac12\pi_1$；
- 第 1 式 ⟹ 代入后得 $\pi_1 = \pi_1$（恒等，不提供新信息 —— 正是 1.11.2 说的「只有 $n-1$ 个独立方程」）。

归一化：$\pi_1 + \frac12\pi_1 = \frac32\pi_1 = 1 \Rightarrow \pi_1 = \frac23,\ \pi_2 = \frac13$。

$$\boxed{\ \pi = \left(\tfrac23,\ \tfrac13,\ 0,\ 0\right)\ }$$

**验算**（代回 $\pi P = \pi$，逐列）：

- 第 1 列：$\frac23\cdot\frac12 + \frac13\cdot1 + 0 + 0 = \frac13+\frac13 = \frac23$ ✓
- 第 2 列：$\frac23\cdot\frac12 + \frac13\cdot0 + 0 + 0 = \frac13$ ✓
- 第 3、4 列：全为 $0$ ✓

> [!note] 补充：可约链的平稳分布为什么这里仍唯一
> 一般地，**可约链的平稳分布可能不唯一** —— 有 $k$ 个常返类，就有一族平稳分布（各常返类上的不变分布做凸组合）。
> 本题虽然可约（$\{1,2\}$ 之外还有 3、4），但**只有一个常返类** $\{1,2\}$ —— 概率只能分给常返类，所以**唯一**。

> [!tip] 顺带：这里的极限分布也等于它
> 从**任何**状态出发，链最终都会进入 $\{1,2\}$ 并再也出不来（3、4 是非常返，$P(\text{永远留在外面}) = \lim_n(\frac23)^n = 0$），而 $\{1,2\}$ 非周期，所以
> $$\lim_{n\to\infty} p_{ij}^{(n)} = \left(\tfrac23,\ \tfrac13,\ 0,\ 0\right) \qquad (\text{对一切 } i)$$
> **非常返状态在极限里被「清空」** —— 这是可约链与不可约链最直观的差别。

#### 1.2.5.4 （4）返回时间

$$\mu_i = \frac{1}{\pi_i}\ (\text{正常返}), \qquad \mu_i = +\infty\ (\text{非常返})$$

| 状态 | 类型 | 返回时间 |
|---|---|---|
| 1 | 正常返，$\pi_1=\frac23$ | $\mu_1 = \dfrac{1}{2/3} = \dfrac32$ |
| 2 | 正常返，$\pi_2=\frac13$ | $\mu_2 = \dfrac{1}{1/3} = 3$ |
| 3 | 非常返 | $\mu_3 = +\infty$ |
| 4 | 非常返 | $\mu_4 = +\infty$ |

> [!warning] 「非常返」的返回时间为什么是 $+\infty$（而不是 $\frac23$）
> 常见误解：对状态 3 硬套 $\mu_i = \sum_k k\,f_{33}^{(k)}$，算出 $\mu_3 = 1\times\frac23 = \frac23$ —— 像个答案，**但错了**。
> 因为「返回时间」这个随机变量以概率 $1-f_{33} = \frac13$ 取 $+\infty$（有 $\frac13$ 的概率**永不返回**）：
> $$\mathbb{E}[\text{返回时间}] = \sum_k k\,f_{33}^{(k)} + (+\infty)\cdot\big(1-f_{33}\big) = +\infty$$
> **$\frac23$ 只是「返回成功那部分」的加权，漏掉了「永不返回」的 $\frac13$。** 状态 4 更极端：$f_{44}=0$，100% 不返回。

**自洽验算**（首步分析，不依赖 $\pi$）：

- $\mu_1 = 1 + p_{12}\times(\text{从 2 首返 1 的期望}) = 1 + \frac12\times 1 = \frac32$ ✓（从 2 一定一步到 1）
- $\mu_2 = 1 + (\text{从 1 首达 2 的期望}) = 1 + 2 = 3$ ✓（从 1 每次有 $\frac12$ 概率成功，几何分布期望 $1/\frac12 = 2$）

**要点**：可约链的最省力路径 —— **先找闭集**（闭集内必常返），**再看闭集外**（出去回不来就是非常返）；非常返状态的 $\pi_i = 0$、$\mu_i = +\infty$ **直接写，不用算**。

## 1.3 题型归纳（补充内容）

### 1.3.1 这道题在考什么

```
马氏链综合题（本页 ②）
      │
      ├── (1) 求 P{X_0 = i, X_n = j}    →  两步转移概率 p_ij^(2) = (P²)_ij
      │                                      ↑ 起点【写死】：直接取矩阵元素
      │
      ├── (2) 求 P{X_n = j}（边缘分布）  →  对起点用全概率 Σ_i p_i(0)·p_ij^(n)
      │                                      ↑ 起点【没写】：按初始分布加权求和
      │
      └── (3) 证遍历 + 求平稳分布        →  ① 不可约 + 周期 1 + 正常返
                                             ② 解 πP = π，配 Σπ_i = 1
```

**一句话抓住主线**：**(1) 和 (2) 的差别只在「起点固定不固定」** —— 固定就取元素，不固定就按初始分布加权。

### 1.3.2 $n$ 步转移矩阵怎么算（本题的核心）

$$\boxed{\ P^{(n)} = P^{\,n} = \underbrace{P\cdot P\cdots P}_{n\ \text{个}}\ }$$

这就是 **Chapman–Kolmogorov 方程** $P^{(m+n)} = P^{(m)}P^{(n)}$ 反复相乘的结果。
所以「两步转移是自己乘自己」—— **对**；三步就再乘一次，$n$ 步就是 $n$ 个 $P$ 相乘。

| 步数 | 转移矩阵 | $p_{ij}^{(n)}$ 的读法 |
|---|---|---|
| 1 步 | $P$ | 第 $i$ 行第 $j$ 列 |
| 2 步 | $P^2$ | $P^2$ 的第 $i$ 行第 $j$ 列 |
| $n$ 步 | $P^n$ | $P^n$ 的第 $i$ 行第 $j$ 列 |

> [!important] 三个别踩的坑
> 1. **下标是「先行后列」**：$p_{01}^{(2)}$ = $P^2$ 的**第 0 行第 1 列**（从 0 出发、走 2 步、落在 1）。
> 2. **状态编号从 0 开始**（$S=\{0,1,2\}$）：$P$ 的第一行对应**状态 0**，不是状态 1。抄元素前先对齐编号（与知识点 1.2.1 是同一条陷阱）。
> 3. **$P^n$ 不是逐元素取幂**：$p_{ij}^{(2)} \ne (p_{ij})^2$，必须做矩阵乘法 $p_{ij}^{(2)} = \sum_k p_{ik}p_{kj}$。

### 1.3.3 三种问法的对照

| 问法 | 特征 | 公式 | 本页 |
|---|---|---|---|
| 联合概率 $P\{X_0=i,\ X_n=j\}$ | 起点**写死** | $= p_i(0)\,p_{ij}^{(n)}$ | ②(1) |
| 边缘概率 $P\{X_n=j\}$ | 起点**没写** | $= \sum_i p_i(0)\,p_{ij}^{(n)}$ | ②(2) |
| 极限概率 $\lim_n p_{ij}^{(n)}$ | $n\to\infty$ | $= \pi_j$（遍历时） | ②(3)③ |

### 1.3.4 常见情形表

| 问法 | 关键式子 | 注意 |
|---|---|---|
| 求 $n$ 步转移概率 | $p_{ij}^{(n)} = (P^n)_{ij}$ | 矩阵乘法，不是逐元素幂 |
| 求 $P\{X_0=i,\ X_n=j\}$ | $p_i(0)\cdot p_{ij}^{(n)}$ | 起点固定，**无**求和 |
| 求 $P\{X_n=j\}$ | $\sum_i p_i(0)\,p_{ij}^{(n)}$ | 起点不固定，要全概率加权 |
| 求 $n$ 步后的分布向量 | $\pi^{(n)} = \pi^{(0)}P^{\,n}$ | **行**向量右乘 |
| 证遍历 | 不可约 + 周期 1 + 正常返 | 有限链正常返自动成立 |
| 求平稳分布 | $\pi P = \pi$ 且 $\sum_i \pi_i = 1$ | 取 $n-1$ 个分量方程即可 |
| 验算平稳分布 | 代回 $\pi P = \pi$ | 逐列算一遍 |

### 1.3.5 直观理解

- **$P^{\,n}$** 描述「**走 $n$ 步之后落在哪**」—— 一步矩阵的 $n$ 次幂，把 $n$ 步的所有走法都累加进去了。
- **全概率公式** 描述「**不知道从哪来，就把所有来路都算一遍再加权**」—— 权重就是初始分布。
- **平稳分布** 描述「**走无穷多步后，各状态的占比固定下来**」—— 与起点无关，这就是「稳」。

### 1.3.6 ② 与 ③ 的对照（同一套拳，两个变量）

| | 习题 ② | 习题 ③ |
|---|---|---|
| 状态编号 | $0,1,2$ | $1,2,3$ ⚠️ **不同** |
| 初始分布 | **均匀** $(\frac13,\frac13,\frac13)$ | **退化** $(1,0,0)$ |
| (1) 求 $P\{X_2=j\}$ | 要**加权求和**三项 | **直接取元素**（只有一个起点） |
| 两步转移矩阵 | $P^2$ | $P^2$ |
| 平稳分布 | $(\frac37,\frac37,\frac17)$ | $(\frac{8}{23},\frac{7}{23},\frac{8}{23})$ |
| 证遍历 | 题目要求写 | 题目没要求（但 $\pi$ 唯一靠它兜底） |

**一句话**：**两题问的是同一件事，唯一的变量是「初始分布」** —— 它决定求 $P\{X_2=j\}$ 时要不要 $\sum$。

### 1.3.7 ②③（不可约）与 ④（可约）的差别

| | 习题 ② ③ | 习题 ④ |
|---|---|---|
| 链 | **不可约** | **可约**（有闭集 $\{1,2\}$） |
| 状态类型 | 全部正常返 | 1、2 正常返；3、4 **非常返** |
| 平稳分布 | 每个 $\pi_i > 0$ | 非常返状态 **$\pi_i = 0$** |
| 求 $\pi$ 的技巧 | 老老实解方程组 | **先看出非常返 ⟹ 直接置 0**，少解两个方程 |
| 返回时间 | 全部有限，$\mu_i = 1/\pi_i$ | 常返的有限；**非常返的 $= +\infty$** |
| 平稳分布唯一吗 | 必唯一 | 本题唯一（只有一个常返类）；**多常返类时是一族** |

> [!important] 可约链的解题顺序（与不可约链相反）
> - **不可约链**：一切靠**方程** —— 解 $\pi P = \pi$，所有状态都正常返，$\mu_i = 1/\pi_i$。
> - **可约链**：一切靠**图** —— 先找**闭集**（闭集内必常返，按老办法解）；闭集外的状态只要**出去回不来就是非常返**，$\pi_i = 0$、$\mu_i = +\infty$ **直接写，不用算**。
>
> **找闭集**＝在转移图上找「进去了就出不来」的状态团。
> **判非常返最快的特征**＝**看第 $j$ 列是不是全 0**：全 0 表示没有任何状态能转移到 $j$，那么 $j$ 一旦离开就回不来（本题状态 4 正是如此，$P$ 第 4 列全是 0）。

## 1.4 注意点与陷阱

1. **$P^{(2)}$ 不是逐元素平方**。最常见的错：以为 $p_{01}^{(2)} = (\frac14)^2 = \frac1{16}$。正确是 $\sum_k p_{0k}p_{k1} = \frac{5}{16}$，差了 5 倍。
2. **下标顺序**。$p_{ij}$ 里 $i$ = 现在（行），$j$ = 下一步（列）；写反了整题错位。
3. **状态编号起点**。②的 $S=\{0,1,2\}$（第一行是状态 0），③的 $S=\{1,2,3\}$（第一行是状态 1）——**两道题编号规则不同**，抄元素前先对齐，否则所有行列平移一位。
4. **(1) 与 (2) 别混**。(1) 起点固定 $X_0 = 0$，乘完 $P\{X_0=0\} = \frac13$ 就停手；(2) 要对三个起点全加权。漏乘、多乘都错。
5. **归一化别忘**。只用 $\pi P = \pi$ 解出来的是**比例解**（一族解），必须加 $\sum_i \pi_i = 1$ 才唯一。
6. **证遍历别只写一句**。三条条件要逐条验：不可约、周期为 1、正常返（有限链就说明「自动成立」）。写成「不可约故遍历」会丢分。
7. **可约链别硬解方程**。④ 的 3、4 是非常返，$\pi_3=\pi_4=0$、$\mu_3=\mu_4=+\infty$ **直接写**，解方程反而绕远。
8. **非常返的返回时间是 $+\infty$**，不是 $\sum_k k f_{ii}^{(k)}$ 算出来的那个有限值（如本题的 $\frac23$）。那个级数只统计了「返回成功」的部分，**漏掉了「永不返回」的概率 $1-f_{ii}$**。
