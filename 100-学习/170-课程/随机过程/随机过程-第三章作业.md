## 1.1 题目

### 1.1.1 习题 3.1

设 $X_1(t)$ 和 $X_2(t)$ 是分别具有参数 $\lambda_1$ 和 $\lambda_2$ 的相互独立的泊松过程，证明：

1. $Y(t) = X_1(t) + X_2(t)$ 是具有参数 $\lambda_1 + \lambda_2$ 的泊松过程；
2. $Z(t) = X_1(t) - X_2(t)$ 不是泊松过程。

### 1.1.2 习题 3.2

设到达某商店的顾客组成强度为 $\lambda$ 的泊松过程，每个顾客购买商品的概率为 $p$，且与其他顾客是否购买商品无关。若 $\{Y_t,\ t \ge 0\}$ 是购买商品的顾客数，证明 $\{Y_t,\ t \ge 0\}$ 是强度为 $\lambda p$ 的泊松过程。

### 1.1.3 习题 3.3

设电话总机在 $(0,t]$ 内接到电话呼叫数 $X(t)$ 是具有强度（每分钟）为 $\lambda$ 的泊松过程，求：

1. 两分钟内接到 3 次呼叫的概率；
2. 「第二分钟内收到第三次呼叫」的概率。

### 1.1.4 习题 3.8

设脉冲到达计数器的规律是到达率为 $\lambda$ 的泊松过程，记录每个脉冲的概率为 $p$，记录不同脉冲的概率是相互独立的。令 $X(t)$ 表示已被记录的脉冲数。

1. 求 $P\{X(t) = k\}$，$k = 0, 1, 2, \cdots$；
2. $X(t)$ 是否为泊松过程。

### 1.1.5 习题 3.9

某商店每日 8 时开始营业，从 8 时到 11 时平均顾客到达率线性增加，在 8 时顾客平均到达率为 5 人/时，11 时到达率最高峰 20 人/时。从 11 时到 13 时，平均顾客到达率维持不变，为 20 人/时。从 13 时到 17 时，顾客到达率线性下降，到 17 时顾客到达率为 12 人。假定在不重叠的时间间隔内到达商店的顾客数是相互独立的，问在 8:30—9:30 间无顾客到达商店的概率是多少？在这段时间内到达商店的顾客数学期望是多少？

### 1.1.6 习题 3.10

设移民到某地区定居的户数是一泊松过程，平均每周有 2 户定居，即 $\lambda = 2$。如果每户的人口数是随机变量，一户四人的概率为 $\dfrac16$，一户三人的概率为 $\dfrac13$，一户二人的概率为 $\dfrac13$，一户一人的概率为 $\dfrac16$，并且每户的人口数是相互独立的，求在五周内移民到该地区人口的数学期望与方差。

## 1.2 解答

### 1.2.1 习题 3.1

**预备（泊松过程的定义）**：$\{N(t), t\ge0\}$ 是强度 $\lambda$ 的泊松过程，指它是一个**计数过程**（$N(0)=0$、取值非负整数、单调不减），且有

- **独立增量**：不重叠区间上的增量相互独立；
- **平稳增量**：对 $s<t$，$N(t)-N(s) \sim P\big(\lambda(t-s)\big)$。

证明「是泊松过程」就是把这三样一条条核对。

#### 1.2.1.1 （1）$Y(t) = X_1(t) + X_2(t)$ 是强度 $\lambda_1+\lambda_2$ 的泊松过程

**① 计数过程**：$Y(0) = 0 + 0 = 0$；$Y(t)$ 是两个非负整数之和，仍非负整数；$X_1, X_2$ 都单调不减，故 $Y$ 单调不减。

**② 独立增量**：任取 $0 \le t_0 < t_1 < \dots < t_n$，第 $i$ 段增量为

$$Y(t_i) - Y(t_{i-1}) = \big[X_1(t_i)-X_1(t_{i-1})\big] + \big[X_2(t_i)-X_2(t_{i-1})\big]$$

$X_1$ 的各段增量独立、$X_2$ 的各段增量独立，且 $X_1 \perp X_2$，所以这 $2n$ 个增量整体独立，它们两两求和得到的 $Y$ 的各段增量也相互独立。

**③ 增量分布**：对 $s<t$（记 $\tau = t-s$），两段增量分别服从泊松分布

$$X_1(t)-X_1(s) \sim P(\lambda_1\tau), \qquad X_2(t)-X_2(s) \sim P(\lambda_2\tau)$$

且**相互独立**（因为 $X_1 \perp X_2$）。要证 $Y(t)-Y(s) \sim P\big((\lambda_1+\lambda_2)\tau\big)$，就是**把「两个独立泊松变量之和」的分布实实在在地算出来**（卷积）。

**第一步：按「$X_2$ 出了几个」分类（全概率 / 卷积）。** 和等于 $n$，就枚举 $X_2$ 贡献的个数 $i$：

$$P\{Y(t)-Y(s)=n\} = \sum_{i=0}^{n} P\big\{X_1(t)-X_1(s)=n-i,\ X_2(t)-X_2(s)=i\big\}$$

**第二步：用独立性把联合概率拆成乘积**，再代入泊松分布律：

$$= \sum_{i=0}^{n} \underbrace{\frac{(\lambda_1\tau)^{n-i}}{(n-i)!}e^{-\lambda_1\tau}}_{\text{来自 } X_1}\cdot\underbrace{\frac{(\lambda_2\tau)^{i}}{i!}e^{-\lambda_2\tau}}_{\text{来自 } X_2}$$

**第三步：把与 $i$ 无关的因子提到求和号外**（两个 $e^{-\lambda\cdot\tau}$ 都跟 $i$ 无关）：

$$= e^{-(\lambda_1+\lambda_2)\tau}\sum_{i=0}^{n}\frac{(\lambda_1\tau)^{n-i}(\lambda_2\tau)^{i}}{(n-i)!\,i!}$$

**第四步（关键一步）：凑出二项式系数。** 分母里只有 $(n-i)!\,i!$，缺一个 $n!$，于是**上下同乘 $n!$**：

$$= \frac{e^{-(\lambda_1+\lambda_2)\tau}}{n!}\sum_{i=0}^{n}\underbrace{\frac{n!}{(n-i)!\,i!}}_{=\ \binom{n}{i}}(\lambda_1\tau)^{n-i}(\lambda_2\tau)^{i}$$

**第五步：认出这是二项式定理的展开。** 取 $a=\lambda_1\tau$、$b=\lambda_2\tau$，用

$$\sum_{i=0}^{n}\binom{n}{i}a^{\,n-i}b^{\,i} = (a+b)^n$$

得

$$= \frac{e^{-(\lambda_1+\lambda_2)\tau}}{n!}\big(\lambda_1\tau+\lambda_2\tau\big)^n = \frac{\big[(\lambda_1+\lambda_2)\tau\big]^n}{n!}\,e^{-(\lambda_1+\lambda_2)\tau}$$

即

$$Y(t)-Y(s) \sim P\big((\lambda_1+\lambda_2)(t-s)\big)$$

（老师手写版把这些写成 $P\{Y(t+\tau)-Y(t)=n\}$，其中 $\tau$ 就是区间长度，与这里的 $t-s$ 是同一个东西。）

三条齐备 ⇒ $\{Y(t), t\ge0\}$ 是强度为 $\lambda_1+\lambda_2$ 的泊松过程。∎

> [!important] 卡住的那一步 = 二项式定理（全文只有这一个技巧）
> 从 $\displaystyle\sum_{i=0}^{n}\frac{a^{n-i}b^{i}}{(n-i)!\,i!}$ 变到 $\dfrac{(a+b)^n}{n!}$，**全部的魔法就是乘了一个 $\dfrac{n!}{n!}$**：
> $$\frac{1}{(n-i)!\,i!} \;=\; \frac{1}{n!}\cdot\frac{n!}{(n-i)!\,i!} \;=\; \frac{1}{n!}\binom{n}{i}$$
> 而 $\sum_i \binom{n}{i}a^{n-i}b^i = (a+b)^n$ 就是**二项式定理**（把 $(a+b)^n$ 展开而已）。
> **一句话记住**：**「两个独立泊松变量之和仍是泊松」这条结论，本质上就是二项式定理** —— 参数之所以相加，就是因为 $(a+b)^n$ 里的 $a+b=\lambda_1\tau+\lambda_2\tau$。

> [!tip] 考场上可以更省事（但要知道来处）
> 直接引用**泊松可加性**（见 [[随机过程-第一章知识点]] 1.1.1）：两个独立泊松变量之和仍服从泊松、参数相加。
> 上面五步就是这条性质的**证明**。答题时写「由泊松可加性，$Y(t)-Y(s)\sim P((\lambda_1+\lambda_2)(t-s))$」即可 —— **但要能默出这个求和**，否则像这次一样看不懂标答。

> [!note] 顺带：这个求和就是「卷积」
> 第一步那个按 $i$ 分类再求和，就是概率论里求「两个独立随机变量之和的分布」的标准动作 —— **卷积**。所以本题的结论也可以一句话概括：
> **泊松分布对卷积封闭**（离散情形下，二项式定理就是它的证明）。

#### 1.2.1.2 （2）$Z(t) = X_1(t) - X_2(t)$ 不是泊松过程

给两条独立的理由，任取其一即可。

**理由一：它根本不是计数过程。**

泊松过程首先是计数过程，必须取值非负、单调不减。当 $t>0$ 时

$$P\{X_1(t)=0,\ X_2(t)=1\} = e^{-\lambda_1 t}\cdot \lambda_2 t\,e^{-\lambda_2 t} > 0$$

这种情形下 $Z(t) = -1 < 0$。而且 $X_2$ 增加时 $Z$ 会下降，$Z$ 不是单调不减的。**取值会变负 ⇒ 不可能是泊松过程。**

**理由二：均值与方差不相等。**

$$E[Z(t)] = E X_1(t) - E X_2(t) = (\lambda_1-\lambda_2)t, \qquad D[Z(t)] = D X_1(t) + D X_2(t) = (\lambda_1+\lambda_2)t$$

（方差用 $D(X_1-X_2) = DX_1 + DX_2$，因两者独立。）

泊松过程的招牌特征是**均值 = 方差 = $\lambda t$**。若 $Z$ 是强度 $\lambda$ 的泊松过程，就必须 $\lambda_1-\lambda_2 = \lambda_1+\lambda_2$，即 $\lambda_2 = 0$，与 $\lambda_2>0$ 矛盾。

**要点**：泊松过程对「加法」封闭（**叠加定理**），对「减法」不封闭。判断一个过程「不是泊松过程」的两条快路：**① 它是不是计数过程**（非负 + 单调不减）；**② 均值与方差是否相等**（泊松的 $E = D = \lambda t$）。

### 1.2.2 习题 3.2

这是泊松过程的**稀释（稀疏）定理**：按概率 $p$ 独立筛选，强度从 $\lambda$ 变成 $\lambda p$。

**第一步：把 $Y_t$ 与 $N(t)$ 挂钩。** 设 $N(t)$ 为 $(0,t]$ 内到达商店的顾客数，则 $N(t) \sim P(\lambda t)$。给定 $N(t)=n$，这 $n$ 个顾客各自独立地以概率 $p$ 购买商品，所以

$$Y_t \mid N(t) = n \ \sim\ B(n,p)$$

**第二步：全概率公式求一维分布。** 对 $k \ge 0$：

$$P\{Y_t = k\} = \sum_{n=k}^{\infty} P\{N(t)=n\}\,P\{Y_t=k \mid N(t)=n\} = \sum_{n=k}^{\infty} \frac{(\lambda t)^n}{n!}e^{-\lambda t}\binom{n}{k}p^k(1-p)^{n-k}$$

用 $\binom{n}{k} = \dfrac{n!}{k!\,(n-k)!}$ 把 $n!$ 约掉，再令 $m = n-k$：

$$= e^{-\lambda t}\frac{(\lambda tp)^k}{k!}\sum_{m=0}^{\infty}\frac{\big[\lambda t(1-p)\big]^m}{m!} = e^{-\lambda t}\frac{(\lambda tp)^k}{k!}\,e^{\lambda t(1-p)} = \frac{(\lambda tp)^k}{k!}e^{-\lambda tp}$$

（倒数第二步用了 $e^{x} = \sum_{m\ge0} x^m/m!$，其中 $x = \lambda t(1-p)$。）

所以

$$Y_t \sim P(\lambda p\,t)$$

**第三步：独立增量与平稳增量。**

- **独立增量**：对不重叠区间 $(s_1,t_1],\dots,(s_m,t_m]$，各区间内的到达数相互独立（$X$ 的独立增量），各区间内「买不买」的判定也相互独立（题设「与其它顾客无关」），故 $Y_{t_i}-Y_{s_i}$（即各区间内购买的顾客数）相互独立；
- **平稳增量**：区间长度相同时，上面的计算只用到长度 $t$，故 $Y_t - Y_s \sim P\big(\lambda p (t-s)\big)$，分布只依赖 $t-s$。

**第四步：计数过程。** $Y_0 = 0$（$(0,0]$ 内无人到达），$Y_t$ 取值非负整数、关于 $t$ 单调不减。

四条齐备 ⇒ $\{Y_t,\ t\ge0\}$ 是强度为 $\lambda p$ 的泊松过程。∎

> [!tip] 稀释定理的两个副产品
> 1. **两股流彼此独立**：被筛掉的（不购买的）顾客也构成强度 $\lambda(1-p)$ 的泊松过程，且**与 $Y_t$ 相互独立**。
> 2. **反向条件分布**：给定 $Y_t = k$ 时，没买的人数仍服从泊松，即 $N(t) - k \sim P\big(\lambda t(1-p)\big)$。
>
> 记忆只有一个字：**打薄** —— $\lambda \to \lambda p$。

**要点**：稀释定理的证明套路固定 —— **对 $N(t)$ 条件化 → 得二项分布 → 求和 → 凑指数展开得泊松**。这一套在 3.8 里一个字都不用改。

### 1.2.3 习题 3.3

强度 $\lambda$ 的单位是「次/分钟」。

#### 1.2.3.1 （1）两分钟内接到 3 次呼叫

$X(2) \sim P(2\lambda)$，直接代分布律：

$$P\{X(2)=3\} = \frac{(2\lambda)^3}{3!}e^{-2\lambda} = \boxed{\ \frac{4}{3}\lambda^3 e^{-2\lambda}\ }$$

#### 1.2.3.2 （2）「第二分钟内收到第三次呼叫」

读作：**第 3 次呼叫发生在第二分钟内**，即 $W_3 \in (1,2]$。先过桥翻译成计数事件（见 [[随机过程-泊松过程典型题型]] 1.3.2）：

$$W_3 \le t \iff X(t) \ge 3$$

于是

$$\{1 < W_3 \le 2\} = \{W_3 \le 2\} \setminus \{W_3 \le 1\} = \{X(2) \ge 3\} \setminus \{X(1)\ge 3\}$$

$$\Rightarrow\quad P\{1<W_3\le2\} = P\{X(2)\ge3\} - P\{X(1)\ge3\}$$

分别用 $X(2)\sim P(2\lambda)$、$X(1)\sim P(\lambda)$ 的分布律（各用 $1 - P(0) - P(1) - P(2)$）：

$$P\{X(2)\ge3\} = 1 - e^{-2\lambda}\left(1 + 2\lambda + \frac{(2\lambda)^2}{2}\right) = 1 - e^{-2\lambda}\big(1+2\lambda+2\lambda^2\big)$$

$$P\{X(1)\ge3\} = 1 - e^{-\lambda}\left(1 + \lambda + \frac{\lambda^2}{2}\right)$$

相减得

$$\boxed{\ P\{1 < W_3 \le 2\} = e^{-\lambda}\left(1 + \lambda + \frac{\lambda^2}{2}\right) - e^{-2\lambda}\big(1 + 2\lambda + 2\lambda^2\big)\ }$$

> [!tip] 等价写法（条件化着算，结果一模一样）
> 记 $\Delta = X(2)-X(1) \sim P(\lambda)$，与 $X(1)$ 独立。按第一分钟来了几个人分三种情况：
> $$P = P\{X(1)=0\}P\{\Delta\ge3\} + P\{X(1)=1\}P\{\Delta\ge2\} + P\{X(1)=2\}P\{\Delta\ge1\}$$
> 展开后同样得到上面那个式子。**这条路更不容易把减法减错**，考场上二选一。

> [!warning] 第 (2) 问的另一种读法
> 「第二分钟内收到第三次呼叫」通常读作「**第 3 次呼叫落在第二分钟内**」（上面这个答案）。
> 若老师的意思其实是「在第二分钟这一分钟内**恰好**来了 3 次呼叫」，答案就变成 $P\{X(2)-X(1)=3\} = \dfrac{\lambda^3}{3!}e^{-\lambda}$。两个答案完全不同，答题时按课上讲的写。

**要点**：凡问「第几次发生在哪段时间」，一律先翻译成计数事件再作差 —— $\{a < W_n \le b\} = \{X(b)\ge n\} - \{X(a)\ge n\}$。比求 $W_n$ 的 $\Gamma$ 密度再积分快得多。

### 1.2.4 习题 3.8

本题与 3.2 是**同一个稀释定理**，只是 3.2 让你「证」、3.8 让你「算」和「判断」。

#### 1.2.4.1 （1）求 $P\{X(t) = k\}$

设 $N(t)$ 为到达计数器的脉冲数，$N(t) \sim P(\lambda t)$。给定 $N(t)=n$ 时，每个脉冲被独立地以概率 $p$ 记录，所以被记录的脉冲数

$$X(t) \mid N(t)=n \ \sim\ B(n,p)$$

完全照搬 3.2 的求和（令 $m = n-k$）：

$$P\{X(t)=k\} = \sum_{n=k}^{\infty}\frac{(\lambda t)^n}{n!}e^{-\lambda t}\binom{n}{k}p^k(1-p)^{n-k} = \frac{(\lambda tp)^k}{k!}e^{-\lambda tp}, \quad k = 0,1,2,\dots$$

即 $X(t) \sim P(\lambda tp)$。

#### 1.2.4.2 （2）$X(t)$ 是否为泊松过程

**是**，且强度为 $\lambda p$。逐条核对：

1. **计数过程**：$X(0)=0$；$X(t)$ 非负整数、单调不减（被记录的脉冲只会越积越多）；
2. **独立增量**：不重叠区间上的「到达脉冲」与「是否记录」两组判定互不影响，故各区间对应的 $X$ 增量相互独立；
3. **增量分布**：与 (1) 同样的计算，把区间长度 $t$ 换成 $t-s$，得 $X(t)-X(s)\sim P\big(\lambda p(t-s)\big)$，只依赖长度。

故 $\{X(t),\ t\ge0\}$ 是强度为 $\lambda p$ 的泊松过程。

> [!note] 3.2 与 3.8 的差别只在最后一问
> 3.2 直接要「整个过程是泊松过程」；3.8(1) 只要「每个固定 $t$ 的分布」，3.8(2) 才把问题升级回过程层面。
> **(1) 是「分布」层面的结论，(2) 是「过程」层面的结论** —— 前者只说明 $X(t)$ 对每个 $t$ 服从泊松，后者还多了「增量独立 + 平稳」。答题时别把 (1) 直接当 (2) 的答案。

**要点**：「每个事件以概率 $p$ 被独立挑出」的题，结论永远是**强度乘 $p$**，且被挑出的与被漏掉的两股流都还是泊松过程、相互独立。

### 1.2.5 习题 3.9

强度 $\lambda(t)$ 随时间变化 ⇒ 这是**非齐次泊松过程**。先把时刻统一成变量：**以 8:00 为原点 $t=0$，单位小时**，于是

$$\lambda(t) = \begin{cases} 5 + 5t, & 0 \le t \le 3 \quad (\text{8:00–11:00})\\[4pt] 20, & 3 \le t \le 5 \quad (\text{11:00–13:00})\\[4pt] 30 - 2t, & 5 \le t \le 9 \quad (\text{13:00–17:00})\end{cases}$$

验一下端点：第一段 $t=0$ 时 $5$、$t=3$ 时 $5+15=20$ ✓（斜率 $(20-5)/3 = 5$）；第三段 $t=5$ 时 $30-10=20$ ✓、$t=9$ 时 $30-18=12$ ✓（斜率 $-2$）。

**所求时段落在第一段**：8:30 ↔ $t=0.5$，9:30 ↔ $t=1.5$。

非齐次泊松过程在 $(s,t]$ 内的到达数服从

$$X(t)-X(s) \sim P\big(m(t)-m(s)\big), \qquad m(t) = \int_0^t \lambda(u)\,du$$

**算累积强度**：

$$m(1.5) - m(0.5) = \int_{0.5}^{1.5}(5+5u)\,du = 5\times 1 + 5\left[\frac{u^2}{2}\right]_{0.5}^{1.5} = 5 + 5(1.125 - 0.125) = 10$$

（物理意义：8:30 到达率 $5+2.5 = 7.5$ 人/时，9:30 到达率 $5+7.5 = 12.5$ 人/时，线性变化 ⇒ 这一小时的平均到达率正好是 $(7.5+12.5)/2 = 10$ 人/时。）

**（1）无顾客到达的概率**

$$P\{X(1.5)-X(0.5) = 0\} = \frac{10^0}{0!}e^{-10} = \boxed{\ e^{-10} \approx 4.54\times10^{-5}\ }$$

> [!important] 为什么「到达率一直在变」还能只代一个数进去
> 到达率从 7.5 一路升到 12.5，中间没有一秒钟是常数，答案里却只有一个 $10$。这不是凑巧，理由分四层：
> 1. **$10$ 是累积强度，不是 $\lambda t$。** 非齐次情形的全部结论就是把常强度公式里的 $\lambda t$ 换成 $m(t)=\int_0^t\lambda(u)du$，区间上就用 $\Delta m=\int_s^t\lambda(u)du$。这里 $\Delta m=10$，是它**顶替**了 $\lambda t$ 的位置。
> 2. **为什么一个积分能「收成一个数」。** 把 $(0.5,1.5]$ 切成 $n$ 段、每段长 $h=\frac1n$，由**独立增量**逐段相乘：
>    $$P\{\text{全区间无人到达}\} = \prod_{i=1}^{n}\Big(1-\lambda(u_i)h+o(h)\Big) \xrightarrow[n\to\infty]{} \exp\Big(-\int_{0.5}^{1.5}\lambda(u)du\Big)$$
>    $\lambda$ 只以**积分**的形式露面，所以 $\lambda(t)$ 中途怎么拐弯都不影响结果，只看积分值。
> 3. **「代平均」这个说法对，但要认清是哪种平均。** 本题 $\Delta m=\frac{7.5+12.5}{2}\times 1=10$，恰好等于「平均到达率 × 时长」—— 那是因为 $\lambda$ **线性**时 $\int\lambda$ 就是梯形面积。**一般情形要代积分**，「端点平均 × 时长」只对线性成立（$E[X]$ 也是同一个 $\Delta m$，见第 (2) 问）。
> 4. **根本原因：泊松分布是单参数族。** 期望 $=$ 参数 $=$ 全部信息，给定了 $\Delta m=10$，分布就定死了 —— 所以「把平均代进去」合法。
>
> **反面检查**：若真按「线性」去想，会写成 $1-10=-9$，概率为负，显然是错的。$e^{-x}\approx 1-x$ 只在 $x$ 很小时可用，这里 $x=10$ 早已超出适用范围。

> [!tip] 三个「平均」别混（这题最容易说错的地方）
> | 说法 | 记号 | 单位 | 本题 |
> |---|---|---|---|
> | 瞬时的到达率 | $\lambda(t)$ | 人/时 | 7.5 → 12.5 |
> | 区间上的**平均到达率** | $\Delta m/\tau$ | 人/时 | $10/1=10$ |
> | 区间内的**平均到达次数** | $\Delta m=\int_s^t\lambda(u)\,du$ | **人** | $10$ |
>
> **能喂进泊松分布的是第三行（平均次数），不是第二行（平均率）。** 泊松分布的参数本来就是「期望次数」，而增量 $X(t)-X(s)$ 的期望恰好是这段区间的累积强度。
> 常强度时 $\Delta m=\lambda\tau$ —— 看见 $\lambda t$ **别把 $t$ 读成「单位时间」，那个 $t$ 就是区间长度**：$\lambda t=$ 率 × 时长 $=$ 这段里平均来几个人。单位时间到达几次是 $\lambda$，区间里到达几次是 $\lambda t$，差一个时长。

**（2）到达顾客数的数学期望**

$$E\big[X(1.5)-X(0.5)\big] = m(1.5)-m(0.5) = \boxed{\ 10\ (\text{人})\ }$$

> [!warning] 结果的量级别被吓到
> $e^{-10}$ 是个极小的数，看着不像标答，但它是对的：这一小时里期望来 10 个人，所以「一个都不来」自然是极小概率。
> 如果题目问的是「8:00—9:00 无顾客到达」，那才是 $m = \int_0^1 (5+5u)du = 7.5$，概率 $e^{-7.5}$。**算之前先把积分上下限对准时段**。

**要点**：强度随时间变时，把泊松过程结论里的 $\lambda t$ 一律替换成**累积强度** $m(t)=\int_0^t\lambda(u)du$：区间内 $k$ 人的概率 $= \dfrac{(\Delta m)^k}{k!}e^{-\Delta m}$，期望 $=\Delta m$。门槛只在**写对 $\lambda(t)$ 的分段表达式**（线性增加/下降就先求出斜率和截距）。

### 1.2.6 习题 3.10

**识别模型**：户数的到达是强度 $\lambda = 2$（户/周）的泊松过程，每户的人数 $Y_j$ 独立同分布，总人口是「到达数 × 每户人数」的随机和

$$S = \sum_{j=1}^{N(5)} Y_j, \qquad N(5) \sim P(2 \times 5) = P(10)$$

这正是**复合泊松过程**（教材第 39 页顶部刚推完它的两条数字特征）。

**第一步：先算每户人数的数字特征。** $Y$ 的分布为

$$P(Y=4) = \frac16,\quad P(Y=3) = \frac13,\quad P(Y=2) = \frac13,\quad P(Y=1) = \frac16$$

$$E(Y) = 4\cdot\frac16 + 3\cdot\frac13 + 2\cdot\frac13 + 1\cdot\frac16 = \frac{4+6+4+1}{6} = \frac{15}{6} = \frac52$$

$$E(Y^2) = 16\cdot\frac16 + 9\cdot\frac13 + 4\cdot\frac13 + 1\cdot\frac16 = \frac{16+18+8+1}{6} = \frac{43}{6}$$

（顺带 $D(Y) = E(Y^2) - [E(Y)]^2 = \dfrac{43}{6} - \dfrac{25}{4} = \dfrac{86-75}{12} = \dfrac{11}{12}$，后面验算用。）

**第二步：套复合泊松的公式。** 教材第 39 页给出的结论是

$$E[X(t)] = \lambda t\,E(Y_1), \qquad D[X(t)] = \lambda t\,E(Y_1^2)$$

本题 $\lambda t = 2 \times 5 = 10$，于是

$$E(S) = 10 \times \frac52 = \boxed{\ 25\ (\text{人})\ }$$

$$D(S) = 10 \times \frac{43}{6} = \frac{430}{6} = \boxed{\ \frac{215}{3} \approx 71.67\ }$$

> [!tip] 不背公式也行：条件化 + 全期望/全方差
> $$E(S) = E\big[E(S \mid N)\big] = E\big[N\,E(Y)\big] = E(N)E(Y)\ \checkmark$$
> $$D(S) = E\big[D(S\mid N)\big] + D\big[E(S\mid N)\big] = E(N)D(Y) + D(N)\big[E(Y)\big]^2$$
> $$= 10\times\frac{11}{12} + 10\times\frac{25}{4} = \frac{110}{12} + \frac{250}{4} = \frac{215}{3} \ \checkmark$$
> 两条公式是同一个东西的两种样子（用了 $D(N) = E(N) = \lambda t$）。全期望/全方差见 [[随机过程-第一章知识点]] 1.2.4。

> [!warning] 方差里用的是「二阶原点矩」
> 复合泊松的方差是 $D = \lambda t\,E(Y^2)$，**不是** $\lambda t\,D(Y)$。
> 写成 $\lambda t D(Y) + \lambda t (EY)^2$ 就对了 —— 本题里前者只有 $9.17$，后者 $62.5$，加起来才是 $71.67$。差一个 $(EY)^2$ 项是这道题最常见的错误。

**要点**：题面「**户数/个数是泊松过程，每个个体带一个随机量**」⇒ 复合泊松，直接上 $E = \lambda t\,EY$、$D = \lambda t\,E(Y^2)$。先把 $E(Y)$、$E(Y^2)$ 算准（这里 $E(Y) = 5/2$、$E(Y^2) = 43/6$），剩下就是乘法。

## 1.3 本章常用结论与速查

### 1.3.1 这六道题用到的四条定理

| 定理 | 内容 | 出现在 |
|---|---|---|
| **叠加** | 两个**独立**的泊松过程之和仍是泊松过程，强度相加 | 3.1(1) |
| **减法不封闭** | 差不是泊松过程（取值可负、$E \ne D$） | 3.1(2) |
| **稀释 / 稀疏** | 每个事件以概率 $p$ **独立**保留 ⇒ 强度变 $\lambda p$；保留与舍弃两股流独立 | 3.2、3.8 |
| **非齐次** | 强度随时间变：$\lambda t \to m(t)=\int_0^t\lambda(u)du$ | 3.9 |
| **复合泊松** | 到达数 × 随机批量：$E = \lambda t\,EY$，$D = \lambda t\,E(Y^2)$ | 3.10 |

### 1.3.2 速查表

| 你要干什么 | 用什么 |
|---|---|
| 判断某过程是否泊松过程 | 核对四条：计数过程、$N(0)=0$、独立增量、$N(t)-N(s)\sim P(\lambda(t-s))$ |
| 证明某过程**不是**泊松过程 | ① 看是否取负值 / 是否单调不减；② 看 $E$ 与 $D$ 是否相等（泊松要求 $E=D=\lambda t$） |
| 事件被以概率 $p$ 独立筛选 | 强度 $\lambda \to \lambda p$（稀释定理） |
| 求区间内到达数 $k$ 的概率 | $P\{N(t)-N(s)=k\} = \dfrac{[\lambda(t-s)]^k}{k!}e^{-\lambda(t-s)}$ |
| 强度 $\lambda(t)$ 随时间变 | 把 $\lambda(t-s)$ 换成 $\Delta m = \int_s^t \lambda(u)\,du$，期望 $=\Delta m$ |
| 问「第 $n$ 次落在哪个区间」 | 过桥 $W_n \le t \iff N(t)\ge n$，再作差 $\{a<W_n\le b\}=\{X(b)\ge n\}-\{X(a)\ge n\}$ |
| 到达 × 随机批量 | 复合泊松：$E = \lambda t\,E(Y)$，$D = \lambda t\,E(Y^2)$ |
| 多个独立泊松流合并 | 强度相加 |
| 已知 $N(t)=n$，每个人独立以概率 $p$ 被选中 | 选中的 $\sim B(n,p)$；再对 $n$ 求和得 $P(\lambda tp)$ |
| 两个**独立**泊松变量之和 | 仍泊松、**参数相加**；证明 = 按 $i$ 分类求和（卷积）后用**二项式定理**收口（3.1(1)） |
