# 1 随机过程（第五版）第四章知识点 · 状态的分类

> [!info] 本篇说什么
> 第 4 章讲马尔可夫链。本篇只解决一个问题：**给定一个状态 $i$，它是「好状态」还是「坏状态」？**
> 判据只有三把尺子，一把比一把细：
> 1. **会不会回来** —— 首次返回概率之和 $f_{ii} = \sum_{k\ge 1} f_{ii}^{(k)}$：$<1$ 非常返，$=1$ 常返；
> 2. **回来要等多久** —— 平均返回时间 $\mu_i = \sum_k k\,f_{ii}^{(k)}$：有限 → 正常返，无穷 → 零常返；
> 3. **每隔几步回来** —— 周期 $d_i = \gcd\{n \ge 1 : p_{ii}^{(n)} > 0\}$：$=1$ 非周期。
>
> 三把尺子合起来，就是「遍历」的定义（不可约 + 正常返 + 非周期）。

---

## 1.1 本章脉络

```
马尔可夫链 {X_n, n = 0,1,2,…}
        │
        ├── 怎么刻画它？   转移概率 p_ij、转移矩阵 P、n 步转移 p_ij^(n)
        │
        └── 把状态 i 单独拎出来看 → 状态分类【本篇】
                 │
                 ├── 会不会回来？   f_ii = Σ_{k≥1} f_ii^(k)          ← 图 (5)(6)
                 │        ├── f_ii < 1   → 非常返（暂留 / 瞬态）
                 │        └── f_ii = 1   → 常返
                 │
                 ├── 回来等多久？   μ_i = Σ_k k·f_ii^(k)            ← 图 (7)
                 │        ├── μ_i < +∞   → 正常返
                 │        └── μ_i = +∞   → 零常返
                 │
                 └── 每隔几步回来？ d_i = gcd{n : p_ii^(n) > 0}      ← 图 (8)
                          ├── d_i = 1   → 非周期
                          └── d_i ≠ 1   → 周期 = d_i
```

**一句话抓住主线**：**先算 $f_{ii}$ 分「常返 / 非常返」，再算 $\mu_i$ 分「正常返 / 零常返」，最后看 $p_{ii}^{(n)}$ 的非零步数求 gcd 定周期。** 三步都是「只看状态 $i$ 回到自己的那件事」，与别的状态无关。

## 1.2 记号与定义

### 1.2.1 状态空间 $S$

$S = \{1,2,3,4\}$ 与 $S = \{0,1,2,3\}$ **不同**。

> [!warning] 做题前先确认编号从 0 还是从 1 开始
> 状态编号的起点不同，转移矩阵 $P$ 的行列顺序、$p_{ij}$ 的两个下标全部跟着平移一位。
> 例：题目说「状态 1」，在 $S=\{1,2,3,4\}$ 下对应 $P$ 的**第 1 行**；若换成 $S=\{0,1,2,3\}$，它就跑到了**第 2 行**。
> 抄矩阵、查元素之前先把这个对清楚，否则整题错位。

### 1.2.2 转移概率与转移矩阵（补充：图里默认已学）

$$p_{ij} = P\{X_{n+1} = j \mid X_n = i\}, \qquad P = (p_{ij})$$

- 每行和为 1：$\sum_{j \in S} p_{ij} = 1$（**行**归一，不是列）
- **马氏性**（无后效性）：$P\{X_{n+1} = j \mid X_n = i,\ X_{n-1},\dots,X_0\} = p_{ij}$ —— 未来只由**现在**决定，与更早的历史无关

### 1.2.3 $n$ 步转移概率（补充）

$$p_{ij}^{(n)} = P\{X_{n} = j \mid X_0 = i\}, \qquad P^{(n)} = P^{\,n}$$

即 $n$ 步转移矩阵就是一步转移矩阵的 $n$ 次幂（Chapman–Kolmogorov 方程）。**注意 $p_{ii}^{(n)}$ 与 $f_{ii}^{(n)}$ 是两回事**，见 1.2.4 和 1.7。

### 1.2.4 首次返回概率 $f_{ii}^{(k)}$【图 (5)】

> $f_{ii}^{(k)}$：从状态 $i$ 出发，经过 $k$ 步**首次**返回状态 $i$ 的概率，$k = 1, 2, \dots$

写成式子就是把「中途一次都没回来」的条件写进去：

$$f_{ii}^{(k)} = P\{X_k = i,\ X_v \ne i \ (1 \le v \le k-1) \mid X_0 = i\}$$

也就是说，$f_{ii}^{(k)}$ 只统计**第 $k$ 步才第一次踩回 $i$** 的那些路径。

> [!important] 「首次」两个字是全部考点
> $p_{ii}^{(k)}$ 统计的是「第 $k$ 步在 $i$」，允许中途回过 $i$ 无数次；$f_{ii}^{(k)}$ 要求**前 $k-1$ 步都没回**。
> 所以 $f_{ii}^{(k)} \le p_{ii}^{(k)}$，等号只在 $k=1$ 时成立（$f_{ii}^{(1)} = p_{ii}^{(1)}$）。

## 1.3 核心：状态怎么分类

### 1.3.1 第一层：非常返 / 常返【图 (5)(6)】

把首次返回概率按步数全加起来，得到**最终一定会返回**的概率：

$$\boxed{\ f_{ii} = \sum_{k=1}^{\infty} f_{ii}^{(k)}\ }$$

| 判据 | 类别 | 直观含义 |
|---|---|---|
| $f_{ii} < 1$ | **非常返**（也叫暂留 / 瞬态） | 从 $i$ 出发，**有正概率此后再也不回来** |
| $f_{ii} = 1$ | **常返** | 从 $i$ 出发**几乎必然**会回来 |

> [!note] 常返 ⇒ 返回无穷多次
> $f_{ii}=1$ 不只是「回来一次」。由马氏性，回来后一切重新开始，所以「回来 $n$ 次」的概率也是 1 —— 常返状态会被访问**无穷多次**；反之非常返状态的访问次数期望有限。

### 1.3.2 第二层：正常返 / 零常返【图 (7)】

常返只是「一定会回来」，还得看**回来得快不快**，于是引入平均返回时间 $\mu_i$（见 1.4）：

| 判据 | 类别 | 直观含义 |
|---|---|---|
| $\mu_i < +\infty$ | **正常返** | 一定会回来，且平均等待时间有限 |
| $\mu_i = +\infty$ | **零常返** | 一定会回来，但平均要等**无穷久** |

> [!important] 分类是有顺序的，别跳步
> 要先确定 $f_{ii} = 1$（常返），才有资格谈「正常返 / 零常返」。
> 完整的层级是：**非常返 ‖ 常返 ｛ 正常返 / 零常返 ｝**。$f_{ii} < 1$ 的状态不存在「正常返」这一说。

### 1.3.3 三层判据合起来长什么样

| 会回来吗 $f_{ii}$ | 等多久 $\mu_i$ | 周期 $d_i$ | 名称 |
|---|---|---|---|
| $< 1$ | — | — | 非常返（瞬态） |
| $= 1$ | $+\infty$ | 任意 | 零常返 |
| $= 1$ | $< +\infty$ | $> 1$ | 正常返（周期为 $d_i$） |
| $= 1$ | $< +\infty$ | $= 1$ | **遍历**（正常返 + 非周期） |

> [!note] 有限状态链的一个便利
> 状态数有限时：**正常返与零常返的区分常常可以绕过**（有限不可约链一定是正常返的），但 $f_{ii}<1$ 的非常返状态依然存在，所以第一层判据（会不会回来）永远要算。

## 1.4 返回时间 / 回转时间【图 (7)】

**定义**：状态 $i$ 的平均返回时间（回转时间）是以首次返回步数为取值的随机变量的期望：

$$\boxed{\ \mu_i = \sum_{k=1}^{\infty} k\, f_{ii}^{(k)}\ }$$

**图里的例子**（同一个状态 1 的 $f$ 值）：

$$\mu_i = 1 \times \tfrac12 + 2 \times \tfrac12 + 3 \times 0 + \dots + n \times 0 = \tfrac32$$

即：$1$ 步回来的概率 $\tfrac12$（等 1 步），$2$ 步回来的概率 $\tfrac12$（等 2 步），更长的路径概率为 0 —— 加权平均得 $\tfrac32$。

> [!tip] 另一个等价算法：$\mu_i = \dfrac{1}{\pi_i}$
> 若链是正常返的，平均返回时间与**平稳分布 / 极限分布**在 $i$ 处的概率 $\pi_i$ 互为倒数：
> $$\mu_i = \frac{1}{\pi_i} \iff \pi_i = \frac{1}{\mu_i}$$
> 上例 $\mu_i = \frac32 \Rightarrow \pi_1 = \frac{2}{3}$。**这条常用来互相验算**：先由定义算 $\mu_i$，再看解出来的 $\pi_i$ 对不对得上。
> 反过来，$\mu_i = +\infty$ 就意味着 $\pi_i = 0$ —— 零常返状态在平稳分布里分不到概率。

**分类**（承接 1.3.2）：若已知 $f_{ii}$ 为常返态，则

$$\begin{cases}\mu_i < +\infty & \Rightarrow \text{正常返}\\[2pt] \mu_i = +\infty & \Rightarrow \text{零常返}\end{cases}$$

## 1.5 周期【图 (8)】

**求一个状态的周期的两步法**：

1. **看该状态返回自身能走几步** —— 列出所有使 $p_{ii}^{(n)} > 0$ 的步数 $n$（等价地，列出所有 $f_{ii}^{(n)} > 0$ 的 $n$）；
2. **求这些步数的最大公约数**：

$$\boxed{\ d_i = \gcd\{n \ge 1 : p_{ii}^{(n)} > 0\}\ }$$

$$\begin{cases} d_i = 1 & \Rightarrow \text{非周期}\\[2pt] d_i \ne 1 & \Rightarrow \text{周期} = d_i\end{cases}$$

**例**：某状态满足 $p_{ii}^{(2)} > 0$、$p_{ii}^{(4)} > 0$，而 $p_{ii}^{(1)} = p_{ii}^{(3)} = 0$，则

$$d_i = \gcd\{2, 4, 6, \dots\} = 2 \quad\Rightarrow\quad \text{周期为 } 2$$

> [!tip] 有自环就一定非周期
> 若 $p_{ii} = p_{ii}^{(1)} > 0$，那么步数集合里有 1，$\gcd$ 必为 1 —— **非周期**。
> 所以判断非周期最快的办法：**看这个状态有没有一步回到自己的自环**（$p_{ii} > 0$），或者转移图里有没有长度为 1 的回路。
> 图 (5) 的例子中 $f_{11}^{(1)} = p_{11} = \frac12 > 0$，直接就知道 $d_1 = 1$，状态 1 非周期。

## 1.6 例题：求图中状态 1 的 $f_{11}$

> **eg.（原图）** 求上图中状态 1 的状态 $f_{11}$。

**已知**（据原图顶部残留的一行转移矩阵 $( \tfrac12\ 0\ \tfrac12\ 0\ \cdots )$ 及算式 $\tfrac12 \times 1$ 反推）：

$$S = \{1,2,3,4\}, \qquad p_{11} = \tfrac12,\quad p_{12} = 0,\quad p_{13} = \tfrac12,\quad p_{14} = 0, \qquad p_{31} = 1$$

即：状态 1 有 $\tfrac12$ 概率原地不动、$\tfrac12$ 概率去状态 3；状态 3 一步必定回到状态 1。

**① 逐步算 $f_{11}^{(k)}$**

$$f_{11} = f_{11}^{(1)} + f_{11}^{(2)} + f_{11}^{(3)} + \dots + f_{11}^{(n)}$$

| $k$ | 路径 | 计算 |
|---|---|---|
| 1 | $1 \to 1$（自环） | $f_{11}^{(1)} = p_{11} = \dfrac12$ |
| 2 | $1 \to 3 \to 1$ | $f_{11}^{(2)} = p_{13}\,p_{31} = \dfrac12 \times 1 = \dfrac12$ |
| 3 及以上 | 必在第 1 步或第 2 步已经回过 1，不满足「首次」 | $f_{11}^{(3)} = 0,\ \dots,\ f_{11}^{(n)} = 0$ |

**② 求和**

$$\therefore\ f_{11} = \frac12 + \frac12 + 0 + \dots = \boxed{\ 1\ }$$

**③ 顺带把三把尺子都量一遍**

- $f_{11} = 1 \Rightarrow$ 状态 1 是**常返**态；
- $\mu_1 = 1 \times \frac12 + 2 \times \frac12 = \frac32 < +\infty \Rightarrow$ **正常返**；
- $f_{11}^{(1)} = p_{11} = \frac12 > 0 \Rightarrow d_1 = 1 \Rightarrow$ **非周期**；
- 三者合起来：状态 1 是**遍历状态**；由 $\mu_1 = 1/\pi_1$ 得 $\pi_1 = \frac{2}{3}$。

> [!question] 题干里的「上图」没拍到
> 原图只拍到算式，没有转移图。上面的 $p_{11}, p_{13}, p_{31}$ 是从残留的矩阵行 $(\frac12\ 0\ \frac12\ 0)$ 和算式 $\frac12 \times 1$ 倒推出来的，与图 (7) 里 $\mu_i = \frac32$ 的结果自洽。
> **补上转移图后请核对这三个数**；若图里状态 1 的 $\frac12$ 是去状态 2（而不是 3），结论不变，只是路径写成 $1 \to 2 \to 1$。

**要点**：算 $f_{ii}$ 的套路是「**按步数枚举首次返回路径，只留首次的**」——自环贡献 $k=1$ 项，绕一圈回来的贡献 $k=2$ 项，更长的项因为中途已经返回过而**全部为 0**。于是 $f_{ii}$ 常常只有两三项，好算。

## 1.7 常见情形表

| 问法 | 关键式子 | 结论 |
|---|---|---|
| 求状态 $i$ 的首次返回概率 | $f_{ii} = \sum_{k\ge1} f_{ii}^{(k)}$ | $<1$ 非常返；$=1$ 常返 |
| 一个状态可能「再也不回来」吗 | $f_{ii} < 1$ | 是，即非常返（瞬态） |
| 平均要等几步回来 | $\mu_i = \sum_k k f_{ii}^{(k)}$ | 有限 → 正常返；无穷 → 零常返 |
| 已知平稳分布求返回时间 | $\mu_i = 1/\pi_i$ | 反着用：$\pi_i = 1/\mu_i$ |
| 求周期 | $d_i = \gcd\{n : p_{ii}^{(n)} > 0\}$ | $=1$ 非周期；$\ne 1$ 周期为 $d_i$ |
| 判断非周期最快的办法 | 看有没有自环 $p_{ii} > 0$ | 有 ⇒ $d_i = 1$ |
| 判断遍历 | 不可约 + 正常返 + 非周期 | 三者齐备 |

## 1.8 直观理解

- **$f_{ii}^{(k)}$** 描述「**第 $k$ 步才第一次回家**」—— 关键词是「第一次」，中途回过就不算。
- **$f_{ii}$** 描述「**这个人到底会不会回家**」—— 等于 1 就是一定会回，小于 1 就是有一直不回的可能。
- **$\mu_i$** 描述「**回家平均要花多久**」—— 注意它是**首次**返回步数的期望，不是所有返回时刻的平均。
- **$1/\pi_i$** 描述「**回家的频率**」—— 概率大（$\pi_i$ 大）就是回得勤（$\mu_i$ 小），两者成反比。
- **周期 $d_i$** 描述「**回家只可能踩在某几个步数上**」—— 若只能隔 2 步回一次（$p_{ii}^{(1)} = 0$），就永远踩不到奇数步，这就是周期 2。

> [!note] 一个能拔高的观察
> 状态分类的层次是**层层加码**的：会不会回（常返性）→ 回得多快（正常返性）→ 回的步数有没有节拍（周期性）。前一层不成立，后一层就没意义。
> 而在**有限**状态链里，若整个链不可约，则「正常返」自动成立、无需检验，只剩下周期性要算 —— 这是考试里最省力的路径。

## 1.9 注意点与陷阱

1. **$p_{ii}^{(n)}$ 与 $f_{ii}^{(n)}$ 别混**。前者「第 $n$ 步在 $i$」（允许中途回来），后者「第 $n$ 步**首次**回到 $i$」。只有 $n=1$ 时两者相等。
2. **状态空间编号 $S=\{1,2,3,4\}$ 与 $S=\{0,1,2,3\}$ 不同**。抄转移矩阵、数第几行第几列之前，先在草稿上把编号与位置的对应写出来，否则整题错位。
3. **$f_{ii}$ 里别把「回来过一次以后又回来」重复计入**。枚举路径时要排除中途已回 $i$ 的路径，图 (5) 的例子中 $f_{11}^{(3)} = 0$ 正是这个原因。
4. **分类有顺序**。$f_{ii} < 1$ 就到此为止（非常返），不要再谈正常返/零常返。
5. **周期看的是 gcd，不是最小步数**。最小非零步数是 2、但 $p_{ii}^{(4)} > 0$ 也存在时，周期仍是 $\gcd(2,4) = 2$，只有当出现**互质**的步数（尤其出现 1）时才是非周期。
6. **行归一别写成列归一**。$\sum_j p_{ij} = 1$，行的和为 1；写成列和为 1 是最常见的手误。
7. **$\mu_i = 1/\pi_i$ 只对正常返状态成立**。零常返状态下 $\pi_i = 0$，这条式子会给出发散值，不能拿来当判据。

## 1.10 速查表

| 你要干什么 | 用什么 |
|---|---|
| 求首次返回概率序列 | 按步数枚举「第一次回到 $i$」的路径，$f_{ii}^{(1)} = p_{ii}$ |
| 判断非常返 / 常返 | $f_{ii} = \sum_{k\ge1} f_{ii}^{(k)}$：$<1$ / $=1$ |
| 求平均返回时间 | $\mu_i = \sum_k k\,f_{ii}^{(k)}$ |
| 用平稳分布求返回时间 | $\mu_i = \dfrac{1}{\pi_i}$ |
| 区分正常返 / 零常返 | $\mu_i < +\infty$ / $\mu_i = +\infty$ |
| 求周期 | $d_i = \gcd\{n \ge 1 : p_{ii}^{(n)} > 0\}$ |
| 判断非周期 | $d_i = 1$；有自环 $p_{ii} > 0$ 即可直接判定 |
| 判断遍历 | 不可约 + 正常返 + 非周期 |
| 写转移矩阵前 | 先确认 $S$ 从 0 还是从 1 开始编号 |
