# 1 随机过程（第五版）· 平稳过程典型题型

> [!info] 本篇说什么
> 这是平稳随机过程习题课（讲义 `PART 10`）的第 ① 题 —— **随机相位正弦波过程**
> $$X(t) = A\cos(\omega_0 t + \Theta),\qquad A,\ \omega_0 \text{ 为常数},\quad \Theta \sim U(-\pi,\pi)$$
> 它要求把第 6 章的「四件套」（均值、方差、相关函数、协方差函数）全算一遍，再用它们判断**广义平稳性**与**各态历经性**。

## 1.2 解答

### 1.2.1 习题 ①

#### 1.2.1.1 预备：$\Theta$ 的分布与数字特征（原图）

$\Theta$ 在 $(-\pi,\pi)$ 上均匀分布，故密度

$$f(\theta) = \begin{cases}\dfrac{1}{2\pi}, & -\pi < \theta < \pi\\[6pt] 0, & \text{其他}\end{cases}$$

$$E[\Theta] = 0,\qquad D[\Theta] = \frac{(2\pi)^2}{12} = \frac{4\pi^2}{12} = \frac{\pi^2}{3}$$

> [!tip] 区间长度别算错
> $(-\pi,\pi)$ 的**长度是 $2\pi$**（不是 $\pi$），所以均匀分布方差是 $\dfrac{(2\pi)^2}{12}$。
> 记住公式：$U(a,b)$ 的方差 $= \dfrac{(b-a)^2}{12}$ —— **端点是 $-\pi$ 与 $\pi$，差为 $2\pi$**。

#### 1.2.1.2 均值 $E[X(t)]$（原图）

$$E[X(t)] = A\,E\big[\cos(\omega_0 t + \Theta)\big] = A\int_{-\pi}^{\pi}\frac{1}{2\pi}\cos(\omega_0 t + \theta)\,d\theta$$

$$= \frac{A}{2\pi}\Big[\sin(\omega_0 t + \pi) - \sin(\omega_0 t - \pi)\Big] = 0$$

（因为 $\sin(\omega_0t+\pi) = -\sin\omega_0t$、$\sin(\omega_0t-\pi) = -\sin\omega_0t$，两者相减为 $0$。）

> [!important] 这一步为什么等于 $0$
> $\Theta$ 在**整整一个周期** $(-\pi,\pi)$ 上均匀，余弦在这个区间上的积分恰好抵消。
> 这是本题所有「等于 $0$」的来源 —— **相位在整周期上均匀 ⇒ 余弦平均为 $0$**。
> 若 $\Theta$ 只在半个周期上均匀，结果就**不是** $0$ 了，平稳性也不成立。

#### 1.2.1.3 方差 $D[X(t)]$（原图）

$$D[X(t)] = E\big[X^2(t)\big] - \big(E[X(t)]\big)^2 = E\big[X^2(t)\big] - 0$$

$$= A^2 E\big[\cos^2(\omega_0 t + \Theta)\big] = A^2\int_{-\pi}^{\pi}\frac{1}{2\pi}\cos^2(\omega_0 t+\theta)\,d\theta$$

$$\boxed{\ D[X(t)] = \frac{A^2}{2}\ }$$

**为什么是 $\dfrac{A^2}{2}$**：用降幂公式 $\cos^2\alpha = \dfrac{1+\cos 2\alpha}{2}$，在整周期 $(-\pi,\pi)$ 上平均，$\cos 2\alpha$ 那段积分为 $0$，剩下 $\dfrac{1}{2}$：

$$\int_{-\pi}^{\pi}\frac{1}{2\pi}\cdot\frac{1}{2}\,d\theta = \frac{1}{2}\ \Longrightarrow\ D[X(t)] = A^2\cdot\frac12 = \frac{A^2}{2}$$

> [!tip] 余弦的「均方值」
> 记结论：**正弦波 $\cos(\cdot)$ 在整周期上均匀平均，均值 $=0$、均方值 $= \dfrac12$**。
> 所以 $A\cos(\cdot)$ 的均值 $0$、方差与均方值都是 $\dfrac{A^2}{2}$。这一条在本题里用了三次。

#### 1.2.1.4 （1）相关函数 $R_X(t_1,t_2)$

$$R_X(t_1,t_2) = E\big[X(t_1)X(t_2)\big] = A^2 E\big[\cos(\omega_0 t_1+\Theta)\cos(\omega_0 t_2+\Theta)\big]$$

用积化和差 $\cos\alpha\cos\beta = \dfrac{1}{2}\big[\cos(\alpha-\beta) + \cos(\alpha+\beta)\big]$：

$$= \frac{A^2}{2}\underbrace{E\big[\cos\omega_0(t_1-t_2)\big]}_{A_1} + \frac{A^2}{2}\underbrace{E\big[\cos\big(\omega_0(t_1+t_2) + 2\Theta\big)\big]}_{A_2}$$

- $A_1$ **不含随机量**，直接摘出来：$A_1 = \cos\omega_0(t_1-t_2)$；
- $A_2$ 是**频率 $2$ 倍**的余弦，$\Theta$ 在整周期上均匀 ⇒ 平均为 $0$：$A_2 = 0$。

$$\boxed{\ R_X(t_1,t_2) = \frac{A^2}{2}\cos\omega_0(t_1-t_2) = R_X(\tau),\qquad \tau = t_1-t_2\ }$$

**验算**（和原图的方差对上）：取 $t_1 = t_2 = t$，即 $\tau = 0$：

$$R_X(0) = \frac{A^2}{2}\cos 0 = \frac{A^2}{2} = D[X(t)] + \big(E[X(t)]\big)^2 = \frac{A^2}{2} + 0 \quad ✓$$

与原图得到的 $D[X(t)] = \dfrac{A^2}{2}$ 一致 —— 这正说明补全的部分没错位。

#### 1.2.1.5 （1）协方差函数 $C_X(t_1,t_2)$

$$C_X(t_1,t_2) = \operatorname{Cov}\big(X(t_1),X(t_2)\big) = R_X(t_1,t_2) - E[X(t_1)]\,E[X(t_2)]$$

因为 $E[X(t)] \equiv 0$，所以**协方差函数与相关函数完全相同**：

$$\boxed{\ C_X(t_1,t_2) = R_X(t_1,t_2) = C_X(\tau) = \frac{A^2}{2}\cos\omega_0\tau\ }$$

> [!important] 均值为 $0$ 时 $C_X = R_X$
> 一般地 $C_X(\tau) = R_X(\tau) - m_X^2$，是**减去均值的乘积**以后还剩多少相关。
> 本题 $m_X = 0$，减掉的是 $0$，所以两者数值一样 —— 但**概念不同、写答案时两个都要写**（题目是分两问要的）。

#### 1.2.1.6 （2）判断广义平稳性

逐条对照第 6 章的三条件：

| 条件 | 本题的验证 | 结论 |
|---|---|---|
| (1) 二阶矩存在 | $R_X(0) = \dfrac{A^2}{2} < +\infty$ | ✓ |
| (2) 均值为常数 | $E[X(t)] = 0$，与 $t$ 无关 | ✓ |
| (3) 相关函数只与时间差有关 | $R_X(t_1,t_2) = \dfrac{A^2}{2}\cos\omega_0(t_1-t_2)$，只含 $\tau = t_1-t_2$ | ✓ |

三条同时满足 $\Rightarrow$ **$X(t)$ 是（广义）平稳过程**（$m_X = 0$，$R_X(\tau) = \dfrac{A^2}{2}\cos\omega_0\tau$）。

> [!tip] 第 (3) 条怎么一眼看出来
> 展开后 $t_1+t_2$ 那一项被 $\Theta$ 均掉了，**只剩下 $t_1 - t_2$** —— 单独的 $t_1$、$t_2$ 一个都不剩，所以合格。
> 反过来记忆：**「$t_1+t_2$ 的项一定归零，$t_1-t_2$ 的项一定留下」**，这是所有随机相位题的固定套路。

#### 1.2.1.7 （2）判断各态历经性

**① 均值各态历经**

$$\langle X(t)\rangle = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}A\cos(\omega_0 t + \Theta)\,dt = \lim_{T\to\infty}\frac{A}{2T}\cdot\Big[\frac{\sin(\omega_0 t+\Theta)}{\omega_0}\Big]_{-T}^{T}$$

$$= \lim_{T\to\infty}\frac{A}{2T\omega_0}\cdot 2\cos\Theta\sin(\omega_0 T) = \lim_{T\to\infty}\underbrace{\frac{A\cos\Theta}{\omega_0 T}}_{\to 0}\sin(\omega_0 T) = 0 = E[X(t)]$$

$\Rightarrow$ **均值具有各态历经性** ✓

**② 自相关函数各态历经**

$$\langle X(t)X(t+\tau)\rangle = \lim_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}A^2\cos(\omega_0 t+\Theta)\cos\big(\omega_0(t+\tau)+\Theta\big)\,dt$$

同样用积化和差，第二项（频率 $2\omega_0$ 的余弦）在时间上平均为 $0$，第一项与 $t$ 无关原样留下：

$$= \frac{A^2}{2}\cos\omega_0\tau$$

对比 $R_X(\tau) = \dfrac{A^2}{2}\cos\omega_0\tau$ —— **两者相等**（因为题设 $A$ 是常数）：

$$\Rightarrow\ \textbf{自相关函数具有各态历经性}\ ✓$$

**③ 结论**

均值、自相关函数**都**具各态历经性 $\Rightarrow$ **$X(t)$ 是各态历经过程**。

**要点**：这题的四步一条龙 ——
① **求 $\Theta$ 的密度与数字特征**（$E\Theta=0$，$D\Theta = \frac{\pi^2}{3}$）；
② **求 $E[X]$**：$E[\cos(\omega_0 t+\Theta)] = 0$（整周期均匀）；
③ **求 $R_X$**：积化和差后 **$t_1+t_2$ 项归零、只剩 $t_1-t_2$** ⇒ 平稳；
④ **验各态历经**：时间平均里**频率非零的余弦项全归零**，只剩常数 ⇒ 两条都成立 ⇒ 遍历。
**关键分水岭**：$A$ 是**常数** ⇒ 自相关各态历经 ⇒ 过程遍历；$A$ 若是**随机变量**，第 ② 条就塌了（见 1.3.3 对比表与[[随机过程-第六章知识点]] 1.8.2）。

## 1.3 题型归纳（补充内容）

### 1.3.1 这类题长什么样

```
随机相位正弦波过程  X(t) = A cos(ω₀t + Θ)
        │
        ├── 一条暗线：Θ 均匀分布在「整周期」上 ⇒ 一切 cos(含 Θ) 的平均都是 0
        │
        ├── 第一问（四件套）
        │      ├── E[X]  = A·E[cos(ω₀t+Θ)] = 0
        │      ├── D[X]  = E[X²] − (E[X])² = A²/2      （降幂公式）
        │      ├── R_X(t₁,t₂) = (A²/2)cos ω₀(t₁−t₂)     （积化和差，t₁+t₂ 项归零）
        │      └── C_X = R_X − m_X² = R_X               （因 m_X = 0）
        │
        └── 第二问（两个判断）
               ├── 广义平稳？ 三条件：二阶矩有限 ✓ 均值常数 ✓ R_X 只含 τ ✓
               └── 各态历经？
                      ├── ⟨X⟩ = 0 = E[X]                  ⇒ 均值各态历经 ✓
                      └── ⟨X(t)X(t+τ)⟩ = (A²/2)cos ω₀τ
                                    = R_X(τ) ⟺ A 是常数   ← 全题唯一的「分水岭」
```

**一句话抓住主线**：**「$\Theta$ 均匀 ⇒ 余弦平均为 $0$」是唯一的暗线；「$t_1+t_2$ 归零」管平稳，「$A$ 是否常数」管各态历经。**

### 1.3.2 随机相位正弦波过程的「标准答案」（背下来）

只要过程形如

$$X(t) = A\cos(\omega_0 t + \Theta),\qquad A,\omega_0\ \text{常数},\ \Theta\sim U(-\pi,\pi)\ \text{（或任意整周期均匀）}$$

就**直接写**：

| 量 | 结果 |
|---|---|
| $E[X(t)]$ | $0$ |
| $D[X(t)]$ | $\dfrac{A^2}{2}$ |
| $R_X(\tau)$ | $\dfrac{A^2}{2}\cos\omega_0\tau$ |
| $C_X(\tau)$ | $\dfrac{A^2}{2}\cos\omega_0\tau$（＝$R_X$，因 $m_X = 0$） |
| 广义平稳？ | **是** |
| 均值各态历经？ | **是** |
| 自相关各态历经？ | **是**（$A$ 为常数时） |
| 过程各态历经？ | **是** |

> [!note] 这组数为什么值得背
> 它是所有「正弦 + 随机相位」题的**母版**：$A$ 换成随机变量、$\omega$ 换成随机变量、加上初相、多个正弦叠加，都只是在这组数上打补丁。
> 记法：**均值 $0$、方差（＝均方值）$A^2/2$、自相关 $A^2/2 \cdot \cos$（频率不变）。**

### 1.3.3 常见情形表：$A$ 常数 vs $A$ 随机（本章最爱的对比）

| $X(t) = A\cos(\omega_0 t+\Theta)$，$\Theta\sim U(-\pi,\pi)$，$A\perp\Theta$ | $E[X(t)]$ | $R_X(\tau)$ | 广义平稳？ | 均值遍历？ | 自相关遍历？ |
|---|---|---|---|---|---|
| **$A$ 为常数**（**本题**） | $0$ | $\dfrac{A^2}{2}\cos\omega_0\tau$ | 是 | **是** | **是** |
| $A$ 随机，$E[A^2]<\infty$ | $0$ | $\dfrac{E[A^2]}{2}\cos\omega_0\tau$ | 是 | **是** | **否**（$\langle X X_\tau\rangle = \frac{A^2}{2}\cos\omega_0\tau \ne R_X$） |
| $A$ 随机且 $E[A^2] = \infty$ | $0$ | — | **否**（二阶矩不存在） | 无从谈起 | 无从谈起 |
| $\Theta$ 只均匀分布在**半周期**上 | $\ne 0$（含 $t$） | 含 $t_1,t_2$ | **否** | 无从谈起 | 无从谈起 |
| $X(t) = A\cos(\omega_0 t+\Theta) + B\sin(\omega_0 t+\Theta)$ | $0$ | $\dfrac{A^2+B^2}{2}\cos\omega_0\tau$ | 是 | 是 | 是（$A,B$ 常数时） |

> [!important] 本题与「$A$ 随机」版本只差一个字
> **平稳性两者都成立**（$R_X$ 都只含 $\tau$），但**各态历经性只对 $A$ 是常数成立**。
> 原因是各态历经要比较 $\langle X(t)X(t+\tau)\rangle = \dfrac{A^2}{2}\cos\omega_0\tau$ 与 $R_X(\tau) = \dfrac{E[A^2]}{2}\cos\omega_0\tau$ —— **左边是「一次抽到的 $A$」，右边是「$A$ 的全体平均」**，只有当 $A$ 没有随机性（常数）时二者才恒等。
> 完整推导见 [[随机过程-第六章知识点]] 1.8.2 例 2。

### 1.3.4 直观理解

- **随机相位 $\Theta$** 描述「**我知道这是个正弦波，但不知道它此刻处在波形的哪个位置**」—— 相位在整周期上均匀，相当于对波形做了一次彻底的「随机平移」，于是任何时刻的取值正负各半 ⇒ 均值为 $0$。
- **$R_X(\tau) = \frac{A^2}{2}\cos\omega_0\tau$** 描述「**同一条波相隔 $\tau$ 后还像不像**」—— 相隔一个整周期（$\omega_0\tau = 2k\pi$）时完全像（$R_X = \frac{A^2}{2}$），相隔半个周期时符号相反（$-\frac{A^2}{2}$）。这就是余弦的自相关。
- **各态历经性成立** 描述「**这条波的振幅 $A$ 是确定的**」—— 只要振幅是常数，沿时间测足够久，均值与自相关都能测出来；振幅一旦随机，无论测多久都测不出 $E[A^2]$，因为它藏在这一条曲线的振幅里。

> [!note] 一个能拔高的观察
> 本题的 $R_X(\tau) = \frac{A^2}{2}\cos\omega_0\tau$ **不衰减**（永远在 $\pm A^2/2$ 之间振荡），所以 1.4.2 里那个**充分条件** $\int_{-\infty}^{+\infty}|R_X(\tau)-m_X^2|\,d\tau<\infty$ **不满足**。
> 但均值仍然各态历经 —— 因为**充要条件**（带三角权重的积分）依然趋于 $0$：
> $$\lim_{T\to\infty}\frac{1}{T}\int_{0}^{2T}\Big(1-\frac{\tau}{2T}\Big)\cos\omega_0\tau\,d\tau = \lim_{T\to\infty}\frac{1-\cos(2\omega_0T)}{2\omega_0^2T^2} = 0\ ✓$$
> **教训**：充分条件不满足 $\ne$ 各态历经不成立。**判断时以定义式（时间平均 vs 统计平均）为准**，充分条件只是省事用的。

## 1.4 注意点与陷阱

1. **$(-\pi,\pi)$ 的长度是 $2\pi$，不是 $\pi$**。密度是 $\dfrac{1}{2\pi}$，方差是 $\dfrac{(2\pi)^2}{12} = \dfrac{\pi^2}{3}$。写成 $\dfrac{1}{\pi}$ 或 $\dfrac{\pi^2}{12}$ 都会连锁错掉后面所有 $0$ 与 $A^2/2$。
2. **均值为 $0$ 的论证必须靠「整周期均匀」**。$E[\cos(\omega_0t+\Theta)] = 0$ 的关键是 $\Theta$ 覆盖了一整个周期；换成半周期分布就不为 $0$，随即平稳性也不成立（见 1.3.3 第 4 行）。
3. **$A$、$\omega_0$ 是常数这件事要在「各态历经」那一步显式用到**。求 $R_X$ 时 $A$ 是常数还是随机**不影响**结果形式，只有到 $\langle X(t)X(t+\tau)\rangle$ 与 $R_X(\tau)$ 相比时才见分晓 —— 千万别在最后一步忘了它是常数、白丢掉一个结论。
4. **相关函数与协方差函数要分别写**。本题 $m_X = 0$ 使二者相等，但题目问了两项，答题时两个式子都要出现（并注明「因 $E[X(t)]=0$ 故与 $R_X$ 相同」）。
5. **相关函数别漏自变量**。写 $R_X(t_1,t_2)$ 或 $R_X(\tau)$ 都要**明确指出 $\tau = t_1-t_2$**；直接写 $R_X$ 不交代 $\tau$ 会被扣分。
6. **时间平均的分母是 $2T$、区间是 $[-T,T]$**。与手写稿 ②(4) 一致；若题目换成 $\frac{1}{T}\int_{0}^{T}$，结论不变但式子要跟着改。
7. **$\langle X(t)\rangle$ 里极限的次序**：先积出 $\dfrac{A\cos\Theta\sin(\omega_0T)}{\omega_0T}$，再让 $T\to\infty$ —— 是 **$\dfrac{\sin(\omega_0T)}{T}\to 0$** 在起作用（分子有界、分母发散），别误以为「$\sin$ 有极限」。
8. **判断题要有「三条件逐条对照」的过程**。只写「显然平稳」不给分；写清 (1)(2)(3) 各验了什么，才踩得到分。
9. **各态历经性的两条必须分别验、都要写**。只验均值就下结论「过程各态历经」是常见失分点 —— 自相关那条才是本题真正的考点。

| 你要干什么 | 用什么 |
|---|---|
| 写出 $\Theta$ 的密度 | $f(\theta) = \dfrac{1}{2\pi},\ -\pi<\theta<\pi$ |
| 求 $\Theta$ 的方差 | $D\Theta = \dfrac{[(\pi)-(-\pi)]^2}{12} = \dfrac{\pi^2}{3}$ |
| 求 $E[X(t)]$ | $A\,E[\cos(\omega_0t+\Theta)] = 0$（整周期均匀） |
| 求 $D[X(t)]$ | $E[X^2] - (E[X])^2 = A^2E[\cos^2] = \dfrac{A^2}{2}$（降幂公式 + 余弦整周期平均为 $\frac12$） |
| 求 $R_X(t_1,t_2)$ | 积化和差：$t_1+t_2$ 项归零，只剩 $\dfrac{A^2}{2}\cos\omega_0(t_1-t_2)$ |
| 求 $C_X$ | $R_X - m_X^2$；本题 $m_X = 0$ ⇒ $C_X = R_X$ |
| 判广义平稳 | 二阶矩有限 $+$ 均值常数 $+$ $R_X$ 只含 $\tau$ |
| 判均值各态历经 | $\langle X(t)\rangle = \lim\limits_{T\to\infty}\frac{1}{2T}\int_{-T}^{T}X(t)dt \stackrel{?}{=} m_X$ |
| 判自相关各态历经 | $\langle X(t)X(t+\tau)\rangle \stackrel{?}{=} R_X(\tau)$ |
| 判过程各态历经 | 上面两条**同时**成立 |
| 时间平均里余弦项 | 频率非零的 $\cos/\sin$ 项**一律归零**，只留与 $t$ 无关的常数 |
| 快速自检 $R_X$ | $R_X(0) = \frac{A^2}{2}$ 应等于 $D[X] + m_X^2$ ✓ |
