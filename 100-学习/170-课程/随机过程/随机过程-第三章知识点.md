# 1 随机过程（第五版）第三章知识点 · 泊松过程与复合泊松

> [!info] 本篇说什么
> 第 3 章讲泊松过程。全篇回答三个问题：
>
> 1. **它是什么** —— 计数过程 $+$ 独立增量 $+$ 平稳增量，即 $N(t)-N(s)\sim P\big(\lambda(t-s)\big)$；
> 2. **它有哪些性质** —— 叠加（强度相加）、稀释（$\lambda\to\lambda p$）、间隔 $\sim\mathrm{Exp}(\lambda)$、$W_n\sim\Gamma(n,\lambda)$；
> 3. **它怎么推广** —— 两条路：
>    - **时间不均匀** ⇒ **非齐次泊松过程**：$\lambda t \to \displaystyle\int_s^t\lambda(u)\,du$；
>    - **每次带来的量是随机的** ⇒ **复合泊松过程**：
>      $$\boxed{\ E[X(t)] = \lambda t\,E(Y_1),\qquad D[X(t)] = \lambda t\,E(Y_1^{\,2})\ }$$
>
> 第 3 条是**本篇重点**（习题 3.10 就是它），也是教材第 39 页顶部那段推导的结论。

---

## 1.1 本章脉络

```
泊松过程 {N(t), t ≥ 0}  ——「状态离散、时间连续」的计数过程
        │
        ├── 怎么定义？    计数过程 + 独立增量 + 平稳增量
        │                        └── N(t) - N(s) ~ P(λ(t-s))
        │
        ├── 两张脸          ┌── 计数脸（离散）：N(t) → 泊松分布律      ←「来了几件事」
        │                   └── 时刻脸（连续）：X_i、W_n → 概率密度    ←「隔了多久」
        │
        ├── 怎么推广？      ┌── 时间不均匀  → 非齐次   λt  →  ∫_s^t λ(u)du = Δm
        │                   └── 每次量随机  → 复合     N(t) →  Σ_{j≤N(t)} Y_j
        │
        └── 两条运算定理
                 ├── 叠加（合并）  几个独立泊松过程之和仍是泊松，强度相加
                 └── 稀释（稀疏）  每个事件以概率 p 独立保留 ⇒ 强度变 λp
```

**一句话抓住主线**：**泊松过程的一切都由两个数撑着 —— 「强度 $\lambda$」和「区间长度 $t$」，两者相乘的 $\lambda t$ 就是这段区间里平均来几件事。** 所有推广都是在改这堆东西：非齐次是让 $\lambda$ 随时间变（$\lambda t$ 升级成积分），复合是让每次来的「量」从 $1$ 变成随机变量 $Y$。

> **两种推广的方向完全不同**：非齐次改的是「**率**」（时间轴不均匀），复合改的是「**大小**」（每次事件的幅度随机）。一个是 $\lambda\to\lambda(t)$，一个是 $1\to Y$。别混。

## 1.2 记号与定义

### 1.2.1 泊松过程（定义三条件）

设 $\{N(t),\ t\ge0\}$ 是一个**计数过程**（$N(t)$ 表示 $(0,t]$ 内某事件发生的次数）。若它满足

1. **计数过程**：$N(0)=0$；$N(t)$ 取非负整数，且关于 $t$ **单调不减**；
2. **独立增量**：任意不重叠区间上的增量**相互独立**；
3. **平稳增量**：对任意 $s<t$，
   $$N(t)-N(s) \sim P\big(\lambda(t-s)\big)$$
   （分布只依赖区间长度 $t-s$，且是参数为 $\lambda(t-s)$ 的泊松分布）

则称 $\{N(t),\ t\ge0\}$ 是**强度为 $\lambda$ 的泊松过程**。

**记法**：$N(t)\sim P(\lambda t)$，且
$$E[N(t)] = D[N(t)] = \lambda t$$

> [!important] 「均值 $=$ 方差」是泊松的招牌
> 泊松分布的期望与方差都等于它的参数，所以泊松过程永远满足 $E[N(t)] = D[N(t)] = \lambda t$。
> 这一条反过来有大用：**要证明某个过程不是泊松过程，最省事的一条就是看 $E$ 与 $D$ 相不相等**（习题 3.1(2) 就是这么证的）。

### 1.2.2 强度 $\lambda$ 的三层读法

| 读法 | 说法 | 式子 |
|---|---|---|
| **率** | 单位时间平均来几件事 | $\lambda = \dfrac{E[N(t)]}{t}$ |
| **小区间** | 一小段时间里恰好来一件的概率 | $P\{N(t+h)-N(t)=1\} = \lambda h + o(h)$；来两件以上是 $o(h)$ |
| **区间量** | 长 $t$ 的区间里平均来几件事 | $E[N(t)] = \lambda t$ |

**单位**：$\lambda t$ 里的 $t$ 是**区间长度**（不是「单位时间」）。$\lambda t =$ 率 $\times$ 时长 $=$ 这段区间里平均来几个人。

### 1.2.3 非齐次泊松过程

强度不是常数，而是随时刻变化的函数 $\lambda(t)$（例如商店上午客流渐增、傍晚渐减）。此时把定义里的 $\lambda t$ 换成**累积强度**

$$m(t) = \int_0^t \lambda(u)\,du$$

定义改为：**独立增量**保留，但增量分布只依赖**累积强度之差**

$$N(t)-N(s) \sim P\big(m(t)-m(s)\big) = P\!\left(\int_s^t\lambda(u)\,du\right)$$

**平稳增量不再成立**（不同时段的分布不同）。常强度时 $m(t)=\lambda t$，退化为普通泊松过程。

| | 普通泊松 | 非齐次泊松 |
|---|---|---|
| 参数 | $\lambda t$ | $m(t)-m(s)=\int_s^t\lambda(u)du$ |
| 独立增量 | ✓ | ✓ |
| 平稳增量 | ✓ | ✗ |

### 1.2.4 复合泊松过程【本篇重点】

设 $\{N(t),\ t\ge0\}$ 是强度为 $\lambda$ 的泊松过程，$Y_1,Y_2,\dots$ 是**独立同分布**的随机变量，且**与 $\{N(t)\}$ 相互独立**。令

$$X(t) = \sum_{j=1}^{N(t)} Y_j,\qquad X(t)=0\ \text{当}\ N(t)=0$$

则称 $\{X(t),\ t\ge0\}$ 是**复合泊松过程**。

**怎么读**：$N(t)$ 数「来了几批」，$Y_j$ 是「第 $j$ 批带来多少」。所以 $X(t)$ 是「**到达数 $\times$ 随机批量**」的随机和。

- **名字的来处**：$X(t) = N(t)\cdot Y$（随机个随机变量之和），一层「计数」套一层「批量」，故名「复合」。
- **它确实是泊松的推广**：取 $Y_j\equiv1$（每批恰好一件），则 $X(t)=N(t)$，退回普通泊松过程。
- **典型场景**：商店来「户」、每户人数不同；保险索赔按「笔」、每笔金额不同；放射性粒子成「簇」到达、每簇能量不同；习题 3.10 的「移民户数 $\to$ 人口数」。

> [!warning] 三个前提缺一不可
> ① $N(t)$ 是泊松过程；② $Y_j$ **独立同分布**；③ $Y_j$ **与 $N(t)$ 独立**（来了几批 与 每批多大 互不影响）。
> 少了 ② 或 ③，下面 1.5 的两条公式都不成立。

## 1.3 核心一：$N(t)$ 的分布（计数脸）

这就是「两张脸」里的**离散那张** —— 固定时刻问「来了几件事」。

**① 一维分布**：$N(t)\sim P(\lambda t)$，即
$$P\{N(t)=k\} = \frac{(\lambda t)^k}{k!}\,e^{-\lambda t},\qquad k=0,1,2,\dots$$

**② 增量分布**：$N(t)-N(s)\sim P\big(\lambda(t-s)\big)$，与 $s$ 无关，只依赖长度。

**③ 叠加（合并）定理**：若 $N_1(t),\dots,N_m(t)$ **相互独立**，强度分别为 $\lambda_1,\dots,\lambda_m$，则
$$N(t) = N_1(t)+\cdots+N_m(t)$$
仍是泊松过程，强度为
$$\lambda = \lambda_1+\lambda_2+\cdots+\lambda_m$$
（**「相加」这条结论本质上就是二项式定理**，证明见 [[随机过程-第三章作业]] 1.2.1 的五步求和。）

**④ 稀释（稀疏）定理**：把每个事件**独立地**以概率 $p$ 保留、以概率 $1-p$ 舍弃，则保留下来的事件构成强度为
$$\lambda p$$
的泊松过程；被舍弃的那股也是泊松过程（强度 $\lambda(1-p)$），且**两股相互独立**。

> [!tip] 稀释定理的另一个用法：判断「这次到达属于谁」
> 若干股独立泊松流合并后，**每一次到达属于哪一股是独立的，且概率正比于强度**：
> $$P\{\text{这次属于第 } i \text{ 股}\} = \frac{\lambda_i}{\sum_j\lambda_j}$$
> 这是习题 3.7 的巧解（几何分布）所依赖的那条事实。

## 1.4 核心二：间隔与等待时刻（时刻脸）

这是「两张脸」里的**连续那张** —— 问「隔了多久」，答案是**概率密度**。

**① 间隔分布**：相邻两次事件的时间间隔 $X_1,X_2,\dots$ **相互独立且同分布**，服从参数 $\lambda$ 的指数分布：
$$f_{X}(t) = \lambda e^{-\lambda t}\ (t>0),\qquad E X = \frac{1}{\lambda},\qquad E[X^2] = \frac{2}{\lambda^2},\qquad D X = \frac{1}{\lambda^2} = (EX)^2$$

> [!important] 这个密度不是定义，是推论 —— 而且它说明「指数时长 $+$ 泊松计数 $=$ 几何」
> **推导**（从计数分布反推出时刻分布）：
> $$P\{X_1 > t\} = P\{(0,t]\ \text{内没有事件}\} = P\{N(t)=0\} = e^{-\lambda t}\ \Longrightarrow\ F_{X_1}(t) = 1-e^{-\lambda t}\ \Longrightarrow\ f_{X_1}(t) = \lambda e^{-\lambda t}$$
> 反之，「一个过程的间隔 $\sim\mathrm{Exp}(\lambda_1)$，期间另一个过程按 $P(\lambda_2\tau)$ 计数」⇒ 计数结果服从**几何分布**（见 [[随机过程-第三章作业]] 1.2.6）。**混合改变分布族，这是本课最漂亮的一对搭档。**
>
> 顺带解释「为什么泊松过程能有密度」：它是「**状态离散、时间连续**」—— 计数 $N(t)$ 是离散的（有分布律），事件时刻 $W_n$、间隔 $X_i$ 是连续的（有密度）。时间连续 ⇒ $P\{X=t\}=0$ ⇒ 只能谈落在小区间里的概率 ⇒ 必须有密度。

**② 等待时刻**：第 $n$ 次事件发生的时刻是 $n$ 个间隔之和
$$W_n = X_1+X_2+\cdots+X_n \sim \Gamma(n,\lambda),\qquad f_{W_n}(t) = \frac{\lambda^n t^{\,n-1}}{(n-1)!}e^{-\lambda t}\ (t>0)$$
$$E W_n = \frac{n}{\lambda},\qquad D W_n = \frac{n}{\lambda^2}$$
（记忆式：**段数 $\times$ 平均间隔** $= n\times\frac1\lambda$。）

**③ 过桥关系（两种问法之间的那座桥）**：对任意 $n\ge1$、$t\ge0$，
$$W_n \le t \iff N(t) \ge n$$
「第 $n$ 次发生在 $t$ 之前」$\iff$「截至 $t$ 至少来了 $n$ 次」。**所有问「第几次落在哪段时间」的题，第一步都过这座桥翻译成计数事件**，见 [[随机过程-泊松过程典型题型]] 1.3.2。

**④ 非负随机变量的期望捷径**：
$$E X = \int_0^{\infty} P\{X > t\}\,dt$$
（$X\sim\mathrm{Exp}(\lambda)$ 时给出 $1/\lambda$；求 $EW_n$ 也能用它验算。）

## 1.5 核心三：复合泊松的两条数字特征【本篇重点】

### 1.5.1 结论

$$X(t) = \sum_{j=1}^{N(t)}Y_j \quad\Longrightarrow\quad \boxed{\ E[X(t)] = \lambda t\,E(Y_1)\ },\qquad \boxed{\ D[X(t)] = \lambda t\,E(Y_1^{\,2})\ }$$

**务必注意**：方差里是**二阶原点矩** $E(Y^2)$，**不是**方差 $D(Y)$。

> **教材第 39 页顶部**推导的就是这两条；习题 3.10 直接套用。

### 1.5.2 期望：全期望公式一步出

先在「来了几批」上条件化。给定 $N(t)=n$，$X(t)$ 就是**确定的 $n$ 个**独立同分布变量之和，故

$$E\big[X(t)\mid N(t)=n\big] = n\,E(Y)\quad\Longrightarrow\quad E\big[X(t)\mid N(t)\big] = N(t)\,E(Y)$$

再对 $N(t)$ 取一次期望（**全期望公式**，见 [[随机过程-第一章知识点]] 1.2.4）：

$$E[X(t)] = E\Big[E\big(X(t)\mid N(t)\big)\Big] = E\big[N(t)\,E(Y)\big] = E[N(t)]\,E(Y) = \boxed{\lambda t\,E(Y)}$$

（第三个等号能用，是因为 $E(Y)$ 是常数。）

### 1.5.3 方差：全方差公式，两项各管一半

$$D[X(t)] = \underbrace{E\Big[D\big(X(t)\mid N(t)\big)\Big]}_{\text{批内波动}} + \underbrace{D\Big[E\big(X(t)\mid N(t)\big)\Big]}_{\text{批数波动}}$$

逐项算：

- **批内波动**：给定 $N(t)=n$，$n$ 个 $Y$ 独立 ⇒ $D(X\mid N=n) = n\,D(Y)$，即 $D(X\mid N)=N(t)D(Y)$，故
  $$E\big[N(t)D(Y)\big] = E[N(t)]\,D(Y) = \lambda t\,D(Y)$$
- **批数波动**：$E(X\mid N) = N(t)E(Y)$，故
  $$D\big[N(t)E(Y)\big] = \big[E(Y)\big]^2 D[N(t)] = (EY)^2\,\lambda t$$
  （这里用了泊松过程的招牌 $D[N(t)] = E[N(t)] = \lambda t$ —— **换成别的到达过程，这一项就不是 $\lambda t(EY)^2$ 了。**）

两项相加：

$$D[X(t)] = \lambda t\,D(Y) + \lambda t\,(EY)^2 = \lambda t\Big[\underbrace{D(Y)+(EY)^2}_{=\,E(Y^2)}\Big] = \boxed{\lambda t\,E(Y^2)}$$

> [!note] 为什么「方差里会冒出一个 $E(Y^2)$」
> 因为复合泊松的波动有**两个来源**：
> $$D = \underbrace{\lambda t\,D(Y)}_{\text{每批大小都在抖}} + \underbrace{\lambda t\,(EY)^2}_{\text{来几批也在抖}}$$
> 这两项恰好凑成 $E(Y^2) = D(Y)+(EY)^2$ —— 所以公式才能写得这么短。**这也解释了那个最常犯的错**：只写 $\lambda t D(Y)$ 就漏掉了「批数波动」那半壁江山（习题 3.10 里漏掉的部分占了 $62.5/71.67$，占大半）。

> [!warning] 复合泊松一般**不是**泊松过程
> 取 $Y_j\equiv c$（每批固定 $c$ 个），则 $X(t)=c\,N(t)$，于是 $E = c\lambda t$、$D = c^2\lambda t$。除非 $c=1$，否则 $E\ne D$ —— 而泊松过程必须 $E=D$。**所以复合泊松只是「泊松驱动」的过程，本身不是泊松过程。**

> [!tip] 想求 $X(t)$ 的分布？（补充，选读）
> 一般没有简单闭式。若 $Y$ 取非负整数值，用**概率母函数**（见 [[随机过程-第一章知识点]] 1.6.6）最省事：给定 $N(t)=n$ 时 $G_{X|N=n}(z) = [G_Y(z)]^n$，再对 $n$ 求混合
> $$G_{X(t)}(z) = \sum_{n\ge0}\frac{(\lambda t)^n}{n!}e^{-\lambda t}\big[G_Y(z)\big]^n = e^{-\lambda t\left(1-G_Y(z)\right)}$$
> 顺带可以从中反推出上面的两条数字特征（对 $z$ 求导取 $z=1$）。**考纲一般不要求**，知道有这么个工具即可。

## 1.6 常见情形

| 情形 | 模型 | 关键结果 |
|---|---|---|
| 固定时长内的到达数 | $N(t)\sim P(\lambda t)$ | $E = D = \lambda t$ |
| 不重叠区间的增量 | $N(t)-N(s)$ | $\sim P(\lambda(t-s))$，且各段**独立** |
| 几股**独立**流合并 | $N_1+\cdots+N_m$ | 仍是泊松，强度**相加** |
| 每个事件以概率 $p$ 独立保留 | 稀释 | 强度变 $\lambda p$；两股独立 |
| 相邻两次事件的间隔 $X$ | 指数分布 $\mathrm{Exp}(\lambda)$ | $EX=\frac1\lambda$，$E[X^2]=\frac2{\lambda^2}$，$DX=\frac1{\lambda^2}$ |
| 第 $n$ 次事件的时刻 $W_n$ | $\Gamma(n,\lambda)$ | $EW_n=\frac n\lambda$，$DW_n=\frac n{\lambda^2}$ |
| 强度随时间变 $\lambda(t)$ | **非齐次** | $\lambda t \to \Delta m=\int_s^t\lambda(u)du$ |
| 每次事件带一个随机量 $Y_j$ | **复合** | $E=\lambda t\,EY$，$D=\lambda t\,E(Y^2)$ |

## 1.7 直观理解

- **泊松过程** 描述「**完全随机**的点流」—— 过去不影响未来（独立增量），什么时候开始看都一样（平稳增量）。它是把「随机性」理想化到极致的模型，也是第 3 章所有结论的地基。
- **两张脸** 描述「**同一个过程的两种问法**」—— 问「来了几件」是计数脸（离散，用分布律）；问「隔了多久」是时刻脸（连续，用密度）。过桥关系 $W_n\le t\iff N(t)\ge n$ 是两张脸之间的翻译器。
- **非齐次** 描述「**率在变**」—— 时间轴被动过手脚，$\lambda$ 是 $t$ 的函数。
- **复合** 描述「**量在变**」—— 时间轴没动，但每次事件从「算 1 个」变成「算 $Y$ 个」。

> [!note] 两个推广是一张表的两列
> | | 改什么 | 公式怎么变 |
> |---|---|---|
> | **非齐次** | 改 $\lambda$：$\lambda\to\lambda(t)$ | $\lambda t \to \int_s^t\lambda(u)du$ |
> | **复合** | 改「一次算几个」：$1\to Y$ | $N(t)\to\sum_{j\le N(t)}Y_j$，$E\to\lambda t EY$、$D\to\lambda t E(Y^2)$ |
>
> 一个动「**时间轴**」（哪段热闹哪段冷清），一个动「**幅度轴**」（来了几件、每件多大）。**考试看到题，先判断它动的是哪根轴**，公式自然就选出来了。

## 1.8 例题：复合泊松（习题 3.10）

> 设移民到某地区定居的户数是一泊松过程，平均每周有 2 户定居，即 $\lambda=2$。若每户的人口数是随机变量，一户 4 人的概率为 $\dfrac16$，一户 3 人的概率为 $\dfrac13$，一户 2 人的概率为 $\dfrac13$，一户 1 人的概率为 $\dfrac16$，且各户人口数相互独立。求五周内移民到该地区人口的数学期望与方差。

**识别模型**：户数是强度 $\lambda=2$（户/周）的泊松过程，每户人数 $Y_j$ 独立同分布，总人口是「到达数 $\times$ 每户人数」的随机和

$$S = \sum_{j=1}^{N(5)}Y_j,\qquad N(5)\sim P(2\times5)=P(10)$$

⇒ 这是**复合泊松**，$\lambda t = 10$。

**第一步：先把每户人数的**两个**数字特征算出来**（一个是 $E(Y)$，一个是公式里要用的 $E(Y^2)$）：

$$E(Y) = 4\cdot\frac16+3\cdot\frac13+2\cdot\frac13+1\cdot\frac16 = \frac{4+6+4+1}{6} = \frac{15}{6} = \frac52$$

$$E(Y^2) = 16\cdot\frac16+9\cdot\frac13+4\cdot\frac13+1\cdot\frac16 = \frac{16+18+8+1}{6} = \frac{43}{6}$$

$$\Big(D(Y) = \frac{43}{6}-\frac{25}{4} = \frac{86-75}{12} = \frac{11}{12}\ \text{，后面验算用}\Big)$$

**第二步：套公式**（$\lambda t=2\times5=10$）：

$$E(S) = 10\times\frac52 = \boxed{\ 25\ (\text{人})\ },\qquad D(S) = 10\times\frac{43}{6} = \boxed{\ \frac{215}{3}\approx71.67\ }$$

**验算（走全方差公式，见 1.5.3）**：

$$D(S) = \lambda t\,D(Y)+\lambda t\,(EY)^2 = 10\times\frac{11}{12}+10\times\frac{25}{4} = \frac{55}{6}+\frac{125}{2} = \frac{55+375}{6} = \frac{430}{6} = \frac{215}{3}\ \checkmark$$

> [!warning] 方差里用的是「二阶原点矩」
> $D(S) = \lambda t\,E(Y^2) = 10\times\dfrac{43}{6}$，**不是** $\lambda t\,D(Y)=10\times\dfrac{11}{12}\approx9.17$。
> 写 $\lambda tD(Y)+\lambda t(EY)^2 = 9.17+62.5$ 才对 —— 差的那一项恰好是 $(EY)^2$ 那半壁，是这道题最常见的错误。

**要点**：题面出现「**个数 / 户数 / 批数是泊松过程，每个个体还带一个随机量**」⇒ 复合泊松，直接上 $E=\lambda t\,EY$、$D=\lambda t\,E(Y^2)$。**关键在于把 $E(Y)$ 与 $E(Y^2)$ 两个都算准**，剩下全是乘法。详细解答（含条件化的另一条路子）见 [[随机过程-第三章作业]] 1.2.9。

## 1.9 注意点与陷阱

1. **复合泊松的方差用 $E(Y^2)$，不用 $D(Y)$** —— 二者差一个 $(EY)^2$。教材写成 $\lambda t\,E(Y_1^2)$ 就是为了省掉这一项，别自己「化简」成 $\lambda t\,D(Y)$。
2. **$E(Y)$ 和 $E(Y^2)$ 要各算一遍，别只算一个**。$E(Y^2)$ 直接把每个 $y$ 平方后加权，不要用 $E(Y^2)=D(Y)+(EY)^2$ 绕一圈（容易算错）。
3. **$\lambda t$ 里的 $t$ 是时段长度**（本题 5 周），不是事件数、也不是「单位时间」。$\lambda=2$ 户/周、$t=5$ 周 ⇒ $\lambda t=10$ 户。
4. **复合泊松的三个前提**：$N(t)$ 是泊松过程、$Y_j$ i.i.d.、$Y_j\perp N(t)$。题目里「每户人口数相互独立」这句话就是在交代前两条。
5. **复合泊松一般不是泊松过程**（$E\ne D$），别把它当成「强度变了」的泊松过程。
6. **非齐次与复合别混**：非齐次改 $\lambda$（用 $\Delta m=\int_s^t\lambda$），复合改「一次算几个」（用 $\lambda t\,E(Y^k)$）。两者可以同时出现（非齐次复合泊松），此时 $E=\Delta m\cdot EY$。
7. **非齐次别用「端点平均 $\times$ 时长」代替积分** —— 那只在 $\lambda$ **线性**时才对（见 [[随机过程-第三章作业]] 1.2.8）。
8. **「均值 $=$ 方差」只对普通泊松成立**。这个招牌既能用来快速**否定**一个过程是泊松（3.1(2)），也是复合泊松公式的来源（1.5.3 里 $D[N(t)]=\lambda t$ 那一步）—— 别一边用它一边忘了它有前提。

## 1.10 速查表

| 你要干什么 | 用什么 |
|---|---|
| 判断某过程是不是泊松过程 | 核对四条：**计数过程**（$N(0)=0$、非负整数、单调不减）、**独立增量**、**平稳增量**、$N(t)-N(s)\sim P(\lambda(t-s))$ |
| 证明某过程**不是**泊松过程 | ① 取值会不会变负 / 是否单调不减；② $E$ 与 $D$ 是否相等（泊松要求 $E=D=\lambda t$） |
| 求区间内来了 $k$ 件事的概率 | $\dfrac{[\lambda(t-s)]^k}{k!}e^{-\lambda(t-s)}$，期望 $=\lambda(t-s)$ |
| 强度 $\lambda(t)$ 随时间变 | 把 $\lambda(t-s)$ 换成 $\Delta m=\displaystyle\int_s^t\lambda(u)du$ |
| 求相邻间隔 $X$ 的数字特征 | $X\sim\mathrm{Exp}(\lambda)$：$EX=\frac1\lambda$，$E[X^2]=\frac2{\lambda^2}$，$DX=\frac1{\lambda^2}$ |
| 求第 $n$ 次到达时刻 $W_n$ | $W_n=\sum_{i\le n}X_i\sim\Gamma(n,\lambda)$：$EW_n=\frac n\lambda$，$DW_n=\frac n{\lambda^2}$ |
| 问「第 $n$ 次落在哪段时间」 | 过桥 $W_n\le t\iff N(t)\ge n$，再作差 $\{a<W_n\le b\}=\{X(b)\ge n\}-\{X(a)\ge n\}$ |
| 几股独立泊松流**合并** | 仍是泊松，强度**相加** |
| 每个事件以概率 $p$ 独立**保留** | 稀释：强度变 $\lambda p$；保留与舍弃两股独立 |
| 合并后问「这次到达属于谁」 | 概率正比于强度：$\dfrac{\lambda_i}{\sum_j\lambda_j}$ |
| **每次事件带一个随机量**（复合泊松） | $E[X(t)]=\lambda t\,E(Y)$，$D[X(t)]=\lambda t\,E(Y^2)$ ← **本篇重点** |
| 求复合泊松的分布 | 母函数 $G_{X(t)}(z)=e^{-\lambda t(1-G_Y(z))}$（补充，一般不考） |
