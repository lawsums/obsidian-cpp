# 1 最优化原理 · 线性规划：单纯形法与对偶理论

> [!info] 本篇说什么
> 第 1 章说「多面体的极点是有限个，可以枚举」，第 2 章就把这句话变成算法。
> 两条主线：**单纯形法** —— 沿棱从一个顶点走到更好的顶点（$\sigma_j<0$ 就进基，$\theta$ 规则决定谁出基）；**对偶理论** —— 每个 LP 背后都站着一个镜像 LP，两者最优值相等（$\min c^{\mathsf T}x = \max b^{\mathsf T}y$），对偶最优解就是资源的**影子价格**。
> 末尾再补两把整数规划的刀：**割平面**（切一刀）与**分支定界**（分两支）。

---

## 1.1 本章脉络

```
线性规划（第 2 章）
│
├── 标准形与几何
│   ├── 标准形：min cᵀx, Ax = b, x ≥ 0
│   ├── 基 B → 基解 x_B = B⁻¹b → 基可行解（x_B ≥ 0）
│   └── 基可行解 ⟷ 可行域的顶点   ← 第 1 章「顶点」的算法版
│
├── 单纯形法（主算法）
│   ├── 检验数 σⱼ = cⱼ − zⱼ：min 问题里 σⱼ < 0 就进基
│   ├── θ 规则：min{b̄ᵢ/aᵢⱼ : aᵢⱼ > 0} → 谁出基（保证可行性不破）
│   ├── 初始基不好找？→ 补人工变量
│   │   ├── 大 M 法：目标里加 +M·a
│   │   └── 两阶段法：先 min w = Σa，再换回原目标
│   └── 已知初始基可行解 → 直接算 B⁻¹ 化简，不用人工变量
│
├── 对偶理论（同题的另一面）
│   ├── 对偶规则表：约束类型 ↔ 对偶变量符号，变量符号 ↔ 对偶约束类型
│   ├── 弱对偶   cᵀx ≥ yᵀb        （「非负乘不等式保号」的夹心结构）
│   ├── 强对偶   z* = w*          （一个有限最优，另一个也是）
│   ├── 互补松弛 xⱼ>0 ⇒ 对偶约束取等；yᵢ>0 ⇒ 原约束取等
│   └── 影子价格 y*ᵢ = 第 i 种资源多一个单位的边际价值
│
└── 整数规划（给 LP 加上整数要求）
    ├── 割平面法：从「取分数值」的基变量那行切一刀，切掉非整数最优点
    └── 分支定界法：对取分数的变量分 xⱼ ≤ k 与 xⱼ ≥ k+1 两支
```

**一句话抓住主线**：线性规划 = **在顶点之间走**（单纯形法）+ **每个 LP 都有个对偶**（对偶理论）；整数规划 = 在 LP 上**切一刀**或**分两支**。

## 1.2 定义

### 1.2.1 标准形与化标准形

**标准形**：

$$\min\ c^{\mathsf T}x \quad \text{s.t.}\quad Ax = b,\ x\ge0,\quad b\ge0$$

化标准形三招：

| 原形式 | 怎么改 |
|---|---|
| $\max c^{\mathsf T}x$ | 令 $z'=-z$，转成 $\min\ (-c)^{\mathsf T}x$ |
| $a_ix\le b_i$ | 加**松弛变量** $s_i\ge0$：$a_ix+s_i = b_i$ |
| $a_ix\ge b_i$ | 减**剩余变量** $s_i\ge0$：$a_ix-s_i = b_i$ |
| $x_j$ 自由 | 拆成 $x_j = x_j^+-x_j^-$，$x_j^\pm\ge0$ |
| $b_i<0$ | 该行两边乘 $-1$ |

### 1.2.2 基、基解、基可行解

设 $A$ 是 $m\times n$ 且 $\operatorname{rank}A=m$。

- **基 $B$**：从 $A$ 中挑 $m$ 个**线性无关**的列组成的方阵。这 $m$ 列对应的变量叫**基变量**，其余叫**非基变量**。
- **基解**：令非基变量为 $0$，解出 $x_B = B^{-1}b$。
- **基可行解**：满足 $x_B = B^{-1}b\ge0$ 的基解。

> [!important] 基可行解 ⟷ 顶点
> 这正是第 1 章「顶点（极点）」的计算版本：**基可行解与可行域的顶点一一对应**。所以线性规划的最优解一定能在某个基可行解上取到，单纯形法只需要在顶点之间跑。

### 1.2.3 对偶规划

给定原问题 $(P)$，按 **1.3.1 的对偶规则表**造出的另一个 LP 称为 $(P)$ 的**对偶规划** $(D)$；$(P)$ 与 $(D)$ 互为对偶。

$$
(P)\quad \begin{aligned} \min\ & c^{\mathsf T}x \\ \text{s.t.}\ & Ax\ge b \\ & x\ge0 \end{aligned}
\qquad\Longleftrightarrow\qquad
(D)\quad \begin{aligned} \max\ & b^{\mathsf T}y \\ \text{s.t.}\ & A^{\mathsf T}y\le c \\ & y\ge0 \end{aligned}
$$

### 1.2.4 检验数

在基 $B$ 下，第 $j$ 个变量的**检验数**：

$$\sigma_j = c_j - z_j = c_j - c_B^{\mathsf T}B^{-1}a_j$$

**含义**：把 $x_j$ 从 $0$ 提高一个单位（同时调整基变量保持等式成立），目标函数的变化率。

$$\sigma_j\ge0\ (\forall j) \iff \text{当前的基可行解已是最优解} \quad(\min\ \text{问题})$$

### 1.2.5 人工变量、大 M 法与两阶段法

**人工变量**：为了让初始表出现单位基而**硬加**进去的变量。它没有物理意义，最优解里必须为 $0$。

- **大 M 法**：目标里给它加一个巨大的罚项。$\min$ 问题加 $+M a$（$M$ 充分大）。
- **两阶段法**：
  - **阶段一**：$\min\ w=\sum_i a_i$，只求可行基。$w_{\min}=0$ ⟹ 原问题可行；$w_{\min}>0$ ⟹ 原问题**无可行解**。
  - **阶段二**：划掉人工变量列，换回原目标继续迭代。

### 1.2.6 割平面与分支定界

- **割平面**（Gomory）：从最优表里**取分数值**的基变量那行提取一个不等式，切掉非整数最优点，但**不切掉任何整数可行点**。
- **分支定界**：若 LP 松弛的最优解中 $x_j^* = k+f\ (0<f<1)$，就把问题劈成 $x_j\le k$ 与 $x_j\ge k+1$ 两个子问题分别再解。

## 1.3 核心关系式

### 1.3.1 对偶规则表（本章最重要的一张表）

设原问题是 **$\min$**，对偶就是 **$\max$**。逐行、逐变量对照：

| 原问题（$\min c^{\mathsf T}x$） | 对偶（$\max b^{\mathsf T}y$） |
|---|---|
| 第 $i$ 个约束：$a_ix\ge b_i$ | $y_i\ge0$ |
| 第 $i$ 个约束：$a_ix\le b_i$ | $y_i\le0$ |
| 第 $i$ 个约束：$a_ix = b_i$ | $y_i$ **自由** |
| $x_j\ge0$ | 第 $j$ 个约束：$(A^{\mathsf T}y)_j\le c_j$ |
| $x_j\le0$ | 第 $j$ 个约束：$(A^{\mathsf T}y)_j\ge c_j$ |
| $x_j$ **自由** | 第 $j$ 个约束：$(A^{\mathsf T}y)_j = c_j$ |
| 目标 $\min c^{\mathsf T}x$ | 目标 $\max b^{\mathsf T}y$ |

**一句记法**：**约束与变量互换，$\ge$ 与 $\le$ 互换，等号与自由互换。**

> [!important] 最反直觉的两行
> - **变量自由 ⟹ 对偶约束取等号**（不是取 $\ge$ 或 $\le$）
> - **等式约束 ⟹ 对偶变量自由**（不是非负）
>
> 这两条是「等号 ↔ 自由」这一对互换的两面，考试最爱考。

### 1.3.2 三个对偶定理

**弱对偶定理** —— $x$ 是 $(P)$ 的可行解、$y$ 是 $(D)$ 的可行解，则

$$\boxed{\ c^{\mathsf T}x\ \ge\ b^{\mathsf T}y\ }$$

（证明就是「非负向量乘不等式保号」夹两次，见 [[最优化原理-第二章作业]] 1.2.10。）

**强对偶定理** —— 若 $(P)$、$(D)$ 之一有有限最优值，则另一个也有，且

$$\boxed{\ z^* = w^*\ },\qquad z^*=\min c^{\mathsf T}x,\quad w^*=\max b^{\mathsf T}y$$

**互补松弛定理** —— 设 $x^*,y^*$ 分别是 $(P)$、$(D)$ 的最优解，则

$$y_i^*\big(a_ix^*-b_i\big) = 0,\qquad x_j^*\big(c_j-(A^{\mathsf T}y^*)_j\big) = 0$$

即：**约束松着（$a_ix^*>b_i$）⟹ 它的对偶变量必为 $0$；变量取正（$x_j^*>0$）⟹ 它的对偶约束必取等。**

### 1.3.3 影子价格

对偶最优解 $y^*$ 是**资源的影子价格**：$y_i^*$ 就是第 $i$ 种资源多一个单位时，最优值的边际变化率。

[[最优化原理-第二章作业]] 1.2.9 证的

$$z^*+y^{*\mathsf T}d \ \le\ s^*$$

说的正是这件事：右端项扰动 $b\to b+d$，最优值的增量**至少**是 $y^{*\mathsf T}d$（$d$ 很小时近似相等）。

> [!tip] 从最优单纯形表里直接读对偶最优解
> 对「$\min c^{\mathsf T}x$，$Ax\le b$，$x\ge0$」这一型，最优表里**松弛变量 $s_i$ 那几列的检验数取负**就是 $y_i^*$：
> $$y_i^* = -\sigma(s_i)$$
> 因为 $\sigma(s_i)=0-y^{*\mathsf T}e_i = -y_i^*$。

### 1.3.4 割平面公式

取最优表里基变量 $x_B$ 那一行，写 $x_B=b̄-\sum_j a_jx_j$，把系数与右端项都拆成「整数部分 + 分数部分」：

$$a_j = \lfloor a_j\rfloor + f_j,\qquad \bar b = \lfloor\bar b\rfloor + f_0$$

则**割平面**为

$$\boxed{\ \sum_j f_j\,x_j \ \ge\ f_0\ }$$

### 1.3.5 分支定界的分枝规则

若 LP 松弛的最优解里 $x_j^* = k+f$（$0<f<1$，即不是整数），则分成两个子问题：

$$\boxed{\ x_j\le k \quad\text{与}\quad x_j\ge k+1\ }$$

其余约束**一字不动**。

## 1.4 常见情形

| 你碰到的情况 | 用什么 |
|---|---|
| 有 $\le$ 约束、右端非负 | 加松弛变量就得到初始单位基，**直接单纯形法** |
| 有 $=$ 或 $\ge$ 约束 | 初始基不好找 ⟹ 补**人工变量**，走大 M 法或两阶段法 |
| 题目已给一个初始基可行解 | 直接算 $B^{-1}$ 化简，**不用人工变量**（习题 4(1) 就是这种） |
| 要判断原问题有没有可行解 | 大 M 法：人工变量还留在基里且非零 ⟹ 无解；两阶段法：$w_{\min}>0$ ⟹ 无解 |
| 要写对偶规划 | 逐行逐变量贴标签 → 翻 **1.3.1** 表 |
| 要 LP 的整数解 | LP 松弛 + **割平面**（1.3.4）或**分支定界**（1.3.5） |
| 问「右端项变了最优值怎么变」 | **影子价格** $y^{*\mathsf T}d$（1.3.3） |
| 已知 (P) 最优解要 (D) 的最优解 | **互补松弛**（1.3.2）联立，或从最优表读检验数（1.3.3） |

## 1.5 直观理解

- **单纯形法** 描述「**沿多面体的棱，从一个顶点走到更好的顶点**」—— 因为最优解必在顶点上，所以只逛顶点就够了。
- **检验数 $\sigma_j$** 描述「**让 $x_j$ 进基划不划算**」—— $\sigma_j<0$ 说明把 $x_j$ 提上来能降目标值。
- **$\theta$ 规则** 描述「**往这个方向走能走多远**」—— 走太远会有基变量变负（跑出可行域），所以取最小比值。
- **人工变量** 描述「**先借一个假基，再想办法还掉**」—— 还掉的方式就是大 M（重罚逼它走）或两阶段（先只求可行）。
- **对偶** 描述「**同一件事的两种算法**」—— 原问题问"怎么用资源最省"，对偶问"资源本身值多少钱"。
- **影子价格 $y^*$** 描述「**资源多一块钱值多少**」—— 是"资源的边际价值"，不是资源的市场价。
- **割平面** 描述「**切一刀，把非整数最优点切掉，但一个整数点都不碰**」。
- **分支定界** 描述「**整数解要么在左边要么在右边，那就两边都查**」。

> [!note] 一个能拔高的观察：为什么「对偶」这么有用
> ① **给最优性一个证书**：弱对偶说 $c^{\mathsf T}x\ge b^{\mathsf T}y$ 恒成立，所以只要能找到一个可行 $x$ 和一个可行 $y$ 使两者相等，就**证明了最优**，不用遍历所有顶点。
> ② **给了敏感度**：影子价格告诉你该多买哪种资源。
> ③ **给了新算法**：当原问题约束多、变量少时，转去解对偶可能快得多。
> ④ **后续章节的入口**：KKT 条件、拉格朗日对偶，本质上都是 LP 对偶的推广 —— 第 1 章那句「有效集是最优性条件的入口」，到那里就和这里接上了。

## 1.6 例题

### 1.6.1 例 1（写对偶规划：含自由变量）

> 写出 $\min\ 3x_1+2x_2$ s.t. $x_1+x_2\ge4$，$2x_1+x_2\le6$，$x_1\ge0$，$x_2$ 自由 的对偶规划。

逐条贴标签：

| 原问题 | 对偶 |
|---|---|
| $x_1+x_2\ge4$（$\ge$ 型） | $y_1\ge0$ |
| $2x_1+x_2\le6$（$\le$ 型） | $y_2\le0$ |
| $x_1\ge0$ | $y_1+2y_2\le3$ |
| $x_2$ **自由** | $y_1+y_2 = 2$ |
| $\min(3x_1+2x_2)$ | $\max(4y_1+6y_2)$ |

$$\max\ 4y_1+6y_2 \quad \text{s.t.}\quad \begin{cases} y_1+2y_2\le3 \\ y_1+y_2 = 2 \\ y_1\ge0,\ y_2\le0 \end{cases}$$

**要点**：**先把每个约束、每个变量贴上标签**，再翻表 —— 顺序不能反。自由变量那一条最容易忘（这里 $x_2$ 自由 ⟹ 对偶第二行取**等号**）。

### 1.6.2 例 2（单纯形法：标准型）

> 用单纯形法解 $\min\ -x_1-2x_2$ s.t. $x_1+x_2\le4$，$x_1+3x_2\le6$，$x_1,x_2\ge0$。

加松弛变量 $x_3,x_4$ 得标准形。初始基 $\{x_3,x_4\}$：

| 基 | $x_1$ | $x_2$ | $x_3$ | $x_4$ | RHS |
|---|---|---|---|---|---|
| $x_3$ | 1 | 1 | 1 | 0 | 4 |
| $x_4$ | 1 | 3 | 0 | 1 | 6 |
| $\sigma$ | $-1$ | $-2$ | 0 | 0 | $z=0$ |

$\sigma_2=-2$ ⇒ $x_2$ 进基；$\theta=\min\{4/1,\ 6/3\}=2$ ⇒ $x_4$ 出基。

| 基 | $x_1$ | $x_2$ | $x_3$ | $x_4$ | RHS |
|---|---|---|---|---|---|
| $x_3$ | $2/3$ | 0 | 1 | $-1/3$ | 2 |
| $x_2$ | $1/3$ | 1 | 0 | $1/3$ | 2 |
| $\sigma$ | $-1/3$ | 0 | 0 | $2/3$ | $z=-4$ |

$\sigma_1=-1/3$ ⇒ $x_1$ 进基；$\theta=\min\{2/(2/3),\ 2/(1/3)\}=\min\{3,\ 6\}=3$ ⇒ $x_3$ 出基。

| 基 | $x_1$ | $x_2$ | $x_3$ | $x_4$ | RHS |
|---|---|---|---|---|---|
| $x_1$ | 1 | 0 | $3/2$ | $-1/2$ | 3 |
| $x_2$ | 0 | 1 | $-1/2$ | $1/2$ | 1 |
| $\sigma$ | 0 | 0 | $1/2$ | $1/2$ | $z=-5$ |

全部 $\sigma_j\ge0$ ⇒ 最优：$x^*=(3,1)^{\mathsf T}$，$\min z = -3-2 = -5$。

> [!tip] 顺手读出对偶最优解
> 松弛变量那两列的检验数是 $\sigma(x_3)=\sigma(x_4)=1/2$，按 1.3.3 的 $y_i^*=-\sigma(s_i)$ 得 $y^*=(-1/2,\,-1/2)$。
> 验证：对偶 $\max\ 4y_1+6y_2$ s.t. $y_1+y_2\le-1$，$y_1+3y_2\le-2$，$y\le0$ —— 代入得 $4(-1/2)+6(-1/2)=-2-3=-5$ ✓ 与 $z^*=-5$ 相等，强对偶成立。

**要点**：$\min$ 问题 **$\sigma_j<0$ 进基**、取最负的那个；$\theta$ 只对**正**的列元素算比值。表做到**全部 $\sigma_j\ge0$** 就停。

### 1.6.3 例 3（大 M 法：$\ge$ 约束）

> 用大 M 法解 $\min\ 2x_1+3x_2$ s.t. $x_1+x_2\ge3$，$x_1+2x_2\le8$，$x_1,x_2\ge0$。

$\ge$ 约束要减剩余变量 $s_1$，但 $s_1$ 的系数是 $-1$，凑不出单位基 ⇒ 补人工变量 $a_1$：

$$
\begin{aligned}
\min\ & 2x_1+3x_2+Ma_1 \\
\text{s.t.}\ & x_1+x_2-s_1+a_1 = 3 \\
& x_1+2x_2+s_2 = 8 \\
& x_1,x_2,s_1,s_2,a_1\ge0
\end{aligned}
$$

| 基 | $x_1$ | $x_2$ | $s_1$ | $s_2$ | $a_1$ | RHS |
|---|---|---|---|---|---|---|
| $a_1$ | 1 | 1 | $-1$ | 0 | 1 | 3 |
| $s_2$ | 1 | 2 | 0 | 1 | 0 | 8 |
| $\sigma$ | $2-M$ | $3-M$ | $M$ | 0 | 0 | $z=3M$ |

$2-M$ 比 $3-M$ 更负 ⇒ $x_1$ 进基；$\theta=\min\{3/1,\ 8/1\}=3$ ⇒ $a_1$ 出基。

| 基 | $x_1$ | $x_2$ | $s_1$ | $s_2$ | $a_1$ | RHS |
|---|---|---|---|---|---|---|
| $x_1$ | 1 | 1 | $-1$ | 0 | 1 | 3 |
| $s_2$ | 0 | 1 | 1 | 1 | $-1$ | 5 |
| $\sigma$ | 0 | 1 | 2 | 0 | $M-2$ | $z=6$ |

全部 $\sigma_j\ge0$，且 $a_1$ 已出基（$a_1=0$）⇒ 最优：$x^*=(3,0)^{\mathsf T}$，$\min z=6$。

**验算**：$3+0=3\ge3$ ✓；$3+0=3\le8$ ✓

**要点**：人工变量在目标里的系数是 $+M$，所以算 $\sigma(a_1)$ 时别忘了**它自己的成本也含 $M$**（这里 $\sigma(a_1)=M-2>0$，保证它不会再挤回基里）。

### 1.6.4 例 4（两阶段法）

> 用两阶段法解 $\min\ -x_1-x_2$ s.t. $2x_1+x_2\ge4$，$x_1+3x_2\le6$，$x_1,x_2\ge0$。

**阶段一**：$\min\ w=a_1$（行 1 补人工变量）

| 基 | $x_1$ | $x_2$ | $s_1$ | $s_2$ | $a_1$ | RHS |
|---|---|---|---|---|---|---|
| $a_1$ | 2 | 1 | $-1$ | 0 | 1 | 4 |
| $s_2$ | 1 | 3 | 0 | 1 | 0 | 6 |
| $\sigma$ | $-2$ | $-1$ | 1 | 0 | 0 | $w=4$ |

$x_1$ 进基；$\theta=\min\{4/2,\ 6/1\}=2$ ⇒ $a_1$ 出基。

| 基 | $x_1$ | $x_2$ | $s_1$ | $s_2$ | $a_1$ | RHS |
|---|---|---|---|---|---|---|
| $x_1$ | 1 | $1/2$ | $-1/2$ | 0 | $1/2$ | 2 |
| $s_2$ | 0 | $5/2$ | $1/2$ | 1 | $-1/2$ | 4 |
| $\sigma$ | 0 | 0 | 0 | 0 | 1 | $w=0$ |

$w_{\min}=0$ ⇒ **原问题可行**，可行基 $\{x_1,s_2\}$，阶段一结束。

**阶段二**：划掉 $a_1$ 列，换回原目标 $\min\ -x_1-x_2$。

| 基 | $x_1$ | $x_2$ | $s_1$ | $s_2$ | RHS |
|---|---|---|---|---|---|
| $x_1$ | 1 | $1/2$ | $-1/2$ | 0 | 2 |
| $s_2$ | 0 | $5/2$ | $1/2$ | 1 | 4 |
| $\sigma$ | 0 | $-1/2$ | $-1/2$ | 0 | $z=-2$ |

$x_2$ 进基；$\theta=\min\{2/(1/2),\ 4/(5/2)\}=\min\{4,\ 8/5\}=8/5$ ⇒ $s_2$ 出基。

| 基 | $x_1$ | $x_2$ | $s_1$ | $s_2$ | RHS |
|---|---|---|---|---|---|
| $x_1$ | 1 | 0 | $-3/5$ | $-1/5$ | $6/5$ |
| $x_2$ | 0 | 1 | $1/5$ | $2/5$ | $8/5$ |
| $\sigma$ | 0 | 0 | $-2/5$ | $1/5$ | $z=-14/5$ |

$\sigma(s_1)=-2/5<0$，**剩余变量 $s_1$ 要进基**（这在第二阶段很常见，别以为 $s$ 就不能进）；$\theta=(8/5)/(1/5)=8$ ⇒ $x_2$ 出基。

| 基 | $x_1$ | $x_2$ | $s_1$ | $s_2$ | RHS |
|---|---|---|---|---|---|
| $x_1$ | 1 | 3 | 0 | 1 | 6 |
| $s_1$ | 0 | 5 | 1 | 2 | 8 |
| $\sigma$ | 0 | 2 | 0 | 1 | $z=-6$ |

全部 $\sigma_j\ge0$ ⇒ 最优：$x^*=(6,0)^{\mathsf T}$，$\min z=-6$。

**验算**：$2\cdot6+0=12\ge4$ ✓；$6+0=6\le6$ ✓

**要点**：两阶段法的关键是**阶段的交接** —— 阶段一结束时**只划掉人工变量列**，基和表都保留，换成原目标接着迭代。**$w_{\min}=0$ 是可行性的判据**，这一步一定要报告。

> [!warning] 例题里最容易丢的分
> 例 1 忘掉「自由变量 ⟹ 对偶取等号」、例 2 把 $\sigma$ 的符号方向记反、例 3 忘了人工变量自身成本含 $M$、例 4 以为剩余变量 $s_1$ 不能进基 —— 四处都是判分点。

## 1.7 注意点与陷阱

1. **$\sigma$ 的符号习惯分 $\min$/$\max$。** $\min$ 问题 **$\sigma_j<0$ 进基**；$\max$ 问题反过来。换算方式是先统一成 $\min$（$\max z = -\min(-z)$），别两套记法混用。
2. **$\theta$ 规则只对正的列元素算比值。** 负数和零直接跳过（对应"反方向走不会跑出可行域"）。若进基列**全是非正**，则问题**无界**。
3. **写对偶最容易错的两条：「变量自由 ⟹ 对偶约束取等号」「等式约束 ⟹ 对偶变量自由」。** 这两条是同一对互换的两面。
4. **双边约束 $b_1\le Ax\le b_2$ 必须拆成两行。** 拆的招式是「$\le$ 乘 $-1$ 变 $\ge$」，统一方向后再查表，于是配**两个**对偶变量。
5. **大 M 法要迭代到人工变量全部出基才算完。** 若最优表里人工变量还留在基中且**非零** ⟹ 原问题**无可行解**。
6. **割平面拆分数部分时，负数要按「向下取整」拆。** $-\frac15 = -1+\frac45$，分数部分是 $\frac45$ 而不是 $-\frac15$。这一步搞错，整个割平面就错了。
7. **分支定界只对「取分数值」的变量开花**，并且每支**只加一条界约束**，其余约束一字不动。
8. **互补松弛是双向的**：$y_i^*>0$ ⟹ 第 $i$ 个约束**取等**；反过来约束松着（$a_ix^*>b_i$）⟹ $y_i^*=0$。求解时用这两条可以**联立出对偶最优解**，不必再解一次 LP。
9. **LP 松弛的最优解已经全是整数 ⟹ 它就是整数规划的最优解**，不必分枝。（因为整数规划的最优值不可能比它的松弛更小。）

## 1.8 速查表

| 你要干什么 | 用什么 |
|---|---|
| 化标准形 | $\le$ 加松弛、$\ge$ 减剩余、自由变量拆两项、$b<0$ 整行乘 $-1$ |
| 判断当前基可行解是否最优 | $\min$ 问题：全部 $\sigma_j\ge0$ ⟺ 最优 |
| 选进基变量 | $\min$ 问题取 **$\sigma_j$ 最负**的那个（都不负则已最优） |
| 选出基变量 | $\theta=\min\{b̄_i/a_{ij}:\ a_{ij}>0\}$，取最小的那一行 |
| 判断无界 | 进基列**全部** $a_{ij}\le0$ ⟹ 目标无界 |
| 初始基不好找 | 补**人工变量** → 大 M 法或两阶段法 |
| 已知初始基可行解 | 直接算 $B^{-1}$ 化简方程组，**不用**人工变量 |
| 判断原问题无可行解 | 大 M 法：人工变量留基且非零；两阶段法：$w_{\min}>0$ |
| 写对偶规划 | 逐行逐变量贴标签 → 翻 **1.3.1** 的对偶规则表 |
| 求对偶最优解 | $y^{*\mathsf T}=c_B^{\mathsf T}B^{-1}$；或从最优表读（$\min c^{\mathsf T}x,\ Ax\le b$ 型：$y_i^*=-\sigma(s_i)$）；或用互补松弛联立 |
| 影子价格 | 就是对偶最优解 $y_i^*$ —— 第 $i$ 种资源的边际价值 |
| 右端项扰动后的最优值 | 至少增加 $y^{*\mathsf T}d$（$d$ 小则近似等于） |
| 写割平面方程 | 取分数值的基变量那行 → $\sum f_jx_j\ge f_0$，系数按 $\lfloor\cdot\rfloor$ 拆 |
| 分支定界分枝 | $x_j^*=k+f$ ⟹ 分成 $x_j\le k$ 与 $x_j\ge k+1$ |
