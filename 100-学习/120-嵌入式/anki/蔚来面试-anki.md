### 0.1.1 一、单选题卡片

{Q}在 Linux 中，执行 `cat /proc/cpuinfo | grep "processor" | wc -l` 命令，其作用是什么？{A}查看逻辑 CPU 的个数（线程数）。`grep "processor"` 筛选出每个逻辑 CPU 的行，`wc -l` 统计行数。{E}

{Q}在服务端主机上排查 TCP 连接是否建立成功，客户端 IP 为 10.157.128.100:8600，服务端 IP 为 10.157.123.200:8700，应该使用什么命令？{A}`netstat -ant | grep "10.157.123.100:8600" | grep "10.157.123.200:8700" | grep "ESTABLISHED"`。必须使用 `-a`（显示所有连接，含已建立）而非 `-l`（仅监听），并用 `-n` 数字显示避免域名解析。{E}

{Q}C++11 中，以下哪个不属于模板新特性？A.允许模板右尖括号 B.引入 using 定义模板别名 C.允许函数模板使用默认模板参数 D.可以直接使用 copy 进行模板复制{A}D。前 3 项均为 C++11 引入的模板特性，第 4 项“直接使用 copy 进行模板的复制”并非 C++11 新增特性。{E}

{Q}从集合 S={1,2,…,300} 中可重复任选两个数字，两数之积能被 5 整除的概率是多少？{A}9/25。能被 5 整除的数为 60 个，不能被 5 整除的为 240 个。两数都不能被 5 整除的概率 = (4/5)² = 16/25，故积能被 5 整除的概率 = 1 - 16/25 = 9/25。{E}

{Q}以下 C++ 程序的输出是什么？`int a=5; float b; cout<<sizeof(++a+b); cout<<a;`{A}4 5。`sizeof` 是编译时运算符，只关心表达式类型，不对表达式求值，因此 `++a` 未执行。`int + float` 结果为 float 类型，占 4 字节。{E}

### 0.1.2 二、不定项选择题卡片

{Q}关于 C++ 类的成员，下列说法正确的有哪些？A.类中一个数据成员表示每个对象都持有的一个值 B.调用类中成员函数必须确定一个作用对象 C.类中至少应包含一个成员 D.类中各个成员的声明没有严格次序{A}D。A 错：静态数据成员属于类本身，不每个对象独有；B 错：静态成员函数可不通过对象调用；C 错：C++ 允许空类；D 对：声明次序无严格要求（但使用前需声明）。{E}

{Q}关于 Android 系统，下列说法正确的有哪些？A.Android 使用的虚拟机为 JVM B.Android 是开源操作系统 C.Android 中所有布局类都是 View 的子类 D.清单文件包含应用程序所有信息{A}B、C。A 错：Android 使用 ART/Dalvik 虚拟机，非 JVM；B 对：Android 基于开源 Linux 内核；C 对：布局类继承自 View；D 错：清单文件包含核心信息，但并非“所有”信息（如代码、资源等不在其中）。{E}

{Q}关于堆排序，以下说法错误的有哪些？A.所有元素有序的递增数组可以……（题干缺失）B.所有元素有序的递减数组可以……（题干缺失）C.堆排序在任何情况下时间复杂度均为 O(n log₂ n) D.小根堆中任意结点的值均大于其左右孩子结点的值{A}D（以及 A、B 需视完整题干判断）。C 对：堆排序最坏/平均/最好均为 O(n log n)；D 错：小根堆中父节点值应小于等于孩子节点值，而不是大于。{E}

### 0.1.3 三、编程题卡片（思路 + 数据结构）

{Q}【算法题】删除排序链表中的重复节点（保留不重复节点）。如 1→2→3→3→4，删除后为 1→2→4。核心数据结构和解题思路是什么？{A}哈希表（或双指针）。用哈希表统计每个值出现次数，再遍历一次链表，只保留出现次数为 1 的节点。由于链表已排序，也可用双指针一次遍历跳过重复段。时间复杂度 O(n)。{E}

{Q}【算法题】合法括号字符串判断：字符串只含 `(`、`)`、`*`，其中 `*` 可视为 `(`、`)` 或空字符。如 `"((*)"` → true，`"(((*)"` → false。核心数据结构和解题思路是什么？{A}双栈法（左括号栈 + 星号栈）。1. 遇 `(` 压入左栈，遇 `*` 压入星栈；2. 遇 `)` 优先匹配左栈（弹出），若左栈空则匹配星栈，若都空则返回 false；3. 遍历结束后，用星栈中的 `*` 匹配左栈剩余的 `(`，必须保证星号索引在左括号索引之后。时间复杂度 O(n)。{E}

{Q}【算法题】给定二叉树的根节点，返回中序遍历结果。输入 `{1, 2, #, #, 3}`，输出 `[2, 3, 1]`。核心数据结构和解题思路是什么？{A}树 + 递归/显式栈。中序遍历顺序为：左子树 → 根节点 → 右子树。递归写法最简洁；迭代写法需用栈模拟递归过程，先沿左子树一直入栈，弹出后访问节点，再转向右子树。时间复杂度 O(n)，空间复杂度 O(n)。{E}

{Q}【算法题·补充】删除排序链表中的重复节点，能否用双指针一次遍历完成？请简要描述双指针解法。{A}可以。由于链表已排序，重复节点必然相邻。使用双指针，一个指向当前不重复链表的尾部（prev），另一个用于遍历（cur）。当 cur 与下一个节点值不同时，将 prev->next 指向 cur 并移动 prev；若相同，则跳过所有相同值的节点。注意要处理头节点可能被删除的情况，通常使用哑节点（dummy head）简化边界处理。{E}

{Q}【算法题·补充】合法括号字符串判断，除了双栈法，还有什么其他解法？{A}贪心法（维护最低/最高可能未匹配左括号数）。遍历字符串：遇到 `(` 则最低和最高都 +1；遇到 `)` 则最低和最高都 -1（最高不能为负，最低不能低于 0）；遇到 `*` 则最低 -1、最高 +1（`*` 视为右括号或左括号）。遍历结束后若最低为 0 则合法。该法空间复杂度 O(1)，比双栈更优。{E}
