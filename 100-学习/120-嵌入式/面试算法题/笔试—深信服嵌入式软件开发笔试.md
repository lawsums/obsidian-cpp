# 2 题目

## 2.1 题目 1：数组游戏——找出连胜 k 场的数字

### 2.1.1 问题描述

给定一个元素都唯一的数组 `arr` 和一个大于 0 的整数 `k`，来进行一个游戏，找到符合游戏规则的数字。

每回合游戏都在数组的前两个元素（即 `arr[0]` 和 `arr[1]`）之间进行。

比较 `arr[0]` 与 `arr[1]` 的大小，较大的整数将会取得这一回合的胜利并保留在位置 0，较小的整数移至数组的末尾。

当一个整数赢得 `k` 个连续回合时，游戏结束，该整数就是我们需要找到的数字。

- 数组 `arr` 的长度为 2 ~ 1000
- 整数 `k` 的取值范围为 1 ~ 999

### 2.1.2 输入描述

输入为一行，n 个数字，用空格隔开。

前面 n-1 个数字组成题目中的数组 `arr`，第 n 个数字为 `k`。

```javascript
const arr = xxx.split(' ')
const k = arr.pop()
```

#### 2.1.2.1 示例输入

```text
2 1 4 3 6 5 0 7 3
```

### 2.1.3 输出描述

输出为我们需要找到的数字（以字符串的形式）。

#### 2.1.3.1 示例输出

```text
6
```

### 2.1.4 样例说明

| 回合 | 数组 | 获胜数字 | 连胜回合数 |
| --- | --- | --- | --- |
| 1 | `[2, 1, 4, 3, 6, 5, 0, 7]` | 2 | 1 |
| 2 | `[2, 4, 3, 6, 5, 0, 7, 1]` | 4 | 1 |
| 3 | `[4, 3, 6, 5, 0, 7, 1, 2]` | 4 | 2 |
| 4 | `[4, 6, 5, 0, 7, 1, 2, 3]` | 6 | 1 |
| 5 | `[6, 5, 0, 7, 1, 2, 3, 4]` | 6 | 2 |
| 6 | `[6, 0, 7, 1, 2, 3, 4, 5]` | 6 | 3 |

第 6 回合后 6 已连胜 3 场，达到 k = 3，游戏结束。

## 2.2 题目 2：最大排序连续上升子段长度

### 2.2.1 问题描述

给一个长度为 n 的数组，求出**最大排序连续上升子段长度**。

即找一个连续子段 `[i, j]`，使其元素互不相同，且将这些元素排序后恰好构成一段连续上升的序列（相邻元素差值恒为 1）。

### 2.2.2 输入描述

- 第一行给出一个数 n，表示第二行数字个数，1 ≤ n ≤ 5000
- 第二行是 n 个数，1 ≤ 每个数 ≤ 1000000000

#### 2.2.2.1 示例输入

```text
5
3 1 2 4 6
```

### 2.2.3 输出描述

每个输入输出一个数，代表最大排序连续上升子段的长度。

#### 2.2.3.1 示例输出

```text
4
```

> [!note] 说明
> 子段 `[3, 1, 2, 4]` 的最小值为 1、最大值为 4，`max - min = 3 = 长度 - 1`，
> 排序后为 `[1, 2, 3, 4]`，是连续上升序列，长度为 4。

## 2.3 题目 3：病毒伪装度最少变换次数

### 2.3.1 问题描述

一年一度的入侵行动来了，病毒小绿被病毒大王安排去入侵多个主机。但是每个主机都装有了深信服强大的 EDR 杀毒设备。小绿想要避开这些杀毒设备去入侵主机，是一项非常困难的任务。

好在，病毒大王赋予了小绿特殊的力量，让它能通过伪装去绕过杀毒设备的检测。

小绿需要**按顺序**去入侵 n 个主机，每个主机上的杀毒设备有自己的辨识度 `a[i]`。如果小绿的伪装度 `v` 与杀毒设备的辨识度 `a[i]` 的绝对值不超过 `x`（主机的辨识精确度），即 `|a[i] - v| <= x`，则病毒可以入侵成功当前主机。

现给定 n 个主机的辨识度，问小绿**最少需要变化多少次伪装度**（伪装度可以取任意值），才能按照顺序成功入侵所有主机。

> [!warning] 注意
> 小绿初始时的伪装度可以取任意值，且**不计入**小绿变化的伪装次数。

### 2.3.2 输入描述

给定正整数 `n` 和 `x`，分别表示主机数和主机的辨识精确度。接下来是 `n` 个正整数 `a[i]`，分别表示这 n 个主机的辨识度。

#### 2.3.2.1 示例输入

```text
5 4
4 9 6 7 8
```

### 2.3.3 输出描述

输出一个整数，表示小绿最少需要变化多少次伪装度，才能入侵 n 个主机。

#### 2.3.3.1 示例输出

```text
0
```

### 2.3.4 样例说明

小绿将初始伪装度设置为 6，由于 4、9、6、7、8 与 6 的差的绝对值都不超过 4，因此小绿可以成功入侵这些主机，最少需要变化 **0** 次伪装度。

# 3 答案解析

## 3.1 题目 1：数组游戏——找出连胜 k 场的数字

### 3.1.1 解题思路

1. **解析输入**：整行读入 → `stringstream` 拆成数字序列 → 最后一个数是 `k`，前面的构成 `arr`。
2. **关键剪枝**：若 `k >= arr_size`，无需模拟。数组中最大的元素最终一定会移动到队首，并连续击败其余全部 `arr_size - 1` 个元素；此时 `k >= arr_size` 必然已经满足，答案就是数组最大值。
3. **模拟游戏**：用 `std::deque` 维护队列，因为它支持 O(1) 的队首/队尾插入删除。
   - 每次取出队首两个元素 `p1`、`p2`；
   - 较大者为 `winner`，较小者为 `loser`；
   - `winner` 放回队首，`loser` 追加到队尾；
   - 若 `winner` 与上一回合胜者相同则连胜数 +1，否则重置连胜数为 1。
4. **终止条件**：连胜数达到 `k` 时输出当前胜者。

**复杂度**：模拟轮数不超过 `arr_size + k`，每轮 O(1)，时间 O(n + k)，空间 O(n)。

### 3.1.2 参考代码（C++）

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <vector>
#include <deque>      // 使用双端队列，在头部和尾部操作效率很高
#include <algorithm>  // 用于 std::max_element

int main() {
    // 1. 读取整行输入
    std::string line;
    std::getline(std::cin, line);

    // 2. 使用 stringstream 解析输入到 vector
    std::stringstream ss(line);
    int num;
    std::vector<int> numbers;
    while (ss >> num) {
        numbers.push_back(num);
    }

    // 3. 分离 k 和 arr
    int k = numbers.back();
    numbers.pop_back();

    int arr_size = numbers.size();

    // 4. 【重要优化】
    // 如果 k 远大于数组长度，我们不需要模拟。
    // 数组中的最大值最终会到达头部并连续击败所有其他 (arr_size - 1) 个元素。
    // 如果 k >= arr_size，获胜者必定是数组中的最大值。
    // 样例 2 和 4 都属于这种情况。
    if (k >= arr_size) {
        // *std::max_element 会返回指向最大元素的迭代器，* 解引用得到该值
        std::cout << *std::max_element(numbers.begin(), numbers.end()) << std::endl;
        return 0;
    }

    // 5. 将数组元素放入双端队列 (deque) 以便高效模拟
    std::deque<int> dq(numbers.begin(), numbers.end());

    // 6. 开始模拟游戏
    int current_winner = -1; // 记录当前的连胜者
    int consecutive_wins = 0; // 记录连胜次数

    while (true) {
        // 取出前两个元素
        int p1 = dq.front();
        dq.pop_front();
        int p2 = dq.front();
        dq.pop_front();

        int winner, loser;

        // 比较大小
        if (p1 > p2) {
            winner = p1;
            loser = p2;
        } else {
            winner = p2;
            loser = p1;
        }

        // 胜者放回队首，败者放到队尾
        dq.push_front(winner);
        dq.push_back(loser);

        // 7. 检查连胜
        if (winner == current_winner) {
            consecutive_wins++;
        } else {
            // 换了新的胜者，重置
            current_winner = winner;
            consecutive_wins = 1;
        }

        // 8. 检查游戏是否结束
        if (consecutive_wins == k) {
            std::cout << current_winner << std::endl;
            break; // 游戏结束
        }
    }

    return 0;
}
```

## 3.2 题目 2：最大排序连续上升子段长度

### 3.2.1 解题思路

核心判据：一个长度 `len` 的子段能排序成连续上升序列，当且仅当

```
子段元素互不相同  且  max - min == len - 1
```

1. **枚举起点** `i`：对每个起点重置 `min_val`、`max_val` 和判重集合 `seen`。
2. **向右扩展终点** `j`：
   - 若 `arr[j]` 已在 `seen` 中出现 → 子段含重复元素，再往右只会更差，直接 `break`（剪枝）；
   - 否则加入 `seen`，更新 `min_val` / `max_val`。
3. **判定**：若 `max_val - min_val == j - i`，说明 `[i, j]` 合法，用 `j - i + 1` 更新答案。
4. 单元素子段天然满足（`max == min`，`j - i == 0`），答案至少为 1。

**复杂度**：最坏 O(n²)，n ≤ 5000 时约 2.5 × 10⁷ 次操作，可接受。

### 3.2.2 参考代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <unordered_set>

int main() {
    int n;
    std::cin >> n;

    std::vector<int> arr(n);
    for (int i = 0; i < n; ++i) {
        std::cin >> arr[i];
    }

    int max_length = 0; // 存储最终的最大长度

    // 遍历所有可能的子段起点 i
    for (int i = 0; i < n; ++i) {

        // --- 对于每个新的起点 i，重置 ---
        int min_val = arr[i]; // 当前子段 [i...j] 的最小值
        int max_val = arr[i]; // 当前子段 [i...j] 的最大值

        // seen 用于检查 [i...j] 范围内的重复元素
        std::unordered_set<int> seen;

        // 遍历所有可能的子段终点 j (从 i 开始)
        for (int j = i; j < n; ++j) {

            // 1. 检查重复元素
            // 如果 arr[j] 已经在 [i...j-1] 中出现过
            if (seen.count(arr[j])) {
                // 那么从 [i...j] 往后的所有子段 (如 [i...j+1])
                // 也都包含重复元素，可以直接
                // 终止这个 j 循环，开始下一个 i
                break;
            }
            seen.insert(arr[j]);

            // 2. 更新当前子段 [i...j] 的 min 和 max
            min_val = std::min(min_val, arr[j]);
            max_val = std::max(max_val, arr[j]);

            // 3. 检查核心条件：max - min == 长度 - 1
            if (max_val - min_val == j - i) {
                // 如果条件满足，说明 [i...j] 是一个有效的
                // “排序后连续上升”的子段
                int current_length = j - i + 1;
                max_length = std::max(max_length, current_length);
            }
        }
    }

    // 至少为 1（如果 n > 0），因为单个元素 [x] 排序后是 [x]，
    // max=x, min=x, j=i。max-min = 0, j-i = 0。
    // 我们的逻辑在 i=j 时 (current_length=1) 已经处理了这种情况。
    // 如果 n=0，max_length 保持为 0，也是正确的。
    std::cout << max_length << std::endl;

    return 0;
}
```

## 3.3 题目 3：病毒伪装度最少变换次数

### 3.3.1 解题思路

把「伪装度 v 能入侵主机 a[i]」理解为一个**区间约束**：

```
|a[i] - v| <= x   ⟺   v ∈ [a[i] - x,  a[i] + x]
```

于是问题转化为：**用尽量少的伪装度(区间)，按顺序覆盖所有主机**。贪心维护「当前伪装度可行区间」的交集即可。

1. **初始化**（不计入变化次数）：以第一个主机为基准，`current = [a[0] - x, a[0] + x]`。
2. **逐个主机求交**：对 `a[i]`，计算 `new = current ∩ [a[i] - x, a[i] + x]`。
3. **判断交集**：
   - **非空** → 缩小可行区间为 `new = [max(下界), min(上界)]`，无需变化；
   - **为空**（`new_min > new_max`）→ 当前伪装度无法兼顾，必须变化一次（`changes++`），并把可行区间**重置**为 `[a[i] - x, a[i] + x]`，从当前主机重新开始一段。
4. **输出变化的次数**。

**贪心正确性**：每次不得不变化时，把区间重置为当前主机的最大可行区间，能为后续主机保留最大的兼容空间，因此不会比任何其他策略更差。

**注意**：`a[i] + x` 可能超过 32 位整数范围，需用 `long long`。

**复杂度**：时间 O(n)，空间 O(n)（只维护两个变量则空间 O(1)）。

### 3.3.2 参考代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <algorithm> // 用于 std::max 和 std::min

int main() {
    int n;
    long long x; // 辨识精确度 x 可能很大，用 long long

    std::cin >> n >> x;

    std::vector<long long> a(n);
    for (int i = 0; i < n; ++i) {
        std::cin >> a[i];
    }

    if (n == 0) {
        std::cout << 0 << std::endl;
        return 0;
    }

    int changes = 0; // 记录变化次数，初始为0

    // 1. 设置初始的可行伪装范围 (基于第一个主机 a[0])
    // 这个初始设置不计入 "changes"
    long long current_min_v = a[0] - x;
    long long current_max_v = a[0] + x;

    // 2. 遍历从第二个主机 (i=1) 开始的所有主机
    for (int i = 1; i < n; ++i) {

        // 2a. 计算当前主机 a[i] 要求的伪装范围
        long long required_min = a[i] - x;
        long long required_max = a[i] + x;

        // 2b. 计算[当前可行范围]与[a[i]要求范围]的交集
        long long new_min = std::max(current_min_v, required_min);
        long long new_max = std::min(current_max_v, required_max);

        // 2c. 检查交集是否为空
        // 如果下界大于上界，说明没有交集
        if (new_min > new_max) {
            // 必须更换伪装度
            changes++;

            // 以当前主机 a[i] 的要求范围为新的“可行范围”，
            // 重新开始一个新的入侵序列
            current_min_v = required_min;
            current_max_v = required_max;
        } else {
            // 交集不为空，可以继续使用（更窄的）范围
            // 更新可行范围为这个更小的交集
            current_min_v = new_min;
            current_max_v = new_max;
        }
    }

    // 3. 输出总的变化次数
    std::cout << changes << std::endl;

    return 0;
}
```
