# 2 题目

## 2.1 题目 1：两个有序数组合并后的中位数

### 2.1.1 问题描述

随着国民经济的发展，某省为了更好地发展区域经济、更好地协调资源，决定将其下辖的 A 市和 B 市合并成一个市。为了更好地了解两市合并后的经济情况，需要将原来两市所辖各县的年度 GDP 总数进行统计分析。我们知道，要更好地了解一组数据，用**中位数**会优于用平均数。

原来 A、B 两市的各个区（县）的年度 GDP 数据已经分别按照**从低到高**排好了，现在要求写一个程序，根据这两市排好序的 GDP 数据，计算出**合并后的 GDP 中位数**。

例如：A 市各区县排序后的 GDP 数据为 `1, 2, 3, 4, 5`（单位：千亿），B 市各区县排序后的 GDP 数据为 `2, 3, 4`，则两市合并后区县 GDP 中位数为 `3`。

> **中位数的计算方法**：先将数据进行排序，如果数据个数为**奇数**，则中间那个数即为中位数；如果数据个数为**偶数**，则中间两个数的平均数为中位数。

### 2.1.2 输入描述

分别输入两个市各区县 GDP 从低到高排序后的数据（两行，每行为一个市的全部数据），各区县数据之间用空格隔开。

#### 2.1.2.1 示例输入

```text
1 2 3 4 5
2 3 4
```

### 2.1.3 输出描述

根据输入的两市各区县 GDP 数据，计算出合并两市各区县 GDP 数据的中位数值。

#### 2.1.3.1 示例输出

```text
3
```

## 2.2 题目 2：货物多次交易的最大利润

### 2.2.1 问题描述

有一个小贩，只有一个小仓库用于保存货物。因为仓库太小了，**每次只能存放一种货物**，只有将这种货物卖出去后，才能将小仓库腾出来放其他进的货。作为一个精明的小贩，他能准确地预估熟悉的货物接下来几天的价格趋势，并据此进行货物的交易以获取最大利润。

例如：接下来 6 天货物的价格是 `[700, 200, 500, 200, 800, 400]`，则这六天里获取最大利润的交易方式为：

1. 第 2 天（价格 = 200）买入，第 3 天（价格 = 500）卖出，获利 `500 - 200 = 300`
2. 第 4 天（价格 = 200）买入，第 5 天（价格 = 800）卖出，获利 `800 - 200 = 600`

经过这两次交易，一共获利 `600 + 300 = 900` 元。

要求：输入一系列预估价格，计算出这系列价格中**可以通过交易赚取的最高利润值**。

### 2.2.2 输入描述

输入 n 个整数价格，价格之间用空格隔开。

#### 2.2.2.1 示例输入

```text
700 200 500 200 800 400
```

### 2.2.3 输出描述

输出上面 n 个价格能产生的最大利润值。

#### 2.2.3.1 示例输出

```text
900
```

# 3 答案解析

## 3.1 题目 1：两个有序数组合并后的中位数

### 3.1.1 解题思路

1. **读取数据**：分别读取两行代表 A 市和 B 市 GDP 的数据。由于数据量不确定，使用 `std::vector` 存储非常合适；`std::stringstream` 可以方便地解析以空格分隔的数字字符串。
2. **确定中位数位置**：计算两个数组的总长度 `totalSize`。
   - 若 `totalSize` 为**奇数**：只需要找到合并后排序数组中第 `totalSize / 2` 个位置的数（0-based 索引）。
   - 若 `totalSize` 为**偶数**：需要找到第 `totalSize / 2 - 1` 和第 `totalSize / 2` 两个位置的数，然后求平均值。
3. **模拟归并查找（双指针）**：不需要创建一个完整的合并后数组（那样会浪费空间）。使用双指针分别指向 A、B 数组，模拟归并过程，只需迭代到中位数所在位置即可，即迭代 `totalSize / 2 + 1` 次。每次迭代比较两个指针指向的元素，选择较小的那一个，并将对应指针后移。
   - 用 `middle1`、`middle2` 两个变量记录迭代过程中的最后两个元素：`middle2` 总是当前找到的最小元素，`middle1` 是上一次找到的最小元素。
4. **计算中位数**：迭代结束后，`middle2` 持有第 `totalSize / 2` 位置的元素，`middle1` 持有第 `totalSize / 2 - 1` 位置的元素。根据 `totalSize` 的奇偶性，使用 `middle1` 和/或 `middle2` 计算出最终的中位数。
5. **输出格式**：若中位数是整数则不显示小数部分，否则保留 1 位小数。

### 3.1.2 参考代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <sstream>
#include <iomanip> // 用于设置输出精度

// 函数：从标准输入读取一行空格分隔的数字到 vector 中
void readGdpData(std::vector<double>& gdp_vector) {
    std::string line;
    if (std::getline(std::cin, line)) {
        std::stringstream ss(line);
        double num;
        while (ss >> num) {
            gdp_vector.push_back(num);
        }
    }
}

int main() {
    // 为了提高 cin/cout 的性能
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(NULL);

    // 1. 读取两市的 GDP 数据
    std::vector<double> gdpA;
    std::vector<double> gdpB;
    readGdpData(gdpA);
    readGdpData(gdpB);

    size_t sizeA = gdpA.size();
    size_t sizeB = gdpB.size();
    size_t totalSize = sizeA + sizeB;

    // 如果没有数据，直接返回
    if (totalSize == 0) {
        std::cout << 0 << std::endl;
        return 0;
    }

    // 2. 双指针模拟归并，找到中间的一或两个元素
    size_t ptrA = 0;
    size_t ptrB = 0;
    double middle1 = 0.0;
    double middle2 = 0.0;

    for (size_t i = 0; i <= totalSize / 2; ++i) {
        // middle1 记录上一个 middle2 的值
        middle1 = middle2;

        // 比较两个数组当前指针的元素，取较小者
        // 同时处理一个数组已经遍历完的情况
        if (ptrA < sizeA && (ptrB >= sizeB || gdpA[ptrA] <= gdpB[ptrB])) {
            middle2 = gdpA[ptrA];
            ptrA++;
        } else if (ptrB < sizeB) {
            middle2 = gdpB[ptrB];
            ptrB++;
        }
    }

    // 3. 根据总数的奇偶性计算中位数
    double median;
    if (totalSize % 2 == 1) {
        // 总数为奇数，中位数是中间那个数
        median = middle2;
    } else {
        // 总数为偶数，中位数是中间两个数的平均值
        median = (middle1 + middle2) / 2.0;
    }

    // 设置输出格式，如果中位数是整数，则不显示小数部分
    if (median == static_cast<long long>(median)) {
        std::cout << static_cast<long long>(median) << std::endl;
    } else {
        std::cout << std::fixed << std::setprecision(1) << median << std::endl;
    }

    return 0;
}
```

## 3.2 题目 2：货物多次交易的最大利润

### 3.2.1 解题思路

这是一个经典的 **「买卖股票的最佳时机」问题** 的变种，**允许多次交易**。解决这个问题的最有效方法是使用**贪心算法**。

这个问题的核心在于：由于可以随时买入和卖出（卖出后第二天即可再次买入），我们不需要去寻找一个全局的最低点和最高点。相反，我们应该**抓住每一个价格上涨的机会**。

贪心策略非常简单：

1. 从第二天开始，观察当天的价格和前一天的价格。
2. 如果今天的价格比昨天高，那就意味着存在一个盈利机会——我们可以假设自己在昨天买入，然后在今天卖出，从而赚取差价。
3. 将所有"今天价格 > 昨天价格"的差价累加起来，得到的就是总的最大利润。

**复杂度**：时间 `O(n)`，空间 `O(1)`。

### 3.2.2 参考代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <sstream>

int main() {
    // 为了提高 cin/cout 的性能
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(NULL);

    // 读取一整行价格数据
    std::string line;
    std::getline(std::cin, line);

    // 使用 stringstream 解析以空格分隔的数字
    std::stringstream ss(line);
    std::vector<int> prices;
    int price;
    while (ss >> price) {
        prices.push_back(price);
    }

    // 如果价格数据不足两天，则无法交易，利润为0
    if (prices.size() < 2) {
        std::cout << 0 << std::endl;
        return 0;
    }

    // 使用 long long 防止利润累加后溢出
    long long max_profit = 0;

    // 遍历价格，累加所有上涨区间的利润
    for (size_t i = 1; i < prices.size(); ++i) {
        // 如果今天的价格比昨天高，就累加差价
        if (prices[i] > prices[i - 1]) {
            max_profit += prices[i] - prices[i - 1];
        }
    }

    std::cout << max_profit << std::endl;

    return 0;
}
```
