# 2 题目

## 2.1 题目 1：骰子三面之和

### 2.1.1 问题描述

给定一个骰子展开图的 6 个面（a, b, c, d, e, f），每个面有一个数字。骰子的展开图对应关系为：

- **a** 的对面是 **e**
- **b** 的对面是 **d**
- **c** 的对面是 **f**

求所有**共用一个顶点**的三个面的数字之和，共有多少种不同的结果，并从小到大输出。

### 2.1.2 输入描述

6 个正整数（≤ 1000），分别代表 a, b, c, d, e, f。

### 2.1.3 输出描述

- 第一行：结果数量
- 第二行：所有结果（从小到大，空格分隔）

---

## 2.2 题目 2：电脑选择问题

### 2.2.1 问题描述

有 N 道题，比赛时长 T 分钟。可以选择使用 **1 台电脑**或 **3 台电脑**：

- 使用 1 台电脑时，第 i 题耗时 `a_i`
- 使用 3 台电脑时，第 i 题耗时 `b_i`

同一时刻只能解一道题（无论几台电脑），可任意选择做题顺序。若解出某题后总时间超过 T，则该题不算解出。求：

1. 最多能解出多少题
2. 选择几台电脑（解出数量相同时，选电脑少的）

### 2.2.2 输入描述

- 第一行：`N T`（N ≤ 20，T ≤ 4320）
- 第二行：N 个 `a_i`
- 第三行：N 个 `b_i`

### 2.2.3 输出描述

- 第一行：最大解题数
- 第二行：电脑数量（1 或 3）

---

## 2.3 题目 3：经过所有标记点的最短路

### 2.3.1 问题描述

给定 n 个点 m 条边的**有向图**，以及 k 个标记点。求从起点 s 出发，**按任意顺序**经过所有标记点，最终到达终点 t 的最短距离。若不可达，输出 -1。

### 2.3.2 输入描述

- 第一行：`n m k s t`
- 接下来 m 行：`u v w`（u → v 权值 w）
- 接下来 k 行：标记点编号

### 2.3.3 输出描述

最短距离；若不可达，输出 -1。

# 3 答案解析

## 3.1 题目 1：骰子三面之和

### 3.1.1 解题思路

将展开图还原为立方体，建立面与空间位置的对应关系：

- **顶面**：a，**底面**：e
- **左面**：b，**右面**：d
- **前面**：c，**后面**：f

立方体有 **8 个顶点**，每个顶点由 3 个面交汇。根据相对面关系列出全部组合：

| 顶点位置 | 三面组合 |
|---------|---------|
| 顶-前-左 | a + c + b |
| 顶-前-右 | a + c + d |
| 顶-后-左 | a + f + b |
| 顶-后-右 | a + f + d |
| 底-前-左 | e + c + b |
| 底-前-右 | e + c + d |
| 底-后-左 | e + f + b |
| 底-后-右 | e + f + d |

> 观察规律：任意一个顶点必然包含一对相对面中的**一个**面，因此可归纳为「4 个含顶面 a 的顶点」+「4 个含底面 e 的顶点」。

用 `std::set<int>` 存放 8 个和值，**自动去重并排序**，最后输出集合大小与所有元素。

### 3.1.2 参考代码（C++）

```cpp
#include <iostream>
#include <set>

int main() {
    int a, b, c, d, e, f;
    std::cin >> a >> b >> c >> d >> e >> f;

    std::set<int> sums;

    // 4 个与顶面 a 相邻的顶点
    sums.insert(a + b + c);
    sums.insert(a + c + d);
    sums.insert(a + b + f);
    sums.insert(a + d + f);

    // 4 个与底面 e 相邻的顶点
    sums.insert(e + b + c);
    sums.insert(e + c + d);
    sums.insert(e + b + f);
    sums.insert(e + d + f);

    std::cout << sums.size() << std::endl;
    bool first = true;
    for (int s : sums) {
        if (!first) std::cout << " ";
        std::cout << s;
        first = false;
    }
    std::cout << std::endl;
    return 0;
}
```

## 3.2 题目 2：电脑选择问题

### 3.2.1 解题思路

**贪心策略**：在固定总时间内解最多题，应**优先做耗时最短的题目**。

1. 将 `a` 数组排序，从最小开始累加，直到超过 T，得到 `cnt1`（1 台电脑最多解题数）
2. 将 `b` 数组排序，同样操作，得到 `cnt3`（3 台电脑最多解题数）
3. 比较：
   - 若 `cnt3 > cnt1` → 输出 `cnt3` 和 `3`
   - 否则 → 输出 `cnt1` 和 `1`（数量相等时选电脑少的 1 台）

> 正确性依据：选择做题集合后，为了在 T 内解出最多题，显然应优先选择耗时最少的题（类似"任务调度-最短作业优先"思想）；两套耗时方案互不影响，分别独立贪心后取更优即可。

### 3.2.2 参考代码（C++）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int calc(int T, std::vector<int>& times) {
    std::sort(times.begin(), times.end());
    int cnt = 0;
    long long spent = 0;
    for (int t : times) {
        if (spent + t <= T) {
            spent += t;
            cnt++;
        } else break;
    }
    return cnt;
}

int main() {
    int N, T;
    std::cin >> N >> T;
    std::vector<int> a(N), b(N);
    for (int i = 0; i < N; i++) std::cin >> a[i];
    for (int i = 0; i < N; i++) std::cin >> b[i];

    int cnt1 = calc(T, a);
    int cnt3 = calc(T, b);

    if (cnt3 > cnt1) {
        std::cout << cnt3 << "\n3\n";
    } else {
        std::cout << cnt1 << "\n1\n";
    }
    return 0;
}
```

## 3.3 题目 3：经过所有标记点的最短路

### 3.3.1 解题思路

这是 **TSP（旅行商问题）变种**，结合 **Dijkstra 最短路** + **状态压缩 DP**。

#### 3.3.1.1 步骤 1：预处理关键点之间的最短路

关键点包括：起点 s、所有 k 个标记点。

以每个关键点为源点运行一次 Dijkstra，得到 `dist[i][v]`：从第 i 个关键点到所有点的最短距离。

#### 3.3.1.2 步骤 2：状态压缩 DP

定义 `dp[mask][i]`：已访问标记点集合为 `mask`，当前位于第 i 个标记点的最短距离。

- **初始化**：`dp[1 << i][i] = dist[s][marked[i]]`（从起点直接到第 i 个标记点）
- **状态转移**：从标记点 i 走到未访问的标记点 j：
  `dp[mask | (1 << j)][j] = min(dp[mask | (1 << j)][j], dp[mask][i] + dist[marked[i]][marked[j]])`
- **最终答案**：遍历最后停留的标记点 i，加上到终点 t 的距离：
  `min(dp[(1 << k) - 1][i] + dist[marked[i]][t])`

> 注意边界：任一步 Dijkstra 距离为 INF（不可达）时跳过；最终答案仍为 INF 则输出 -1。复杂度 `O((k+1) · Dijkstra + 2^k · k²)`。

### 3.3.2 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;
const long long INF = 1e18;

vector<pair<int, int>> adj[105];
long long dist[25][105];
long long dp[1 << 21][21];

void dijkstra(int src, int n, int idx) {
    fill(dist[idx], dist[idx] + n + 1, INF);
    dist[idx][src] = 0;
    priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>> pq;
    pq.push({0, src});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[idx][u]) continue;
        for (auto [v, w] : adj[u]) {
            if (dist[idx][u] + w < dist[idx][v]) {
                dist[idx][v] = dist[idx][u] + w;
                pq.push({dist[idx][v], v});
            }
        }
    }
}

int main() {
    int n, m, k, s, t;
    cin >> n >> m >> k >> s >> t;
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
    }

    vector<int> mark(k);
    for (int i = 0; i < k; i++) cin >> mark[i];

    // 关键点 = 所有标记点 + 起点 s
    vector<int> key = mark;
    key.push_back(s);

    for (int i = 0; i < (int)key.size(); i++) {
        dijkstra(key[i], n, i);
    }

    int s_idx = k;  // 起点 s 在 key 中的下标（mark 之后最后一个）

    // 初始化 dp 为 INF
    for (int mask = 0; mask < (1 << k); mask++) {
        for (int i = 0; i < k; i++) dp[mask][i] = INF;
    }

    // 初始化：从起点出发，访问第一个标记点 i
    for (int i = 0; i < k; i++) {
        dp[1 << i][i] = dist[s_idx][mark[i]];
    }

    // 状态压缩 DP 转移
    for (int mask = 1; mask < (1 << k); mask++) {
        for (int i = 0; i < k; i++) {
            if (!(mask & (1 << i))) continue;
            for (int j = 0; j < k; j++) {
                if (mask & (1 << j)) continue;
                int u = mark[i], v = mark[j];
                int u_idx = find(key.begin(), key.end(), u) - key.begin();
                if (dist[u_idx][v] < INF) {
                    dp[mask | (1 << j)][j] = min(dp[mask | (1 << j)][j],
                                                  dp[mask][i] + dist[u_idx][v]);
                }
            }
        }
    }

    // 收尾：所有标记点都访问完，再到终点 t
    long long ans = INF;
    int full = (1 << k) - 1;
    for (int i = 0; i < k; i++) {
        int u = mark[i];
        int u_idx = find(key.begin(), key.end(), u) - key.begin();
        if (dp[full][i] < INF && dist[u_idx][t] < INF) {
            ans = min(ans, dp[full][i] + dist[u_idx][t]);
        }
    }

    cout << (ans == INF ? -1 : ans) << endl;
    return 0;
}
```
