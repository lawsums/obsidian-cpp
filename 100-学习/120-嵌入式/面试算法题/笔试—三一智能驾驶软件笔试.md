# 2 题目

## 2.1 题目 1：苹果二进制平分（maximumBenefit）

### 2.1.1 问题描述

有一筐苹果，每个苹果的重量均为正整数（十进制）。现有甲、乙两人来分这一筐苹果。

甲要求必须按重量平分，否则就不分。甲与常人不同，是在**二进制**下进行运算，同时由于其数学功底较差，所以**不会进位操作**（即按位异或 XOR，不进位相加）。如果你是乙，如何在满足甲的要求的情况下，让自己分得最多的苹果。

> 甲眼中的"平分"：将苹果分成两组，两组的二进制不进位和（异或）相等。

### 2.1.2 输入描述

一个重量数组 `weights`，元素为十进制正整数。

#### 2.1.2.1 示例输入

```
[1,2,3]
```

### 2.1.3 输出描述

- 如果不能按甲的要求平分，则输出 `-1`；
- 如果可以，则输出乙能得到的最多的苹果重量。

函数原型：`int maximumBenefit(int[] weights)`

#### 2.1.3.1 示例输出

**示例 1**

```
输入: [1,2,3]
输出: 5
```

解释：1、2、3 的二进制分别为 01、10、11，按照甲的计算方式，2 和 3 相加（无进位）的结果为 `10 ^ 11 = 01`，与 1 相等，所以乙能分得总重量为 5 的苹果（{2,3}）。

**示例 2**

```
输入: [1,2,4]
输出: -1
```

解释：找不到一种划分方式满足甲的要求。

# 3 答案解析

## 3.1 题目 1：苹果二进制平分（maximumBenefit）

### 3.1.1 解题思路

#### 3.1.1.1 核心结论：总异或为 0 才可分

设全部苹果的异或和为 `X = w₁ ^ w₂ ^ … ^ wₙ`。

把苹果分成两组 A、B，若甲要求"平分"，即 `XOR(A) == XOR(B)`。两边同时异或 `XOR(B)`：

```
XOR(A) ^ XOR(B) == 0
```

而 `XOR(A) ^ XOR(B) == 全部苹果的异或和 X`，因此"能平分"**等价于 `X == 0`**。

> 反过来，当 `X == 0` 时，任意一个子集的异或值都等于其补集的异或值（因为 `XOR(S) ^ XOR(comp) = X = 0`），所以**任何划分都满足甲的要求**。

#### 3.1.1.2 乙的最优策略

当 `X == 0` 时，甲乙平分方式任意，乙要让自己那一组总重量最大：

- 乙拿的组重量 = 总重量 `sum` − 甲拿的组重量；
- 甲、乙两组都必须**非空**；
- 因此只要让**甲拿得最少**即可 → 甲只拿**最轻的那个苹果**。

所以答案 = `sum − min(weights)`。

**结论汇总**：

| 条件 | 输出 |
|------|------|
| `异或和 != 0` | `-1` |
| `异或和 == 0` | `总和 − 最小重量` |
| 存在 `weight <= 0`（数据非法） | `-1` |

#### 3.1.1.3 验证示例

- `[1,2,3]`：异或 = `1^2^3 = 0`，总和 − 最小值 = `6 − 1 = 5`。✓
- `[1,2,4]`：异或 = `1^2^4 = 7 ≠ 0` → `-1`。✓
- `[1,1]`：异或 = `1^1 = 0`，`2 − 1 = 1`（甲 {1}，乙 {1}）。✓

> 复杂度：排序 `O(n log n)`（求最小值其实 `O(n)` 即可），空间 `O(1)`。

### 3.1.2 参考代码（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 函数原型：weights 为每个苹果的重量
int maximumBenefit(vector<int>& weights) {
    if (weights.empty()) return -1;

    long long sum = 0;      // 总重量
    int x = 0;              // 全部重量的异或和
    int mn = INT_MAX;       // 最小重量

    for (int w : weights) {
        if (w <= 0) return -1;   // 数据有效性：重量必须为正整数
        sum += w;
        x ^= w;
        mn = min(mn, w);
    }

    if (x != 0) return -1;            // 异或和不为 0，无法平分
    return (int)(sum - mn);          // 乙拿走除最轻苹果外的全部
}

// 本地测试
int main() {
    int n;
    cin >> n;                        // n 代表输入几个数
    vector<int> weights(n);
    for (int i = 0; i < n; i++) cin >> weights[i];
    cout << maximumBenefit(weights) << endl;
    return 0;
}
```

> 说明：原始提交代码先 `sort` 再取 `arr[0]` 作为最小值，逻辑一致；本版免去排序，`O(n)` 更直接。

### 3.1.3 参考代码（Java）

```java
public class Solution {

    // 函数原型：weights 为每个苹果的重量
    public static int maximumBenefit(int[] weights) {
        if (weights == null || weights.length == 0) return -1;

        long sum = 0;      // 总重量
        int x = 0;         // 全部重量的异或和
        int mn = Integer.MAX_VALUE;  // 最小重量

        for (int w : weights) {
            if (w <= 0) return -1;   // 数据有效性：重量必须为正整数
            sum += w;
            x ^= w;
            mn = Math.min(mn, w);
        }

        if (x != 0) return -1;       // 异或和不为 0，无法平分
        return (int) (sum - mn);     // 乙拿走除最轻苹果外的全部
    }

    public static void main(String[] args) {
        java.util.Scanner sc = new java.util.Scanner(System.in);
        int n = sc.nextInt();
        int[] weights = new int[n];
        for (int i = 0; i < n; i++) weights[i] = sc.nextInt();
        System.out.println(maximumBenefit(weights));
    }
}
```

> 相关：本题即经典的「按位异或平分」问题，LeetCode 上同源题号为 **Divide Array（异或平分思想）**，核心记忆点：**异或和为 0 ⇒ 任意划分都满足；乙拿总重 − 最小值**。
