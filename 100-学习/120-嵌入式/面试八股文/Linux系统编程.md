## 1.1 一、进程与线程

### 1.1.1 Linux 中的进程创建（fork / vfork / clone）的区别

**难度**：简单 ｜ **来源**：腾讯 ｜ **分类**：Linux系统编程
（浏览 163 · 练习 78 · 收藏 7）

#### 1.1.1.1 参考答案

**fork / vfork / clone 的区别：**

1. **fork**：创建子进程，完整拷贝父进程地址空间（COW 优化）
   - 子进程独立，修改互不影响
2. **vfork**：子进程共享父进程地址空间
   - 父进程阻塞直到子进程 `exec` 或 `exit`
   - 现代 Linux 已不太推荐使用
3. **clone**：最灵活，通过标志位控制共享哪些资源
   - `CLONE_VM`：共享地址空间（相当于线程）
   - `CLONE_FILES`：共享文件描述符表
   - `pthread_create` 底层就是调用 clone
4. **关系**：clone 是底层原语，fork 和 pthread 都基于它实现
