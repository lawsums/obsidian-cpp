# 2 笔记

## 2.1 day 04 调度器完善
之前的调度器 resume 实现的是从主协程切换到**子协程**，然后在子协程内执行完毕之后 yield 回来实现单线程执行，但是问题就在于是单线程执行
- 第一，它只能单线程执行。多个 CPU 核心无法参与。
- 第二，它不能接收函数任务，只能接收已经创建好的 Fiber。
- 第三，它没有空闲状态。任务跑完了，调度器也就结束了，后面再投递任务没人处理。
- 第四，它没有停止协议。工程里的线程池必须回答一个问题：什么时候可以安全退出？
我们今天更加细化了这个 scheduler
```cpp
class Scheduler
{
public:
    Scheduler(size_t threads = 1,
              bool use_caller = true,
              const std::string& name="Scheduler");
    virtual ~Scheduler();

    const std::string& getName() const {return m_name;}

public:
    static Scheduler* GetThis();

protected:
    void SetThis();

public:
    template <class FiberOrCb>
    void scheduleLock(FiberOrCb fc, int thread = -1);

    virtual void start();
    virtual void stop();

protected:
    virtual void tickle();
    virtual void run();
    virtual void idle();
    virtual bool stopping();

    bool hasIdleThreads() {return m_idleThreadCount>0;}
};
```
