# 2 二、`main` 函数流程（超级简单）
```cpp
int main(int argc, char **argv) {
    // 1. 设置默认监听地址
    std::string addr = "http://127.0.0.1:8080";

    // 2. 如果用户命令行传参，就用用户的地址
    if (argc > 1)
        addr = argv[1];

    // 3. 启动协程框架，运行 amain 这个服务器主逻辑
    co_main(amain(addr));

    return 0;
}
```

### 2.1.1 `main` 只干 3 件事：
1. **设置监听IP端口**（默认 8080）
2. **读取命令行参数**（可选）
3. **调用 `co_main` 启动协程服务器**
   它会阻塞，直到服务器退出

# 4 四、WebSocket 连接建立后的流程
```cpp
// 打印连接成功
co_await stdio().putline("连接成功"sv);

std::string loginUser;  // 保存当前客户端的昵称
```

### 4.1.1 设置消息回调 `on_message`
```cpp
ws->on_message([&](std::string const &data) -> Task<Expected<>> {
    // 解析 JSON：LoginParams 或 SendParams
    auto params = co_await json_decode<variant<LoginParams, SendParams>>(data);

    std::visit(overloaded{
        // 登录：保存用户名
        [&](LoginParams &&p) {
            loginUser = p.user;
        },
        // 发消息：存入房间，广播给所有人
        [&](SendParams &&p) {
            room.mMessages.push_back({
                .user = loginUser,
                .content = p.content
            });
            room.mMessageUpdated.notify_all();
        }
    }, params);

    co_return {};
});
```

### 4.1.2 设置关闭回调 `on_close`
```cpp
ws->on_close([&]() {
    co_await stdio().putline("正在关闭连接"sv);
});
```

### 4.1.3 设置心跳回调 `on_pong`
```cpp
ws->on_pong([&](auto dt) {
    // 打印延迟
});
```

### 4.1.4 同时运行两个协程（核心设计）
```cpp
co_await when_any_common(
    ws->start(),      // 1. WebSocket 收消息、处理协议
    roomPoller(*ws)   // 2. 监听房间消息，推送给客户端
);
```

- `ws->start()`：处理**客户端 → 服务器**
- `roomPoller(*ws)`：处理**服务器 → 客户端（广播）**

# 5 五、`roomPoller` 广播协程流程
```cpp
Task roomPoller(WebSocket &ws) {
    size_t lastSize = 0;
    while (true) {
        // 等待新消息
        while (room.mMessages.size() <= lastSize)
            co_await room.mMessageUpdated.wait();

        // 把新消息发给当前客户端
        for (size_t i = lastSize; i < room.mMessages.size(); ++i) {
            co_await ws.send(json_encode(RecvParams{
                .message = room.mMessages[i]
            }));
        }
        lastSize = room.mMessages.size();
    }
}
```

作用：**消息广播**
有新消息 → 通知所有客户端 → 推送消息

# 6 六、服务器主循环（永远运行）
```cpp
while (true) {
    // 等待新客户端连接
    if (auto income = co_await listener_accept(listener)) {
        // 抛入协程池，处理 HTTP 请求
        co_spawn(server.handle_http(std::move(*income)));
    }
}
```

# 7 🔥 最终极简总结（必看）
## 7.1 `main`
设置地址 → 启动协程

## 7.2 `amain`
绑定端口 → 创建HTTP服务器 → 注册路由 → **无限循环接受客户端**

## 7.3 每个客户端连接
1. 访问 `/` → 返回聊天室HTML
2. 浏览器建立 WebSocket
3. 服务器升级协议 → 创建 `WebSocket` 对象
4. **同时跑两个协程**
   - 收消息（登录/发消息）
   - 发消息（广播推送）
5. 连接断开 → 清理

---

**main 启动 → amain 监听端口 → 接收客户端 → HTTP 升级为 WebSocket → 双向聊天通信 → 广播消息**
