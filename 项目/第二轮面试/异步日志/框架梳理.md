# 1 流程图
![[Pasted image 20260421222943.png]]

1. [x] 基础定义层（日志级别、日志消息封装）
2. [ ] 核心日志业务层（异步日志器、全局管理器 `Manager`）
3. [ ] 缓冲与异步工作层（内存缓冲 + 后台写线程 `AsyncBuffer/Worker` `ThreadPoll`） 最好自己写一下
4. [ ] 多落地输出层（控制台 / 本地文件 / 滚动切分文件 `LogFlush`）
5. [ ] 远程备份上报层（高危日志上报 + 远端服务持久化）

该日志库由用户产生日志：`mylog::GetLogger("asynclogger")->Info("NewStorageInfo end");`，由异步线程实际写日志到文件。采用双缓冲设计，分为消费者缓冲区以及生产者缓冲区，生产者缓冲区存放用户产生的日志，当生产者缓冲区中有数据的时候，交换生产者与消费者缓冲区，省去了把生产者缓冲区的数据拷贝给消费者缓冲区的开销。缓冲区的大小可自行配置，也可配置缓冲区容量动态增长。
