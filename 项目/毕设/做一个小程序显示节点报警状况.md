### 1.4.2 ESP32 端代码（上传状态，极简修改）

```cpp
// 你已有的WiFi、云平台上传代码...

void loop() {
  float temp = dht.readTemperature(); // 你的传感器
  float smoke = analogRead(A0);
  
  int status = 0; // 0=正常

  // 异常规则（自己改阈值）

    status = 1; // 异常

  // 上传状态到云平台
  cloud.send("node1_status", status); 
  cloud.send("node1_temp", temp);
  
  delay(2000);
}
```
