# 2 完整工作流程（按执行顺序）
## 2.1 ① 程序启动
1. 日志系统所有组件**自动以单例初始化**
   - Logger、AsyncLogger、Formatter 都是单例
2. **线程池初始化**，创建好预设数量的线程
3. AsyncLogger 向线程池 **submit(workLoop)**
   - 线程池中的**一个线程**被占用，专门执行日志后台循环
   - 该线程**永远执行 workLoop**，不再接收其他任务

---

## 2.2 ② 用户打日志（业务线程）
1. 调用宏 `LOG_INFO(...)`
2. 进入 **Logger::log()**
   - 用 `va_list` / `vsnprintf` 格式化可变参数
   - 获取文件名、行号、当前时间
   - 组装成 **LogMsg** 结构体
3. 调用 **AsyncLogger::push(msg)**
   - 将日志**放入安全队列**
   - 入队完成后**立刻返回**，不阻塞业务线程

---

## 2.3 ③ 异步后台线程（核心工作）
后台线程 **永远循环执行 workLoop**：
1. 从 **SafeQueue\<LogMsg>** 中取一条日志
2. 用 **Formatter** 格式化字符串
3. 分发给所有 **Appender**（控制台、文件、远程）
4. 队列为空时**休眠 10ms**，不浪费 CPU
5. 直到收到停止信号，才退出循环

---

## 2.4 ④ 输出落地（Appender）
1. **ConsoleAppender**：输出到屏幕
2. **FileAppender**：写入文件，定时刷盘
3. **RemoteAppender**：上报服务器
4. 每个 Appender 都实现 **flush()**
   - 退出前统一调用，确保日志不丢失

---

## 2.5 ⑤ 程序退出
1. AsyncLogger::stop() 被调用
2. 后台线程退出 workLoop
3. 调用 **flushAll()** 让所有 Appender 强制刷盘
4. 线程池关闭，所有线程退出

 ① `std::thread`
- **作用**：创建操作系统线程，构成线程池的执行单元。

 ③ `std::packaged_task`
- **作用**：包装异步任务，将任务的执行与结果分离。
- **关键点**：执行后结果自动存入关联的 `future`。
 ④ `std::future`
- **作用**：获取异步任务的返回值 / 异常。

 ⑤ `std::bind` + 完美转发 `std::forward`

- **关键点**：实现通用、通用任意函数、任意参数。
 ⑥ `std::result_of` / `decltype`
- **作用**：推导函数调用的返回值类型。
- **关键点**：让 `packaged_task` 和 `future` 自动适配返回类型。
 ⑦ `std::mutex` + `std::condition_variable`
- **作用**：线程同步。
