## 0.1 ssh 连接
1. 环境准备与基础配置
在开始之前，确保你的 Ubuntu 系统已就绪。如果是全新安装的系统，建议先执行系统更新：

``` bash
sudo apt update && sudo apt upgrade -y
```
### 0.1.1 安装 OpenSSH 服务端
现代 Ubuntu 系统通常预装了 SSH 客户端，但服务端需要手动安装。以下命令会安装最新版本的 openssh-server：
``` bash
sudo apt install openssh-server -y
```

### 0.2.1 安装 gcc 和 make
#### 0.2.1.1 先禁用光盘源（解决报错）
执行这条命令：
```bash
sudo sed -i '/cdrom/d' /etc/apt/sources.list
```
#### 0.2.1.2 再安装 gcc + make（正确命令）
```bash
sudo apt update && sudo apt install -y gcc make
```
