# 2 笔记
## 2.1 S1-Agent第一次运行.md
用户的 goal 需要被传给 LLM，但不是简单地发一次消息、等一次回复。Agent 要的是多轮对话：LLM 可能说"帮我读一下这个文件"，我们执行，把结果告诉 LLM，LLM 继续思考……这个过程可能反复好几轮，直到 LLM 觉得任务完成了。
所以需要
- 维护对话历史
- 驱动循环的控制器
- 调用 LLM 的组件
- 工具系统
- 观测管道

cmd_run 流程为：
- 创建一个 StdoutPrinter 接管输出打印
- 异步执行任务 asyncio.run()
- 如果用户输入 Ctrl+C 就退出

今天用到了哪些类？
- AgentRunner：组件组装中心，负责准备所有依赖
- EventBus：广播中心，负责通知运行所有的订阅函数
- [ ] ExecutionContext：工作记忆
- [ ] AgentLoop：核心循环
- [ ] AnthropicProvider——和 LLM 对话
- [ ] 工具系统——执行 LLM 的请求
- [ ] 回到 AgentRunner：收尾工作
- [ ] StdoutPrinter：终端的实时输出
