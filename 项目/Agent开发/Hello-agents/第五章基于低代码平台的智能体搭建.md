  本地部署与云端部署对比

1. 数据安全
本地部署在数据安全上更进一层，因为数据都保存在本地。

2. 成本要求
本地部署成本要求较高。如果一个局域网内所有的机器都使用 Dify 去部署的话，那么所有机器的基础性能都需要在 Dify 的推荐配置以上。
云端部署成本相对较低。因为只需要能登录网页，然后调用云端的工作流就可以。

3. 性能方面
本地部署的机器性能一般难以企及云端服务器的性能，但是没有网络延迟。
云端部署机器性能较高，但由于在工作流完成之后还需要有个数据传输的过程，所以是有延迟的。

4. 维护难度
本地部署的维护较为麻烦。因为在一个局域网内维护所有本地部署，相当于每台机器都要去操作。
云端部署维护更简单。修改一个云端的工作流，同步到平台上，大家就是同步更新的。
