## 1.1 第01章 单片机/RTOS架构的概念

### 1.1.1 🟢 实践1-1：裸机程序改写为RTOS程序
**任务描述：** 以下是一段裸机轮询程序，完成喂饭和回信息两件事。请将其改写为FreeRTOS双任务版本。

```c
// 裸机程序
void main(void)
{
    while (1)
    {
        feed_child();   // 喂一口饭
        reply_message(); // 回一个信息
    }
}
```

**要求：**
1. 创建两个任务：`vTaskFeed` 和 `vTaskReply`
2. 在 `main` 中创建任务并启动调度器
3. 每个任务内使用 `vTaskDelay` 模拟耗时操作
4. 通过串口打印观察两个任务"同时"运行的效果



这里我用 x task create 应该就能实现这个功能，然后就是创建两个函数，一个是 feed children，一个是 reply message，里面各自打印这个 feed children 和 reply message 就可以了,但是这里是不是又引入了一个新的问题？就是你的 feed children 和 reply message 可能会互相穿插，不能完整的打印出来。

但是这样做的话，会引入一个新的竞态问题，就是他们俩打印会互相穿插。所以这个时候就要用到三种方式之一来解决这个问题：
1. 使用互斥量
2. 挂起任务调度器
3. 关中断
