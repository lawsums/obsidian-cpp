动态创建任务
通过 executeTask 动态创建任务，通过 executeStatic 静态创建任务。静态创建任务需要额外传入栈以及任务本身的缓冲区。
不是这个，它 create static 需要定义一个宏，也就是 static allocation，将其置为 1 来启用这个函数。然后启用完这个函数之后，还需要准备另一步，就是手动写一个函数来处理空闲任务，要求提供空闲任务的缓冲区、空闲任务的栈，还有空闲任务的任务栈大小。

进一步实验
- 优先级实验
- 删除任务
	使用 xTaskDelete 函数进行删除。 
- 使用同一个任务函数创建多个任务
	通过一个可以传参的函数，将指定参数传入。由于每个函数的栈不同、参数也不同，因此生成的任务即为该任务。
- 栈大小实验
	故意指定一个大小超出 400 字节的局部变量，此时运行程序会导致程序崩溃，导致结果无法预料。

任务状态
![[Pasted image 20260714163957.png]]
任务包括四个状态：
1. 准备状态
任务刚进来时处于准备状态，即时刻准备着运行。如果当前没有优先级更高的任务，且前面的任务都已执行完毕，则进入运行状态。

2. 运行状态
正在执行任务的状态。

3. 休眠状态 (Suspended)
表示什么也不做的状态。任何状态都可以进入休眠状态：
- 从运行状态进入休眠状态，属于主动休息；
- 从其他状态进入休眠状态，是由运行中的任务让它们去休息。

4. 阻塞状态
在等待某些任务时，将运行权交给其他任务的状态。为了避免因盲目等待而耽误整体运行，因此让出执行权。主要适用于执行异步任务，或等待 read/write 等操作时。
