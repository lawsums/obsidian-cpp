# Embedded Exam Organizer（嵌入式面试算法题整理）

专门用于把嵌入式方向的笔试/面试算法题归档进 `100-学习/120-嵌入式/面试算法题/`，并联动在 Obsidian Tasks 文件创建明天的复习任务。

## 目标位置与命名

- **目录**：`100-学习/120-嵌入式/面试算法题/`
- **文件命名**：`笔试—<公司/考试名>嵌入式软件开发笔试.md`
  - 例：`笔试—科大讯飞嵌入式软件开发笔试.md`
  - 若题目来自非公司（如专项、八股合集），用清晰可检索的名字，如 `笔试—<主题>.md`
- 若同名文件已存在：先 `Read` 全文，将新题目**追加/合并**进现有结构，不覆盖已有题目。

## 笔记结构约定（题目在前，答案解析在后）

```
# 1 <文件名标题>
**题型**：N 道编程题

# 2 题目
## 2.1 题目 1：<题名>
### 2.1.1 问题描述
### 2.1.2 输入描述
#### 2.1.2.1 示例输入
### 2.1.3 输出描述
#### 2.1.3.1 示例输出
## 2.2 题目 2：<题名>
...

# 3 答案解析
## 3.1 题目 1：<题名>
### 3.1.1 解题思路
### 3.1.2 参考代码（C++）
## 3.2 题目 2：<题名>
...
```

- 题干完整保留：问题描述 / 输入描述 / 输出描述 / 示例输入 / 示例输出。
- 解题思路 + 参考代码统一收在末尾"答案解析"章节，按题号一一对应。
- 保持编号风格（`# 1`、`## 2.1`、`### 3.1.1`），新题目按顺序续号。
- 顶部可加导航 callout：跳转"题目"与"答案解析"。

## 创建明天复习任务

调用 / 遵循 **create-obsidian-task** skill（格式与写入流程以该 skill 为准），参数：

- **描述**：`完成 [[笔记名]] N 道题目`
- **计划日期**：明天（默认；只写 `⏳`，不写 `📅`）
- **优先级**：`⏫`
- **标签**：`#study` 打底，追加 `#algorithm`、`#embedded` 等

写入位置：`Templates/Tasks.md` 的 `# 1 Inbox` 第一行。

## 执行步骤

1. **确定笔记路径**：按上面命名规则生成 `100-学习/120-嵌入式/面试算法题/笔试—<公司>嵌入式软件开发笔试.md`。优先用用户指定路径或 `<linked_note>`。
2. **整理笔记**：写入"题目在前、答案解析在后"的结构，代码/示例完整。
3. **创建任务**：在 `Templates/Tasks.md` 的 `# 1 Inbox` 顶部插入任务行（只写 `⏳`）。
4. **校验并汇报**：确认任务行日期正确、wikilink 指向存在的笔记；用 wikilink 汇报新建/修改的文件。

## 示例

用户："把科大讯飞这 3 道题整理到面试算法题目录，明天复习。"

- 笔记：`100-学习/120-嵌入式/面试算法题/笔试—科大讯飞嵌入式软件开发笔试.md`
- Tasks：`# 1 Inbox` 顶部新增
  `- [ ] 完成 [[笔试—科大讯飞嵌入式软件开发笔试]] 3 道编程题 #study #algorithm #embedded ⏫ ➕ 2026-08-30 ⏳ 2026-08-31`

## 注意
- 只动 `Templates/Tasks.md` 的 Inbox 区域，不改 `not done` 查询块与其他任务行。
- 若用户指定了具体日期（"下周一""某日"），以用户指定为准；否则默认明天。
