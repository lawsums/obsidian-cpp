# 代码模板整理（Code Template Organizer）

把用户丢来的代码收进模板库 `100-学习/110-计算机/代码模版/`，让每个板子「找得到、分类对、能直接抄」。

> 只负责**通用可复用模板**的入库。若是某道题的题解/笔记，走 `leetcode-organizer`，不要硬收。

## 目标位置

- 模板库根目录：`100-学习/110-计算机/代码模版/`
- 分类用两位编号子文件夹，当前已有：
  - `01-排序/`、`02-数据结构/`、`03-字符串/`、`04-数学/`、`05-多语言对照/`
- 索引：`代码模版/00-索引.md`（每个板子都在这里有登记行）
- 库内写法统一用 **「模版」**（不是「模板」），路径用相对路径、不要前导 `/`

## 分类速查表（先按这张表对号入座）

| 子文件夹 | 收纳什么 | 典型例子 |
| --- | --- | --- |
| `01-排序/` | 各类排序算法 | 归并/快排/堆排/预排序（按值排下标） |
| `02-数据结构/` | 基础数据结构板子 | 堆、队列/循环队列、栈、链表、树、并查集… |
| `03-字符串/` | 字符串算法 | KMP、Trie、Manacher、字符串哈希… |
| `04-数学/` | 数论/组合/数学结论 | 费马小定理、容斥原理、快速幂、素数筛… |
| `05-多语言对照/` | 跨语言速查对照表 | 容器对比、库函数对比 |

表格只用于引导；**以库内实际子文件夹为准**。代码属于多语言对照表性质的（如「C++/Python/Go 怎么找子串」），放 `05-多语言对照/`。

## 没有合适分类 → 新建分类文件夹

1. 列出 `代码模版/` 现有子文件夹，取最大的两位编号前缀（如 `05`）。
2. 新建 `NN-<中文短名>/`，`NN = 最大前缀 + 1`（如 `06-图论/`），名称用能概括主题的短中文词（图论、动态规划、树、位运算…）。
3. 新建分类后，必须同步在 `00-索引.md` 追加一节 `## NN · 分类名` 并登记该板子。

## 文件层面：三选一

| 情况 | 做法 |
| --- | --- |
| 这个主题库里还没有板子文件 | **新建** `<主题>板子.md`（参考表：队列→`队列板子`、图→`图论板子`） |
| 同主题已有板子文件 | **追加一个 tab**，不要另起文件（如给 `排序板子` 加「计数排序」tab） |
| 内容是语言对照/速查，或纯理论知识 | 用主题名建文件（如 `容器对比.md`）；纯理论放对应分类文件夹独立成篇 |

## 笔记格式约定

新建/改写板子文件统一用这个骨架：

```markdown
# <主题>板子

> <一句话：这板子能干什么 / 适用场景 / 复杂度>

```` tab
tab: <版本或语言说明>
``` <lang>
<用户代码原样>
```
````
```

- 代码块语言标签按实际写：`cpp` / `c` / `python` / `go` / `sql` …
- **代码原样保留，不删改逻辑**；最多加注释。用户写的来源注释（作者/链接）要保留。
- 同一主题的多种语言/多种写法 = 多个 `tab:`；**不同主题不要塞进同一个文件**。
- 大段原理、避坑讲解可以放在代码块下方的普通章节，但**不要把讲解塞进代码块**。
- 若用户只贴了一段非整块代码（比如一个函数），把它补成能直接复制使用的完整形态，代码内部逻辑仍不动。

## 索引同步（必做）

- 在 `00-索引.md` 对应分类小节下加一行：

  `- [[<NN-分类>/<文件名>|<显示名>]] — 一句话说明`

- 若新建了分类文件夹，同时加新小节 `## NN · 分类名`。
- 若只是给已有板子加了 tab，把该行「一句话说明」顺带补全即可。

## 执行步骤

1. **读现状**：`Read` 模板库 `00-索引.md`，并列出 `代码模版/` 下的子文件夹与已有板子文件。
2. **判断分类**：按速查表把代码归类；拿不准时按代码主体选一个，并在汇报里说明理由。
3. **三选一**：新建文件 / 追加 tab / 建对照或理论文件（见上表）。
4. **写文件**：遵循「笔记格式约定」，路径为 `100-学习/110-计算机/代码模版/<NN-分类>/<文件名>.md`。
5. **更新索引**：在 `00-索引.md` 登记；新建分类则追加小节。
6. **校验**：代码围栏（tab 内外）闭合、wikilink 指向存在的文件、目录编号连续、没有把旧文件的引用写断。
7. **汇报**：用 wikilink（如 `[[02-数据结构/队列板子]]`）告知「放进了哪个分类 / 新建了哪个分类 / 索引是否更新」。

## 示例

用户贴入一段 C 写的**循环队列**（`QueueInit / QueueEnqueue / QueueDequeue / QueueIsEmpty` …，数组 + 环形复用，无 `main`）：

1. 分类 → 队列属于基础数据结构，进 `02-数据结构/`。
2. 库里没有队列板子 → 新建 `02-数据结构/队列板子.md`，用一个 `tab: 循环队列 · C`，代码原样放入。
3. 索引 → 在 `## 02 · 数据结构` 下加：`- [[02-数据结构/队列板子|队列板子]] — 循环队列（数组实现，C）`。

## 注意

- 本 skill 只整理模板，不建任务、不动 `.obsidian/`、不改 `Leetcode/` 等其他笔记。
- 若代码明显是**某道题的特化解**而不是通用板子，提醒用户应走 `leetcode-organizer`，不要误收进模板库。
- 编辑时若 clangd 等报头文件找不到，属于本机环境问题，与入库内容无关，忽略即可。
