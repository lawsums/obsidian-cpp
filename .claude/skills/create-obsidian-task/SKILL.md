# Create Obsidian Task（Obsidian 任务生成器）

把一条任务按 **Obsidian Tasks 插件**格式写入 `Templates/Tasks.md` 的 `# 1 Inbox` 列表。这是一个通用任务 skill，可独立使用，也可被其他 skill（如 exam-organizer）委托调用。

## 目标文件与格式

- **文件**：`Templates/Tasks.md`
- **插入位置**：`# 1 Inbox` 下的**第一行**（即 `# 1 Inbox` 标题正下方）
- **不触碰**：文件顶部的 ```tasks``` 查询块、其他任务行

**格式模板**：

```
- [ ] <任务描述> <标签...> <优先级> ➕ YYYY-MM-DD ⏳ YYYY-MM-DD
```

- `- [ ]` 未完成勾选框
- 任务描述：可含 `[[笔记名]]` wikilink 关联笔记，或外部链接 `[文字](url)`
- 标签：`#tag`（可多个）
- 优先级：`🔺`=最高，`⏫`=高，`🔼`=中，`🔽`=低
- `➕ YYYY-MM-DD`：创建日期（今天）
- `⏳ YYYY-MM-DD`：计划/提醒日期（scheduled）
- **默认只写 `⏳`，不写 `📅`（due）**。除非用户明确要求截止日期，否则绝不写 `📅`。
- 不手写 `✅`（完成日期）和块 ID `^task-...`（Tasks 插件会自动生成）。

## 参数解析

从用户请求中解析（有缺省默认值）：

| 参数 | 默认值 | 说明 |
|---|---|---|
| **描述** | 必填 | 用户要做的任务内容 |
| **日期** | 明天 | 今天 `➕`；`⏳` 默认=今天+1 天。用户给相对词（明天/下周一/下周X）或具体日期时按用户指定 |
| **优先级** | `⏫` | 用户说"最高"→`🔺`；"高/重要"→`⏫`；"中"→`🔼`；"低"→`🔽` |
| **标签** | 无（或按上下文给 `#task`） | 用户没给时尽量不加；给 `#study`/`#algorithm` 等则用用户给的 |
| **关联笔记** | 无 | 若有对应笔记用 `[[笔记名]]` 链接 |

## 执行步骤

1. **解析参数**：确定描述、日期、优先级、标签、关联链接。
2. **计算日期**：今天 = 当前日期（如 `2026-08-30`）；明天 = 今天 +1 天（`2026-08-31`）。
3. **拼装任务行**：按上面模板生成一行文本。
4. **写入文件**：用 Edit 在 `Templates/Tasks.md` 的 `# 1 Inbox` 标题后插入任务行。
5. **校验**：确认行格式正确、日期正确、无 `📅`（除非用户要求）、wikilink 指向的笔记存在。
6. **汇报**：用 wikilink 告知用户任务已添加，并给出完整任务行。

## 示例

用户："提醒我明天做科大讯飞那 3 道题。"

- 描述：`完成 [[笔试—科大讯飞嵌入式软件开发笔试]] 3 道编程题`
- 标签：`#study #algorithm #embedded`
- 日期：`➕ 2026-08-30 ⏳ 2026-08-31`，优先级 `⏫`

生成：
```
- [ ] 完成 [[笔试—科大讯飞嵌入式软件开发笔试]] 3 道编程题 #study #algorithm #embedded ⏫ ➕ 2026-08-30 ⏳ 2026-08-31
```

用户："下周一安排体检，中优先级。"

- 描述：`体检`，优先级 `🔼`，`⏳` = 下周一日期，标签可留空
```
- [ ] 体检 🔼 ➕ 2026-08-30 ⏳ 2026-08-31
```

## 注意
- 同一任务已存在（同描述+同日期）时不重复插入，改为提示用户。
- 若用户明确要求 `📅` 截止日期才添加，否则一律只用 `⏳`。
- 其他 skill 需要建任务时，可直接在指令中"遵循 create-obsidian-task 的格式与流程"或调用本 skill。
