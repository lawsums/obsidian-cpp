## 标准答案
### mutable 关键字核心功能总结
`mutable` 核心作用是**移除特定场景下的 const 只读限制**，允许修改原本被 const 限定的变量/数据，且两种核心用途均围绕这一核心，分别适用于**类的非静态成员变量**和**lambda 表达式**场景，具体功能如下：
1. **修饰类的非静态成员变量**：突破 `const` 成员函数的只读限制，让该变量能在 `const` 成员函数中被修改（仅修改该变量，不影响对象其他成员的 const 只读特性，多用于线程安全、惰性求值等内部实现细节，不破坏对象对外的 const 语义）。
2. **修饰 lambda 表达式**：移除 lambda 自身函数调用运算符的 `const` 限定，允许在 lambda 函数体内**修改按值捕获**的外部变量副本（按引用捕获无需 mutable，可直接修改原变量；mutable 仅作用于按值捕获的副本，不影响原变量）。
