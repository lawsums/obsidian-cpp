
DECK: 面试题

## 0.1 标准答案
const 是运行时只读约束，仅保证变量不可修改但不要求编译期确定值；constexpr 是编译期常量约束，强制表达式在编译阶段求值，可看作 const 的“编译期强化版”，核心解决编译期常量计算与优化的问题，兼具 const 的只读特性且约束更强。

## 0.3 应用场景
**场景**：开发高性能的数学工具库时，定义圆周率 π 常量
- 不用 constexpr/仅用 const：
  ```cpp
  // 运行时初始化，每次使用都需读取内存，无法编译期优化
  const double PI = 3.1415926535; 
  // 甚至若通过函数赋值，连“真常量”都不是，无法用于数组长度等编译期场景
  const double PI = calc_pi(); 
  ```
- 用 constexpr：
  ```cpp
  // 编译期确定值，直接嵌入指令，运行时无内存读取开销，且强制保证值不可变
  constexpr double PI = 3.1415926535; 
  // 编译期计算，结果直接固化，可用于数组长度、模板参数等编译期上下文
  constexpr double calc_pi() { return 4 * atan(1.0); }
  constexpr double PI = calc_pi(); 
  ```
- 核心好处：编译期完成常量计算，减少运行时开销，同时强制约束常量的“真常量”属性，避免因运行时赋值导致的编译期场景（如数组长度、模板参数）使用失败，提升代码性能与安全性。
