## 哈希表的原理是什么


## 标准答案
### 哈希表
哈希表是一种通过关键字 (key) 和值 (value) 进行访问的数据结构
既然要访问, 那肯定需要知道访问的内容存放在哪里, 所以这就需要通过一种映射关系将访问元素的关键字和元素的存储地址关联起来, 而这种映射关系就是通过哈希函数来实现的
### 哈希函数
哈希函数就是 k-v 之间的关系, 通过哈希函数计算出元素的存储位置

### 哈希函数构造方法详解
哈希函数的核心目标是：**把任意长度的输入（Key）映射到固定长度的输出（存储位置）**，且要尽可能减少冲突（不同Key映射到同一位置）。下面逐一讲解这5种经典构造方法：

#### 1. 数字分析法
**核心原理**：
分析一组关键字的数字特征（比如各位数字的分布规律），选择分布最均匀、随机性最强的几位数字作为哈希地址。
- 适用场景：关键字的位数较多，且每一位数字的分布有明显规律（比如手机号、身份证号、银行卡号等固定格式的数字）。

**示例**：
假设有一批手机号关键字：
13812345678、13898765432、13912349876、13998761234
分析发现：前3位（138/139）重复度高，最后4位分布最均匀，因此取最后4位作为哈希地址：
- 1381234**5678** → 哈希地址：5678
- 1389876**5432** → 哈希地址：5432

#### 2. 平方取中法
**核心原理**：
1. 将关键字平方，扩大数字的差异；
2. 取平方结果的中间几位作为哈希地址（中间位受所有位的影响，随机性更强）。
- 适用场景：关键字的位数较短，且各位数字分布无明显规律（比如短数字、随机编号）。

**示例**：
关键字：1234
1. 平方：1234 × 1234 = 1522756
2. 取中间3位：227 → 哈希地址：227

**代码示例**：
```python
def mid_square_hash(key, length=3):
    """
    平方取中法构造哈希函数
    :param key: 关键字（整数）
    :param length: 要取的中间位数
    :return: 哈希地址
    """
    if not isinstance(key, int) or key < 0:
        raise ValueError("关键字必须是非负整数")
    
    square = key * key  # 平方
    square_str = str(square)  # 转为字符串方便取中间位
    str_len = len(square_str)
    
    # 计算中间位的起始位置
    start = (str_len - length) // 2
    # 处理长度不足的情况（补0）
    if start < 0:
        square_str = square_str.zfill(length)
        start = 0
    
    # 取中间length位并转为整数
    hash_addr = int(square_str[start:start+length])
    return hash_addr

# 测试
print(mid_square_hash(1234))  # 输出：227
print(mid_square_hash(567))   # 567²=321489 → 取中间3位：214，输出：214
```

#### 3. 分段叠加法（折叠法）
**核心原理**：
1. 将关键字按固定长度分段（比如每3位一段）；
2. 将各段数字相加（叠加），得到的结果作为哈希地址（若结果过长，可取模或截断）。
- 适用场景：关键字位数很长，且各位数字分布均匀（比如长编号、身份证号）。

**示例**：
关键字：1234567890
1. 分段（每3位一段）：123、456、789、0（不足补0则为000）；
2. 叠加：123 + 456 = 579 → 579 + 789 = 1368 → 1368 + 0 = 1368；
3. 若哈希表长度为1000，取后3位：368 → 哈希地址：368。

**代码示例**：
```python
def segment_hash(key, segment_len=3, table_size=1000):
    """
    分段叠加法构造哈希函数
    :param key: 关键字（整数/字符串）
    :param segment_len: 每段的长度
    :param table_size: 哈希表大小（用于取模）
    :return: 哈希地址
    """
    key_str = str(key).zfill(len(str(key)) + (segment_len - len(str(key)) % segment_len) % segment_len)
    segments = []
    # 分段
    for i in range(0, len(key_str), segment_len):
        segment = key_str[i:i+segment_len]
        segments.append(int(segment))
    # 叠加
    total = sum(segments)
    # 取模得到哈希地址（避免超出哈希表范围）
    hash_addr = total % table_size
    return hash_addr

# 测试
print(segment_hash(1234567890))  # 输出：368
print(segment_hash(123456789, 2)) # 分段：12、34、56、78、9 → 12+34+56+78+9=189 → 189%1000=189，输出：189
```

#### 4. 除留余数法
**核心原理**：
将关键字除以一个**不大于哈希表长度**的质数 `p`，取余数作为哈希地址，公式：
$hash(key) = key \mod p$
- 核心要点：`p` 必须是质数，且尽可能接近哈希表长度（能最大程度减少冲突）；
- 适用场景：最常用的方法，几乎适用于所有数字型关键字。

**示例**：
哈希表长度为101（质数），关键字为123456：
123456 ÷ 101 = 1222 余 34 → 哈希地址：34。

**代码示例**：
```python
def remainder_hash(key, p=101):
    """
    除留余数法构造哈希函数
    :param key: 关键字（整数）
    :param p: 质数（≤哈希表长度）
    :return: 哈希地址
    """
    if p <= 1 or not is_prime(p):
        raise ValueError("p必须是大于1的质数")
    return key % p

# 辅助函数：判断是否为质数
def is_prime(n):
    if n <= 1:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    for i in range(3, int(n**0.5) + 1, 2):
        if n % i == 0:
            return False
    return True

# 测试
print(remainder_hash(123456, 101))  # 输出：34
print(remainder_hash(789, 13))      # 789%13=789-13×60=789-780=9，输出：9
```

#### 5. 伪随机数法
**核心原理**：
使用伪随机数生成器，将关键字作为随机种子，生成一个0到哈希表长度-1之间的数作为哈希地址，公式：
$hash(key) = random(key) \mod table\_size$
- 适用场景：关键字分布极不均匀，或需要动态调整哈希地址的场景（比如负载均衡、分布式存储）。

**代码示例**：
```python
import random

def random_hash(key, table_size=1000):
    """
    伪随机数法构造哈希函数
    :param key: 关键字（任意可哈希类型）
    :param table_size: 哈希表大小
    :return: 哈希地址
    """
    # 将关键字转为固定的随机种子
    random.seed(hash(key))
    # 生成0到table_size-1之间的随机整数
    hash_addr = random.randint(0, table_size - 1)
    return hash_addr

# 测试（同一关键字的结果固定）
print(random_hash("user123", 100))  # 输出固定值，比如：45
print(random_hash(7890, 100))       # 输出固定值，比如：78
```

---

### 总结
1. **数字分析法**：适合长固定格式数字，选分布均匀的位；
2. **平方取中法**：适合短数字，利用平方放大差异，取中间位；
3. **分段叠加法**：适合超长数字，分段叠加降低长度；
4. **除留余数法**：最通用，核心是选质数 `p`，冲突最少；
5. **伪随机数法**：适合分布不均的关键字，结果随机性强。

实际开发中，**除留余数法**是最常用的基础方法，常与其他方法结合使用（比如先平方取中，再除留余数），以进一步减少哈希冲突。
