DECK: 面试题

## 怎么定义一个只能在堆上或栈上创建的对象


## 标准答案
### 只能堆上创建
1. 私有化==构造函数==和==析构函数==, 提供 static的create 和 destory 接口做替代
2. 禁用==拷贝==构造和==拷贝== operator 重载
3. 可选: 优化 create 中创建对象用智能指针做管理
``` cpp
return unique_ptr<HeapOnly, void(*)(HeapOnly*)>
       ( new HeapOnly(), 
         [](HeapOnly* p) { p->destroy(); } 
);
```

### 只能栈上创建
1. 禁用 new 和 delete 调用

## TODO (面试官可能会怎么问)
- 私有构造为什么外部不能用`make_unique`？原理是什么？
  因为 `make_unique` 是全局函数, 不能调 `private` 函数
- 只禁`new`不禁`new[]`会怎么样？
  数组没特化, 会漏掉数组的情况
- 栈专属类能不能用 placement new？怎么规避？
  同时**私有化构造函数**和**禁用 new**, 添加栈类型 create
```scss
// 只暴露安全的、栈上创建接口
static StackOnly create(){
	// 类内部：有权调用私有构造，完美合法
	return StackOnly(); 
}
```
- 堆专属类如果忘记调用 destroy 会造成什么问题？
  内存没释放

## 使用场景 (举例)
- 仅堆创建：单例类、数据库 / 网络连接管理、大型内核资源类，手动管控生命周期，防止栈析构意外释放；
- 仅栈创建：RAII 锁守卫、智能资源清理器、轻量局部工具类，依托栈自动析构回收资源，无堆开销、防内存泄漏。
