- [ ] 尝试自己写成 tasks 形式就可以识别了

完全可以！而且 Obsidian 的「日记模板 + Tasks 插件」是很多人日常管理待办的经典组合，我帮你把适配方法讲得明明白白👇

---

## 0.1 一、核心问题拆解
你现在的痛点是：
- 日记模板里的任务是普通文本，不是 Tasks 插件能识别的格式（`- [ ] 任务内容 📅 日期`）
- 导致 Tasks 插件没法自动抓取、筛选、排序这些任务

解决思路有两种，我按「推荐顺序」给你讲清楚：

---

## 0.2 ✅ 方案1：直接在模板里写好 Tasks 兼容格式（最简单，零成本）
直接修改你的日记模板，把任务写成 Tasks 能识别的格式，这样每天新建日记时，任务就自动带好了，插件直接就能识别。

### 0.2.1 模板里的任务写法示例
在你的日记模板里，直接这样写任务：
```markdown
## 今日待办
- [ ] 喝水 2L 📅 {{date:YYYY-MM-DD}} ⏫
- [ ] 拉伸运动 10 分钟 📅 {{date:YYYY-MM-DD}}
- [ ] 复盘今日待办 📅 {{date:YYYY-MM-DD}}
```

### 0.2.2 配套的 Tasks 查询代码
放在模板里，自动显示今天的所有待办（包括模板里生成的任务）：
```tasks
not done
due today
limit 100
sort by priority
sort by description
```

### 0.2.3 优点
- 完全兼容，不会报错
- 任务和日记绑定，在哪篇日记写的任务，就会在对应日期的列表里显示
- 优先级、日期自动生效，排序正常

---

## 0.3 ✅ 方案2：用「Tasks 模板」自动插入（更灵活，适合固定每日任务）
如果你的每日任务是固定的（比如喝水、运动、复盘），可以用 Obsidian 的「模板插件」+ Tasks 插件，实现：
- 每天新建日记时，自动插入固定的 Tasks 格式任务
- 不需要手动改每一条，模板里写一次，每天自动生效

### 0.3.1 操作步骤
1.  打开你的「日记模板文件」
2.  在你想放任务的位置，插入 Tasks 格式的固定任务，用 `{{date}}` 变量自动填充日期：
    ```markdown
    ## 每日固定待办
    - [ ] 早起喝水 📅 {{date:YYYY-MM-DD}}
    - [ ] 晚间拉伸 📅 {{date:YYYY-MM-DD}}
    - [ ] 睡前复盘 📅 {{date:YYYY-MM-DD}}
    ```
3.  保存模板，之后每天新建日记时，这些任务会自动生成带日期的格式，Tasks 插件直接就能识别。

### 0.3.2 补充：如果你的模板插件不支持变量
Obsidian 自带的「核心模板插件」或 Templater 插件，都支持 `{{date}}` 变量，只要在设置里开启即可。

---

## 0.4 ✅ 方案3：如果不想改任务格式，用「文本转 Tasks」的小技巧（进阶）
如果你不想改模板里的普通文本任务，也可以用一个小技巧，让它们变成可识别的 Tasks 任务：
1.  在模板里先写普通文本任务：
    ```markdown
    今日待办：
    - 喝水 2L
    - 拉伸 10 分钟
    ```
2.  再在模板底部加一个隐藏的 Tasks 代码块，用 Tasks 的「正则筛选」功能，把这些文本转成任务：
    ```tasks
    not done
    path includes {{query.file.path}}
    description includes 喝水 2L
    OR description includes 拉伸 10 分钟
    due today
    limit 100
    ```
⚠️ 这个方法比较麻烦，不如直接写兼容格式省事，更推荐前两种方案。

---

## 0.5 💡 关键避坑：模板里的变量 vs Tasks 查询里的变量
- **模板里的 `{{date}}` 是安全的**：它是 Obsidian 模板插件的变量，会在新建日记时直接替换成日期文本，和 Tasks 插件无关，不会触发之前的报错。
- **Tasks 查询里的 `{{date}}` 会报错**：因为 Tasks 默认禁用了 JavaScript 占位符，所以查询里不能用这个变量，但模板里可以用。

## 0.6 📝 给你一份可以直接复制的「日记模板」示例
你可以直接用这个模板，里面包含了固定任务和 Tasks 查询：
```markdown
# {{date:YYYY年MM月DD日}} {{date:dddd}}

## 📋 今日固定待办
- [ ] 早起喝一杯温水 📅 {{date:YYYY-MM-DD}}
- [ ] 完成今日学习计划 📅 {{date:YYYY-MM-DD}} ⏫
- [ ] 运动 30 分钟 📅 {{date:YYYY-MM-DD}}
- [ ] 睡前复盘今日 📅 {{date:YYYY-MM-DD}}

## 📌 今日待办汇总
```tasks
not done
due today
limit 100
sort by priority
sort by description
```
```
