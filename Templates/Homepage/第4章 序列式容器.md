4. Buffer_size
```cpp
inline size_t __deque_buf_size(size_t n, size_t sz)
{
  // 三目运算符的逻辑拆解：
  // 第一层：判断用户是否自定义了缓冲区大小（n 是模板参数 BufSiz）
  return n != 0 ? 
         n :  // 情况1：n≠0 → 用用户指定的大小
         (sz < 512 ? size_t(512 / sz) : size_t(1)); // 情况2：n=0 → 用默认规则
}
```
参数说明：
- `n`：对应 deque 迭代器模板参数 `BufSiz`，是用户自定义的缓冲区元素个数；
- `sz`：对应 `sizeof(T)`，即 deque 存储的单个元素的字节大小。
