- [00:04:03](https://www.bilibili.com/video/BV16W42197Ge/?t=243.31456#t=04:03.31) ws  开头的 url 请求会有一个升级字段{"upgarde", "websocket"}，
浏览器 / 客户端发起 `ws://xxx` 时，先发一条**普通 HTTP GET 请求**用来升级：
``` http
GET /ws HTTP/1.1
Host: xxx.com
Connection: Upgrade
Upgrade: websocket
Sec-WebSocket-Key: xxxxxxxx
Sec-WebSocket-Version: 13
```
服务端返回 101 状态码，完成协议切换：
``` http
HTTP/1.1 101 Switching Protocols
Connection: Upgrade
Upgrade: websocket
```
之后**TCP 通道就从 HTTP 切换为 WebSocket 二进制 / 文本帧协议**，不再走 HTTP。
