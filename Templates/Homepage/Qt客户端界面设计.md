# 2 过程
## 2.1 远程登录 mysql
### 2.1.1 2002
修改`sudo vim /etc/mysql/mysql.conf.d/`
找到这一行：
```
bind-address = 127.0.0.1
```
改成
```
bind-address = 0.0.0.0
```
然后重启 MySQL：
运行
```
sudo systemctl restart mysql
```

### 2.1.2 1130
```sql
-- 1. 创建用户，允许任何IP连接
CREATE USER 'root'@'%' IDENTIFIED BY '你的密码';

-- 2. 赋予所有权限
GRANT ALL ON *.* TO 'root'@'%';

-- 3. 刷新权限
FLUSH PRIVILEGES;

-- 4. 退出
exit;
```
