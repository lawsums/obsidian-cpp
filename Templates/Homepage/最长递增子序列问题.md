[1671. 得到山形数组的最少删除次数 - 力扣（LeetCode）](https://leetcode.cn/problems/minimum-number-of-removals-to-make-mountain-array/submissions/715292168/)

经典暴力做法
``` python
class Solution:
     def minimumMountainRemovals(self, nums: List[int]) -> int:
         n = len(nums)
         if n < 3:
             return 0
       
         # 1. 求 LIS：left[i] = 以 i 结尾的最长递增子序列长度
         left = [1] * n
         for i in range(n):
             for j in range(i):
                 if nums[i] > nums[j]:
                     left[i] = max(left[i], left[j] + 1)
       
         # 2. 求 LDS：right[i] = 以 i 开头的最长递减子序列长度（反向递增）
         right = [1] * n
         for i in range(n-1, -1, -1):
             for j in range(i+1, n):
                 if nums[i] > nums[j]:
                     right[i] = max(right[i], right[j] + 1)
       
         # 3. 找最大山形长度（必须左右都>1，否则不是山）
         max_mountain = 0
         for i in range(n):
             if left[i] > 1 and right[i] > 1:
                 max_mountain = max(max_mountain, left[i] + right[i] - 1)
       
         # 最少删除数
         return n - max_mountain
```
