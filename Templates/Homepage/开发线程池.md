# 1 🧾 案例：校园二手交易小程序（极简版互联网产品）
业务超级简单：
- 学生**发布二手商品**
- 其他学生**浏览、搜索、下单、留言**
- 后台管理商品、用户、订单

足够你完成：
**业务需求分析 + 中间件架构图 + 存储说明 + 服务器位置**
而且完全不复杂，老师一看就懂。

---

# 2 业务需求（几句话写完）
1. 用户模块：注册、登录、个人中心
2. 商品模块：发布、上传图片、详情展示
3. 交易模块：下单、取消、标记已卖出
4. 互动模块：留言、收藏
5. 高并发点：热门商品浏览、高峰期集中访问

---

# 3 用哪些中间件？（极简但标准）
## 3.1 ① 数据库
- **MySQL**：存用户、商品、订单、留言
  结构化、强一致性，必须用它。
- **Redis**：缓存热门商品、用户登录态、简单排行榜
  扛高并发、减轻 MySQL 压力。

## 3.2 ② 其他必备中间件（不多，刚好够作业）
- **OSS 对象存储**：存商品图片（小程序必用）
- **Nginx**：反向代理、负载均衡
- **MinIO / 本地存储**（可选，代替OSS更简单）
- **JWT**：做登录鉴权（不算中间件但可以写）

## 3.3 不需要的东西（为了简单全部去掉）
- 不用 MongoDB
- 不用 Kafka/RocketMQ
- 不用 Elasticsearch
- 不用分布式事务
- 不用分库分表

这样架构**干净、清晰、不翻车**。

---

# 4 架构图（文字版，你直接画方框就行）
```
用户手机 → 小程序前端
       ↓
Nginx（反向代理+负载均衡）
       ↓
后端服务（Java/Node/PHP 都行）
   ↙        ↓        ↘
Redis    MySQL     OSS图片存储
```

三层就够：
1. 接入层：Nginx
2. 应用层：后端服务
3. 数据层：MySQL + Redis + OSS

完美符合作业要求：**业务 + 中间件架构图**。

---

# 5 存储分别存什么（对应你之前的疑问）
- **MySQL**
  - 用户信息（学号、姓名、密码）
  - 商品信息（标题、价格、描述、状态）
  - 订单、留言、收藏记录

- **Redis**
  - 热门商品缓存
  - 用户登录 token
  - 防止重复提交、简单限流

- **OSS**
  - 商品封面图、详情图

**不用 MongoDB，简单项目完全不需要。**

---

# 6 服务器放在哪里？（最简单标准答案）
- 服务器：**阿里云 / 腾讯云 ECS 服务器**
- 位置：**上海 / 杭州 / 广州 节点**（就近用户，访问快）
- 图片存储：阿里云 OSS 或腾讯云 COS
- 说明：小型互联网产品一般都**放在云厂商机房，不需要自建机房**

作业这样写非常标准、不浮夸、不复杂。

---

# 7 你作业可以直接抄的总结句
本二手交易小程序业务清晰，采用前后端分离架构，
使用 **Nginx** 作为流量入口，**MySQL** 存储核心业务数据，
**Redis** 提升并发访问性能，**OSS** 存储商品图片，
服务器部署在阿里云上海节点，满足校园用户低延迟访问需求。

> 为线程池实现增加线程？ 为线程池减少线程？
```c
// 获取新的thread
nWorker *New(nThreadPool *pool) {
    if (!pool) return NULL;

    pthread_mutex_lock(&pool->workers_mtx);

    nWorker* new_worker = malloc(sizeof(nWorker));
    // 如果申请内存失败要提前退出
    if (!new_worker) {
        pthread_mutex_unlock(&pool->workers_mtx);
        return NULL;
    }

    // TODO 线程ID 必须后面 pthread_create 赋值，不能自己写
    new_worker->terminate = 0;
    new_worker->next = NULL;
    new_worker->prev = NULL;
    pool->max_thread_id++;

    // 向头部填加线程
    LL_ADD(new_worker, pool->workers);

    pthread_mutex_unlock(&pool->workers_mtx);

    return new_worker;
}

void Delete(nThreadPool *pool, nWorker *worker) {
    pthread_mutex_lock(&pool->workers_mtx);

    // 删除首个线程
    LL_REMOVE(worker, pool->workers);
    // 清除内存
    free(worker);

    pthread_mutex_unlock(&pool->workers_mtx);
}
```
