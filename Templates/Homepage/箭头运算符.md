
## 0.1 一、箭头运算符的基础概念
### 0.1.1 核心定义
箭头运算符 `->` 是 C++ 中用于**访问对象成员**的操作符，分为**内置用法**和**重载用法**，是指针/智能对象访问成员的核心语法。

### 0.1.2 基础语法规则
对于表达式 `point->member`：
- `point` 只能是两种类型：**类对象指针** 或 **重载了 `operator->()` 的类对象**
- `member` 是类的成员（成员变量/成员函数）

---

## 0.2 二、箭头运算符的两种作用规则
### 0.2.1 规则（a）：类对象指针 -> 成员（内置用法）
这是箭头运算符的**原生、默认用法**。
- 适用场景：`point` 是**指向类对象的指针**
- 等价转换：`point->member` ⇨ `(*point).member`
- 执行逻辑：先对指针**解引用**得到对象，再通过 `.` 访问对象成员
- 约束：指针指向的类必须包含 `member` 成员，否则编译报错

**示例**：
```cpp
class Test {
public:
    int num;
    void func() {}
};
Test* p = new Test;
p->num;    // 等价于 (*p).num
p->func(); // 等价于 (*p).func()
```

### 0.2.2 规则（b）：类对象 -> 成员（重载用法）
这是 C++ 为**类对象**自定义的箭头行为，必须手动重载 `operator->()`。
- 适用场景：`point` 是**重载了 `operator->()` 的类对象**
- 等价转换：`point->member` ⇨ `point.operator->() -> member`
- 执行逻辑：**递归调用**，直到返回指针，切换为规则（a）

---

## 0.3 三、箭头运算符重载的核心约束
重载 `operator->()` 有**严格的返回值要求**，不满足则编译失败：
1. 必须返回 **指向类类型的指针**（触发规则a）；
2. 或者返回 **重载了 `operator->()` 的类类型对象/引用**（继续递归规则b）；
3. 禁止返回基本数据类型（int/float等）、无重载`->`的普通对象。

### 0.3.1 递归调用流程
对象调用重载 `->` → 返回值判断：
- 是指针 → 执行内置规则（a），结束流程；
- 是重载了`->`的对象 → 重复规则（b），递归调用；
- 其他类型 → 编译报错。

---

## 0.4 四、完整代码示例（多层递归重载）
定义三个嵌套类 `A`、`B`、`C`，演示**指针内置用法**和**对象递归重载用法**：

```cpp
#include <iostream>
using namespace std;

// 最底层类
class A {
public:
    void action() {
        cout << "Action in class A!" << endl;
    }
};

// B类包含A，重载->返回A指针
class B {
    A a;
public:
    // 重载箭头：返回A类指针（触发内置规则）
    A* operator->() {
        return &a;
    }
    void action() {
        cout << "Action in class B!" << endl;
    }
};

// C类包含B，重载->返回B对象（触发递归）
class C {
    B b;
public:
    // 重载箭头：返回B类对象（继续递归调用B的->）
    B operator->() {
        return b;
    }
    void action() {
        cout << "Action in class C!" << endl;
    }
};

int main() {
    // 1. 指针调用：内置箭头用法
    C* pc = new C;
    pc->action();  // 等价于 (*pc).action()，调用C自身的action

    // 2. 对象调用：重载箭头用法（递归调用）
    C c;
    c->action();   // 递归：C->() → B->() → A指针 → A::action()

    getchar();
    return 0;
}
```

### 0.4.1 输出结果
```
Action in class C!
Action in class A!
```

### 0.4.2 执行过程详解
1. `pc->action()`
   - `pc` 是**C类指针**，使用**内置规则**
   - 解引用指针 → 调用C类自身的`action()`

2. `c->action()`
   - `c` 是**C类对象**，使用**重载规则**
   - 第一步：`c.operator->()` → 返回**B类对象**
   - 第二步：B对象调用`operator->()` → 返回**A类指针**
   - 第三步：指针使用**内置规则** → 调用`A::action()`
   - 完整等价：`c.operator->().operator->()->action()`

---

## 0.5 五、核心总结
1. **指针用`->`**：原生用法，等价于解引用+点操作符；
2. **对象用`->`**：必须重载`operator->()`，支持递归调用；
3. **重载返回值**：只能是「指针」或「重载了`->`的对象」；
4. **终止条件**：递归最终必须返回指针，否则编译报错。

### 0.5.1 总结
1. 指针的`->`是内置用法，直接解引用访问成员；
2. 对象的`->`依赖重载，支持递归调用，最终必须返回指针；
3. 重载箭头的返回值是核心约束，决定了调用流程。
