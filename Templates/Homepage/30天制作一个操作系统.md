### 3.2.1 实现万能 Makefile
```makefile
# 基础配置（保留原书的编译逻辑）
AS = ../z_tools/nask.exe
CC1 = ../z_tools/gcc.exe -m32 -fno-asynchronous-unwind-tables -s -O2 -c -Wall -Werror
GAS2NASK = ../z_tools/gas2nask.exe -a
OBJ2BIM = ../z_tools/obj2bim.exe
MAKEFONT = ../z_tools/makefont.exe
BIN2OBJ = ../z_tools/bin2obj.exe
BIM2HRB = ../z_tools/bim2hrb.exe
RULEFILE = ../z_tools/haribote/haribote.rul
EDIMG = ../z_tools/edimg.exe
IMGTOL = ../z_tools/imgtol.com
COPY = cmd /c copy
DEL = cmd /c del

# 自动检测当前目录下的.img文件（核心修复1：动态获取img文件名）
IMG_FILE := $(wildcard *.img)
ifeq ($(words $(IMG_FILE)),0)
$(error 错误：未找到任何.img文件！请先执行 make img 生成镜像文件)
endif
ifeq ($(words $(IMG_FILE)),1)
TARGET_IMG := $(IMG_FILE)
else
$(warning 警告：检测到多个.img文件，默认使用第一个：$(firstword $(IMG_FILE)))
TARGET_IMG := $(firstword $(IMG_FILE))
endif

# 原书的 img 目标（保留不动）
img:
	../z_tools/make.exe -r haribote.img

# 原书的 haribote.img 目标（保留不动，确保能编译出img）
haribote.img: ipl.bin
	$(EDIMG) imgin:../z_tools/fdimg0at.tek \
		wbinimg src:ipl.bin len:512 from:0 to:0 \
		imgout:haribote.img

# ipl.bin 编译目标（保留不动）
ipl.bin: ipl.nas
	$(AS) ipl.nas ipl.bin ipl.lst

# 修复后的 run 目标（核心修复2：加 cmd /c，用动态文件名）
run: img
	$(COPY) $(TARGET_IMG) ..\z_tools\qemu\fdimage0.bin
	../z_tools/make.exe -C ../z_tools/qemu

# 修复后的 clean 目标（之前的 del 问题也一并修复）
clean:
	$(DEL) ipl.bin
	$(DEL) ipl.lst

# 彻底清理目标（可选，清理img文件）
src_only: clean
	$(DEL) haribote.img

```

### 3.2.4 TODO 为什么用循环读取而不是 BIOS 自带的指令
因为早期 FD (软盘) 不支持跨磁道读取, 所以如果是循环的话可以自己处理进位, 但是调用系统 BIOS 是一个黑盒, 有的时候读取错误了自己也不知道
1. **兼容性考虑**：不同主板的 BIOS 对 “一次性读多个扇区” 的支持不一致，部分老旧 BIOS 即使是同磁道，一次性读超过几个扇区也可能失败；
2. **鲁棒性**：循环读 + 重试机制（失败 5 次才报错），比一次性读更稳定，能应对软盘读取的偶发错误；
3. **扩展性**：如果后续要读取跨磁道的扇区（比如磁道 0 的 18 个扇区 + 磁道 1 的扇区 1），循环逻辑无需大改，而一次性读会直接失败。

### 3.2.5 保存 BIOS_INFO
为了后续转到 C 语言开发, 方便我们使用 32 位系统, 之后我们就不使用 BIOS 了, 因为 BIOS 是 16 位程序, 所以我们需要提前使用 BIOS 指令保存一些必要的内容
- CYLS 设定驱动区地址
- VMODE 设定颜色的位数
- SCANX 分辨率 X
- SCANY 分辨率 Y
- VRAM 图像缓冲区地址

### 3.4.3 显示鼠标
```cpp
void init_mouse_cursor8(char *mouse, char bc)
/* 准备鼠标指针（ 16× 16） */
{
	static char cursor[16][16] = {
	"**************..",
	"*OOOOOOOOOOO*...",
	"*OOOOOOOOOO*....",
	"*OOOOOOOOO*.....",
	"*OOOOOOOO*......",
	"*OOOOOOO*.......",
	"*OOOOOOO*.......",
	"*OOOOOOOO*......",
	"*OOOO**OOO*.....",
	"*OOO*..*OOO*....",
	"*OO*....*OOO*...",
	"*O*......*OOO*..",
	"**........*OOO*.",
	"*..........*OOO*",
	"............*OO*",
	".............***"
	};
	
	int x, y;
	for (y = 0; y < 16; y++) {
		for (x = 0; x < 16; x++) {
			if (cursor[y][x] == '*') {
			mouse[y * 16 + x] = COL8_000000;
			}
			if (cursor[y][x] == 'O') {
			mouse[y * 16 + x] = COL8_FFFFFF;
			}
			if (cursor[y][x] == '.') {
			mouse[y * 16 + x] = bc;
			}
		}
	}
	return;
}
```
