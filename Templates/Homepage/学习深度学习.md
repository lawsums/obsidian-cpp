## 3.5 理解损失和梯度

你可以把整个网络想象成一条**流水线**：

```
1输入 x → [层1] → [层2] → [层3] → 输出 ŷ → 损失 L
```

反向传播就是：从损失 LL 开始，**逆着流水线**把"这个参数对最终损失的贡献有多大"这个信息，一层一层往回传。每一层只需要知道自己局部的导数，再乘上后面传回来的梯度，就能算出对自己的参数的梯度。

所以你说的完全正确——**简单单元拼起来 + 链式法则 = 整个网络的梯度都能算出来**。这也是为什么反向传播能在深度学习中如此成功的关键：它把"对几百万个参数求导"这个看似恐怖的事情，变成了每一层做一次简单的局部计算。

## 3.7 线性回归 + 基础优化算法

### 3.7.1 线性回归模型

线性回归是所有监督学习模型中最基础的一个——用一条一次函数的直线来拟合数据。

**例子：房价预测**

选取影响房价的几个因素作为输入 $X$：
- $X_1$：卧室个数
- $X_2$：卫生间个数
- $X_3$：居住面积

将它们合成为向量 $\mathbf{X} = [X_1, X_2, X_3]$。

每个因素对房价的影响权重不同，给每个 $X$ 分配不同权重：
- $X_1$ 的权重为 $w_1$
- $X_2$ 的权重为 $w_2$
- $X_3$ 的权重为 $w_3$

权重同样合成向量 $\mathbf{W} = [w_1, w_2, w_3]$。

**模型公式：**

$$
\hat{y} = \mathbf{W} \cdot \mathbf{X} + b
$$

其中 $\hat{y}$ 是预测的理论成交价，$b$ 是偏置（bias）。理论值和实际值 $y$ 之间总会有误差。

### 3.7.2 损失函数

这个误差称为**损失（loss）**，通过损失函数来量化。一个好的损失函数能准确体现理论值与实际值的差距。

提到"差距"，最直观的就是**距离**。所以一开始我们用的损失函数是：

$$
L(\mathbf{W}, b) = \frac{1}{2}\|\hat{y} - y\|^2
$$

即理论值与实际值差的平方（二范数），非常符合直觉——差距越大，损失越大。**目标就是最小化损失**，从而找到最优的 $\mathbf{W}$ 和 $b$。

### 3.7.3 解析解

损失函数 $L$ 是一个凸函数（可类比二次函数），必定有最低点，在最低点处**导数为零**。

因此，对损失求导，令导数为零，可以直接解出 $\mathbf{W}$，这就是**解析解**——一步到位求出最优参数。

### 3.7.4 梯度下降

现实中很多模型无法直接求解析解，这时就用**梯度下降（Gradient Descent）** 迭代逼近。

**直观类比：盲人下山**

> 一个盲人在下山。他看不见，于是用脚尖 360° 转一圈，感受哪里路面最陡。最陡的方向就是**梯度最大**的方向——往那边走一步。不断重复"转一圈 → 走一步"，最终逼近山底（损失最低点）。

### 3.7.5 学习率

**学习率（learning rate）** 决定每一步迈多大。

| 学习率    | 表现              | 问题                                         |
| ------ | --------------- | ------------------------------------------ |
| **太小** | 每次只挪几厘米，然后重新找方向 | 花费大量时间，计算代价高                               |
| **太大** | 像跳过去而非走过去       | 可能从一个山头跳到另一个山头，造成**震荡**，在两个山头间来回跳，永远到不了最低点 |
|        |                 |                                            |

> 学习率太小太慢，太大震荡，需选取合适的值。

### 3.7.6 为什么梯度下降合理？

目标是让模型走到损失函数的最低点（山底），损失 = 当前位置到最低点的垂直距离。

每一步只能做**局部抉择**时，选择最陡峭方向下降最快。每一步都这样走，整体下降最快——不迷路、不绕弯，最高效地逼近最优解。（这当然也与学习率的选择有关。）

### 3.7.7 批次大小

**批次大小（batch size）** 也是一个重要的超参数，决定了每次用多少样本计算梯度。

### 3.9.1 感知机理论
感知机其实是一个很简单的二分类模型。将权重与 x 的点积加上偏置输入到感知机中，然后感知机进行判断：如果输入值大于 0，则输出 1；否则输出 -1。
所以这个感知机是很适合二元分类问题，比如猫狗问题的。
感知机的 loss 函数策略是比较神奇的。感知机的 loss 函数是这个，相当于是在 0 和负的 y 乘 w 乘 x 的点积之间取一个最大值。

1. w+ = yi×xi
2. b+ = yi
这个可以通过 loss 函数求导得出
### 3.9.2 XOR 问题
![[Pasted image 20260722220637.png]]

#### 3.9.2.1 什么是 XOR (异或)？

- **逻辑规则**：XOR 是一种逻辑运算，规则是“如果两个输入相同，结果为假（0）；如果两个输入不同，结果为真（1）”。
    - 0 和 0 → 0 (相同)
    - 1 和 1 → 0 (相同)
    - 0 和 1 → 1 (不同)
    - 1 和 0 → 1 (不同)
- **图示对应**：图片中的坐标系展示了这四个点。
    - **绿色点 (+1)**：代表结果为真的情况（即输入不同）。
    - **红色点 (-1)**：代表结果为假的情况（即输入相同）。

#### 3.9.2.2 为什么这是一个“问题”？

- **线性不可分**：请看图中的蓝色直线。无论你如何画一条直线，都无法将这两个绿色点和两个红色点完美地分开。
    - 如果你画一条线把左上的绿点分开，右下的绿点就会漏掉。
    - 这就是所谓的**“线性不可分”**。
- **感知机的局限**：图片文字提到“感知机只能产生线性分割面”。这意味着单层感知机就像一把直尺，只能画直线来分类数据。面对 XOR 这种需要“曲线”或者“折线”才能分开的数据，它就彻底失效了。

### 3.9.3 多层感知机理论
多层感知机的原理是：一层感知机无法区分的样本，可以通过多层感知机结合来解决。例如异或问题，一层感知机无法处理，因此使用两层感知机。

1. 第一层感知机相当于横轴的那条线，即 y > 0 和 y < 0 的分界。
2. 第二层感知机相当于竖着的那条线，即 x > 0 和 x < 0 的分界。
所以我们判定：
3. x > 0 且 y > 0，或者 x < 0 且 y < 0，这两个情况值为 1
4. 其余两个情况值为 0
就实现了异或。

## 3.12 卷积层
我们的识别器需要有两个原则，就是需要有一个平移不变性和一个局部性。平移不变性指的是不管这个对象在图片里的哪个位置，我们都应该都能找到它。
第二个是局部性原则，即不需要看全局特征，而是针对识别器，以较小的特征就能找到对象。

![[Pasted image 20260730171230.png]]
这里为什么二维的权重矩阵变成了四维的权重矩阵？原因是原本的全连接层，输入层和输出层都是一维向量；而现在输入和输出都变成了图片。我们知道图片是二维的，所以二维加二维就是四维的权重矩阵。
后续我们又引入了一个新的索引，将绝对坐标的 K, L 重新映射为 I+A 和 j +B。
也就是把绝对索引换成了相对索引，后面的坐标就全部换成了相对索引。相对索引的概念更加清晰，它是以当前单元格为中心，通过四周单元格加上偏移量来看，这样比较容易做卷积。而之前是以零零坐标点为中心来看，那样就不适合做卷积。


![[Pasted image 20260730174634.png]]
关于平移不变性，从卷积核的角度来看，卷积本身不依赖于其他因素，卷积核是保持不变的。其中，i、j 是大矩阵的偏移量，而 a、b 是卷积核内的偏移量。因此，卷积核只依赖于 a、b 这两个因素，可以将其收缩为一个二维矩阵，无需包含 i、j。

这个局部性原理就相对简单了，说白了就是说卷积核的大小是有限制的。我们的 VAB 如果 A 大于 VA 或者 B 大于这个卷积核的边界的话，结果值都是 0。

## 3.13 池化层
最简单的池化层就是最大值池化层，它对池化范围内的所有单元格求最大值。
主要作用是缓解卷积层对于位置的敏感性

池化层有什么作用？池化层和卷积层想要实现的目的有什么区别？
### 3.13.1 池化层的作用
池化层的核心作用是对特征图进行**下采样（降维）**，具体包括：

- **降低计算量和参数量**：通过缩小特征图的空间尺寸（宽和高），减少后续层的计算负担。
- **增大感受野**：让后续卷积层能"看到"更大范围的输入区域。
- **提供一定的平移不变性**：正如你提到的，池化层能缓解卷积层对位置的敏感性。例如最大值池化（Max Pooling）只保留局部区域中最强的激活值，即使特征在空间上发生了小幅偏移，池化后仍能被检测到。
- **防止过拟合**：通过丢弃部分信息，起到一定的正则化效果。
### 3.13.2 池化层 vs 卷积层的目的区别

| 卷积层          | 池化层                             |                          |
| ------------ | ------------------------------- | ------------------------ |
| **核心目的**     | **特征提取**                        | **特征压缩/聚合**              |
| **做什么**      | 通过可学习的卷积核扫描输入，检测局部模式（边缘、纹理、形状等） | 对已有特征图做下采样，保留最重要的信息      |
| **是否有可学习参数** | ✅ 有（卷积核权重和偏置）                   | ❌ 通常没有（操作是固定的，如取最大值或平均值） |
| **输出通道数**    | 可以改变（由卷积核数量决定）                  | 不改变（通道数保持不变）             |
| **空间尺寸**     | 可以通过步幅和填充控制，但主要目的不是缩小           | 主要目的就是缩小空间尺寸             |


> **卷积层负责"发现特征"，池化层负责"提炼和压缩特征"。**

### 3.14.1 🖼️ 左侧路径：传统机器学习方法

这是深度学习爆发之前的主流做法，流程比较繁琐，依赖人工智慧。

1. **原始图片输入**：比如这是一张猫的照片。
2. **人工特征提取**：这是最关键的一步。程序员需要手动告诉计算机什么是“猫”。比如：寻找边缘、检测角点、描述纹理（毛茸茸的）、形状（尖耳朵）等。这需要深厚的数学和图像处理知识（如SIFT, HOG算法）。
3. **SVM (支持向量机)**：提取出来的特征数据（比如一长串数字）会被送给 SVM 这个分类器。SVM 的任务很简单：根据你给的特征，判断它是“猫”还是“狗”。

- **缺点**：如果人设计的特征不够好（比如没考虑到猫在不同光线下的颜色变化），识别率就低。而且不同任务需要设计不同的特征，工作量巨大。

### 3.14.2 🚀 右侧路径：深度学习方法

这是现在的主流（也就是大家常说的 AI / 深度学习）。

1. **原始图片输入**：同样是一张猫的照片。
2. **通过 CNN 学习特征**：
    - **CNN (卷积神经网络)** 代替了人类工程师。
    - 你不需要告诉机器什么是猫，而是直接把图片和答案（这是猫）喂给 CNN。
    - 网络会自动通过层层计算，自己摸索出什么样的特征代表猫（底层学边缘，高层学眼睛、鼻子）。这叫**端到端的学习**。
3. **Softmax 回归**：CNN 提取出高级特征后，最后通常接一个 Softmax 层。它的作用是把特征转化为概率。比如输出：90%是猫，5%是狗，5%是兔子。

## 3.15 使用块的网络 VGG

### 3.15.1 为什么“长宽减半，通道翻倍”？

这种设计并非巧合，而是为了在**空间信息**和**语义信息**之间寻找平衡，同时控制计算量。

#### 3.15.1.1 感受野的扩大与特征的抽象

- **长宽减半（下采样）**：通过池化层（MaxPool2d），图像的物理尺寸变小。这意味着后续卷积核的每一个像素点，实际上覆盖了原始图像更大的区域（即**感受野变大**）。随着网络加深，我们不再关注具体的边缘或纹理细节，而是开始关注更高级的语义特征（比如“这是猫的眼睛”、“这是车轮”）。
- **通道翻倍（增加宽度）**：当空间分辨率降低时，单张特征图包含的信息量变少了。为了弥补这一损失并提取更多样化的特征，我们需要增加特征图的厚度（通道数）。更多的通道意味着网络可以同时学习更多种类的滤波器（Filters），从而捕捉更丰富的语义模式。

#### 3.15.1.2 计算量的平衡

- 如果只减小长宽而不增加通道，网络的表达能力会迅速下降。
- 如果只增加通道而不减小长宽，计算量（FLOPs）和参数量会呈爆炸式增长，导致显存溢出。
- **折中方案**：将长宽减半（面积变为原来的 1/4），同时将通道数翻倍。这样既保留了足够的信息容量，又有效地控制了计算复杂度。

### 3.15.2 VGG 的“分块”设计与 AlexNet 的区别

虽然 AlexNet 和 VGG 都是卷积神经网络，但它们在结构设计哲学上有显著不同：

#### 3.15.2.1 模块化 vs. 整体化

- **VGG (分块设计)**：
    - 代码中的 `vgg_block` 体现了**模块化**思想。它将网络看作是由多个相同的“积木”堆叠而成的。
    - 每个 Block 内部结构一致（几个 3×33×3 卷积 + 一个池化）。这种设计使得网络非常规整，易于扩展（比如把 `(2, 512)` 改成 `(3, 512)` 就能变成更深的 VGG-19）。
- **AlexNet (整体设计)**：
    - AlexNet 的结构比较“随意”。它的每一层卷积核大小都不一样（第一层是 11×1111×11 ，第二层是 5×55×5 ，后面是 3×33×3 ），步幅和填充也没有统一规律。
    - 它更像是一个手工精心调制的“特制菜肴”，而 VGG 像是标准化的“预制件组装”。

#### 3.15.2.2 小卷积核的级联效应

- **VGG 的核心创新**：VGG 发现，**堆叠多个小的 3×33×3 卷积核**可以替代大的卷积核（如 5×55×5 或 7×77×7 ），且效果更好。
    - 例如：两个 3×33×3 卷积串联，其感受野等同于一个 5×55×5 卷积，但参数量更少（2×32=182×32=18 vs 52=2552=25 ），且多了一层非线性激活（ReLU），增加了网络的判别力。
- **AlexNet**：主要依赖大卷积核来快速提取特征并大幅减小尺寸。

#### 3.15.2.3 深度带来的优势

- **VGG**：通过简单的重复 Block，VGG 成功将网络加深到了 16 层甚至 19 层。这种深度的增加直接带来了性能的提升，证明了“更深”通常意味着“更强”（前提是能训练得动）。
- **AlexNet**：只有 8 层，相对较浅。

### 3.15.3 总结

VGG 的这种设计让卷积神经网络变得**标准化**和**可预测**。它告诉我们：不需要每一层都去发明新的卷积核大小，只要简单地重复“卷积+池化”并逐渐增加通道数，配合小卷积核，就能构建出强大的深层网络。

## 3.16 批量归一化
![[Pasted image 20260805161639.png]]

我们计算小批量的均值与方差，然后利用该小批量的均值和方差对数据进行归一化，得到归一化后的 x。接着，为归一化后的 x 定义一个缩放系数 γ 和一个偏移量 β。将 x 乘以 γ 再加上 β 后，新的 x 的方差变为 γ²，均值变为 β。这两个新参数即为我们的可学习参数。

·可学习的参数为γ和β
·作用在
	·全连接层和卷积层输出上，激活函数前
	·全连接层和卷积层输入上
·对全连接层，作用在特征维
·对于卷积层，作用在通道维

这两个学习参数的学习标准并不是单独有一个 loss 函数，而是以全局的 loss 函数作为它自己的 loss，所以它是以全局为基准在进行学习。因此，它是在学习一个合适的偏移以及缩放系数。目前对于它的原理并没有一个特别完善的解释，但这个方法确实好用。


## 3.17 残差网络 ResNet
- 残差原理：“输入作为输出的一部分（跳跃连接）”保证了**恒等映射的可能性**，让深层网络训练时不会因“学不到东西”而变差，这是ResNet能堆叠极深的关键。
- 残差块使得很深的网络更加容易训练
- 甚至可以训练一千层的网络
- 残差网络对随后的深层神经网络设计产生了深远影响，无论是卷积类网络还是全连接类网络。

## 3.18 ResNet 为什么能训练出 1000 层的模型
因为在这个训练的时候，正常来说我们之前的这个训练，它的梯度是会通过链式法则逐层相乘的。

一开始的梯度是 y 对 w 进行求导，然后后续的话，下一层就是对于第一层的输出。第一层的输出相当于第二层的输入，所以就相当于第二层的梯度，我们要先对第一层求导，再对第一层的输出求导，然后再对第二层的输入求导，然后再对第一层的输入求导，就变成了一个乘法的链式法则。

但是我们知道，它的梯度实际上就是跟正确答案的偏差。所以如果偏差较小的话，这样逐层地去进行链式法则相乘，它后续的层数的梯度会非常小，那么它的训练也就非常慢了。这个就是常规的神经网络的一个缺陷。

残差网络之所以能训练出 1000 层的网络，就在于它的输出每次都是把上一层的输入加进来的。所以即使到了几十层、上百层的时候，它的输出也是包含最早层输入的。

对它求导的话，相当于一个类似于级数展开的操作，它永远有第一层的输入。而第一层的输入对它的求导是一个大数，所以无论如何求导结果都不会太小，导致训练速度并不会很慢。

## 3.22 关于 Python/numpy 向量（吴恩达 2.16）

**核心建议：不要用秩为 1 的数组（rank-1 array），要用明确的向量。**

在 numpy 里，`np.random.randn(5)` 得到的是 shape 为 `(5,)` 的数组，它既不是行向量也不是列向量：

``` python
a = np.random.randn(5)   # 别这么写：shape 是 (5,)，秩为 1
a.shape                  # (5,)
a.T.shape                # (5,)  转置无效！
```

这种数组和矩阵做运算时行为不明确，容易埋下难以察觉的 bug（乘出来的结果形状不是你以为的那样）。

所以应该显式地写成行 / 列向量：

``` python
a = np.random.randn(5, 1)   # 列向量，shape (5,1)
b = np.random.randn(1, 5)   # 行向量，shape (1,5)
```

- 用 `(n,1)` 或 `(1,n)` 后，转置才会真正互换形状；
- 可以用断言保护自己：`assert a.shape == (5, 1)`；
- 如果已经拿到了秩为 1 的数组，用 `a = a.reshape((5, 1))` 修正即可。

## 3.23 向量化（Vectorization）（吴恩达 2.11–2.14）

吴恩达课里那段经典的「向量化对比演示」总结。

**一句话：向量化 = 不写 for 循环，改用 NumPy / 框架的批量运算函数，一次处理整个数组。** 代码更短、可读性更好；而且底层是高度优化的 C + SIMD 指令，速度通常快一到两个数量级。在深度学习里它不是「优化技巧」，而是**基本编程习惯**。

### 3.23.1 四种运算：循环写法 vs 向量化写法

同一组数据，用两种方式算四种运算，只差「怎么算」：

| 运算 | 含义 | 数学形式 | 向量化写法 |
| --- | --- | --- | --- |
| 点积 dot product | 对应元素相乘再求和 | $\sum_i x_1[i]\,x_2[i]$ | `np.dot(x1, x2)` |
| 外积 outer product | 每个 $x_1[i]$ 乘以整个 $x_2$ | $outer[i,j] = x_1[i]\,x_2[j]$ | `np.outer(x1, x2)` |
| 逐元素乘 elementwise | 对应位置相乘，结果仍是向量 | $mul[i] = x_1[i]\,x_2[i]$ | `np.multiply(x1, x2)` |
| 矩阵×向量 general dot | $W$ 每行与 $x_1$ 做点积 | $gdot[i] = \sum_j W[i,j]\,x_1[j]$ | `np.dot(W, x1)` |

### 3.23.2 两种写法的差别

非向量化（Python `for` 循环）：

``` python
dot = 0
for i in range(len(x1)):
    dot += x1[i] * x2[i]   # 每个元素都要过一遍解释器
```

向量化（一行搞定）：

``` python
dot = np.dot(x1, x2)
```

### 3.23.3 为什么更快

1. **省掉解释器开销**：循环变量、索引、类型检查全都不需要。
2. **底层 C/Fortran 实现**：NumPy 核心用 C 写，本身就快几十倍。
3. **SIMD 并行**：一条指令同时处理多个浮点数（如 AVX 一次算 8 个 float）。
4. **缓存友好**：连续内存访问，命中率高。
5. **可选多线程**：某些 BLAS 实现会自动并行。

实测大致是这个量级：

```
dot = 278   time = 0.05  ms   ← for 循环
dot = 278   time = 0.003 ms   ← np.dot   （快 10~100 倍）
```

维度越大差距越明显——这也是 TensorFlow / PyTorch 里**一切张量运算都向量化**的根本原因。

### 3.23.4 两个小坑

- 演示代码里 `W` 在第一组（经典）定义、第二组（向量化）直接复用，能跑通，但两组输入不完全独立，严格说应各自重新生成。
- 想计时更准：先跑一次热身（避免首次调用的编译/缓存开销），并用 `time.perf_counter()`（墙上时间）而不是 `time.process_time()`。
