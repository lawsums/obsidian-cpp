### 0.1.2 项目开发计划（三阶段）

```
阶段一（Agent 框架）          阶段二（语音层）           阶段三（STM32 执行层）
━━━━━━━━━━━━━━━━━━        ━━━━━━━━━━━━━━━━━━       ━━━━━━━━━━━━━━━━━━
ESP32 + Telegram/微信        ESP32 + 麦克风 + 喇叭      ESP32 + STM32 + 继电器
    ↓                           ↓                          ↓
 文字对话                      语音对话                    语音控制物理设备
 Agent 推理                    Agent 推理                  Agent 推理
 调用内置工具                   调用内置工具                 调用自定义工具
（搜索、时间）                  （搜索、时间）               （control_relay）
```

#### 0.1.2.1 阶段一：跑通 Agent 框架（预计 3-5 天）

**目标**：ESP32 上跑通 ESP-Claw，通过微信/Telegram 和 Agent 文字对话

**步骤**：

1. **环境搭建**：安装 ESP-IDF v5.5.4，克隆 ESP-Claw 仓库
2. **在线烧录体验**（可选）：先用浏览器在线烧录工具体验，零门槛跑通
3. **本地编译烧录**：配置 Wi-Fi、LLM API Key（通义千问）、IM 渠道（微信/Telegram）、搜索引擎（Tavily）
4. **验证对话**：在微信/Telegram 里和 Agent 对话，测试内置工具（搜索、时间查询）
5. **写一个自定义工具**：比如 `control_led(pin, state)`，在聊天里说"开灯"，板子上的 LED 亮了

**阶段一交付物**：能通过微信文字指令控制 ESP32 板载 LED

---

#### 0.1.2.2 阶段二：加上语音交互层（预计 5-7 天）

**目标**：把 Telegram/微信换成语音，实现"说一句话 → Agent 处理 → 语音回复"

**步骤**：

1. **I2S 麦克风采集**：用 ESP-ADF 或 ESP-SR 框架，实现按键触发录音（按住说话）
2. **ASR 云端识别**：录音数据通过 HTTP POST 发送到阿里云/百度语音识别 API，返回文字
3. **文字喂给 Agent**：把 ASR 返回的文字作为输入，喂给阶段一已经跑通的 Agent 引擎
4. **TTS 云端合成**：Agent 回复的文字发送到语音合成 API，返回音频数据
5. **I2S 播放音频**：通过 MAX98357 / ES8311 驱动扬声器播放

**阶段二交付物**：按下按键说"帮我查一下今天天气" → 喇叭播报天气

---

#### 0.1.2.3 阶段三：接入 STM32 执行层（预计 5-7 天）

**目标**：Agent 的自定义工具通过 UART 控制 STM32，STM32 驱动继电器/电机

**步骤**：

1. **设计通信协议**：自定义 UART 帧格式（帧头 + 命令字 + 数据 + 校验），比如 `0xAA 0x01 0x01 0x55`（开继电器）
2. **ESP32 端**：在 Agent 框架里注册 `control_relay(device_id, state)` 工具，工具内部通过 UART 发送指令帧
3. **STM32 端**：UART 中断接收 → 帧解析 → 根据命令字控制 GPIO（继电器开/关、LED 亮/灭）
4. **联调验证**：对着麦克风说"打开客厅灯" → Agent 理解意图 → 调用 `control_relay(1, ON)` → UART 下发 → STM32 继电器吸合 → 灯亮了

**阶段三交付物**：完整的"语音 → AI 推理 → 物理执行"闭环

### 0.1.3 最终简历描述

> **基于 STM32 + ESP32-S3 异构架构的边缘 AI Agent 智能管家**
> 
> - **架构设计**：采用"大脑 + 四肢"异构设计。ESP32-S3（双核 LX7 @ 240MHz）运行轻量化 Agent Runtime，负责语音交互与 AI 推理决策；STM32F103（Cortex-M3 @ 72MHz）基于 FreeRTOS 负责底层硬件的实时控制与状态上报。
> - **AI Agent**：基于乐鑫 ESP-Claw 框架，实现 ReAct 推理循环 + Tool Calling 机制。用户通过自然语言表达意图，大模型自主决策并调用工具（如 `control_relay`、`web_search`），摒弃传统 If-Then 规则引擎。
> - **语音交互**：I2S 数字麦克风采集 → 云端 ASR 语音识别 → Agent 推理 → 云端 TTS 语音合成 → I2S 功放播放，实现完整的语音对话闭环。
> - **双芯通信**：设计基于 UART 的自定义帧协议（帧头 + 命令字 + 数据 + CRC 校验），实现上下位机之间的高可靠指令下发与状态上报。
