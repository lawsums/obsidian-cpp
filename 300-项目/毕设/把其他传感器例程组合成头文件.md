当然可以！把这些传感器的功能封装成头文件（`.h`）和实现文件（`.cpp`），既能避免代码冗余，又能灵活分配端口（避开已用的GPIO4），还能方便后续集成到Mesh组网代码中。

### 0.1.1 第一步：端口规划（避开冲突）
先明确各传感器的**无冲突引脚分配**（避开GPIO4/DHT22、GPIO6-11/Flash引脚）：

| 传感器   | 类型  | 分配引脚   | 备注       |
| ----- | --- | ------ | -------- |
| DHT22 | 数字  | GPIO4  | 已占用，保留   |
| 烟雾传感器 | ADC | GPIO34 | 替换原GPIO7 |
| 火焰传感器 | 数字  | GPIO15 | 保留（无冲突）  |
| 光敏传感器 | ADC | GPIO35 | 替换原GPIO7 |
| 火焰指示灯 | 数字  | GPIO3  | 保留（无冲突）  |

### 0.1.2 第二步：封装传感器为头文件+实现文件
#### 0.1.2.1 传感器配置头文件（`SensorPins.h`）
用于统一管理所有传感器引脚，方便后续修改：
```cpp
#ifndef SENSOR_PINS_H
#define SENSOR_PINS_H

// 已占用引脚（DHT22）
#define DHT22_PIN 4

// 烟雾传感器（ADC）
#define SMOKE_SENSOR_PIN 34

// 火焰传感器（数字输入）+ 指示灯（数字输出）
#define FLAME_SENSOR_PIN 15
#define FLAME_LED_PIN    3

// 光敏传感器（ADC）
#define LIGHT_SENSOR_PIN 35

#endif // SENSOR_PINS_H
```

#### 0.1.2.2 烟雾传感器封装（`SmokeSensor.h` + `SmokeSensor.cpp`）
**SmokeSensor.h**
```cpp
#ifndef SMOKE_SENSOR_H
#define SMOKE_SENSOR_H

#include <Arduino.h>
#include "SensorPins.h"

class SmokeSensor {
public:
  // 构造函数：初始化引脚
  SmokeSensor();
  
  // 读取烟雾传感器电压值（返回0-3.3V）
  float readVoltage();

private:
  const uint8_t pin = SMOKE_SENSOR_PIN; // 引脚从配置文件读取
};

#endif // SMOKE_SENSOR_H
```

**SmokeSensor.cpp**
```cpp
#include "SmokeSensor.h"

SmokeSensor::SmokeSensor() {
  // ADC引脚默认输入模式，无需额外配置
  analogReadResolution(12); // 设置ADC分辨率12位（0-4095）
}

float SmokeSensor::readVoltage() {
  int adcValue = analogRead(pin);
  // 转换为电压：ADC值 / 最大值 * 供电电压
  return 3.3 * (float)adcValue / 4095;
}
```

#### 0.1.2.3 火焰传感器封装（`FlameSensor.h` + `FlameSensor.cpp`）
**FlameSensor.h**
```cpp
#ifndef FLAME_SENSOR_H
#define FLAME_SENSOR_H

#include <Arduino.h>
#include "SensorPins.h"

class FlameSensor {
public:
  // 构造函数：初始化传感器引脚和LED引脚
  FlameSensor();
  
  // 检测火焰（返回true=检测到火焰，false=无火焰）
  bool detectFlame();
  
  // 控制火焰指示灯（on=true亮，false灭）
  void setLed(bool on);

private:
  const uint8_t sensorPin = FLAME_SENSOR_PIN; // 火焰传感器引脚
  const uint8_t ledPin = FLAME_LED_PIN;       // 指示灯引脚
};

#endif // FLAME_SENSOR_H
```

**FlameSensor.cpp**
```cpp
#include "FlameSensor.h"

FlameSensor::FlameSensor() {
  // 初始化引脚模式
  pinMode(sensorPin, INPUT);
  pinMode(ledPin, OUTPUT);
  // 默认熄灭指示灯
  digitalWrite(ledPin, LOW);
}

bool FlameSensor::detectFlame() {
  // 火焰传感器检测到火焰时，输出低电平（根据模块特性调整）
  return digitalRead(sensorPin) == LOW;
}

void FlameSensor::setLed(bool on) {
  digitalWrite(ledPin, on ? HIGH : LOW);
}
```

### 0.1.3 第三步：主程序调用（示例）
将所有传感器集成到一个主程序，测试功能且不冲突：
```cpp
#include <Arduino.h>
#include "SensorPins.h"
#include "SmokeSensor.h"
#include "FlameSensor.h"
#include "LightSensor.h"

// 创建传感器实例
SmokeSensor smokeSensor;
FlameSensor flameSensor;
LightSensor lightSensor;

void setup() {
  Serial.begin(115200);
  while (!Serial); // 等待串口连接
  Serial.println("传感器系统初始化完成！");
}

void loop() {
  // 1. 读取烟雾传感器数据
  float smokeVolt = smokeSensor.readVoltage();
  Serial.print("烟雾传感器电压：");
  Serial.print(smokeVolt);
  Serial.println("V");

  // 2. 读取光敏传感器数据
  float lightVolt = lightSensor.readVoltage();
  Serial.print("光敏传感器电压：");
  Serial.print(lightVolt);
  Serial.println("V");

  // 3. 检测火焰并控制指示灯
  bool hasFlame = flameSensor.detectFlame();
  flameSensor.setLed(hasFlame); // 检测到火焰则亮灯
  Serial.print("火焰检测状态：");
  Serial.println(hasFlame ? "检测到火焰" : "无火焰");

  Serial.println("------------------------");
  delay(500); // 500ms刷新一次
}
```

### 0.1.4 第四步：集成到Mesh组网代码（扩展）
如果要把这些传感器数据通过Mesh发送，只需在原Mesh代码中：
1. 引入上述传感器头文件；
2. 在`readDHT()`任务旁新增读取传感器数据的任务；
3. 在`sendMessage()`中把传感器数据拼接到发送的消息里。

示例片段（修改原Mesh代码的`sendMessage`）：
```cpp
// 新增传感器实例
SmokeSensor smokeSensor;
LightSensor lightSensor;
FlameSensor flameSensor;

void sendMessage() {
  String msg = "ESP32 Node ";
  msg += mesh.getNodeId();
  msg += " | Temp: " + String(temperature, 2) + "C";
  msg += " | Hum: " + String(humidity, 2) + "%RH";
  // 新增传感器数据
  msg += " | Smoke: " + String(smokeSensor.readVoltage(), 2) + "V";
  msg += " | Light: " + String(lightSensor.readVoltage(), 2) + "V";
  msg += " | Flame: " + String(flameSensor.detectFlame() ? "YES" : "NO");

  mesh.sendBroadcast(msg);
  taskSendMessage.setInterval(TASK_SECOND * 1);
}
```

### 0.1.5 总结
1. **核心思路**：通过头文件封装传感器功能，用`SensorPins.h`统一管理引脚，避开GPIO4（DHT22）和GPIO6-11（Flash）；
2. **关键优势**：引脚修改只需改配置文件，无需改传感器逻辑；各传感器独立封装，可按需组合/移除；
3. **扩展建议**：后续新增传感器时，只需按相同格式封装类，在主程序中实例化调用即可，完全兼容原Mesh组网代码。

将以下文件放在Arduino项目文件夹中（同一目录）：
- `SensorPins.h`
- `SmokeSensor.h`、`SmokeSensor.cpp`
- `FlameSensor.h`、`FlameSensor.cpp`
- `LightSensor.h`、`LightSensor.cpp`
- `main.ino`（主程序）

这样编译烧录后，所有传感器可同时工作，无引脚冲突，且代码结构清晰易维护。
