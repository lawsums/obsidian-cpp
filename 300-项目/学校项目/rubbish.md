# 1 FPGA 数字信号处理生产实习报告
## 1.1 一、引言
在 5 G 通信、物联网、人工智能等技术高速发展的背景下，数字信号处理技术成为通信工程领域的核心支撑，而现场可编程门阵列（FPGA）凭借其并行处理能力强、延迟低、可重构性高的技术优势，成为实现高效数字信号处理的关键载体。传统数字信号处理方案依赖专用 DSP 芯片，在灵活性和实时性上难以满足现代通信系统的复杂需求，而 FPGA 可通过硬件编程实现复杂算法的定制化开发，完美适配通信系统对信号处理的多样化要求。本次生产实习以 FPGA 数字信号处理实际项目开发为核心，旨在将课堂所学的理论知识与工程实践相结合，深入掌握 FPGA 开发流程、数字信号处理算法的硬件实现方法，提升工程实践能力和项目协作能力，为后续从事通信工程相关工作奠定坚实的技术基础。

## 1.2 二、实习背景
数字信号处理（DSP）是通信系统设计与实现的核心环节，从基础的信号滤波、调制解调，到复杂的频域分析、多载波通信，DSP 技术贯穿通信系统全流程。随着通信技术向高速率、低延迟、大容量方向演进，对数字信号处理的实时性、灵活性和处理效率提出了更高要求，FPGA 技术的成熟与发展为解决这一问题提供了有效路径。FPGA 以其硬件并行运算的特性，能大幅提升信号处理速度，同时可通过重新编程实现硬件功能的灵活调整，适配不同通信场景的信号处理需求，目前已广泛应用于无线通信、雷达、卫星通信等多个领域。

本次实习在专注于通信技术研发的高科技企业开展，企业拥有成熟的 FPGA 开发团队、先进的 Vivado 开发平台和完善的项目开发流程，具备丰富的 FPGA 数字信号处理项目实践经验。实习期间，我深度参与企业实际 FPGA 开发项目，从基础开发环境搭建、硬件描述语言学习，到数字信号处理模块设计、编码实现与测试优化，全方位接触 FPGA 数字信号处理的工程应用环节，接触行业前沿的开发技术和设计思路，实现从理论知识到工程实践的转化。

## 1.3 三、实习目标与计划
### 1.3.1 （一）实习目标
1. **理论学习目标**：深入理解 FPGA 的基本架构和工作原理，掌握 Verilog HDL 硬件描述语言的核心语法和编程思路；系统学习数字信号处理的基本理论，熟练掌握滤波、调制解调、FFT/IFFT 等常见信号处理算法的原理和适用场景；明晰 FPGA 在数字信号处理中的应用优势和实现逻辑。
2. **实践技能目标**：熟练使用 Vivado、MATLAB 等 FPGA 开发和辅助设计工具，掌握开发环境搭建、项目创建、仿真验证、硬件调试的全流程操作；能够独立完成简单 FPGA 模块的设计、编码和调试，实现基础数字信号处理功能；掌握硬件调试的基本方法，能快速定位并解决代码编写和模块实现中的常见问题。
3. **项目开发目标**：参与企业实际 FPGA 数字信号处理项目开发，完成指定模块的设计与实现；根据项目需求优化模块性能，平衡资源占用与处理效率，确保模块满足项目整体设计指标；积累项目开发的实操经验，学会将理论算法转化为可落地的硬件实现方案。
4. **职业素养目标**：遵守企业的开发规范和工作流程，培养严谨的工程设计思维；学会与项目团队成员沟通协作，参与团队讨论、代码审查，提升团队协作能力；掌握技术文档和实习报告的撰写方法，提升专业沟通和文档整理能力。

## 1.4 四、实习过程与内容
### 1.4.1 （一）第一周：基础学习与环境搭建
第一周的核心任务是完成实习基础储备，通过企业培训和实操练习，了解企业工作规范、掌握 FPGA 开发基础工具和知识，为后续项目开发做好全方位准备，每日学习内容围绕基础展开，层层推进搭建知识框架。
1. **新员工培训与 FPGA 开发流程学习（第一天）**
今天参加公司新员工培训，上午系统学习公司的发展历程、核心价值观、组织架构和各部门职责，理解公司“创新、协作、客户至上”的发展理念，快速融入企业的工作氛围，明确作为实习生的行为规范和工作要求。下午的培训重点围绕企业信息安全政策和 FPGA 开发流程展开，掌握数据保护、系统访问、代码管理等各项安全规范，同时全面了解 FPGA 开发从需求分析、硬件设计、代码编写，到仿真验证、硬件测试、优化交付的全流程，明确各环节的开发规范和质量要求，初步建立起对 FPGA 开发的整体认知，为后续的技术学习划定方向。
2. **FPGA 开发环境搭建（第二天）**
今天的核心任务是搭建 FPGA 开发环境，重点学习 Vivado 开发工具的使用方法。上午由企业培训师详细讲解 Vivado 的功能模块，从项目创建、源文件添加、IP 核配置，到仿真参数设置、硬件平台连接、程序下载的全流程操作进行逐一演示，我认真记录关键操作步骤和注意事项，明确各功能模块的使用场景。下午进行实操练习，尝试搭建简单的 FPGA 测试项目，实操过程中遇到了硬件平台配置不匹配、IP 核添加流程不清晰等问题，通过查阅 Vivado 官方文档、向企业工程师请教，逐步解决问题并成功完成项目搭建，熟练掌握了 Vivado 的基础操作，为后续的代码编写和仿真验证奠定了工具基础。
3. **Verilog HDL 语言基础学习（第三天）**
今天的学习重点是 Verilog HDL 语言基础和数字信号处理的基本概念，这是 FPGA 开发的核心理论基础。上午培训师讲解 Verilog HDL 的核心语法，包括模块定义、端口声明、变量类型、逻辑运算、时序描述等内容，重点强调了硬件描述语言与传统软件编程语言的区别，引导我建立 FPGA 编程的硬件思维。下午进行代码实操练习，尝试编写 4 位加法器模块代码，编写过程中出现了语法错误、时序逻辑设计不合理等问题，通过反复调试代码、查阅语法手册，最终成功实现模块功能并完成仿真验证。同时，我还系统学习了数字信号处理的基本概念，包括信号的采样、量化、编码、滤波等，了解数字信号处理的基本流程和核心环节，搭建起理论知识框架。
4. **FPGA 与数字信号处理算法学习（第四天）**
今天深入学习 FPGA 在数字信号处理中的应用特点及常见的数字信号处理算法，实现技术工具与算法理论的结合。上午培训师介绍 FPGA 的并行处理、低延迟、可重构等技术优势，分析其在通信系统数字信号处理中的核心应用场景，对比 FPGA 与专用 DSP 芯片的性能差异，明确 FPGA 在数字信号处理中的应用价值。下午重点学习 FIR/IIR 滤波器、FFT/IFFT 等常见数字信号处理算法的原理，了解 FIR 滤波器线性相位、资源占用高，IIR 滤波器资源占用低、相位非线性的特点，掌握 FFT 算法通过分治法降低计算复杂度的核心逻辑。同时，我尝试用 Verilog HDL 编写基础 FIR 滤波器模块，完成系数设计和接口开发，仿真过程中发现输出精度偏差问题，排查后确定为系数精度不足，调整参数后成功解决问题，初步实现了算法的硬件落地。
5. **基础知识点复盘与实操练习（第五天）**
今天对第一周的学习内容进行全面复盘和巩固练习，查漏补缺夯实基础。上午梳理本周所学的 FPGA 开发流程、Vivado 操作技巧、Verilog HDL 语法和数字信号处理算法知识点，整理学习笔记，标记重点和难点内容，针对理解不透彻的算法原理和操作步骤，再次向培训师请教，确保知识点掌握到位。下午进行综合实操练习，独立完成 Vivado 开发环境的重新搭建、简单 Verilog 代码的编写与仿真、基础 FIR 滤波器模块的优化，将本周的零散知识点整合应用，检验学习效果，同时总结实操过程中的问题和解决方法，形成个人学习总结，为第二周的项目开发做好充分准备。

### 1.4.2 （二）第二周：项目开发与模块实现
第二周正式进入项目开发阶段，深度参与企业实际的 FPGA 数字信号处理项目，围绕无线通信系统数字信号处理模块的开发需求，依次完成各核心功能模块的设计、编码与基础调试，将第一周的理论知识和工具技能应用到实际项目中，实现从理论到实践的转化。
1. **数字信号处理模块整体设计（第一天）**
今天是我在项目团队中正式参与开发的第一天，上午项目负责人向我介绍了无线通信系统数字信号处理项目的整体目标和需求，该模块需要实现信号的调制、解调和滤波功能，满足指定的采样率、信号带宽和处理延迟要求。负责人还详细讲解了项目的整体架构，明确了我负责的信号发生器、滤波器等模块的设计任务和交付标准。下午，我开始根据项目需求设计模块的整体架构，首先分析了输入信号的特性，包括采样率、量化位数和信号带宽，然后结合第一周所学的知识，选择了合适的调制方式（QPSK）和滤波器类型（FIR 滤波器）。在设计过程中，我参考了之前学习的算法和模块设计方法，尝试将理论知识应用到实际项目中，初步完成了模块的架构规划。
2. **数字滤波器模块开发与实现（第二天）**
今天的主要任务是学习数字滤波器的详细设计方法，完成项目中 FIR 低通滤波器模块的开发与实现。上午培训师结合项目需求，讲解了 FIR 滤波器的具体设计方法，包括基于 MATLAB 的滤波器系数设计、窗函数的选择、系数量化等核心内容，明确了滤波器设计需满足的截止频率、阻带衰减等指标要求。下午，我根据项目的指标要求，使用 MATLAB 的 FDATool 工具设计 FIR 低通滤波器系数，将设计好的系数转换为 Verilog HDL 代码并编写滤波器模块的核心代码。编写过程中，我注重平衡数据精度和资源占用，采用流水线设计技术将乘法和加法操作分阶段进行，提升模块的处理效率。仿真验证时发现输出信号存在误差，排查后确定是滤波器系数量化精度不足导致，调整系数位宽后，滤波器精度达到项目要求，同时我还优化了模块接口设计，确保其能与其他模块协同工作。
3. **ASK/FSK 调制解调模块实现（第三天）**
今天的学习和开发重点是调制与解调技术，完成 ASK、FSK 调制信号的 FPGA 实现。上午，培训师为我讲解了调制与解调的基本原理，重点分析了 ASK、FSK 两种调制方式的信号生成原理和特点，ASK 实现简单但抗干扰能力较弱，FSK 抗干扰能力强但实现流程相对复杂，同时还讲解了两种调制信号的解调思路。下午，我开始编写 Verilog 代码实现 ASK 调制模块，通过控制载波信号的幅度来表示数字信息，编写过程中注重信号同步和时序控制的合理性，完成代码编写后进行仿真验证，成功生成了符合项目要求的 ASK 调制信号。随后我尝试实现 FSK 调制模块，该模块需要生成两个不同频率的载波信号，并根据输入数据选择相应的频率，实操中遇到了频率切换不精确、存在频率抖动的问题，通过查阅资料、向资深工程师请教，优化了频率控制逻辑，增加了信号同步模块，成功解决问题并实现 FSK 调制信号。
4. **FFT/IFFT 频域分析模块开发（第四天）**
今天围绕频域分析功能，完成 FFT/IFFT 模块的开发与集成，这是数字信号处理的重要环节。上午，我系统学习了 FFT 和 IFFT 算法的数学原理和硬件实现思路，掌握了 FFT 蝶形运算的基本结构，理解了 IFFT 通过共轭对称性实现的核心逻辑，明确了频域分析在无线通信系统信号处理中的应用价值。下午，我利用 Vivado 的 IP 核生成器，根据项目需求配置输入信号位宽、FFT 点数、变换基等关键参数，生成 FFT IP 核并将其集成到项目中，编写模块接口代码，完成后进行仿真验证，成功实现了时域信号到频域信号的转换。在此基础上，我对 FFT IP 核进行参数调整，通过对输入信号进行共轭操作，实现了 IFFT 模块的开发，仿真验证结果显示，IFFT 模块能准确将频域信号还原为时域信号，且与 FFT 模块协同工作良好。
5. **信号发生器模块编码与基础调试（第五天）**
今天完成数字信号发生器模块的代码编写，并掌握 FPGA 代码的基本调试技巧，实现模块的基础功能。上午，企业工程师讲解了 FPGA 代码的三种核心调试方法：仿真调试、硬件调试和日志分析，仿真调试用于验证代码逻辑的正确性，硬件调试通过实际开发板验证模块的实际功能，日志分析可排查潜在的运行问题。下午，我根据项目需求，编写数字信号发生器模块代码，实现正弦波信号的生成，模块包含信号生成、频率控制、幅度控制三个子模块。仿真调试过程中，发现生成信号的频率和幅度与预期存在偏差，排查代码后发现是频率控制模块的参数设置错误，调整参数后成功解决该问题。随后将模块下载到 FPGA 开发板进行硬件调试，使用示波器观察信号波形，微调代码参数优化信号质量，成功实现信号发生器模块的基础功能。

### 1.4.3 （三）第三周：模块优化与总结汇报
第三周的核心任务是完成项目模块的优化、整合与测试，同时学习团队协作和版本控制工具的使用，最后对整个实习过程进行总结复盘，完成实习报告撰写和汇报，实现实习的闭环收尾。
1. **信号发生器模块功能完善与测试（第一天）**
今天继续对信号发生器模块进行开发，完成模块的功能完善和全面测试，修复测试过程中发现的问题。上午，我在原有模块的基础上增加了相位控制和调制功能，完善代码逻辑，使模块能够生成更复杂的调制正弦波信号，满足项目对信号源的多样化需求。下午，我对完善后的模块进行全面测试，首先通过 Vivado 进行仿真测试，检查信号的频率、幅度、相位是否符合项目指标要求，测试过程中发现信号的相位控制存在误差，分析代码后确定是相位累加器的精度不足导致，通过提高相位累加器的位宽，成功解决了该问题。随后进行硬件测试，将模块下载到开发板，使用示波器和频谱分析仪观察信号的波形和频谱特性，发现频谱中存在一些杂散信号，排查后确定是时钟信号干扰所致，通过优化时钟信号的分配、增加滤波电路，有效降低了杂散信号的幅度，模块功能达到项目要求。
2. **Git 版本控制学习与代码提交（第二天）**

由于前期的学习以软件编程为主，在 FPGA 编程过程中，容易陷入软件编程的思维定式，对硬件时序逻辑的考虑不够周全，导致代码编写中出现时序错误、信号同步不精准等问题；在模块设计时，往往先考虑功能实现，而对 FPGA 的硬件资源限制、实际硬件运行的特点考虑不足，需要在工程师的指导下多次修改才能达到硬件实现的要求，硬件设计思维的培养仍需加强。
