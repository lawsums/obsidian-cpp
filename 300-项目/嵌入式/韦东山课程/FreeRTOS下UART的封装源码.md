### 2.1.2 简单实现带 this 指针的结构体
接下来我们用到了面向对象的思想，封装了一个结构体当做接口，这个结构体里面有 init、receive 和 send 三个函数。非常简单，但是同时引入了一个新的问题：因为我们在发送的时候，设备一指定的是 UART 1，二指定是 UART 2，三指定是 UART 3。
如果应用层直接调用，就会引入硬件知识储备的成本，得不偿失。因此，我们将要调用的 HURT 123 放在结构体内部，由这几个方法在调用时引入结构体的私有数据。由于这些方法不认识结构体本身，所以需要传入结构体的指针。这就很像 C++ 里面我们的 class 有自己的 this 指针一样，因为如果 class 没有自己的 this 指针，它的方法也是不认识自己的，所以我们就相当于简单的改造出了一个带有 this 指针的结构体。
