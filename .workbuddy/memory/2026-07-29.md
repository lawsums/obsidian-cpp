# 2026-07-29 工作日志

## fetch-game.js → fetch-game-cli.cjs CLI 改造

- 用户要求把 `Templates/fetch-game.js`（ESM 交互式 RAWG 游戏卡片生成器）改造成纯命令行版，类似 ACGbangumi-cli.cjs。
- 产出三个新文件（原始 `fetch-game.js` 未改动）：
  - **`fetch-game-cli.cjs`** — CLI 脚本。子命令 `search` / `add`，参数 `--name/--score/--status/--chinese-name/--playtime/--api-key/--folder/--filename/--out/--dry-run/--json/--proxy`。API Key 从 `--api-key` > `RAWG_API_KEY` 环境变量 > `rawg-config.json` 三级回退。状态支持编号(1-4)、中文标签(已通关🎮)、自定义文本任意一种输入。HTTP 层零依赖（http/https/tls + 代理 CONNECT），自动读取系统代理或 --proxy。
  - **`fetch-game.cmd`** — Windows 批处理包装器，绕过 Agent PowerShell stdout 捕获问题。
  - **`fetch-game-API.md`** — Agent 调用协议文档。
- 验证：search "Elden Ring" → 10 条 JSON 结果 ✓；add "Elden Ring" dry-run → 输出格式与现有笔记一致 ✓；中文搜索 "原神" ✓；状态标签输入 "在玩🕹️" ✓。
- 与 ACGbangumi-cli.cjs 的区别：数据源是 RAWG API（JSON）而非 Bangumi HTML 抓取，因此不需要 linkedom，零外部依赖；输出格式自包含（非模板渲染）；默认输出到 Cpp 工作区的 `Projects/game/`。
